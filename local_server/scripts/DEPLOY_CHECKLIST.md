# SEAGNAL 배포 체크리스트
# 관리자 대시보드 분석 기능 개선 (2026-04-05)

> 이 체크리스트는 관리자 대시보드 개선 사항 배포 시 순서대로 확인해야 할 항목입니다.
> 각 단계를 완료하면 `[x]`로 표시하세요.

---

## 1단계: 서버 재시작 확인

- [ ] 서버 재시작 후 콘솔에 에러 없이 정상 기동 확인
- [ ] `subscriber_stats.json` 파일이 `data/` 폴더에 자동 생성되는지 확인
- [ ] `subscriber_events.json` 파일이 `data/` 폴더에 자동 생성되는지 확인
- [ ] 콘솔에 `[SubscriberSnapshot]` 로그가 출력되는지 확인

## 2단계: 스플래시 화면 테스트

- [ ] 앱 실행 시 "SEA:GNAL" 타이틀 애니메이션이 끝까지 재생되는지 확인
- [ ] 애니메이션 완료 후 자연스럽게 fadeOut 되는지 확인
- [ ] 데이터 로딩이 빠를 때도 애니메이션이 잘리지 않는지 확인
- [ ] 3초 안전 타임아웃: 애니메이션 이벤트가 누락되어도 3초 후 자동 사라짐 확인

## 3단계: 관리센터 탭 버튼 스타일

- [ ] 헤더 15회 클릭으로 관리센터 진입
- [ ] "구독현황" / "방문자통계" 탭 버튼이 세그먼트 컨트롤 스타일로 표시되는지 확인
- [ ] 탭 전환 시 활성 탭에 파란 그라데이션 + 글로우 효과 확인
- [ ] 비활성 탭 hover 시 배경색 변화 확인

## 4단계: 구독현황 탭 기능

- [ ] 구독자 수 카드 (FCM / Web 분리) 정상 표시
- [ ] 비교 카드: 어제 대비, 지난달 대비, 작년 대비 증감 표시
- [ ] 이탈률 카드: 신규 구독 / 해지 / 만료 건수 표시
- [ ] 추이 차트: 일별(기본) 그래프 정상 렌더링
- [ ] 추이 차트: "주별" 버튼 클릭 시 주간 집계 차트로 전환
- [ ] 추이 차트: "월별" 버튼 클릭 시 월간 집계 차트로 전환
- [ ] 변동 내역 테이블: 날짜별 구독자 수 + 변동(증감) 표시
- [ ] 지역 분포 트리: 기존과 동일하게 정상 작동

## 5단계: 방문자통계 탭 - 특보 알림 마커

- [ ] 일별 차트에 특보 발송 시각이 주황색(amber) 세로 점선으로 표시되는지 확인
- [ ] 세로선 상단에 ▼ + 특보명 라벨이 표시되는지 확인
- [ ] 시간대별 차트에도 해당 시간의 마커가 표시되는지 확인
- [ ] 월별 차트에 해당 월의 특보 건수가 마커로 표시되는지 확인
- [ ] 상세 테이블 4번째 열 "특보 이벤트"에 발송 내역이 표시되는지 확인
- [ ] 특보가 없는 날/시간/월에는 마커와 이벤트가 표시되지 않는지 확인

## 6단계: Total 방문자 수 리셋 스크립트 실행

> **주의**: 이 단계는 실서버에서 **한 번만** 실행합니다.

- [ ] 실행 전 `data/visitors.json`과 `data/visitors_stats.json` 내용 확인
- [ ] 스크립트 실행: `cd local_server && node scripts/reset_visitor_total.js`
- [ ] 콘솔 출력에서 삭제 대상 날짜와 보존 날짜 확인
- [ ] `.backup` 파일 2개 생성 확인 (`visitors.json.backup`, `visitors_stats.json.backup`)
- [ ] 인덱스 페이지에서 Total 카운터가 3/19 이후 합계로 표시되는지 확인
- [ ] 관리센터 → 방문자통계에서 3/19 이전 데이터가 없는지 확인

## 7단계: 이벤트 로깅 동작 확인

- [ ] 새 기기에서 알림 구독 → `subscriber_events.json`에 `subscribe` 이벤트 기록 확인
- [ ] 구독 해지 → `unsubscribe` 이벤트 기록 확인
- [ ] 만료 토큰 정리 크론(매일) 실행 후 → `expired` 이벤트 기록 확인
- [ ] 관리센터 → 구독현황 탭에서 이탈률 카드에 수치 반영 확인

## 8단계: 회귀 테스트

- [ ] 인덱스 페이지 방문 시 today/total 카운트 정상 증가
- [ ] 특보 자동 푸시 발송 정상 작동
- [ ] 수동 푸시 발송 정상 작동
- [ ] 조위/기상 데이터 수집 정상 작동
- [ ] 프로모 페이지 정상 로딩
- [ ] 구독/해지 API 응답 정상 (기존 응답 형식 유지)
- [ ] Fly.io 환경에서 볼륨 마운트된 `data/` 폴더 내 새 JSON 파일 접근 가능

## 9단계: 다음 날 확인 (배포 익일)

- [ ] `subscriber_stats.json`에 새 날짜 스냅샷이 추가되었는지 확인
  - 크론 실행 시각: 매일 KST 23:55 (UTC 14:55)
- [ ] 구독현황 탭의 추이 차트에 새 데이터 포인트 반영
- [ ] 비교 카드의 "어제 대비" 수치가 정상 계산되는지 확인

## 롤백 방법

문제 발생 시 git으로 이전 커밋으로 복구:
```bash
git log --oneline -5                    # 최근 커밋 확인
git revert <commit-hash>               # 해당 커밋 되돌리기
```

Total 리셋 스크립트 실행 후 롤백:
```bash
cd local_server/data
cp visitors.json.backup visitors.json
cp visitors_stats.json.backup visitors_stats.json
```
