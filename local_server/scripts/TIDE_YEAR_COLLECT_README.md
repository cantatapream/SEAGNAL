## 정해 둔 기본값 (사용자가 따로 말하지 않은 것 — 묻지 말고 이대로)
1. **결과는 작업 가지에 파일로 보관만 한다.** 앱이 읽게 하는 코드 변경과 main 머지는 하지 않는다
   (사용자 2026-11-23 「결과반영은 본선에 합치는것은 대기해」).
   ★**쓰임새(사용자 2026-11-23)**: *「앱에서 바다타임이라는 상용 어플처럼 지정된 위치에 대해서는 로딩없이 바로 보여주고자 하는게 목적이야.
   임의의 해점 말고, 리스트에 있는 임의항의 경우는 그렇게 하고자함이야.」* → 산출물은 **앱이 한 지점만 골라 바로 읽을 수 있는 꼴**로 만든다:
   지점마다 작은 파일 하나(`client/tide_data/points_2027/p/<id>.json` — 그 지점 365일) + 목록 파일 하나
   (`points_2027/index.json` — id·이름·해역·위도·경도·만든 방식·기준 표준항). 한 덩어리 큰 파일로 만들지 않는다
   (표준항 파일은 17MB 라 통째로 읽으면 느리다). 칸 이름은 표준항 파일과 같게(`highTide1Time`…).
   **화면 작업은 하지 않는다**(사용자 2026-11-23 「화면작업은 내가 온다음에 하자」) — 자료와 목록 파일까지만.
   **지점 이름은 바다타임 지점명 그대로** 쓴다(사용자 「바다타임에 있던 지점명 그대로 사용하자」 — `_points.csv` 의 지역명).
   **물흐름도 함께 계산한다**(사용자 2026-11-24 「물 흐름도 함께 계산토록해줘」) — 지점 파일의 날마다 `range`(조차 cm = 가장 높은 고조 − 가장 낮은 저조)와
   `flow`(물흐름 % = 그날 앞뒤 15일 안의 최소 조차를 0·최대 조차를 100 으로 환산)를 넣는다. 바다타임 「물흐름」이 조차를 %로 바꾼 값임은 화면 숫자로 확인했으나
   **0% 기준은 알아내지 못했다** — 그래서 바다타임 숫자와 같지 않다(제주 15일 견줌: 평균 4.9%p 차). 식은 `build_tide_points_year.js addFlow` 한 곳.
2. **독도·향화도**: API 코드는 `DT_0903`·`DT_0066` 으로 바뀌었다(옛 코드는 오류/자료없음 — 실제 호출 확인). 원본 CSV 에는 새 코드 그대로,
   앱이 읽는 `tide_data_2027.js` 에는 앱 이름표 `DT_0040`「독도」·`SO_0565`「향화도항」으로 적는다(`client/tide.js:1729~` 가 코드로 먼저 찾는다).
3. **검증 기준** (2026-11-23 밤 고침 — 사용자 「사용자 측면에서 2분의 2cm는 크게 의미가 없는 수치일 수도 있고」):
   보고는 네 칸으로 나눈다 — 「±2분·2cm 안 / ±5 안 / ±10 안 / 그 밖」. **±10분·±10cm 안이면 합격**(계산값을 그대로 쓴다).
   그 밖으로 벗어난 날이 하루라도 있는 지점만 「불합격」이고, 불합격이 **50곳 이하**면 그 지점만 실제 TideBED 로 1년치를
   통째로 받는다(1곳 1,825번, 새벽 시간대에). 50곳을 넘으면 계산 방식 자체를 의심해야 하니 통째 수집을 하지 말고
   원인(어느 기준항·어느 해역·어떤 날)을 분석해 기록만 한다.
   (왜 10분·10cm 인가: 같은 표준항도 1년 전 자료와 지금 API 가 동해에서 최대 8분 달랐고, 실제 바다 높이는 날씨로 수십 cm 움직인다.)

## 진행 순서 (위에서부터, 끝난 것은 건너뛴다)
> ★**수집 도구는 도구 실행 창의 「백그라운드 실행」(run_in_background, 제한 2시간=7200000ms)으로 돌린다.**
> `nohup setsid … &` 로 떼어 놓으면 **안 된다** — 세션이 쉬면 컨테이너가 멈췄다가 다음에 새로 떠서 그 프로세스가 죽는다
> (2026-11-24 00:07 에 그렇게 띄운 ①이 00:14 에 죽어 02:40 까지 2시간 반을 날렸다 — 02:41 에 가동 시간 0분으로 확인).
> 백그라운드 실행은 끝나면(또는 2시간에 끊기면) 알림이 와서 세션이 다시 깨어난다 → **그때 결과를 커밋·푸시하고, 남은 것이 있으면
> 곧바로 다시 띄운다**(②는 06:50 KST 전일 때만). 두 도구 모두 받은 데까지 남기므로 끊겨도 이어받는다.

**① 표준항 1년치 받기** — `collect_tide_hghlw.py`
```
TIDE_HGHLW_KEYS="키1,키2,키3" python3 -u local_server/scripts/collect_tide_hghlw.py 2027 9900
```

- 받는 도중의 날짜는 `_part/<코드>.json`(저장소에 안 올라간다 — 컨테이너가 새로 뜨면 그 지점은 처음부터).
- 실행이 끝날 때마다 새 `<코드>.csv`·`_coords.csv`·`_nodata.csv` 를 **경로를 지정해** 커밋·푸시.
- ①이 끝나면 앞뒤 하루(2026-12-31·2028-01-01)도 받는다 — 조시차로 자정을 넘는 고조·저조 때문(166×2=332번):
