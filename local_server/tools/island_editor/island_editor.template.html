그릴 섬

도구

· 그리기: 지도에서 섬 둘레를 차례로 클릭, 마지막 점을 두 번 클릭하면 닫힙니다.
· 점 옮기기: 그린 테두리의 점을 끌어서 옮깁니다. 선 위를 끌면 점이 새로 생깁니다.
· 점 삭제: "점 삭제 모드"를 켜고 점을 클릭합니다.
· 한 섬에 테두리를 여러 개 그릴 수 있습니다(예: 독도 동도·서도).
· 노란 점선은 앱이 지금 가진 해안선입니다(참고용).

해안 관광지

지도의 점을 클릭하면 제외(빨강)로 바뀌고, 다시 클릭하면 되돌아갑니다.
