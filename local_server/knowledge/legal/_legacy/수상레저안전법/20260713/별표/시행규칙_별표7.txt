  야간 운항장비의 세부 기준(제29조제1항 관련)

│                │등은 「해사안전법」 제81조제1항 및 제4항부터 제6        │        │
│                │항까지의 규정에 따른 항행 중인 동력선의 등화로 표       │        │
│                │시할 것                                                 │        │
│                │나. 세일링요트의 항해등은 「해사안전법」 제83조제1      │        │
│                │항부터 제4항까지의 규정에 따른 항행 중인 범선의 등      │        │
│                │화로 표시할 것                                          │        │
│                │다. 무동력수상레저기구의 항해등은 「해사안전법」 제     │        │
│                │83조제5항에 따른 노도선(櫓櫂船)의 등화로 표시할         │        │
│                │것                                                      │        │
│                │라. 수상레저기구의 운항구역이 내수면인 경우에는 1개     │        │
│                │의 백색 전주등만을 설치할 수 있다.                      │        │
├────────┼────────────────────────────┼────┤
│2. 전등         │서치라이트(search Light) 또는 방수형 랜턴일 것          │1       │
├────────┼────────────────────────────┼────┤
│3. 야간 조난신호│로켓낙하산 신호, 신호홍염(전자식 장비를 포함한다) 또는  │1       │
│장비            │불꽃신호기(전자식 장비를 포함한다)일 것                 │        │
├────────┼────────────────────────────┼────┤
│4. 등(燈)이 부착│구명조끼 표시등(life jacket light)이 부착되어 있을 것   │정원의  │
│된 구명조끼     │                                                        │수      │
├────────┼────────────────────────────┼────┤
│5. 통신기기     │초단파 무선설비(VHF), 초고속 해상무선통신(LTE-M)        │1       │
│                │송수신기 또는 휴대전화. 이 경우 휴대전화를 통신기기로   │        │
│                │사용할 때에는 운항하는 동안 통화 또는 문자메시지의 송   │        │
│                │수신이 가능한 상태를 항상 유지해야 한다.                │        │
├────────┼────────────────────────────┼────┤
│6. 구명부환     │해양수산부장관이 정하여 고시하는 기준에 적합한 제품일   │1       │
│                │것. 다만, 수상레저기구의 운항구역이 내수면이거나 무동   │        │
│                │력수상레저기구인 경우에는 레스큐(rescue) 튜브로 구명    │        │
│                │부환을 대체할 수 있다.                                  │        │
├────────┼────────────────────────────┼────┤
│7. 소화기       │수상레저기구(무동력수상레저기구는 제외한다)에 화재사    │1       │
│                │고 발생 시 화재의 확산방지 및 진압에 적합한 휴대식 또   │        │
│                │는 간이식 소화기를 갖출 것                              │        │
├────────┼────────────────────────────┼────┤
│8. 자기점화등   │해양수산부장관이 정하여 고시하는 기준에 적합한 제품일   │1       │
│                │것                                                      │        │
├────────┼────────────────────────────┼────┤
│9. 나침반       │조타 자기컴퍼스 또는 휴대용 자기컴퍼스일 것             │1       │
├────────┼────────────────────────────┼────┤

│                │통신단말장치에서 사용되는 애플리케이션(application)을   │        │
│                │갖출 것. 이 경우 이동통신단말장치를 사용할 때에는 운항  │        │

│                │다.                                                     │        │
