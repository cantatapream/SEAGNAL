인증심사의 방법(제41조제1항 관련)

■ 해상교통안전법 시행규칙 [별표 14]                                            
                                                                                  
  인증심사의 방법(제41조제1항 관련)                                               
                                                                                  
  1. 인증심사의 방법                                                              
┌──────────┬────────────────────────────┐
│인증심사 종류       │세부 방법                                               │
├──────────┼────────────────────────────┤
│가. 최초인증심사    │1) 내부심사 실적을 포함하여 안전관리체제가 수립되어 3   │
│                    │개월 이상 동안 효과적으로 시행되고 있는 상태(사업장의   │
│                    │경우에는 선박의 종류별로 1척 이상의 선박에 대하여 3개   │
│                    │월 이상의 안전관리체제가 시행되고 있는 객관적인 증거    │
│                    │를 포함한다)를 심사한다.                                │
│                    │2) 사업장에 대한 인증심사를 할 때 안전관리체제와 관련   │
│                    │된 업무를 수행하는 분사무소가 있는 경우에는 제2호에     │
│                    │따른 분사무소의 수 이상을 심사대상에 포함한다.          │
│                    │3) 사업장에 대한 인증심사는 제40조제1호에 따라 제출된   │
│                    │공동 제출서류를 먼저 심사한 후에 실시한다.              │
│                    │4) 선박에 대한 인증심사는 사업장에 대한 최초인증심사가  │
│                    │완료된 후에 실시한다.                                   │
├──────────┼────────────────────────────┤
│나. 갱신인증심사    │1) 안전관리체제의 수립 및 시행 상태를 심사한다.         │
│                    │2) 안전관리체제와 관련된 업무를 수행하는 분사무소에 대  │
│                    │한 갱신인증심사에 관하여는 가목2)를 준용한다.           │
├──────────┼────────────────────────────┤
│다. 중간인증심사    │1) 안전관리체제가 효과적으로 시행되고 있는지를 심사한   │
│                    │다.                                                     │
│                    │2) 안전관리체제와 관련된 업무를 수행하는 분사무소에 대  │
│                    │한 중간인증심사에 관하여는 가목2)를 준용한다.           │
├──────────┼────────────────────────────┤
│라. 임시인증심사    │1) 사업장에 대해서는 다음의 사항을 심사한다.            │
│                    │  가) 별표 11 제1호, 제2호가목부터 라목까지, 아목ㆍ차목 │
│                    │ㆍ카목 및 제3호에 해당하는 사항에 관한 사업장의 안      │
│                    │전관리체제 수립상태 및 그에 대한 시행계획               │
│                    │  나) 별표 11 제1호, 제2호마목부터 사목까지 및 자목에   │
│                    │해당하는 사항에 관한 사업장의 안전관리체제 수립계       │
│                    │획 및 그에 대한 시행계획                                │
│                    │  다) 사업장에 대하여 선박 도입 후 3개월 이내에 내부심  │
│                    │사를 시행할 계획                                        │
│                    │2) 선박에 대해서는 다음의 사항을 심사한다.              │
│                    │  가) 1)가)에 관한 선장 및 선박직원(「선박직원법」에 따 │
│                    │른 선박직원을 말한다)의 숙지 여부                       │
│                    │  나) 항해 전 해상종사원에 대한 필수정보 제공 여부      │
│                    │  다) 선박에 대하여 3개월 이내에 내부심사를 시행할 계   │
│                    │획(별표 11 제2호에 해당하는 선박은 제외한다)            │
│                    │  라) 안전관리체제와 관련된 필요한 정보가 해상종사원들  │
│                    │이 이용하거나 이해할 수 있는 언어로 제공되고 있는       │
│                    │지 여부                                                 │
│                    │3) 새로운 종류의 선박을 추가함에 따른 인증심사는 사업   │
│                    │장에 대한 인증심사를 실시한 후 선박에 대한 인증심사를   │
│                    │실시한다.                                               │
├──────────┼────────────────────────────┤
│마. 수시인증심사    │1) 안전관리체제가 효과적으로 시행되고 있는지를 심사한   │
│                    │다.                                                     │
│                    │2) 안전관리체제와 관련된 업무를 수행하는 분사무소에 대  │
│                    │한 수시인증심사에 관하여는 가목2)를 준용한다.           │
├──────────┴────────────────────────────┤
│비고                                                                          │
│ 1. 임시인증심사에 합격한 자는 해당 합격일부터 사업장에 대해서는 12개월 이내  │
│에, 선박에 대해서는 6개월 이내에 위 표 라목1)가) 및 나)에 따른 안전관리체제   │
│수립ㆍ시행 계획에 따라 각각 안전관리체제를 갖춰야 한다.                       │
│ 2. 임시인증심사에 합격한 자는 3개월 이내에 위 표 라목1)다) 및 2)다)에 따른   │
│내부심사계획에 따라 내부심사를 실시해야 한다.                                 │
│ 3. 인증심사는 사업장의 경우에는 사업장의 소재지에서, 선박의 경우에는 선박의  │
│소재지에서 실시한다.                                                          │
│ 4. 인증심사기관은 인증심사를 받으려는 자가 요청하는 경우에는 휴일에도 인증   │
│심사를 할 수 있다.                                                            │
│ 5. 그 밖에 인증심사업무의 수행에 필요한 세부 사항은 해양수산부장관이 정하여  │
│고시한다.                                                                     │
