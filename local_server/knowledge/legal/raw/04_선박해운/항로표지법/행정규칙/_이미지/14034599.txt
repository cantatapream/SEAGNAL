|---|---|
| z1 | 전도등의 수평선으로부터의 dip m |
| z2 | 후도등의 수평선으로부터의 dip m |
| γ | 수직각(두개 등화의 앙각의 차) radian |
| γm | 양 등화가 적당히 분개하기 위해서 필요한 수직각의 최소치(radian) |
| θ | 수평각(두개 등화의 앙각의 차) radian |
| θ0 | 수평각의 표준편차 |
| θ1 | θ0의 계산에 사용되는 중간치로서 γ의 변수 |
| θ2 | θ0의 계산에 사용되는 중간치로서 γm의 변수 |
| θD | 안전을 확인할 수 있는 수평각 |
| θ1' | θD의 계산에 사용되는 중간치로서 γ의 변수 |
| θ2' | θD의 계산에 사용되는 중간치로서 γm의 변수 |
| θM | 수로측면 한계로서 권고되어 있는 최소수평각 |
| θ1'' | θM의 계산에 사용되는 중간치로서 γ의 함수 |
| θ2'' | θM의 계산에 사용되는 중간치로서 γm의 함수 |
