[산식]
Ie = J / (C + J/Io)

여기서 Ie = 유효광도 (candelas)
J = 섬광 광력의 적분 값 (candela·seconds)
J = ∫(Flash) I(t) dt
Io = 섬광의 최대 광력 (candelas)
C = 시각적 시간의 상수(야간 관측시에는 0.2초, 주간에는 0.1초)

위 식을 달리 표현하면 다음과 같다.
Ie = (Io·τ) / (C+F) + τ (⚠REVIEW, 수식 배치 불확실)

여기서 τ = 전 섬광 시간 (seconds)
F = 슈미트-클라우첸 계수
F = ∫(t1→t2) I(t)dt / [Io(t2-t1)] (⚠REVIEW, 원본에서 분모 아래첨자 판독 불확실)

여기서 t1 = 섬광 시작 시각
t2 = 섬광 정지 시각
그러므로 τ = t2 - t1
