[별표 11]
선원수첩 등 증명서의 번호부여 체계
(제70조 관련)
1. 선원수첩번호부여 
 ○ 구조(10자리) 
┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│A1│A2│Y1│Y2│C1│―│N1│N2│N3│N4│N5│
└─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
  - A1-A2 : 선원수첩 발급청 영문코드(2자리) 
  - Y1-Y2 : 선원수첩 발급년도 
  - C1 : 체크디지트 
  - N1-N5 : 일련번호 
 ○ 부여방식 
  - 신규발급시 : 해당 연도 번호부여 
  - 재발급시 
   ㆍ 멸실 재교부 : 해당 연도 번호부여 
   ㆍ 부활, 무여백, 훼손 재발급 : 이미 발급된 번호부여 
1의2. 선원신분증명서 번호부여
 ○ 구조(12자리) 
┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│A1│A2│A3│- │B1│B2│Y1│Y2│- │N1│N2│N3│N4│N5│
└─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
   - A1-A3 : 국가명 영문(ISO) 코드(3자리)
   - B1-B2 : 선원신분증명서 발급청 영문코드(2자리)
   - Y1-Y2 : 선원신분증명서 발급년도 
   - N1-N5 : 일련번호 
  ○ 부여방식 
   - 신규 발급시 : 해당 연도 번호부여 
   - 재발급시 
    ㆍ 분실 재발급 : 해당 연도 번호부여 
    ㆍ 정정, 훼손 재발급 : 이미 발급된 번호부여 
2. 해기사면허 부여 
 ○ 구조(10자리) 
┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│A1│A2│―│C1│C2│―│Y1│Y2│―│N1│N2│N3│N4│
└─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
  - A1-A2 : 해기면허 발급청 영문코드(2자리) 
  - C1-C2 : 해기면종코드 
  - Y1-Y2 : 해기면허 발급년도 
  - N1-N4 : 일련번호 
 ○ 부여방식 
  - 신규발급시 : 해당 연도 번호부여 
  - 재발급시 
   ㆍ 멸실 : 해당 연도 번호부여 
   ㆍ 훼손 : 이미 발급된 번호부여 
   ㆍ 갱신 : 해당 연도 번호부여 
2의2. 승무자격증 번호부여
 ○ 구조(12자리)
┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│A1│A2│―│C1│C2│―│Y1│Y2│―│N1│N2│N3│N4│―│M1│M2│
└─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
   - A1∼A2 : 발급기관명(별표11의 해기면허 발급청 기재요령과 동일)
   - C1∼C2 : 승무직종 및 승무등급
┌───────────────────────┬──┬──┐
│구          분                                │항해│기관│
├───────────────────────┼──┼──┤
│승  무  직  종                                │D   │E   │
├──┬────────────────────┼──┼──┤
│승무│운항급(Operation)                       │O   │O   │
│등급├────────────────────┼──┼──┤
│    │관리급(Management)                      │M   │M   │
│    ├────────────────────┼──┼──┤
│    │선  장(Master) / 기관장(Chief Engineer) │C   │C   │
└──┴────────────────────┴──┴──┘
     * 운항급 : 2ㆍ3등 항해사ㆍ기관사
     * 관리급 : 1등 항해사ㆍ기관사
   - Y1∼Y2 : 발급연도(05, 06 등으로 표기)
   - N1∼N4 : 일련번호(해기면허 발급청 일련번호 기재, 0001부터)
   - M1∼M2 : 재발급 일련번호
  ○ 부여방식
   - 신규발급시 : 해당 연도 번호부여
   - 멸실훼손시 : 이미 발급된 번호부여
   - 갱신발급시 : 해당 연도 번호부여
   - 기재사항 변경시 : 이미 발급된 번호에 재발급 번호부여
     ※ 신규교부, 멸실훼손, 갱신발급시 재발급 일련번호는 00표기
3. 승무정원증서교부업무 
 ○ 구조(10자리) 
┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│A1│A2│―│Y1│Y2│Y3│Y4│―│N1│N2│N3│N4│
└─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
  - A1-A2 : 증서발급청 영문코드(2자리) 
  - Y1-Y4 : 발급년도(4자리) 
  - N1-N4 : 일련번호(4자리) 
 ○ 부여방식 
  - 신규발급시 : 해당 연도 번호부여 
  - 재발급시 
   ㆍ 변경 : 해당 연도 번호부여 / ㆍ 멸실 : 해당 연도 번호부여 
   ㆍ 훼손 : 이미 발급된 번호부여 / ㆍ 갱신 : 해당 연도 번호부여 
4. 자격증발급업무 
 ○ 구조(9자리) 
┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│C1│C2│―│R │―│N1│N2│N3│N4│N5│N6│
└─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
  - C1-C2 : 발급청 영문코드(2자리) 
  - R : 자격증분류코드(1자리) 
   ㆍ 당직부원(항해 : G, 기관 : E, 운항 : N) 
   ㆍ 구명정조정사 : S 
   ㆍ 고속구조정 조정사 : F 
   ㆍ 위험물 : D 
  - N1-N6 : 일련번호(6자리) 
 ○ 부여방식 
  - 신규발급시 : 해당 연도 번호부여 
  - 재발급시 : 이미 발급된 번호 부여
