[산식]
1. 연속최대회전수의 105퍼센트이하의 회전수 범위에서 비틀림진동응력은 다음 산식에 의한 fc를 초과하지 아니할 것

fc = ((T+160)/18) · Ck · Cd(3-2r²)   (r ≤ 0.9)
fc = 1.38 · ((T+160)/18) · Ck · Cd   (0.9 < r)

Cd = 0.35 + 0.93d^(-0.2)

fc는 r≤1.05의 회전수범위에서의 비틀림진동응력의 허용한도(N/㎟)
r은 사용회전수와 연속최대회전수의 비
T는 축의 재료의 규격최소인장강도(N/㎟). 이 경우 규격최소인장강도가 980N/㎟를 초과하는 중간축 및 추력축과 590N/㎟를 초과하는 프로펠러축 및 선미관축은 각각 980N/㎟ 또는 590N/㎟로 한다. 다만, 규격최소인장강도가 460N/㎟를 초과하는 고력황동제의 프로펠러축은 460N/㎟로 한다.
Ck는 표16에 정하는 축의 종류 및 형상에 관한 계수 (⚠REVIEW)

표16 Ck의 값
| 구분 | 세부 | 값 |
|---|---|---|
| 중간축 | 일체식 플랜지커플링의 경우 | 1.00 |
| 중간축 | 수축끼워맞춤커플링의 경우 | 0.60 |
| 중간축 | 키홈을 설치할 경우 | 0.60 |
| 추력축 | 추력칼라의 양단 | 0.85 |
| 추력축 | 롤러베어링의 축방향 하중을 받는 부분 | 0.85 |
| 프로펠러축 또는 선미관축 |  | 0.55 |
비고 : 이 표에 정하는 것 이외의 것에 대한 Ck의 값은 해양수산부장관이 인정하는 바에 의한다.

Cd는 축의 크기에 관한 계수
d는 축의 지름 (밀리미터)

2. 제1호의 규정에 불구하고 연속최대회전수의 105퍼센트이하의 회전수 범위에서 제1종프로펠러축으로서 승인된 석출경화계스테인리스강을 사용하는 것 및 제2종프로펠러축에 대한 비틀림진동응력의 허용한도는 다음 산식에 의한 fc를 초과하지 아니하여야 한다.

fc = A-B·r²   (r ≤ 0.9)
fc = C        (0.9 < r ≤ 1.05)

fc, r은 제1호의 산식의 각각 fc 또는 r과 같다.
A, B, C는 표17에 정하는 재료의 종류에 대하여 정하는 정수
