│ 사. 흘수계측에 의한 배수량 및 중심계산법(Calculation of Displacement &               │
│Center of Gravity)                                                                    │
│  1) 본선의 선수, 선미 및 중앙부에 표시된 Draft Marks에 의하여 흘수를 계측한다.       │
│   (1) df: Fore Draft at Draft Mark(m)                                                │
│   (2) da: Aft. Draft at Draft Mark(m)                                                │
│   (3) dm: Midship Draft at Draft Mark(m)                                             │
│  2) F.P와 A.P에서의 흘수를 계산하기 위하여 선수?미 흘수를 수정한다.                 │
│   (1) LBP: 수선간장                                                                  │
│   (2) Lf: 선수수선에서 선수 흘수 마크까지 거리(선수수선에서 중앙부 방향: +)          │
│   (3) La: 선미수선에서 선미 흘수 마크까지 거리(선미수선에서 중앙부 방향: +)          │
│   (4) IT: 초기 트림(선미트림: -)                                                     │
│   (5) : 선수 흘수 수정량 = (df - da - IT) ×Lf / (LBP - Lf -La)                      │
│   (6) : 선미 흘수 수정량 = (df - da - IT) ×La / (LBP - Lf -La)                      │
│   (7) dF: 선수 수선에서 흘수 = df +                                                  │
│   (8) dA: 선미 수선에서 흘수 = da -                                                  │
│  3) Draft 0 Point에서 K.L과 평행한 기준선에 대하여 흘수 수정을 한다.                 │
│   (1) dM : 평균흘수 = (dF + dA) / 20                                                 │
│   (2) dFe: 선수 수선에서 흘수(Extreme) = dF + IT/2                                   │
│   (3) dAe: 선미 수선에서 흘수(Extreme) = dA - IT/2                                   │
│   (4) A.T : 겉보기트림 = dF - dA                                                     │
│   (5) T: 트림 = dFe - dAe = A.T - IT                                                 │
│  4) 평균 흘수(dM)에 대한 L.C.F를 배수량 등곡선표에서 구하여 트림에 의한 수           │
│정을 한다.                                                                            │
│   (1) δT: 트림에 의한 흘수 수정량 = L.C.F × T / LBP                                │
│   (2) deq: 상당흘수 = dM + δT                                                       │
│  5) 상당흘수(deq)에 대한 배수량(Disp')을 Hydrostatic Table에서 구한다.               │
│   ※ 흘수의 중간값에 대하여 선형보간법을 사용한다.                                   │
│  6) 해수 비중의 변경에 따른 배수량 수정을 실시한다.                                  │
│   (1) γm: 흘수 계측시 해수의 비중                                                   │
│   (2) Disp: 수정된 배수량 = Disp' × γm / 1.025                                     │
│  7) 종방향 중량중심(L.C.G)의 계산                                                    │
│   (1) 배수량(Disp)에 대한 MTC, LCB를 Hydrostatic Table에서 구한다.                   │
│   (2) BG = 100 × MTC × T / Disp                                                    │
│   (3) L.C.G = LCB + BG                                                               │
│    ※ 선미트림(T: -)일 경우 L.C.G는 LCB보다 선미쪽에 있다.                           │
│    ※ 선수트림(T: +)일 경우 L.C.G는 LCB보다 선수쪽에 있다.                           │
│                                                                                      │
│ 아. Trimmed Hydrostatic Table 사용법                                                 │
│  1) 용어설명                                                                         │
│   (1) T = 실제 선박의 Trim                                                           │
│   (2) TU = Trimmed Hydrostatic Table의 Tr 보다 많은 Trim 값                          │
│   (3) TL = Trimmed Hydrostatic Table의 Tr 보다 적은 Trim 값                          │
│   (4) H = T 상태에서의 Trimmed Hydrostatic Table 값                                  │
│   (5) HU = Tu 상태에서의 Trimmed Hydrostatic Table 값                                │
│   (6) HL = Tl 상태에서의 Trimmed Hydrostatic Table 값                                │
│  2) 선형보간법을 사용하여 HR을 구한다                                                │
│   (1)                                                                                │
│   (2) KN Table도 동일한 방법을 사용한다.                                             │

│ 자. 적하에 따른 흘수 및 트림계산법(Calculation of Draft & Trim due to Loading)       │
│  1) 본선에 적재하고자 하는 화물, 연료유, 청수, Ballast 및 그 외 중량물을 적재        │
│하였을 경우 선박의 전체 중량(Disp.)과 길이방향(LCG) 및 연직방향(KG) 무게              │
│중심을 구한다.                                                                        │
│  2) Hydrostatic Table로부터 다음의 항목을 읽는다.                                    │
│   (1) deq: 배수량(Disp)에 대한 상당흘수                                              │
│   (2) LCB: 상당흘수에 대한 종방향 부심위치                                           │
│   (3) LCF: 상당흘수에 대한 종방향 부면심위치                                         │
│   (4) MTC: 상당흘수에 대한 1cm 트림변화 모멘트                                       │
│  3) 적하상태에 따른 트림(Tr)계산                                                     │
│   (1) T = Disp × BG  / (MTC ×100), 단, BG = LCG - LCB                              │
│  4) 선수 흘수(dF)와 선미 흘수(dA)를 구한다.                                          │
│   (1) dF = deq + (LBP/2 - LCF) × T / LBP                                            │
│   (2) dA = deq - (LBP/2 + LCF) × T / LBP                                            │
│   (3) dM = (dF + dA) / 2                                                             │
│                                                                                      │
│ 차. GoM 계산법(Calculation of Metacentric Height)                                    │
│  1) 본선의 적하상태에 대한 연직방향 무게중심위치(KG)를 계산한다.                     │
│  2) 배수량에 상당하는 횡방향 메타센타높이(Transverse Metacentric Height,TKM)을       │
│구한다.                                                                               │
│  3) 적하상태에서 유동수에 의한 무게중심 상승량(Effect of FreeSurface, GGo)를         │
│구한다.                                                                               │
│   (1) GGo = ∑(IN × S.GN) / Disp                                                    │
│    * IN: 각 Tank에 대한 Free Surface의 Moment of Inertiaa(m4)                        │
│    * S.GN: 각 Tank의 유동수에 대한 비중                                              │
│   (2) GM = TKM - KG                                                                  │
│   (3) KGo = KG + GGo                                                                 │
│   (4) GoM = KMT - KGo                                                                │
