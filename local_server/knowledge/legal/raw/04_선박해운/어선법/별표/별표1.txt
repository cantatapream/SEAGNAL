어선번호의 부여방법(제21조제3항 관련)

■ 어선법 시행규칙 [별표 1의3]                           
                                                                              
  어선번호의 부여방법(제21조제3항 관련)                                       
                                                                              
  1. 어선에 대한 등록번호는 등록연월 4자리수, 일련번호 3자리수, 등록기관별 분류번  
  호 6자리수 및 오류검색번호 1자리수를 차례로 연결하여 다음과 같이 구성한     
  다.                                                                         
                                                                              
  어선번호의 구성체계(14자리)

          └────────────────────────                  
                                                                              
                                                                              
                                                                              
                                                                              
  2. 등록연월은 연도 끝 2자리수와 월 2자리수를 다음과 같이 구성한다.          
    ┌─┬┬─┬─┐                                                          
    │  ││  │  │

        │                      년도: ’94‥’99, ’00, ’01, ’02 ㆍ ㆍ ㆍ   
        └───────────                                              
                                                                              
                                                                              
  3. 일련번호는 어선원부에 기재하는 매월별 순서번호에 의하여 매월마다 새로운   
  순서에 의하되 그 순서번호가 3자리수가 아닌 경우에는 3자리수가 될 때까지     
  앞에 0을 붙인다.                                                            
        ┌┬─┬─┐

  4. 등록기관별 분류번호는 행정업무용 표준코드에 따라 다음과 같이 구성한다.   
  ┌┬─┬┬─┬─┬─┐                                                      
  ││  ││  │  │  │

      │                                                                      
      │                                                                      
      │                        시ㆍ도 분류번호                               
      └────────────                                              
                                                                              
                                                                              
                                                                                  
    5. 오류검색번호는 다음의 산출방식에 따라 산출한다.                            
      가. 등록연월, 등록순서 번호, 등록기관별 분류번호를 차례로 연결한 13자리     
    의 숫자로 만든다.                                                             
        [예시]                                                                    
                                                                                  
      9406    -   005   -   649720                                                
    ─┬───  ─┬──  ─┬───                                              
      │          │        │                                                    
      │          │        │                                                    
      │          │        │      등록기관별 분류번호                           
      │          │        └───                                              
      │          │                                                              
      │          │                                                              
      │          │                                                              
      │          │                                                              
      │          │                등록순서 번호                                 
      │          └────────                                              
      │                                                                          
      │                                                                          
      │                                                                          
      │                                                                          
      │                            등록연월                                      
      └──────────────                                              
                                                                                  
                                                                                  
      나. 각 숫자에 차례로 1과 2를 곱한 값(곱한 값이 10을 넘을 경우 그 곱한       
    값에서 10을 뺀 나머지의 값)을 모두 더하여 합을 구한다.                        
        [예시]                                                                    
                                                                                  
            9406005649720                                                         
                                                                                  
      ×)   1212121212121                                                         
    ──────────────                                                  
            9802005248740                                                         
                                                                                  
      9+8+0+2+0+0+5+2+4+8+7+4+0=49                                                
                                                                                  
      다. 합을 10으로 나누어 몫과 나머지를 구한다.                                
        [예시] 49÷10=4 나머지 9                                                  
      라. 10에서 나머지를 뺀 값을 오류검색번호로 한다. 다만, 10에서 나머지를      
    뺀 값이 10인 때에는 0을 오류검색번호로 한다.                                  
        [예시] 10-9=1 오류검색번호
