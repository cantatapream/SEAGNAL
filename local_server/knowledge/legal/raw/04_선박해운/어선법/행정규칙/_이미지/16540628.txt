[산식]
t = (P · D) / (20f · J + P) + C

t는 관의 두께(밀리미터)
P는 최고사용압력(바)
D는 관의 바깥지름(밀리미터)
f는 제2항에 정하는 재료의 허용응력(N/㎟)
J는 표32에 정하는 이음효율

표 32 J의 값

| 구분 | J |
|---|---|
| 이음매 없는 관 | 1.00 |
| 전기 저항 용접관 | 0.85(비고) |
| 단접관 | 0.85 |

비고: 전기 저항 용접관에 대해서는 비파괴검사로 용접부에 유해한 결함이 없다고 인정하는 경우에 1.0으로 할 수 있다.

C는 표 33 또는 표 34에 정하는 부식예비두께(밀리미터)

표 33 강관의 부식예비두께

| 관의 사용목적 | 부식예비두께(밀리미터) |
|---|---|
| 과열증기 | 0.3 |
| 포화증기 - 일반 | 0.8 |
| 포화증기 - 연료유탱크 내의 증기관 | 1.0 |
| 보일러 급수 - 개방식 급수계통 | 1.5 |
| 보일러 급수 - 밀폐식 급수계통 | 0.5 |
| 보일러 물방출관 계통 | 1.5 |
| 압축공기 | 1.0 |
| 윤활유 및 조작유 | 0.3 |
| 연료유 | 1.0 |
| 1차 냉매 | 0.3 |
| 청수 | 0.8 |
| 해수 | 3.0 |

비고:
1. 유효한 방식조치가 취하여진 관에서 해양수산부장관이 인정하는 경우에는 이 표의 값을 50퍼센트까지 줄일 수 있다.
2. 적절한 내식성 특수합금강을 사용하는 관은 부식예비두께를 0으로 할 수 있다.
