[산식]
J = 2 / (A + B + √((A-B)² + 4C²))

A = (cos²α + 1) / [2(1 - d·cosα/a)]

B = [(1 - d·cosα/a)(sin²α + 1)] / 2

C = (sinα·cosα) / [2(1 - d·cosα/a)]

cosα = 1 / √(1 + (b²/a²))

sinα = 1 / √(1 + (a²/b²))

J는 리가면트효율
d는 관구멍의 지름(밀리미터)
a, b, α는 그림 6에서 정하는 길이 또는 각도

그림 5 관구멍이 경사진 배치의 경우의 리가면트효율
