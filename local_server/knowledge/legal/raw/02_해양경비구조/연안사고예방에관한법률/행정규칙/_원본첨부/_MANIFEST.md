# 해양경찰서 홈페이지 직접수집 원본 첨부파일 (출입통제 관련)

law.go.kr 행정규칙 API는 "고시"만 카탈로그화하고 "공고"류는 등재하지 않는다.
이 폴더는 각 해양경찰서 홈페이지 고시.공고 게시판에서 직접 확보한 원본 PDF/HWP 바이너리를 보관한다
(카파시 4번 "목표 기반 실행" — 성공 기준: 원본 파일 보존 + 텍스트 전사 + 출처 URL 기록).

**중요 발견(2026-07-31 파일럿)**: `mi=2083&bbsId=28` 게시판은 URL에 어느 해양경찰서(예: inchoncgs·donghaecgs·taeancgs)를
넣어도 완전히 동일한 내용을 반환하는 **전국 공용 "고시.공고" 게시판**이다(POST `currPage`로 페이징, 총 6페이지 60건 확인).
즉 22개 서를 개별로 순회할 필요 없이 이 게시판 하나만 훑으면 된다 — 단, **이 게시판은 최근 항목 위주의 제한된
목록**으로 보이며(60건 중 인천 관련 3건만 "출입통제" 매칭), 태안·보령·동해 등 다른 서의 기존 고시는 이미
law.go.kr에는 있지만 이 게시판 창에는 더 이상 보이지 않았다. 따라서 이 게시판은 "law.go.kr에 아직 등재 안 된
최신/공고류"를 잡아내는 보완 소스로 유용하지만, 전 서 전 이력을 이 게시판만으로 확보할 수는 없다.
