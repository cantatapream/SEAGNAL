[법률] 별표8 — 보호장비의 종류별 사용방법(제43조의4제1항 관련)

■ 외국인보호규칙 [별표 8]  
                                                                                      
  보호장비의 종류별 사용방법(제43조의4제1항 관련)                                     
                                                                                      
  1. 수갑                                                                             
    가. 사용방법                                                                      
  ┌────────────┬───────────────────────────┐
  │1) 양손수갑(앞으로 사용)│2) 양손수갑(뒤로 사용)                                │
  │                        │                                                      │
  │                        │                                                      │
  ├────────────┴───────────────────────────┤
  │3) 한손수갑                                                                     │
  │                                                                                │
  │                                                                                │
  └────────────────────────────────────────┘
                                                                                      
    나. 유의사항                                                                      
      1) 양손수갑은 가목1)의 방법으로 사용하되, 가목1)의 방법으로는 사용목적을        
  달성할 수 없다고 인정되는 경우 가목2)의 방법으로 사용한다.                          
      2) 한손수갑은 진료를 받거나 입원 중인 보호외국인에 대해 가목3)의 방법으로       
  사용한다.                                                                           
      3) 수갑은 손목에만 채워야 하며, 주요 동맥이나 정맥을 압박해 피가 통하지         
  않도록 해서는 안 된다.                                                              
      4) 가목2)의 방법으로 양손수갑을 사용하여 그 목적을 달성한 후에는 즉시           
  가목1)의 방법으로 전환하거나 사용을 중지해야 한다.                                  
                                                                                      
  2. 보호대                                                                           
    가. 사용방법                                                                      
  ┌────────────────────────────────────────┐
  │                                                                                │
  │                                                                                │
  │(앞면)                    (뒷면)                                                │
  └────────────────────────────────────────┘
                                                                                      
    나. 유의사항                                                                      
      1) 보호대는 양손수갑만으로는 사용목적을 달성할 수 없다고 인정되는 경우          
  가목의 방법으로 함께 사용한다.                                                      
      2) 보호대는 허리에만 채워야 하며, 호흡에 지장을 주도록 해서는 안 된다.          
      3) 보호대를 사용하여 그 목적을 달성한 후에는 즉시 보호대의 사용 또는            
  보호대 및 양손수갑의 사용을 중지해야 한다.                                          
                                                                                      
                                                                                      
  3. 포승                                                                             
    가. 사용방법                                                                      
  ┌────────────────────────────────────────┐
  │1) 상체용 벨트형포승                                                            │
  │                                                                                │
  │                                                                                │
  │                                                                                │
  │(앞면)                    (뒷면)                                                │
  ├────────────────────────────────────────┤
  │2) 하체용 벨트형포승                                                            │
  │                                                                                │
  │                                                                                │
  │                                                                                │
  │(앞면)                    (뒷면)                                                │
  ├────────────────────────────────────────┤
  │3) 조끼형포승                                                                   │
  │                                                                                │
  │                                                                                │
  │                                                                                │
  │(앞면)                    (뒷면)                                                │
  └────────────────────────────────────────┘
                                                                                      
    나. 유의사항                                                                      
      1) 상체용 벨트형포승은 가목1)의 방법으로 사용한다.                              
      2) 하체용 벨트형포승은 보호대, 상체용 벨트형포승 또는 조끼형포승(이하 “보호    
  대등”이라 한다)만으로는 사용목적을 달성할 수 없다고 인정되는 경우                  
  가목2)의 방법으로 함께 사용한다.                                                    
      3) 조끼형포승은 가목3)의 방법으로 사용한다.                                     
      4) 포승은 주요 동맥이나 정맥을 압박해 피가 통하지 않도록 해서는 안 된다.        
      5) 하체용 벨트형포승을 사용하여 그 목적을 달성한 후에는 즉시 하체용 벨트형      
  포승의 사용 또는 하체용 벨트형포승 및 보호대등의 사용을 중지해야 한다.

    가. 사용방법                                                                      
  ┌────────────────────────────────────────┐
  │                                                                                │
  │                                                                                │
  │(앞면)                    (뒷면)                                                │
  └────────────────────────────────────────┘
                                                                                      
    나. 유의사항: 머리보호장비는 호흡에 지장을 주지 않도록 가목의 방법으로 사용한다.
