수입동물 운송자의 준수사항
┌────────────────────────────────────┐
│                                                                        │
│    1. 동물운송차량은 동물을 운송하기 전·후에 차량 내·외부를 세척하   │
│고 소독하여야 하며, 검역관이 추가적으로 차량의 세차 및 소독실시를       │

│                                                                        │
│    2. 검역관이 운송차량의 세차 및 소독실시를 요구한 경우 따라야 한     │
│다.                                                                     │
│                                                                        │
│    3. 운송 전 기상조건 및 도로상황 등을 고려하여 검역물을 안전하게 운  │
│송하여야 하며, 적재상태 그대로 즉시 검역시행장으로 운송하여야 한        │
│다.                                                                     │
│                                                                        │
│    4. 온도나 기상조건 등에 의해 동물에게 스트레스나 고통이 유발되지    │
│않도록 환기상태를 조절하는 등 적정한 온도 및 습도가 유지될 수 있도록 한 │
│다.                                                                     │
│                                                                        │
│    5. 동물의 부상방지를 위하여 부드러운 출발과 정차를 하여야 하고,     │
│모퉁이 길은 부드럽게 돌아야 하며. 운송 중 부상을 예방할 수 있도록       │
│안전하게 운행하여야 한다.                                               │
│                                                                        │
│    6. 동물의 운송을 통한 전염성 질병의 전파를 방지하기 위하여 다른     │
│동물 운송자 및 운송동물과 접촉 자제와 운송동물의 분변 등이 차량         │
│밖으로 유출되지 않도록 방지조치를 하여야 한다.                          │
│                                                                        │
│    7. 장거리 운송 중 동물에게 필요한 경우, 동물 간 경쟁을 최소화하는   │
│범위 내에서 사료 또는 물을 적절히 급여하고 적정한 간격으로 휴식을       │
│제공하여야 한다.                                                        │
