# 새 지식 후보 영역 (AI가 새로 알게 된 것)

> 대화 중 기존 위키에 없던 새 정보를 AI가 감지 → 후보로 적재 → 주기 검토 → 관리자에게 "추가 필요" 알림.
> (피드백 학습: 모델 재학습 아님. 위키에 추가할 후보를 사람이 승인.)

## 흐름
1. 답변 중 위키에 없던 사실/용어/관행/빈틈 감지.
2. 개인정보 제거 후 **지식 후보**만 여기 적재(사용자 동의 시).
3. 법령 API로 사실 대조(자동) → 관리자 REVIEW.
4. 승인되면 위키 draft로 → canonical 편입. (다음 사용자부터 검색 없이 답)

## 파일
- `queue.jsonl` — 지식 후보(익명)
- `verified.md` — API 대조 결과 + 관리자 승인 대기

## 연계
- `_dashboard/pending_discussions.md`의 "피드백 학습" 항목의 실체.
