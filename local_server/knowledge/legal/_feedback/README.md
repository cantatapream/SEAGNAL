# 답변 피드백 영역 (따봉 / 언더따봉)

> 챗봇 답변마다 👍/👎 버튼. 사용자 만족도 신호를 모아 AI가 재검토 → 관리자 알림.

## 흐름
1. 답변 하단 👍(만족) / 👎(불만족) 버튼.
2. 👎 누르면 "왜 불만족?" 작성 팝업(선택). 안 써도 "전송"만으로 로그 남김.
3. 서버로는 **개인정보 없는 로그**만: {질문, 답변요지, 👎, (선택)사유, 시각}. 대화 원문·프로필 미전송.
4. 이 로그가 여기 쌓임 → **AI 재검토**: 정말 부적절한 답이었는지 판정.
   - 진짜 문제면 → 원인(위키 빈틈/오답/톤) 분류 + 관리자 REVIEW 큐로.
   - 오해였으면 → 사용자에게 "이 답은 이런 근거로 맞습니다" 피드백 제안.

## 파일
- `logs.jsonl` — 👍/👎 원시 로그(익명)
- `triage.md` — AI 재검토 결과 + 관리자 조치 대기
