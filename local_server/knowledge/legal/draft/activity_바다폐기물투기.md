# 바다에 폐기물 버리기 (폐각·폐그물 등)

> ⚠ **draft — 미승인.** "폐각·폐그물"은 법률에 없는 구어. 아래는 **"폐기물"로 유추 연결**한 결과 → 사람 승인(REVIEW) 후 이동.
> 처리 흐름: "조개껍데기를 바다에 버려요" 같은 질문에 법률 용어가 없어도 → **폐각/그물 = 폐기물**로 연상 → 해양환경관리법·폐기물관리법·수산부산물법으로 연결.

## 정의(구어)

어민·해녀가 **조개·전복 껍데기(폐각)나 못 쓰는 그물(폐그물), 쓰레기를 바다·갯벌에 버리는 행위.** "폐각"·"폐그물"은 법에 정의된 말이 아니지만, 대량으로 바다에 버리면 **"폐기물"**로 취급되어 처벌 대상이 된다.

## ★ 정의부터 (적용·처벌을 가르는 핵심)

| 용어 | 법 정의 | 이 사안 판정 |
|---|---|---|
| 폐기물 | "생활이나 사업활동에 필요하지 않게 된 물질"(폐기물관리법 제2조1호) | 먹고 남은 껍데기·못 쓰는 그물 → **폐기물 해당** |
| **생활폐기물** | "사업장폐기물 외의 폐기물"(제2조2호) | **개인이 소량** 버림 → 생활폐기물 |
| **사업장폐기물** | 대기·물환경·소음진동법상 배출시설 사업장 또는 **대통령령으로 정하는 사업장**에서 발생한 폐기물(제2조3호) → 시행령 제2조: **배출량 기준**(1일 평균 300kg 이상, 일련작업 5톤 이상 등) | 조직 유형이 아니라 **배출량**으로 판정 (아래 ★정의 사슬) |
| 어촌계 | 지구별수협 조합원이 조직(수협법 제15조) | **"어촌계=사업장" 아님.** 사업장 여부는 배출량으로 결정 |
| 수산부산물 | 포획·가공 등에서 부수 발생한 뼈·껍질 등(수산부산물법 제2조2호) | 패각 = 수산부산물(재활용 대상) |

> **같은 굴껍데기라도**: 개인 소량=생활폐기물(과태료 100만원) / 대량(사업장 기준 충족)=사업장폐기물(7년·7천만원). **정의가 처벌을 70배 이상 가른다.**

### ★ 정의 사슬 (다른 법·페이지로 전파 — multi-hop)

"어촌계가 사업장이냐"를 답하려면 한 법에서 안 끝나고 사슬을 타야 한다:
```
바다폐기물투기 → [사업장폐기물?] → 폐기물관리법 제2조3호(대통령령 사업장)
   → [사업장이란?] → 폐기물관리법 시행령 제2조(★배출량 기준: 1일 300kg↑ / 일련작업 5톤↑)
   → [어촌계란?] → 수협법 제15조(지구별수협 조합원 조직) … 조직정의일 뿐, 사업장 판정과 무관
```
**결론: 어촌계라는 '조직'이라서가 아니라, 실제 '배출량'이 시행령 기준을 넘느냐로 사업장폐기물 여부가 갈린다.** 중간에 "어촌계=단체=사업장"으로 멈추면 오답. → [[concept_사업장폐기물]] · [[concept_어촌계]] (편입 예정)

## 유추 연결 (법률 용어 아님 → 법적 개념)

| 사용자가 쓰는 말 | 유추되는 법적 개념 | 근거 |
|---|---|---|
| 폐각·조개/전복 껍데기 | ①해양환경관리법 "폐기물"(제2조4호) ②수산부산물(껍질 등, 수산부산물법 제2조2호) | 대량 투기 시 해양환경 해로운 결과 → 폐기물 |
| 폐그물·쓰레기 | 해양환경관리법·폐기물관리법 "폐기물" | 〃 |

## 적용 가능 법령

| 법령·조문 | 언제 걸리나 | 처벌 | 비고 |
|---|---|---|---|
| **해양환경관리법 제22조** (오염물질 배출금지) | **선박·해양시설에서 바다로** 폐기물 배출 | 제127조 **3년 이하 징역 또는 3천만원 이하 벌금**(과실은 제128조) | 배에서 버리면 이게 핵심 |
| **폐기물관리법 제8조** (투기 금지) — **사업장폐기물** | 어촌계 등 사업장에서 대량 발생 폐기물 무단투기 | 제63조 **7년 이하 징역이나 7천만원 이하 벌금** | "사업장" 요건은 시행령 확인 |
| **폐기물관리법 제8조** (투기 금지) — **생활폐기물** | 개인이 소량(먹고 남은 껍데기 등) 무단투기 | 제68조3항 **100만원 이하 과태료** | 형벌 아님 |
| **수산부산물법** (제2조·재활용) | 패각은 수산부산물 → **재활용·적정처리** 대상, 무단투기 대상 아님 | 처리기준 위반 시 동법 벌칙 | "그냥 버리면 안 되고 처리해야" |

## 예외·구분 (어디서·무엇을 버렸나로 갈림)

| 상황 | 주로 걸리는 법 |
|---|---|
| 조업 중 **선박에서** 바다로 투기 | 해양환경관리법 제22조 (3년/3천만원) |
| **갯벌·연안·육상**에 무단투기 | 폐기물관리법 제8조 (7년/7천만원, 사업장폐기물) |
| 패각을 처리 안 하고 방치·투기 | 수산부산물법 처리기준 + 위 법 |

> ⚠ REVIEW: "폐각=폐기물" 유추와 선박/육상 구분에 따른 적용법 판단은 사서 연결 결과. 실제 사안은 투기 장소·주체·양에 따라 달라지므로 사람 확인.
