## 정의(구어)

밤에 물이 빠진 갯벌·얕은 바다를 걸어 다니며 **맨손 또는 간단한 도구로 조개·낙지·문어 등 해산물을 잡는 활동.** 생계보다는 레저·체험 성격이 많다. 법률에 정의된 용어가 아니며, 실제로는 **"비어업인의 포획·채취"**로 규율된다. *(용어 뜻은 사용자 확인 필요 — 웹 출처 기준)*

## 적용 가능 법령

## 지역별 주의

수산자원관리법 제18조제2항에 따라 **시·도지사가 조례로 포획·채취 기준(허용 어구·수량·구역·시기)을 정한다.** 따라서 같은 해루질이라도 부산·경남·전남·인천 등 **지역마다 허용 범위가 다르다.** → [[comparison_비어업인포획기준_지역별]] (지역별 조례 비교표, 편입 예정)

## 저촉 안 하려면

| 조건/상황 | 해야 할 것 | 출처 |
|---|---|---|
| 해산물 채취 시 | 맨손·허용된 간단한 도구만 사용, 대통령령·조례가 정한 **어구·수량 한도** 준수 | 수산자원관리법 제18조제1·2항 |
| 대상 확인 | **금어기·금지체장** 해당 종(예: 특정 시기 낙지·전복 등) 포획 금지 | 수산자원관리법 제14조 |
| 판매 금지 | 잡은 것은 **자가소비만**, 팔거나 팔 목적 보관·운반 금지 | 수산자원관리법 제18조제4항 |
| 장소 확인 | **마을어장·양식장 등 어업권 구역**인지 확인, 해당 시 채취 금지 | 수산업법 마을어업 규정 |
| 지역 확인 | 조업 지역의 **시·도 조례**에서 허용 어구·수량·구역 확인 | 수산자원관리법 제18조제2항 + 지자체 조례 |
