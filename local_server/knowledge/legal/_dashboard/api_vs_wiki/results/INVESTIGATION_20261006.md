정리: 7건 중 **4건은 결론 문장이 실려 있었는데 물러섬**(그중 1건은 이번엔 결론을 냄), **3건은 결론 문장이 빠져 있었음** —
빠진 3건도 위키에 아예 없는 것은 1건(마이크로폰)뿐이고, 2건은 위키에 있는데 **근거자료로 옮기는 단계(분량 예산·발췌 순서)에서 잘렸다.**
