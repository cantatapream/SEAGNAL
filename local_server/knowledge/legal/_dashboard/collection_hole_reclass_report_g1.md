## 부록 — 이번 라운드 방법론 메모

1. **재검증 → 재수집 → 재확인 루프가 실제로 작동함이 처음 실증됐다.** 직전판(08-16)이 지목한 recollect 4건이 하루 만에 전부 raw에 반영됐고, 그중 국제항해선박 II3는 감사 18R이 **"collection_hole_reclass G1 트랙에서 처리됨(감사 트랙과 별개 경로로 해소)"**이라고 명시적으로 확인했다 — 13라운드 연속 정체됐던 항목이다.
2. **"해소됐다"는 감사 자기신고를 그대로 믿으면 안 된다.** 출입국 별표6은 13R이 "collection_hole 해소"로 보고했으나 14R이 raw 실물 대조로 **근거 없는 인용**임을 밝혀 원상복귀시켰다. 이번 재검증도 raw 파일 grep으로 독립 확인했다. → **해소 판정은 반드시 raw 파일의 실제 존재로 검증**한다.
3. **API 없이 확정할 수 있는 것과 없는 것을 구분했다.** 파일 실재 확인(해소 판정 4건)·raw grep(grounding 실패 1건)·WebSearch 등재 확인(1건)은 API 없이도 확정됐다. 반대로 "위임 문언은 있는데 대응 고시를 못 찾음"에서 (a)미제정/(b)미등재/(c)미수집을 가르는 일은 `lsDelegated` 없이는 불가능해 2건을 `unclear`로 남겼다 — 추측으로 채우지 않았다.
