# 자율루프 에스컬레이션 감시목록 (사용자 확정 2026-07-19)
> 아래 4가지만 사용자에게 별도 알림. 그 외는 AUTO_RUN_LOG.md에 기록만 하고 자율 처리.
1. **부칙 대량누락(DRF 파이프라인 의심)** — 다수 법에 걸친 구조적 부칙 0건 확인 시 = 시스템 결함, 재수집 전략 결정 필요.
2. **raw 파일 오염(자치법규 내용 뒤바뀜)** — 광범위하면 데이터 무결성 = 파이프라인 결정 필요.
3. **상충 공식 수치(처벌·안전값 두 출처 불일치)** — 원문으로 확정 불가 = 사용자/소관부서 확인 필요.
4. **루프 미수렴** — 통합수정+재감사 2~3라운드 돌려도 스코프-내 full률 정체 시 = 방법론 재검토.
