# ⑤보고한 숫자를 다시 검증했다 — 틀린 것 2 · 줄일 것 2 · 말이 부정확했던 것 1 (2026-09-22)

> 사용자 요청: *"네가 분석하여 나에게 보고한 내용이 정확한 분석을 기반으로 된 것인지
> 다시 한번 검토해서 알려줄래?"*
>
> 이 조사 동안 내 자가 **이미 세 번 빗나갔으므로** 타당한 요청이다.
> 보고한 숫자를 **다른 방법으로 다시 세고**, 분류가 들어간 것은 **표본을 열어** 확인했다.

## §1 ★틀린 것 — 2건

### 1-1. "raw 와 `_meta.json` 에 쓰는 도구가 94개" → **과장이었다**

01 문서 §2 에 이렇게 적었다 —
> *"94개 도구가 저마다 자기 방식으로 `_meta.json` 에 키를 적고 raw 에 줄을 적는다."*

**실제로 센 것은 "무엇이든 파일을 쓰는 도구"였다.** 갈라 보니 —

| | |
|---|---|
| `loop/` 도구 | 191개 |
| 무엇이든 **파일을 쓰는** 것 | **94개** ✅(이 말 자체는 맞다) |
| 그중 **`raw/` 경로를 다루는** 것 | **52개** |
| 그중 **`_meta.json` 을 쓰는** 것 | **30개** |

★**"94개가 raw·`_meta.json` 에 쓴다"는 틀렸다.** 나머지 42개는 `_dashboard/` 에 보고서만 쓴다.
⚠52 도 상한이다 — `raw/` 를 **읽기만** 하는 도구가 섞여 있다.

**결론은 바뀌지 않는다** — 단일 기록자가 없다는 사실은 그대로다(30개가 `_meta.json` 을 쓴다).
**숫자만 틀렸다.**

### 1-2. "교훈의 24%가 스스로 재발이라 적었다" → **약 18% 로 낮춰야 한다**

낱말로 세어 **75개(24%)** 라고 보고했다. **표본 10개를 열어 보니 3개가 오탐이었다** —

| | 걸린 대목 | 왜 오탐인가 |
|---|---|---|
| L-248 | *"같은 ID 로 두 번 연속 전혀 다른 행정규칙을 돌려주고"* | **API 가** 두 번 다른 것을 준 것. 내 실수의 반복이 아니다 |
| L-262 | *"같은 질문 두 개를 번갈아 되풀이"* | **챗봇이** 질문을 되풀이한 것 |
| L-265 | *"**두 번째**: 처음엔 팝업이 …"* | 방안을 열거한 "두 번째" |

자를 조여 다시 세니 **69개(23%)**. 그 69개에서 **표본 12개**를 다시 열어 보니
또 2~3개가 오탐이었다(L-62 *"없애면 재발하나?"* 는 가정 · L-236 *"같은 뿌리 질문을 묶기"* 는
질문 묶기 · L-279 *"같은 함정에 걸린 다른 확인이 없는지"* 는 확인 범위).

> ### 정정
> **낱말로 세면 69~75개지만, 표본 검증한 정확도가 75~80% 다.**
> 방어할 수 있는 값은 **약 55개 안팎 · 18% 쯤**이고,
> **정확한 수는 302개를 다 읽어야만 알 수 있다.**
>
> ⚠**"넷 중 하나가 재발"이라고 말한 것은 과했다.** "다섯 중 하나쯤"이 맞다.
> 방향(적지 않은 몫이 스스로 반복이라 적고 있다)은 그대로다.

## §2 줄여야 할 것 — 2건

### 2-1. "항상포함이 못 잡는 변형 225가지·309절·201쪽" → **214가지·287절·199쪽**

11가지(22절·22쪽)는 **코드가 일부러 뺀 것**이었다. `legal_retriever.js` 주석이 밝혀 뒀다 —
*"서식은 `다운로드`가 붙은 표기만 넣는다 — `## 서식 목록`·`## 서식 필드 구성`·
`## 서식(별지) 인덱스`는 전체 서식 이름을 나열한 큰 색인이라 어느 질문에서든 통째로 실으면
예산을 그것만으로 다 쓴다."*

**그 11가지를 빼도 214가지·199쪽이 남는다** — `## 근거`(28) · `## 과태료`(25) ·
`## 위반 시 (처벌 연결)`(12) 등. **결론은 그대로다.**

### 2-2. "마무리 문장 1,560개 중 1,009개(64%)·450쪽" → **1,526개 중 950개(62%)·389쪽**

내가 쓴 정규식이 **"답을 안 한다"는 뜻 없이 `소관부처` 만 언급한 줄**까지 잡고 있었다
(조례 위임 설명, 감사 메모 등 34개). 뜻이 담긴 문장만 남기니 —

| | 보고한 값 | 다시 센 값 |
|---|---|---|
| 문장 | 1,560 | **1,526** |
| 정형 문구 밖 | 1,009 (64%) | **950 (62%)** |
| 쪽 | 450 | **389** |

**쪽수가 61쪽 줄었다.** 비율은 거의 같다 — **결론은 그대로다.**

## §3 말이 부정확했던 것 — 1건

### "위키 절 제목 4,621가지"

세 값이 다 나왔고, **셋 다 맞게 센 값이지만 서로 다른 것을 센다.**

| 세는 법 | 값 |
|---|---|
| `##` 만 (큰 절) | **2,787가지** |
| `##` + `###` + … 전부 | **4,740가지** |
| 위와 같되 **숫자를 N 으로 눌러 합침**(`## 8. 행정처분` → `## N. 행정처분`) | **4,621가지** |

★처음 보고한 **4,621 은 "숫자를 정규화한 뒤의 값"인데 그 말을 안 했다.**
앞으로는 **`##` 기준 2,787** 을 쓴다(작업 대상이 큰 절이므로).

## §5 이 검증에서 배운 것

**틀린 2건과 줄인 2건의 공통점** — 전부 **"무엇을 세는지"를 코드로 못 박기 전에 숫자를 옮겼다.**

- "파일을 쓴다"와 "raw 에 쓴다"를 같은 말로 썼다
- "또"라는 낱말이 있으면 "내가 또 그랬다"로 쳤다
- "소관부처"가 나오면 "답을 안 하는 문장"으로 쳤다
- "절 제목"이 `##`인지 `###`까지인지 밝히지 않았다

★**`_SCHEMA §0-E 규칙 4`("숫자를 보고하기 전에 표본 하나를 눈으로 연다")를
어제 내가 써 놓고 이 조사에서 다섯 번 어겼다.**
(조문머리 2회 · 마무리 문장 2회 · 재발 분류 1회)

**그래서 2단계 규칙집에 이것부터 넣는다** —
> **숫자를 보고하는 모든 자는 ①무엇을 세는지 한 줄로 적고 ②표본 N개를 함께 출력한다.**
> 표본 출력이 없는 자의 숫자는 보고하지 않는다.

이건 문서에 적는 규칙이 아니라 **자(스크립트)가 강제하는 규칙**이어야 한다 —
이 조사의 결론("코드가 읽지 않는 규칙은 죽는다")을 나 자신에게 먼저 적용한다.
