## §3 ★법 하나가 통째로 안 열린다 (C 발견, 내가 재현)

`raw/15_관련타부처/선박에서의오염방지에관한규칙/별표/` — **90개 중 열리는 것 0개**

**원인은 낱말 하나다.**

```js
const BYL_DECL_RE = /■[^\n[〔【]*?(시행규칙|시행령)\s*[[〔【]…/
```
```
■ 선박에서의 오염방지에 관한 규칙 [별표 2]
                        └── "규칙"이다. "시행규칙"이 아니다.
```

이 법은 **`tier: 1`(기준법급)** 이고 꼬리표에 이렇게 적혀 있다 —
```json
"별표_수집현황": { "공식_별표_수": 51, "수집된_별표_파일": 51, "확인일": "2026-09-02" }
```

> **공식 수와 맞춰 51개를 전부 받아 놓고, 한 개도 안 열린다.**
> 그리고 위키는 그 별표 2·3·5·24 를 근거로 짚는다.

같은 꼴: 「국가기술자격법 시행규칙」 **낫표**(21) · 선박톤수측정규칙 "규칙"(6) ·
`■[별지…]` 공백 없음(6) · **`■` 선언줄이 아예 없는 것 122**.
B 가 따로 찾은 것: `[별지 제N호의N서식]` — `ATT_HEAD_RE` 가 `의N` 을 못 넘어간다(**145건**).
