## 2. 왜 이런 일이 생겼나 — 세 겹

```
①규칙은 2026-07-14 부터 있었다 (_SCHEMA.md)
      ↓  그런데 코드가 그것을 읽지 않는다
②코드가 읽지 않는 규칙은 죽는다
      ↓  그래서 게이트(검사기)를 만들었다
③게이트가 재지 않는 자리도 죽는다
      ↓  그런데 그 게이트를 부르는 것이 없다
④★게이트 자신을 부르는 것이 없으면 게이트도 죽는다
```

**저장소가 ②와 ③은 이미 스스로 적어 뒀다** —
`CLAUDE.md:153` *"게이트의 존재와 커버리지는 다른 문제다"* ·
`.githooks/pre-commit` *"사람이 기억해서 돌려야 했다"*.
**④만 아무도 안 적었다.**
