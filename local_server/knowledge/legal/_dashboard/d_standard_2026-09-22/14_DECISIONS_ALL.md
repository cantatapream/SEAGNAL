## Q-1. 해수부·해경이 **같이** 맡은 법 17개를 "우리 법"으로 볼 것인가

### 지금 상황
우리는 법을 세 군으로 나눠 모읍니다.
- **1군** = 우리 법 → **전문(全文)** 을 다 받는다
- **2군** = 우리 법이 가리키는 남의 법 → **가리킨 조문만** 받는다
- **3군** = 그보다 먼 법 → 이름만 적는다

그런데 `_SCHEMA §0-A` 규칙을 글자 그대로 돌리면, 남의 법 430개 중 **80개가 1군**이 됩니다. 그 80개는 **단독 소관 63 + 공동 소관 17** 입니다.

「공동 소관」은 예를 들어 **농림축산식품부와 해양수산부가 같이 맡은 법**입니다.

### 두 길

| | ⓐ 공동소관도 1군 | ⓑ 공동소관은 2군 (추천) |
|---|---|---|
| 새로 전문 받을 법 | **17개 더** | 0개 |
| 받는 분량 | 법 하나에 법률+시행령+시행규칙+별표 = 보통 **200KB~2MB** → 17개면 수 MB~수십 MB | 지금 그대로 |
| 좋은 점 | 그 17개 질문에 조문을 끝까지 따라갈 수 있다 | 창고가 안 커진다. 유지·점검 대상이 안 는다 |
| 나쁜 점 | **우리 소관이 아닌 부분까지** 책임지게 된다. 그쪽 부처 개정을 우리가 못 따라간다 | 공동소관 법의 깊은 질문은 "가리킨 조문까지만" 답한다 |

### 내 추천 — ⓑ
**우리가 고칠 수 없는 법의 최신성을 우리가 보증할 수 없기 때문**입니다. A-1(판번호 점검)이 이미 74법을 따라가기도 버거운데, 남의 부처 법 17개를 더 얹으면 **"받아는 놨는데 낡은" 파일**이 늡니다. 그게 지금 별표21에서 실제로 난 사고(P-1)입니다.

## Q-2. 남의 법 폴더에 있는 **복사본 25개**를 지울 것인가

### 지금 상황
같은 법이 **두 곳에** 있습니다.
```
raw/04_선박해운/○○법/            ← 기준법 폴더 : 전문(全文)
raw/15_관련타부처/○○법/          ← 타법 폴더   : 발췌(일부만)
```
25개가 이 상태이고, **전부 내용이 다릅니다.**

★**챗봇은 피해가 없습니다.** `resolveBase` 를 10번 돌려 보니 **10번 다 기준법(전문)** 을 골랐습니다.
★**그런데 검사기는 속습니다.** V5-16(「다음 각 목」이라 해 놓고 목이 없는 자리)이 지금 14곳 남았는데, **그중 7곳이 이 발췌본 탓**입니다. 발췌본이라 당연히 목이 없는 건데 결손으로 셉니다.

### 두 길

| | ⓐ 그대로 둔다 | ⓑ 타법 쪽 25개를 지운다 (추천) |
|---|---|---|
| 챗봇 | 변화 없음 | 변화 없음 (어차피 안 씀) |
| V5-16 | 14곳 (7곳은 가짜) | **7곳** — 전부 진짜 |
| 위험 | 앞으로도 검사기가 계속 속는다. **가짜 결손을 고치려다 시간을 버린다** | 혹시 어디선가 그 경로를 참조하면 깨진다 → **지우기 전에 참조 전수 검색** 필요 |

### 내 추천 — ⓑ (참조 검색을 먼저)
가짜 숫자는 진짜 숫자보다 나쁩니다. 다만 지우기 전에 `law_raw_paths.json`·위키·도구에서 그 25개 경로를 참조하는 곳을 전수로 찾아 0건임을 확인하고 지우겠습니다.

## Q-3. 위키의 **표준 절(제목) 8개**를 확정할 것인가

### 지금 상황
위키 1,288쪽의 본문 절 제목이 **2,787가지**입니다. 같은 뜻인데 이름이 다릅니다.
```
## 근거 조문
## 근거 조문 (전체 사슬)
## 근거 조문·시행일
## 관련 조문
## 법적 근거
```
그런데 **답변 코드는 "항상 실을 절"을 이름으로 고릅니다.** 그것도 `startsWith` 로요. 코드 주석이 사정을 그대로 적어 뒀습니다 — *"⚠시작 문자열로만 맞춘다 — 실제 위키에 꼬리가 붙은 변형이 있다."*

**그 목록이 못 잡는 변형이 225가지 · 309절 · 201쪽**입니다.

> 정직하게: 못 잡는다 ≠ 안 실린다. 그 절들은 "항상 포함" 보장을 못 받고 **점수 경쟁으로 내려갑니다.** 밀리면 어떻게 되는지는 이미 겪었습니다 — 2026-08-17, 위키에 뻔히 있는 처벌 근거를 **"확인되지 않습니다"** 라고 답했습니다.

### 두 길

| | ⓐ 표준을 안 정한다 | ⓑ 8개로 확정 (추천) |
|---|---|---|
| 쓰는 사람 | 자유롭다 | 8개 중에서 고른다 (쪽 종류마다 2~7개만 해당) |
| 코드 | 계속 데이터를 뒤쫓는다. 변형이 생길 때마다 목록을 늘린다 | **이름만 보면 된다.** 검사로 막을 수 있다 |
| 정리 규모 | 0 | 약 477쪽 자동 통일 + 약 85쪽 수동으로 채움 |

### 8개 후보 (`06_STANDARD_SECTIONS.md` §4)
`## 한눈에` · `## 정의` · `## 의무 내용 (원문 발췌)` · `## 절차` · `## 위반 시 처벌` · `## 근거 조문` · `## 타법 연결` · `## 변경 이력`

### 내 추천 — ⓑ
**표준 = 자유를 뺏는 것이 아니라, 코드가 이름을 믿을 수 있게 하는 것**입니다. 12가지가 아니라 8가지인 이유는, 쪽 종류(개념/법령/별표/비교)마다 필요한 게 달라서 전부 다 쓰라고 하면 빈 절이 생기기 때문입니다.
