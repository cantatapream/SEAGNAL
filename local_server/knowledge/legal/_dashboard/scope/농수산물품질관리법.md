## 4. 수집곤란 (uncollectable)

지자체 고시 등 국가법령정보센터 수집이 곤란한 항목은 원문 전수 확인 결과 **발견되지 않음** — 이 법은 중앙행정기관(농림축산식품부·해양수산부·식품의약품안전처) 고시·훈령 위주이며 지자체 조례·고시 위임은 없음.
