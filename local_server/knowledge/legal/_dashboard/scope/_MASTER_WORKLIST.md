## C. 수집 절차 (phase②)
1. **공용 타법 1회 수집**(위 A표) → raw/15_관련타부처/. 특히 **전자정부법 제36조제1항**(행정정보 공동이용)이 최다.
2. **법별 수집셀**(`collect_fix_cell.js`) — 각 법 매니페스트의 '미수집' 행을 체크리스트로 삼아 하나씩 DRF 수집 → raw 저장 → 위키 연결 → 소관부서·연락처 → checklist[]에 항목별 collected/failed 기록.
3. **수집곤란(지자체 고시·조례, 국제조약, 외국법)** = 억지 수집 안 함 → 위키에 '관할 지자체 소관부서(☎) 확인' 안내(_CHATBOT.md 5-3).
4. **부칙 공백**(다수 법에서 raw에 부칙 섹션 없음) = DRF 재수집 대상으로 각 매니페스트에 기록됨.
