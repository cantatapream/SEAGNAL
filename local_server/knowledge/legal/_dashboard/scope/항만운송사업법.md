# 항만운송사업법 — 수집 범위 매니페스트 (scope)

- 대상 raw: `local_server/knowledge/legal/raw/10_항만물류/항만운송사업법/`
- 원문 3종(법률.txt·시행령.txt·시행규칙.txt) 전수 Read + Grep 교차검증으로 도출.
- 작성일: 2026-07-18. 이 문서는 **수집 대상 확정용**이며 실제 수집·위키 반영은 다음 단계에서 한다.

## 요약
- 법률/시행령/시행규칙 본문 자체는 이미 raw에 전문 수집되어 있음(각 1개 txt, 삭제조문 포함 완전한 조문번호 연속성 확인).
- 별표·서식: 법률이 위임한 별표·서식 **39건 전부 raw/별표/에 존재**(시행령 11 + 시행규칙 별표 5 + 시행규칙 서식 23 = 39, `_meta.json`의 "별표수":39와 일치). 미수집 0건.
- 고시/행정규칙: 항만시설 지정·고시 계열(항만별 세칙 11건 + 당진화력 1건) + 부두운영회사 성과평가 지침 1건 = 13건 raw/행정규칙/에 존재. **2건은 확인필요**(컨테이너부두 지정고시, 부적합항만시설 고시 — 개별 고시라 국가법령정보센터 등재 여부 불확실). **1건은 수집곤란**(지방청/시도 개별 고시 — 다수·비정형).
- 타법 인용: 28개 조문 대상 중 **27개 보유**, **1개 미수집**(전자정부법 제36조제1항 — raw에 전자정부법 폴더 자체가 없음).

## C. 별표·서식 (법률·시행령·시행규칙이 위임한 전체)

- 시행령: 별표1,2,3(삭제),4,5,5의2,6,7,8,9,10 — 11건, 전부 있음(`raw/.../별표/시행령_별표*.txt`).
