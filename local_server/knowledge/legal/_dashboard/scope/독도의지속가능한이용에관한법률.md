# 수집 범위 매니페스트 — 독도의 지속가능한 이용에 관한 법률

- 대상 raw: `local_server/knowledge/legal/raw/08_섬영토/독도의지속가능한이용에관한법률/`
- 원문 확인: 법률.txt(제1~13조, 부칙 없음), 시행령.txt(제1~13조 및 제6조의2, 부칙 없음) 전문 Read + Grep 교차검증
- 시행규칙: 없음 — 법률 전문에 "해양수산부령으로 정한다" 위임이 존재하지 않음(전량 "대통령령으로 정한다" 또는 "장관이 정하여 고시"). `_meta.json`의 `families`에도 시행규칙 없음 → 미수집이 아니라 애초에 존재하지 않는 것으로 판정.
- 별표: 없음 — 법률·시행령 본문에 "별표" 언급 0건, `_meta.json`의 `별표수: 0`과 일치.

## 5. 수집곤란(uncollectable)
