# 발견 01 — 근거 목록에 **어느 법인지 없는 인용줄**이 나온다 (2026-09-07, 27차 라이브 검증)

## 사용자가 보는 것

질문: *"(헬기 조종사) 정선명령을 헬기로 방송해도 법적 효력 있는 정선신호로 인정되나요?"*

챗봇이 내놓은 근거 목록 세 줄 중 가운데 줄이 이렇게 나온다:

```
[어선안전조업 …]  어선안전조업 및 어선원의 안전ㆍ보건 증진 등에 관한 법률 시행규칙 제12조제1항
[시행규칙]        시행규칙 제1조의2                ← 어느 법의 시행규칙인지 없다
[시행령]          수산업법 시행령 제44조제1항
```

이 답변에는 **서로 다른 두 법의 시행규칙**이 함께 실려 있다(어선안전조업법 시행규칙,
그리고 실제로는 해양경비법 시행규칙). 그래서 읽는 사람이 가운데 줄이 어느 법인지 **알 방법이 없다.**

## 왜 그런가 — 코드로 확인한 경로

1. 위키 `## 근거 조문` 표의 **법령명 칸에 계층 낱말만** 적힌 행이 있다.
   예: `wiki/concepts/해양경비법__해상검문검색.md:132`
   ```
   | 시행규칙 | 제1조의2 | 2026-04-20 | 정선요구 6가지 방법 |
   ```
   그 페이지 안에서는 "해양경비법 시행규칙"이 자명하므로 사람이 이렇게 적어 왔다.
2. 서버는 이 꼴을 **알고 있고 원문 찾기는 잘 한다** —
   `legal_retriever.js:2088` `BARE_TIER_CELL_RE = /^(시행령|시행규칙)$/` 가 있고,
   그 줄이 실린 페이지의 법(`baseLaw`)으로 폴더를 찾는다(B3).
3. **그런데 화면에 그릴 때는 그 baseLaw 를 안 쓴다.**
   `client/js/ai-chat/ai_chat.js:3764`
   ```js
   '<span class="nrya-chain-art">' + esc(row.law || '') + (row.article ? ' ' + esc(row.article) : '') + '</span>'
   ```
   `row.law` 이 "시행규칙" 그대로라 화면에도 "시행규칙 제1조의2"로 나온다.
   뱃지(`tierLabel`)도 tier 로 만들어 "시행규칙"이라, **두 자리 모두 법 이름을 안 알려준다.**

즉 **찾기는 되는데 보여주기가 안 된다.** 한 페이지만 볼 때는 안 드러나고,
여러 법이 섞이는 답변에서만 드러난다 — 그래서 지금까지 안 잡혔다.

## 얼마나 넓은가 (기계로 셈)

```
법령명 칸이 "시행규칙"·"시행령"뿐인 근거 조문 행 : 194행
그런 행이 있는 위키 페이지                      :  49장 (전체 1,288장)
  concepts 20장 · statutes 28장 · comparisons 1장
```

## 고치는 방법 두 가지 — 오케스트레이터 판단으로 정하지 않고 남김

**ⓐ 화면에서 고친다(한 곳).** 서버가 이미 줄마다 `baseLaw` 를 붙여 보내므로,
`row.law` 가 계층 낱말뿐이면 `baseLaw + ' ' + row.law` 로 그린다.
- 장점: 한 자리만 고치면 194행 전부와 **앞으로 새로 쓰일 행까지** 덮는다.
- 주의: `row.law` 는 원문 팝업을 여는 열쇠로도 쓰인다(`buildCiteIndex`,
  `usesBaseLaw` 는 "법령 칸이 계층 낱말뿐일 때"를 조건으로 삼는다 — ai_chat.js:3473).
  **표시용 문자열만 바꾸고 판정에 쓰는 값은 건드리지 않아야 한다.**

**ⓑ 위키에서 고친다(194행).** 법령명 칸을 `해양경비법 시행규칙`처럼 전체 이름으로 적는다.
- 장점: 자료 자체가 자기설명적이 된다. 코드 손 안 댄다.
- 단점: 194행을 고쳐야 하고, 앞으로 또 계층 낱말만 적으면 같은 문제가 재발한다.
  게이트가 이 꼴을 막지 않으므로 **검사도 함께 만들어야** 재발이 안 난다.

## 이 발견이 나온 경위

문서를 아무리 대조해도 안 나오는 종류의 결함이다. **여러 법이 한 답변에 섞이는 실제 질문을
던져야** 드러난다. 27차를 "문서 대조"가 아니라 "실제로 물어보기"로 바꾼 것이 이걸 잡았다.
