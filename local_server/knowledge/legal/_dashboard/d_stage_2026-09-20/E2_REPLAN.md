# E-2 다시 쓰기 — draft 승급 계획 (2026-09-20 밤 실측)

HANDOFF 는 E-2 를 이렇게 적어 뒀다:

> **E-2.** draft 136쪽(=[미확인] 0줄인 쪽)을 **숫자 있는 쪽/없는 쪽**으로 갈라 승급. C-3 적용 후.

**그 가름이 이제 안 먹는다.** 오늘 두 가지가 바뀌었기 때문이다. 그래서 다시 쓴다.

## ① 무엇이 바뀌었나

**D-1 이 [미확인]을 0줄로 만들었다 → ⓐ-1 이 더 이상 아무것도 걸러내지 않는다.**

| | 2026-09-20 아침 | **지금** |
|---|---:|---:|
| 비-statute 쪽 | canonical 1,051 · draft 152 · review-pending 5 | canonical **1,051** · draft **157** · review-pending **4** |
| draft 중 ⓐ-1 통과([미확인] 0줄) | 136쪽 | **157쪽 — 전부** |

아침에는 *"136쪽만 ⓐ 를 통과하니 그것부터"* 가 뜻이 있었다. 지금은 **draft 157쪽이 전부 통과**한다.
→ **ⓐ-1 로는 일을 나눌 수 없다.** 이건 나빠진 것이 아니라, 거르는 일을 D-1 이 먼저 해치운 것이다.

**그리고 "숫자 있는 쪽/없는 쪽" 가름도 안 먹는다.**
§5-D ⓑ 의 대상 낱말(*"애매하면 대상으로 본다"*)로 재니 —

```
draft 157쪽 중  숫자 있는 쪽 156쪽  ·  숫자 없는 쪽 1쪽
```
1 대 156 이다. **가름이 아니라 거의 전부다.** 유일한 예외 한 쪽마저
`수상에서의수색ㆍ구조등에관한법률__조난선박예인시책임면제_사람확인` 이라 이름부터 사람 확인 대기다.

## ② 그래서 무엇으로 가르나 — **ⓐ-2(판독·OCR 신호)** 다

§5-D ⓐ-2 는 *"판독ㆍOCRㆍ출처미확인 신호가 있으면 비전 재검증 경로로 보낸다"* 고 정한다.
이것으로 가르면 **경로 자체가 달라지므로** 실제로 일이 나뉜다.

```
ⓐ 통과 draft 157쪽
  ├ ⓐ-2 판독·OCR 신호 있음 → 비전 재검증 경로   62쪽  (대조할 수치 2,755개)
  └ ⓑ 로 바로 갈 수 있음                     95쪽  (대조할 수치 3,190개)
```

수치 개수는 `\d+(원|만원|억원|년|개월|일|시간|톤|미터|노트|퍼센트|%|배|명|개|호|분의N)` 과
`N년 이하의 징역/금고`·`벌금`·`과태료`·`과징금` 을 세어 **중복을 뺀 것**이다.

## ④ 다시 쓴 계획

**E-2 를 "draft 를 없애는 일"로 보지 않는다.** 그렇게 보면 3,190개 수치를 앞에 두고
숫자를 줄이려는 압력이 생기고, 그것이 §5-D ⓑ-1 이 기록한 사고(틀린 배점표가 "검토완료"로 둔갑)로 가는 길이다.

1. **묶음 A — ⓐ-2 에 걸린 62쪽은 승급 대상에서 뺀다.** §5-D 가 정한 대로 비전 재검증 경로다.
   지금 인프라가 없으므로 **줄을 세워 두기만 한다.** 여기에 손대는 것은 별도 과제다.
2. **묶음 B — 95쪽은 ⓑ 를 실제로 거친 쪽만 하나씩 올린다.** 일괄 승급은 하지 않는다(ⓑ-1).
   1차(기계 EXACT 대조)는 자동화할 수 있다. **2차(조·항·호 귀속을 다른 눈이 읽는 것)는 못 한다** —
   그것이 ⓑ 가 두 번을 요구하는 이유 자체다.
3. **순서** — 수치가 적은 8쪽(1~10개)부터. 적어서가 아니라 **경로를 한 바퀴 돌려 보려는 것**이다.
   그 8쪽으로 ⓒ-1 기록 형식과 V5-13 게이트가 실제로 맞물리는지 확인한 뒤 나머지로 간다.
4. **멈추는 조건** — V5-13 이 빨개지면 거기서 멈춘다. 게이트를 완화해서 통과시키지 않는다.

⚠**이 문서는 계획이고, 승급은 한 쪽도 하지 않았다.** 오늘 한 것은 ①가름 기준을 바꾼 것
②크기를 실제로 센 것 ③게이트(V5-13)를 만든 것까지다.
