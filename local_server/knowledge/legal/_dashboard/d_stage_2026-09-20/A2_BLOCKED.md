# A-2 — 시작했으나 **law.go.kr 이 응답하지 않아 멈춰 세웠다** (2026-09-21 00:30 KST)

## 무엇을 하려 했나

`python3 _dashboard/loop/mok_audit.py --out <볼륨경로>` — raw 조문 파일에 **목(가.·나.·다.)이
통째로 빠진 곳**을 원본과 대조해 찾는 검사. A-1b 가 끝나 law.go.kr 이 비었으므로 **단독**으로 띄웠다.

**대상은 573계열이다.** ⚠HANDOFF·스크립트 주석이 적은 **"427개 계열"은 낡은 값**이다
(A-1 의 "653건"이 실제 824건이었던 것과 같은 꼴).

## 왜 멈췄나 — **돌긴 도는데 아무것도 못 받고 있었다**

24분을 돌렸는데 **진행 표시(40건마다)가 한 번도 안 찍혔다.** CPU 시간은 4초 — 거의 전부 네트워크 대기였다.

한 법만 떼어 재 봤다(값싼 확인):
```
python3 _dashboard/loop/mok_audit.py --law 선박안전법 --out <임시>
  → 78초 · 대조 3계열 · ⚠원본을 못 받아 판정 못 한 계열 3개   (3/3 전부 실패)
     선박안전법 법률(MST=246611) · 시행령(266313) · 시행규칙(289035)
```
5분 뒤 다시 해도 **똑같이 3/3 실패**였다.

**원인은 프록시 상태 파일이 밝혀 준다** (`curl "$HTTPS_PROXY/__agentproxy/status"`):
```
kind   : ws_closed_mid_exchange
detail : tunnel closed (code 1006, Connection ended) after 11s;
         517 B sent, 39 B received, client reading
host   : www.law.go.kr:443            ← 같은 실패가 연달아 쌓여 있다
```
**터널이 11초 만에 닫힌다.** 우리 쪽 설정 문제가 아니다 —
네 도구(`admrul_fresh`·`admrul_fresh_pass2`·`law_fresh`·`mok_audit`)가 **전부 같은 호스트**를 쓰고,
그중 앞 둘은 **바로 20분 전까지 824건을 멀쩡히 돌았다.** 그때그때 끊기는 것이다
(HANDOFF 가 적어 둔 `ws_closed_mid_exchange` 와 같은 현상).

## 왜 "그냥 계속 돌리기"를 안 했나

| | |
|---|---|
| 걸리는 시간 | 573계열 × 26초 ≈ **4시간** |
| 나올 결과 | **"판정 불가 573건"** — 아무것도 알려 주지 않는다 |
| ★더 나쁜 것 | 그 보고서를 나중에 **결과로 착각**할 수 있다. `mok_audit.py` 에는 **이어받기가 없어서**, 중간에 네트워크가 살아나도 **앞부분은 이미 실패로 굳는다** |

`⚠원본을 못 받아 판정 못 한 계열` 은 도구 스스로 *"'없다'가 아니라 '모른다'다"* 라고 적는다.
**모르는 것을 4시간 들여 확인하는 것은 검사가 아니다.**

## 그래서 한 것 — 되살아나면 스스로 띄우는 발사대

`a2_launcher.sh`(세션 스크래치패드) — **값싼 probe 한 번**(호출 1회·40초 타임아웃)을 **5분마다** 던져
**JSON 이 돌아올 때만** 본 실행을 띄운다. 상태는 `a2_launcher.tsv` 에 한 줄씩 남는다(`UP`/`DOWN`/`RUNNING`/`DONE`).

⚠**발사대도 컨테이너 재시작은 못 버틴다.** 재시작 뒤에는 사람이 다시 띄워야 한다.

## 다음 사람이 할 것

1. `a2_launcher.tsv` 마지막 줄을 본다. `UP` 이 찍혔으면 `mok.log` 로 진행을 본다.
2. 발사대가 죽어 있으면 **probe 부터** 한다 — 본 실행을 바로 띄우지 말 것:
   `python3 _dashboard/loop/mok_audit.py --law 선박안전법 --out /tmp/probe.json`
   → `판정 못 한 계열 0개` 면 네트워크가 살아난 것이다. 그때 전수를 돌린다.
3. 전수 결과가 나오면 **그때 C-2 스캐너**(`services/mok_audit_scanner.js`)를 만든다 —
   출력 모양을 모르는 채로 카드·푸시를 설계하면 다시 만들게 된다.

## 이번에 도구에 미리 붙여 둔 것 (A-2 와 별개로 이미 커밋됨)

- `--out <경로>` — 서버 정기작업이 **볼륨**에 쓸 수 있게(이미지 안에 쓰면 배포 때마다 날아간다)
- **누락이 0건이어도 반드시 쓴다** — 종전에는 `if rows:` 안에서만 써서, 깨끗하면 파일이 아예 안 생겼다.
  그러면 읽는 쪽이 **지난 번 파일을 지금 결과로 착각**한다. 임시파일 → `fsync` → `os.replace` 로 원자적으로 쓴다.
- `checked`·`missing_moks`·`ran_at` 을 함께 넣었다(`ran_at` 의 시간대 오기도 바로잡았다).
