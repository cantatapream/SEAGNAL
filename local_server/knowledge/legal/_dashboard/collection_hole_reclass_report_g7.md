## 6. 오케스트레이터에게 넘기는 요청

1. **law.go.kr 접속 차단**(§ 상단 경고)을 다른 그룹에도 공유할 것 — 같은 세션 환경이면 다른 그룹의 API 재검증도 동일하게 막혔을 가능성이 높다. 재수집 라운드는 **API가 열린 환경에서** 돌려야 한다.
2. **재수집 배치 구성 권고**: ①자연유산법 4건(+시행규칙 제26조)은 **한 배치**로(동일 결함) ②연안관리법 P102는 `raw/_자치법규/` 공유 디렉토리라 **⚠경합위험 — 단독 처리** ③낚시법·연안관리법 P119/P122는 admrul flDownload 재조회라 묶어도 무방.
3. **§1 말미의 "목 계층 누락 74법 전수 점검"** 은 이 그룹 범위를 넘어서므로 오케스트레이터 판단으로 별도 과제화할 것.
4. **한국해양수산연수원법 5건은 재수집 대상이 아니라 사람 승인 대기**(REVIEW-01·02, 18라운드째)다 — 재수집 큐가 아니라 `HUMAN_ACTION_GUIDE.md` 로 보낼 것.
