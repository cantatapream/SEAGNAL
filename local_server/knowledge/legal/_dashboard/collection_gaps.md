# 수집 완결성 감사 (2026-07-17) — 무엇을 수집했고 무엇이 남았나

수정3 진행 중 에이전트 75법의 still_missing/reclassified 전수 분석 + OCR 워크리스트 + raw 폴더 실사 결과.
**결론: "인용 타법 원문·시행령·시행규칙"은 사실상 완료 단계. 남은 진짜 공백은 ①위임 고시/행정규칙 ②조례 ③OCR 표 ④소수 국제협약/등록령.**

## ✅ 사실상 완료 (추가 조치 거의 불필요)
- **인용 타법 원문(연결 조문)**: 에이전트가 계속 "이미 수집됨" 확인(재분류 183건). 기준법이 실제 인용한 조문은 대부분 raw 존재.
- **공통 일반법 전량 수집 확인**: 형법·형사소송법·행정절차법·행정심판법·행정소송법·국가배상법·질서위반행위규제법·민법·행정기본법·행정대집행법 = 모두 raw 존재. (일부 위키가 "미수집"으로 낡게 표기 → 감사/수정이 정정 중)
- **시행령·시행규칙**: 기준법·타법과 함께 대부분 수집. 별표 전량이관 작업 잔여 1건.

## ⚠️ 진짜 미완 — 별도 수집 패스 필요 (수정3 이후)
### 1) 위임 고시·행정규칙 (가장 큰 공백) — "이 법 자신이 위임한 고시"라 타법연결 유형 밖으로 계속 미착수
- 어업·양식업등록령(대통령령, MST 확인됨) — 3라운드 연속 최우선 미해결
- 도선구간·도선료 요율 고시(도선법) / 정착성어종 목록 고시(EEZ외국인어업법)
- CO2 저장후보지·CCS 모니터링 고시(해양폐기물법)
- 원산지표시 위반 신고포상금 지급기준 별표(농수산물원산지법)
- 검사대행자 수수료 고시(수상레저기구법) / 선박교통관제시설 설치·관리 규칙
- 선박평형수 형식승인시험기관 지정기준 고시 등
- **방법**: WebFetch로는 byte-정확 원문 불가(요약만 반환) → **DRF JSON API(lawService.do?target=law&MST=…) 확인됨 작동**. 이 방식으로 재수집해야 함.

### 2) 조례(지자체 자치법규) — 의도적 후순위 (Phase D)
- 수산업어촌발전기본법 85건, 연안관리 심의회 조례, 해수욕장 조례 등. 지역별이라 대량.

### 3) OCR 라운드 — 실행됨(24항목)이나 완료 대장 없음 → 검증 필요
- 일부는 진짜 이미지-only 미추출: 원산지 신고포상금 별표 등. `ocr_remaining.json` 24건 재검증 대상.

### 4) 소수 국제협약·대법원규칙 (엣지)
- 유류오염: 4개 국제협약(CLC·FUND·SUPPFUND·BUNKERS) 본문 전체 — DRF target=trty HTTP 500, HWP 첨부 파싱 필요. 핵심 SDR 수치는 이미 발췌 반영.
- 유류오염 제12조 "대법원규칙으로 정하는 법원" 등 — 대법원규칙 원문(엣지, 저우선).

## ⏸️ 중간에 멈춘 것?
- **영구 정지된 작업 없음.** 유일한 "멈춤" 사건 = 65-동시 워크플로 서버 rate-limit(0진척) → 12파도 롤링으로 복구 완료.
- fix3 129작업 큐 대기중(대부분 thin심화 60·②일반법 45 = 위키심화, raw수집 아님).

## 병렬 수행 가능성
- **추가 워크플로 병렬 불가**: fix3 12파도가 이미 서버 동시요청 상한. 더 띄우면 rate-limit 재발.
- **내가 직접(에이전트 없이) 가능한 것**: 위 1)·4)의 DRF 직접수집. 단 fix3 커밋과 파일충돌 우려 → **fix3 완주 후 전용 수집 패스**로 실행 예정.
