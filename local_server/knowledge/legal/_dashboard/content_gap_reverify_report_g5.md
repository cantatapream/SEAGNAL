- 담당 그룹: g5 (7개 법)
- 방법: 각 법의 `_dashboard/audit/<slug>.md` 누적 감사파일에서 **명시적으로 `content_gap`·`원문 자체 공백`·`genuine gap`으로 태그된 항목**을 전수 추출 → 같은 항목이 여러 라운드에 걸쳐 반복되면 **가장 최신 판정만 채택** → 각 항목이 인용하는 조문을 해당 법의 `raw/` 원문(법률·시행령·시행규칙·행정규칙·별표/별지)에서 **직접 grep·열람해 재확인**.
