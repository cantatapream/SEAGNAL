### 파이프라인에 반영할 교훈 후보 (사용자 승인 후 `_LESSONS.md` 반영 검토)

- **감사 리포트의 "collection_hole 0건"은 API 전수대조로 재확인하기 전까지 확정으로 취급하지 않는다** — 이번 그룹에서 0건 선언 법 2곳(수상레저·물환경)에서 각각 7건·20건이 나왔다. `lsDelegated` 위임목록 vs 로컬 raw 파일 목록의 기계적 diff는 AI 판단 없이 결정론적으로 돌릴 수 있다(H-29 하이브리드 논거 실측 보강).
- **HWP 별표 전사는 `hwp5txt` 가 아니라 `hwp5html` 경유** — `hwp5txt` 는 표를 `<표>` 플레이스홀더로만 출력해 자격기준표 같은 표 중심 별표에서 전량 유실된다. `hwp5html --output <dir> <file>` 후 index.xhtml 태그 제거가 검증된 경로(선박직원법 별표1에서 6라운드 연속 실패를 이번에 돌파).
- **자치법규(`ordin`)는 `ID` 파라미터 직접조회가 실패한다** — MST(자치법규일련번호) 또는 `lawSearch` 경유로 접근해야 한다.
