### 7-3. 이번 패스에서 새로 남기는 판단

1. **§3 reclassify_note(선원법 3건, b→a)는 그대로 유효**하다. 근거가 "lsDelegated 위임행정규칙 0건 + admrul 전수 + WebSearch 3중 확인"이라 로컬 재확인으로 뒤집을 요소가 없다.
2. **수산물유통법 7건 전부 `a_genuine`도 그대로 유효**하다. 감사 자체가 18R~21R(가장 최근 라운드)에서 **이 리포트(g3)를 인용하며** 6건을 `collection_hole_genuine`으로 재확인했다 — 즉 이 리포트의 판정이 이미 감사 본류에 반영돼 회귀 검증까지 통과한 상태다.
3. **정책 차단 시의 원칙**: law.go.kr이 403으로 막힌 세션에서는 **기존 API 근거를 로컬 추측으로 덮어쓰지 않는다.** 이번처럼 "이행현황 실측 + 잔여분 특정"으로 범위를 좁히는 것이 정직하고 실효가 있다.
