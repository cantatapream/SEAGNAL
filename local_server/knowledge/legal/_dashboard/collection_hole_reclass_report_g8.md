## 6. 후속 처리 권고 (우선순위)

1. **선박법 2건(훈령 2100000025246 / 고시 2100000115389) 즉시 API 수집** — 17R 감사가 통째로 놓친 유형이고, 위키가 "다른 고시 없다"고 **적극적으로 틀린 서술**을 하고 있어 활성오답 위험이 있다. 수집 후 statutes/선박법.md 행정규칙 인덱스 정정 필수.
2. **항만운송 지방청 고시 6건 API 수집** — ID 확보 완료. 동시에 **"lsDelegated에 안 나오는 지방청 고시"라는 유형 자체를 감사 방법론에 반영**해야 한다(다른 법에서도 같은 누락이 있을 수 있음).
3. **수산자원 2건 + 유류오염 1건 API 수집** — 지정판매장소 별표와 CLC 제7조5항은 응답에 실물이 확인돼 즉시 회수 가능. 수산자원 별도1은 파일 다운로드 + OCR 배치.
4. **연안사고 3건 hwp/OCR·게시판 배치** — 군산·보령은 한 배치로 묶고, 서귀포 원공고는 게시판·관보 경로.
5. **wiki_sync 6건 사서 패스** — 재수집 불요. 특히 항만운송 W13은 감사 서술 자체의 정정이므로 감사 파일과 위키를 함께 손봐야 한다.
6. **마리나 P171은 REVIEW로 이관** — collection_hole 집계에서 빼고, 법제처 유권해석·소관부서 확인 트랙으로 옮긴다.
