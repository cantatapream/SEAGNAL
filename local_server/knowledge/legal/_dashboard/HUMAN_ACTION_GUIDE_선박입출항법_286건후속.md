# 선박의 입항 및 출항 등에 관한 법률 — 286건 전수검증 후속 REVIEW 19건 상세 가이드
(2026-07-31, 사용자 지시로 진행한 4개 병렬 Workflow 전수검증의 후속 사람확인 항목)

## 0. 배경 — 왜 이 19건만 남았나

286건(구 "277건", 감사 집계오류 정정) 중 264건은 이미 처리됐습니다:
- **34건**: 위키가 이미 정확했는데 감사가 잘못 판정 → 재분류만, 조치 불필요
- **150건**(진짜공백 109 + 원문인용반영 41): 원문 그대로 인용하거나 "규정 없음"을 정직히 반영 → **원문 인용/부재 확인만으로 끝나는 것들이라 사람 판단이 필요 없음**
- **4건**: 페이지 배정 오류 확인 → 조치 불필요

**남은 19건(신규 18건 + 이월 1건)만** 사람 확인이 필요한 이유: 이 항목들은 **원문 조문 하나만 봐서는 답이 안 나오고, 두 개 이상의 조문(또는 두 개 이상의 법)을 AI가 스스로 조합해서 결론을 낸 것**이기 때문입니다. `_SCHEMA.md` §5 규정상 이런 조합·해석은 AI가 canonical로 직접 승격할 수 없고, `⚠REVIEW-선박입출항법-<번호>` 마커를 달아 draft로만 반영한 뒤 사람 확인을 기다리는 상태입니다.

## 1. 확인 방법 (공통, 한 번만 읽으면 됨)

1. **국가법령정보센터**(www.law.go.kr) 접속 → 검색창에 법령명 입력(대부분 "선박의 입항 및 출항 등에 관한 법률", 타법 비교 항목은 해당 법명) → 법령 탭에서 **법률·시행령·시행규칙**을 각각 클릭해 조문번호로 이동.
2. 아래 각 항목의 "확인할 조문"을 그 화면에서 직접 찾아 **AI가 인용한 문구와 실제 원문이 정확히 일치하는지** 대조.
3. 판단 기준은 셋 중 하나:
   - **AI 판단이 원문과 일치하고 합리적이다** → 승인(canonical 승격).
   - **AI 판단이 틀렸다**(원문을 잘못 읽었거나 결론이 안 나온다) → 반려, 무엇이 잘못됐는지 메모.
   - **애매해서 관할부서·법제처 확인이 필요하다** → 보류, 문의 경로를 밟는다(항목별 문의처는 아래 표기).
4. 판단 결과를 Claude에게 알려주면(예: "REVIEW-선박입출항법-248 승인, 도선법 제4조① 원문과 일치 확인") `review_queue.md` 체크 + 해당 위키 페이지의 draft→canonical 반영을 대신 처리합니다.
