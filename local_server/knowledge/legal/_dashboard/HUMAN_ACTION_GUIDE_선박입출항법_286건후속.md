# 선박의 입항 및 출항 등에 관한 법률 — 286건 전수검증 후속 REVIEW 19건 상세 가이드
(2026-07-31, 사용자 지시로 진행한 4개 병렬 Workflow 전수검증의 후속 사람확인 항목)

## 0. 배경 — 왜 이 19건만 남았나

286건(구 "277건", 감사 집계오류 정정) 중 264건은 이미 처리됐습니다:
- **34건**: 위키가 이미 정확했는데 감사가 잘못 판정 → 재분류만, 조치 불필요
- **150건**(진짜공백 109 + 원문인용반영 41): 원문 그대로 인용하거나 "규정 없음"을 정직히 반영 → 사람 판단 불필요
- **4건**: 페이지 배정 오류 확인 → 조치 불필요

**남은 19건(신규 18건 + 이월 1건)만** 사람 확인이 필요합니다. 이유: 이 항목들은 **원문 조문 하나만 봐서는 답이 안 나오고, 두 개 이상의 조문(같은 법 안의 다른 조문, 또는 서로 다른 두 개의 법)을 AI가 스스로 조합해서 결론을 낸 것**이기 때문입니다.

## 1. 확인 방법 (공통)

1. **국가법령정보센터**(www.law.go.kr) 접속 → 검색창에 **아래 각 항목에 명시된 정확한 법령명**을 그대로 입력 → 검색결과에서 그 법의 **법률·시행령·시행규칙** 중 항목에 표기된 것을 클릭 → 조문번호로 이동.
2. **한 항목에 법이 2개 이상 나오면, 반드시 그 2개 법을 각각 따로 검색해서 각각의 조문을 확인**해야 합니다(한 법만 보면 결론이 안 나옵니다 — 그게 이 REVIEW들의 핵심 성격입니다).
3. AI가 인용한 문구가 실제 원문과 정확히 일치하는지 대조 → 승인/반려/보류 중 하나로 판단.
4. 판단 결과를 Claude에게 알려주면 `review_queue.md` 체크 + 위키 반영을 대신 처리합니다.
