## 0. 총평

21개 개념 페이지 전부가 "★ 정의부터 → 적용범위·제외 → 예외 규정 → 의무 내용(원문 발췌) → 위반 시 처벌 → 벌칙 체계 → (행정처분 체계) → 근거 조문 전체 사슬 → 타법 연결 → 관련 개념 → 변경 이력" **동일한 표준 골격**을 따르고 있고, 원문(법률 제160~180조 처벌 총람)과 대조 검증한 결과 조·항·호·형량이 **정확히 일치**했다(제161~179조 전수 대조). 사서가 "REVIEW" 태그로 스스로 불확실/부재 지점을 정직하게 표시한 점(예: 행정처분 1~4차 별표 부재를 "없다"고 명시)은 이 프로젝트의 환각-0 원칙에 부합하는 모범 사례다.

다만 감사 결과 **구조적 구멍 두 가지**가 확인된다:
1. **선원법 시행령이 통째로 미수집**이다(시행규칙 제1조가 "「선원법」 및 동법 시행령에서 위임된 사항"이라 명시 — 즉 실존하는 법령인데 raw에 없음). 최소 7개 개념 페이지에서 "대통령령(raw 미수집 — REVIEW)"으로 막힌다.
2. **제15장(한국선원복지고용센터, 제142~150조)과 제16장 후반부 일부(제152조의2·3, 제153조, 제156조)가 위키에 전혀 반영되지 않았다** — 개별 개념 페이지도 없고 다른 페이지의 곁가지 언급도 없다(전수 grep 확인).

### method_notes (구체적 미흡 사례)
1. **선원법 시행령 전체 미수집** — 시행규칙 제1조가 "「선원법」 및 동법 시행령"이라 명시할 정도로 실존하는데(예: 제1조의2③이 "「선원법 시행령」 제3조의6" 직접 인용), raw에 파일 자체가 없다. 최소 7개 페이지(감독과행정처분, 선내급식, 선원근로계약과해지, 선원수첩과신분증명서, 승무정원과승무자격, 임금지급원칙과체불보호, 퇴직금_실업수당_송환수당)가 "대통령령(raw 미수집)"으로 답을 못 끝낸다.
2. **제15장(한국선원복지고용센터, 제142~150조) 개념 페이지 부재** — 전수 grep 결과 21개 페이지 어디에도 "한국선원복지고용센터"·"제142조" 언급 없음. 완전한 장(chapter) 하나가 통째로 위키에 없다.
3. **제16장 후반 4개 조문 누락**: 제152조의2(임금등 채권 양도·압류 금지), 제152조의3(임금채권 최우선변제 — 최종 4개월 임금·최종 4년 퇴직금), 제153조(서류 3년 보존 — 벌칙총람에 처벌만 인용되고 의무 자체 설명 없음), 제156조(임금·재해보상 채권 시효 3년). 이 중 제152조의3(파산 시 최우선변제)과 제156조(시효)는 실사용자가 실제로 자주 묻는 주제("회사 망하면 밀린 월급 받을 수 있나", "밀린 월급 시효 몇 년")인데 완전히 빠져 있다.
4. **최저임금 금액이 2018년도 고시뿐** — 위키 자신이 이미 REVIEW로 경고했지만, 실질적으로 "선원 최저임금 얼마?"라는 T1/T2 질문에 현재 유효 금액으로 답할 수 없는 상태(8년째 방치된 collection_hole).
5. **선내안전보건 고시(약 100개조, 105KB)가 색인만 되어 있음** — "진동 노출 기준", "소음 표시 기준" 등 구체 수치 질문에는 원문을 별도로 열어야 하며, 위키 페이지 자체는 답을 완결하지 못한다(설계상 의도된 색인이라는 점은 페이지에 명시돼 있어 정직하나, `_SCHEMA.md`의 "완성도 기준"—"답에 필요한 조각이 미리 다 연결된 채 쌓여 있어야 한다"—에는 못 미친다).
6. **여객안전관리선원 승무기준이 구간표 대신 뭉뚱그려짐** — 시행규칙 제43조의3②는 100~500명:1명/500~1000명:2명/1000~1500명:3명/1500명 초과:4명의 명확한 4구간표인데, 위키(승무정원과승무자격)는 "100명 이상~1,500명 초과 구간별 1~4명 이상"이라고 압축해 정확한 구간 경계가 빠졌다 — 프로필조건 표 원칙(톤수·구간 조건 컬럼화) 위반 소지.
7. **재해보상·임금 관련 대통령령 위임 이율·비율 다수 미확정**: 지연이자율(연 100분의 40 "이내" 대통령령 정함 — 실제 이율 없음), 어선원 통상임금 산정 비율(제57조② "대통령령 정하는 비율"), 유족 범위(제99조 "대통령령으로 정하는 유족") 등 — 전부 시행령 미수집과 동일 원인.
8. **선원법과 근로기준법의 관계가 총론으로 정리돼 있지 않음** — 개별 페이지에 "근로기준법 제5조제1항 적용부분", "제74조 준용" 등 파편적으로만 언급되고, "선원에게 근로기준법 중 어디까지 적용/배제되나"를 한 번에 보여주는 비교 개념 페이지가 없다(T6 질문에 매번 파편적으로만 답 가능).
