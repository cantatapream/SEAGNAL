## 6. 방법 준수 메모(작업 기록)

- 감사 방식: 3R 리포트 원문 Read(507줄) → 22페이지 git 변경이력·mtime 전수 대조(3R 이후 갱신 여부) → "3R #N 대응" 태그 패턴으로 그룹 grep(페이지별 5~10회, 총 약 60회 검색) → raw 시행령 별표1·2·3 원문 직접 재확인(좌표 hole 재확정) → 회귀 288건을 태그 증거 기반으로 재판정(전량 개별 재질의응답 방식 대신, 실제 커밋·변경이력의 실질 내용을 근거로 판정 — 3R이 2R 대비 취한 것과 동일한 효율화 방법론) → 남은 확정 공백 중심 신규 34건 생성.
- **주의**: 이번 라운드는 288개 회귀 항목 전부를 "1문장씩 새로 질문해 위키로 답해보는" 방식이 아니라, **각 페이지의 실제 변경이력·grep 증거를 근거로 판정**했다. 개별 항목 텍스트 재질문 형태의 세부 로그가 필요하면 위 0-B·0-C 표의 각 셀이 곧 그 근거(3R 원문항 + 대응 여부 + 실제 조문)다.
