## 0. 총평

이 법의 위키는 **스키마 준수도가 이 감사에서 본 것 중 상위권**이다. 14개 개념 페이지 전부가 "정의→적용범위·제외→예외규정→의무→처벌→벌칙체계→행정처분체계→근거조문→타법연결→관련개념→변경이력" 순서를 지켰고, 처벌은 조·항·호·금액까지 뭉개지 않았으며, AI가 연결한 부분(관제사 지시↔선박운항통제, 영해밖관제수역 적용배제)에 `REVIEW` 플래그를 정직하게 남겼다. 양벌규정 부재, 행정처분 축 부재도 "없다"고 검증 과정과 함께 명시했다(좋은 사례).

다만 **행정규칙(고시) 원문에 있는데 위키로 못 넘어온 내용**이 몇 군데 있다 — 특히 관제대상선박을 확장하는 「선박교통관제에 관한 규정」 제5조(여객선·예인선·유선·예선·도선선·특수작업선·관공선 8종 추가), 신고 면제 단서(제7조①), 도선사 승선·하선 통신(제7조②), AIS 확인 시 신고생략(제7조③), 영어 사용 근거(시행령 제10조①), 관제사의 입출항시간 조정·경비함정 요청 권한(법 제20조)이 어느 개념 페이지에도 없다. 이것들은 실사용자 질문("낚시어선도 대상?", "도선사 탈 때도 신고해?", "관제사가 출항을 늦출 수 있나?")에 직접 걸리므로 우선 보강 대상이다.

1. **정의 사슬 중단** — 법 제2조③라목("고시하는 선박")의 실제 고시 내용(「선박교통관제에 관한 규정」 제5조: 여객선·예인선·유선·예선·급수선/연료공급선/통선·도선선·특수작업선·국가/공공기관 선박 8종)이 `관제대상선박.md`에 전혀 반영되지 않음. 스키마의 "위임 제외/포함은 그 시행령·시행규칙·고시까지 따라가 실제 대상을 확정한다"(6-E) 원칙 위반. 여객선(톤수 무관 포함), 어업지도선, 유선사업자 선박이 실수로 "대상 아님"으로 오답될 위험.
2. **신고 예외 누락** — 고시 제7조①단서(도선선/예인선 지원 시, 목적지 도착 후 항행 시 신고 면제)가 `선장신고관제통신의무.md`의 `## 예외 규정` 표에 빠짐. 스키마 6-E("예외는 절대 누락하지 않는다")에 정면으로 해당.
3. **도선사 관련 절차 미반영** — 고시 제7조②·별표3(도선사 승선·하선 시 관제통신 방법과 통보사항)이 어느 페이지에도 없음. 실제 도선 업무 종사자·선사가 자주 물을 법한 절차.
4. **AIS 신고 갈음 규정 누락** — 고시 제7조③(사전 협의 시 AIS로 확인되는 사항은 신고 생략)이 미반영.
5. **관제사 권한(제20조) 개념 페이지 부재** — 입출항·이동시간 조정권, 해양사고 시 경비함정/도선/예선 지원 요청권이 독립 개념으로 다뤄지지 않음. "관제사가 출항을 늦출 수 있나"류 질문에 답 불가.
6. **선박소유자 책무(제5조) 개념 미비** — `statutes` 요약 페이지엔 있으나 concept 형식(적용범위·예외·처벌)의 독립 페이지가 없어 완성도 기준(3절) 미달.
7. **wiki/annexes/ 전체가 비어 있음(이 법만의 문제 아님, 위키 전체 구조적 이슈)** — 고시 별표1(20개 구역 경위도 좌표), 고시 별표2(교량 높이 신고기준), 시행규칙 별표1(VHF 채널-주파수 전체표) 원문이 어디에도 verbatim 보존 안 됨. `statutes` 페이지가 HWP 다운로드 링크는 제공하나, 스키마 규칙 8("별표는 요약하지 않는다 — 원문 표 구조를 그대로 wiki/annexes/에 보존")을 지키지 못함. 지도 폴리곤화("좌표 명시 별표는 폴리곤화") 운영결정도 annexes 부재로 실행 불가.
8. **영어 사용 근거(시행령 제10조①) 누락** — "외국 선원과 영어로 교신 가능"이라는, 국제항해선 이용자에게 실무적으로 중요한 조항이 미반영.
9. **「연안관리법」 미편입** — 구역설정기준 3호의 근거법인 연안관리법이 REVIEW로 남아있고 실제 내용 확인이 안 됨(정직하게 REVIEW 표기는 했으나 완결은 아님).
10. **음주운항 교차 연결 실독 부재** — `관제사지시위반.md`이 [[concept_음주운항]] 링크만 걸고 실제 연결 내용(둘 다 걸릴 때 처벌관계)을 서술하지 않음 — 스키마 5번("의미적 링크는 근거를 남긴다") 절반만 충족.
