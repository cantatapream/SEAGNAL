## 핵심 발견 요약 (먼저 읽을 것)

**존재하는 9개 페이지 자체의 완성도는 매우 높다.** 정의·적용범위·예외·의무·벌칙(항·호·금액)·타법연결까지 스키마 형식을 충실히 따르고, 오차허용범위·복원성 면제 등 고시·별표 수치도 상당수 원문 그대로 옮겨져 있다.

**진짜 문제는 법 전체 53개 조문 중 절반 가까이가 개념 페이지 자체가 없다는 것.** 특히 이 법의 **행정처분(등록취소·영업정지·효력정지) 체계 4곳이 전부 통째로 누락**되어 있다 — 그런데 정작 존재하는 페이지들이 이 누락된 페이지를 `[[링크]]`로 이미 가리키고 있어(**깨진 링크**), 사서 스스로 구조는 설계했지만 채우지 못한 상태다.

### ❌ 완전 미수집 뭉치 (개념 페이지 자체 부재)

1. **제9조·제9조의2 어선건조·개조업의 등록·취소** — 등록기준(시행령)·변경등록·**행정처분 1~3차 표(시행규칙 별표1의2)** 전부 없음. [[어선법__건조개조허가]]가 `[[어선법__어선건조개조업등록]]`을 관련개념으로 링크하지만 그 파일이 없다 — **깨진 링크**.
2. **제24조·제24조의2·제24조의3 형식승인·검정·형식승인시험기관** — 형식승인 대상·절차, **취소·효력정지 1~3차 표(별표16의2, 2개 세부표)** 전부 없음. [[어선법__어선의설비기준]]이 `[[어선법__형식승인및검정]]`을 링크하지만 파일 없음 — **깨진 링크**.
3. **제25조·제26조 지정사업장** — 지정기준·지정취소·**효력정지 1~3차 표(별표18의2)**. [[어선법__어선의설비기준]]·[[어선법__어선검사]] 두 페이지가 산발적으로 언급(취소 사유 1개 행만)하지만 독립 페이지가 없어 나머지 6개 위반유형(별표18의2 나~사목)이 전부 빠짐. [[어선법__지정사업장]] 링크도 깨져 있음.
4. **제31조 어선거래시스템** — 완전 미수집.
5. **제31조의2~제31조의9 어선중개업** (등록·결격사유·취소·**과징금(별표1의2 시행령)**·휴폐업신고·보수교육·거래계약서·보증보험) — 전부 미수집. 이 법에서 가장 규모가 큰 조문 뭉치(9개 조문)가 통째로 빔.
6. **제26조의2 하역설비의 확인** — 완전 미수집(과태료 조문만 다른 페이지 표에 스치듯 인용).
7. **제41조제8항 검사업무 대행 취소·정지 및 시행령 별표1의3(대행업무정지 1~3차 표)** — 완전 미수집.
8. **제42조 법정대리인의 의무** — 완전 미수집.
9. **제38조 청문 / 제48조 양벌규정(법조문 자체는 각 페이지에 인용되나 종합 페이지 없음) / 제50~52조 벌칙적용대상·예외·공무원의제** — 통합 "벌칙 및 과태료 체계" 개념 페이지가 없음. [[어선법__건조개조허가]]·[[어선법__어선의정의와적용범위]] 두 페이지가 `[[어선법__벌칙및과태료체계]]`를 링크하지만 파일 없음 — **깨진 링크**.
10. **제37조 다른 법령의 준용 / 제37조의2 지도·단속** — 「선박법」·「선박안전법」 조문을 어선법 조문처럼 준용하는 부분(제37조)이 여러 페이지에 파편적으로만 인용되고 준용 범위 전체를 정리한 페이지가 없음.

이 10개 뭉치가 이번 감사의 핵심 `wiki_gaps`다. 특히 1~3·5·7은 **행정처분 1~3차 escalation 표가 원문(별표)에 이미 존재하는데 위키에 전혀 반영되지 않은 경우**로, 스키마 4-C·CHATBOT 2절(점진적 공개)이 요구하는 데이터 원천 자체가 없다.

### method_notes (구체 미흡 사례)

1. 4개의 행정처분 1~3차 escalation 표(어선건조개조업·형식승인·지정사업장·어선중개업)가 원문(별표1의2, 16의2, 18의2, 19의2)에 존재하지만 개념 페이지 부재로 위키 전체에 반영 안 됨 — 점진공개의 데이터 원천 자체가 없음.
2. 대행업무 정지처분(시행령 별표1의3, 공단·선급법인 대상)도 동일하게 누락.
3. 과징금 escalation(시행령 별표1의2, 어선중개업 1→450→900만원)도 누락.
4. [[어선법__건조개조허가]]·[[어선법__어선의정의와적용범위]]·[[어선법__어선의설비기준]]·[[어선법__어선검사]] 4개 페이지가 존재하지 않는 `[[어선법__어선건조개조업등록]]` · `[[어선법__형식승인및검정]]` · `[[어선법__지정사업장]]` · `[[어선법__벌칙및과태료체계]]` 4개 링크를 걸어두고 있음 — 사서가 구조는 설계했으나 실제 페이지를 만들지 않은 "깨진 링크" 상태.
5. 톤수 조건은 표 컬럼으로 잘 구조화되어 있으나 조업형태·지역 조건은 프로필 필터가 바로 쓸 독립 컬럼이 아니라 서술문에 섞여 있어, 챗봇이 "서해특정해역 조업이세요?" 같은 되물음을 만들려면 별도 파싱이 필요함.
6. [[comparisons/안전장구_구명설비]] 허브가 5개 타법은 상세 비교하면서 정작 어선법 자체의 구명·소방설비(제3조8호) 세부 수치는 고시 미추출로 빈 상태 — 허브의 통합성이 어선법 쪽에서만 깨짐.
7. 「선박법」·「선박안전법」 준용(제37조) 전체 조문을 통합 정리한 페이지가 없어, 준용 범위를 물으면 여러 페이지를 오가며 파편적으로만 답할 수 있음(포괄준용 REVIEW 상태로 남아 있는 것은 스키마 절차상 정상이나, 통합 페이지 부재는 별개 문제).
