### method_notes (8라운드 구체 사례)

1. **[치명적, 신규] 배너버그 = 18/19 canonical 페이지 전량**: `_CHATBOT.md` 3절의 "canonical만 인용" 안전장치가 구현돼도, **페이지 자체가 스스로 "미승인"이라 말하는 배너를 달고 있으면 사용자 신뢰가 흔들린다.** 승급 스크립트가 frontmatter만 바꾸고 본문 배너 삭제를 누락하는 구조적 결함 — 다른 여러 법에서도 반복 확인된 패턴(사용자 프롬프트 확인)이므로 **전역 일괄 수정(모든 법 공통) 권고**: canonical 승급 시 본문 첫 blockquote가 "draft — 미승인"으로 시작하면 자동 제거/치환하는 후처리 스텝 필요.
