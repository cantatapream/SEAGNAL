## 핵심 발견 요약 (먼저 읽을 것)

**1라운드에서 지적한 10개 미수집 뭉치가 전부 해소됐다.** 9개였던 개념 페이지가 **19개**로 늘었고, 신규 10개 페이지(어선건조개조업등록·형식승인및검정·지정사업장·어선거래시스템·법정대리인의무·하역설비확인·검사업무대행·다른법령준용및지도단속·어선중개업·벌칙및과태료체계)가 정확히 1라운드가 지목한 깨진 링크·미수집 조문·collection_hole을 메웠다. 원문(별표1의2·16의2·18의2·19의2, 시행령 별표1의2·1의3) 대조 결과 **숫자·차수·조·항·호 전부 원문과 정확히 일치**했고 환각은 발견되지 않았다.

**행정처분 1~3차 escalation 표(이 법의 핵심 데이터 원천)가 이제 5곳 모두 위키에 존재**하며, 청문 8개 처분을 총괄하는 `[[어선법__벌칙및과태료체계]]` 허브가 신설되어 깨진 링크 4건이 전부 해소됐다. `[[comparisons/안전장구_구명설비]]` 허브에도 어선법 행이 추가되어 1라운드 지적(구 107번 질문, awkward)이 해소됐다.

**남은 진짜 구멍은 성격이 명확히 3가지로 좁혀졌다** — ①고시 수치표 일부가 여전히 이미지(비텍스트)로만 존재해 추출 불가(구명·소화설비 세부 수량, 어선구조기준 전체), ②제39조 수수료 15개 항목 중 1개(건조·개조)만 부분 인용, ③「선박법」·「선박안전법」 본체가 아직 위키에 편입되지 않아 어선법의 포괄 준용(제37조·제49조)이 "이 법이 어느 조문을 끌어오는지"까지는 정리됐으나 그 조문의 실제 내용까지는 확인 불가(이는 어선법 위키의 문제가 아니라 선행 법률 편입 순서 문제로, 페이지 스스로 REVIEW로 정직하게 표시).

### method_notes (구체 미흡 사례 — 2라운드 기준)

1. **제39조(수수료) 15개 항목 중 1개만 인용** — 어선건조·개조업 수수료(별표20 일부)만 [[어선법__건조개조허가]]에 있고, 복원성승인·등록·총톤수측정·검사·형식승인·지정사업장·재검사·정보이용·중개업등록·국제협약검사·발급 등 나머지 14개 항목의 수수료 금액은 위키 어디에도 없음. 사용자가 실제 자주 묻는 "이거 하는데 얼마 드나요?" 질문에 답이 안 됨.
2. **소화기·구명설비 세부 수량표(어선설비기준 제89·104조 등)와 어선구조기준 전체가 여전히 이미지 원본이라 텍스트 미추출** — 1라운드와 동일한 collection_hole 유지. 원본 HWP/PDF 재확보가 전제조건.
3. **`[[comparisons/야간운항장비]]`가 무선설비 페이지에서 "편입 예정"으로 링크되어 있으나 파일이 존재하지 않음** — 신규 발견된 깨진 링크(1라운드에는 없던 항목, 2라운드 신규 설계 과정에서 생김). 사서가 구조는 예고했으나 아직 채우지 않은 상태.
4. **제51조(국가·지자체 벌칙 예외)가 과태료(제53조)까지 면제하는지 조문상 불명확** — 위키가 추측하지 않고 REVIEW로 정직하게 유보한 점은 스키마 원칙에 부합하나, 실제 사용자 질문("공무선 위반해도 과태료는 내나요?")에는 아직 답할 수 없음. 법제처 유권해석 또는 실무 확인 필요.
5. **피한정후견인의 법정대리인 의무 적용 여부**(제42조가 피성년후견인만 명시) — 법 자체의 잠재적 공백일 수 있어 위키가 REVIEW로 정직하게 표시했으나 미해결.
6. **조선소 건조·개조업 등록취소가 지정사업장 지정에 미치는 연동 효과**가 두 페이지 어디에도 서술 없음 — 실무상 같은 사업자가 둘 다 갖는 경우가 흔한데 상호작용이 다뤄지지 않음.
7. **어선중개업자의 어선거래시스템 자료제출 불응 시 제재 공백**(제31조⑤ 관련) — 페이지가 스스로 REVIEW로 인정한 법률 자체의 잠재적 흠결.
8. **검사대행 취소·정지 시 기존 발급 증서의 효력**(소급효 여부)에 대한 서술이 없음.

### wiki_gaps (개념 페이지 자체가 없거나 서술이 완전히 빠진 지점)
- `[[comparisons/야간운항장비]]` 허브 — 무선설비 페이지가 링크만 걸어두고 파일 부재(신규 발견)

### collection_holes (위키가 "고시/별표로 정함"이라 하지만 원문 수치 없음 — 1라운드에서 이어짐)

- 제39조 수수료 — 시행규칙 별표20의 15개 항목 중 14개 미인용

## 1라운드 대비 종합 평가

1라운드 지적사항(10개 미수집 뭉치, 4개 깨진 링크, 8개 collection_hole, 답변방식 2개 weak+1개 missing)의 **압도적 다수가 해소**됐다. 특히 이 법의 핵심 규제 표면(조선소 등록·형식승인·지정사업장·중개업·검사대행·법정대리인·벌칙총괄)이 정확한 조·항·호·금액·차수로 완전히 채워졌고, raw 원문과의 전수 대조에서 **수치 불일치·환각 0건**을 확인했다.

남은 구멍은 성격이 명확히 좁혀졌다 — ①이미지 원본이라 텍스트 자체가 없는 고시 수치(재확보 필요), ②사용 빈도가 낮은 수수료 항목, ③선행 법률(선박법·선박안전법) 미편입에 따른 구조적 대기, ④법 조문 자체의 잠재적 공백(REVIEW로 정직 표시)이다. 이는 "위키가 게을러서" 생긴 구멍이 아니라 "원본 데이터 없음" 또는 "다른 법 편입 순서 대기"로 설명 가능한 종류이며, 사서가 이를 감추지 않고 REVIEW/still_missing으로 표기한 점은 스키마의 환각 0 원칙에 부합한다.
