## 0. 핵심 발견 요약

### 0-1. ✅ 배너버그(8R §0-1, 질문#536) — 완전 해소 확인
8R이 지적한 "canonical인데 본문에 draft 배너" 불일치는 사라졌다. 다만 해소 방식이 "배너 삭제"가 아니라 **4개 페이지를 canonical→draft로 되돌려 배너와 frontmatter를 다시 일치**시키는 방식이었다(`_dashboard/review_queue.md` REVIEW-어선법-04·05·06 + 어선의설비기준 기존 draft 유지). 대상: `건조개조허가.md`·`검사업무대행.md`·`벌칙및과태료체계.md`·`어선의설비기준.md`. 사유는 각 페이지 내부에 **미등록 REVIEW(AI 조문간 유추·일반법리 추정·자기-태깅 미해소)**가 있었기 때문(L-15 위반 재확인). 나머지 15개 canonical 페이지는 배너·상태 일치 확인(grep 전수 재확인 완료).
- **새로운 함의**: `_CHATBOT.md` 3절 "canonical만 인용" 필터가 켜지면, 이 4개 페이지(건조·개조허가/검사업무대행/벌칙총괄/설비기준 — 어선법에서 **가장 무거운 벌칙 조문**과 **설비기준 전체 지도**를 담은 핵심 페이지들)는 **당분간 챗봇 답변 근거에서 빠진다.** 내용 자체는 정확하고 완결돼 있어(REVIEW로 표시된 지엽 부분만 미확정) 실질 정보손실은 작지만, "무허가 건조 시 처벌은?" 같은 통상 질문의 답변 가능성에 영향을 줄 수 있다. **wiki_gaps 신규 1순위로 기록** — REVIEW 항목만 분리해 나머지를 canonical 재승격하는 것이 다음 조치로 바람직.

### 0-2. ✅ 부칙 3641호 페이지간 불일치(8R §0-2, 질문#537) — 완전 해소 확인
`어선등록총톤수.md`·`다른법령준용및지도단속.md` 양쪽 모두 "확보·반영 완료"로 일치. 변경이력에도 8R 해소 기록 확인.

### 0-3. 🆕 신규 collection_hole 발견 — 시행규칙 별표18(자체검사 합격표시 도안)
`지정사업장.md`이 인용하는 시행규칙 별표18("자체검사 합격표시", 제60조의4④ 관련)의 raw 원문을 직접 열람한 결과 **제목 한 줄만 있고 실제 도안·규격 내용이 없다**(`raw/04_선박해운/어선법/별표/시행규칙_별표18.txt`, 4줄 스텁 — 원본이 이미지 첨부일 가능성). 위키는 이미 이 사실을 "재수집 대상"으로 정직하게 적어놓았으나(7R 질문#515 대응 서술), 감사 기준상 이는 **📛 collection_hole**로 정식 집계해야 한다(위키가 "별표로 정함"이라 인용하는데 원문 수치·도안이 없는 경우). 8R까지 collection_holes를 "0건"으로 집계해온 것은 이 항목을 놓친 것 — 9R부터 반영.

### 0-4. 8R 잔존 thin 재확인 — 대부분 불변, 진짜 원문 공백
8R이 마지막까지 thin으로 남긴 #506·#508·#511·#519·#521·#527과 구조적 사유의 #503을 각 페이지 원문으로 직접 재확인한 결과, **전부 불변**(9R 사이에 해당 조문·시행규칙 개정 없음, 원문 재대조로 동일 결론). 아래 §1에서 개별 재확인.

### 0-5. 🆕 무선설비 페이지 — 완전 해소 확인(8R 미언급)
`무선설비.md`을 전문 재확인한 결과, 과거 라운드(3R~8R)가 지적했던 모든 gap(전파법 정의·개설허가·검사절차, 시운전 기간)이 이미 채워져 있고 **더 이상 남은 still_missing 항목이 없다**. 8R이 "완전 정체 6개 페이지" 중 하나로 분류했던 것과 달리, 실제로는 이번 재확인 시점 기준 **완결 상태**로 격상.
