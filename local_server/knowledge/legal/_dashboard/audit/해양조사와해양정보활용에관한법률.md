## 4. 총평 및 잔여 최우선 과제

**7라운드는 6라운드가 예고한 "재빌드 파동 뒤늦은 검증" 패턴이 마침내 잦아드는 국면**을 보여준다 — 이번엔 실질 콘텐츠 변경이 정의허브 1건(E48 해소)뿐이었고 나머지는 인프라성 교차링크 보강이었다. 133건의 non-full 판정이 그대로 유지된 것은 위키가 "정체"됐다는 뜻이 아니라, **최근 파동들이 감사가 지적한 개별 논점보다 인프라(링크망·canonical 승격)에 집중**했다는 뜻으로 해석해야 한다.

**이번 라운드의 진짜 성과는 새 결함 유형의 발견이다**:
1. **wiki_gap(수집됨, 미반영)** — `해양조사·정보업의대가기준.txt`고시가 raw에 이미 있는데 대가기준 개념 페이지가 이를 전혀 쓰지 않은 사례. 지금까지 감사는 "raw에 없다"(collection_hole)만 추적했는데, 이번에 처음으로 "raw엔 있는데 위키가 안 가져다 씀"이라는 **반대 방향 결함**을 확인했다. 이 유형은 회귀검증 루틴에 새 체크포인트로 추가할 것을 제안한다: 사서가 새 raw 파일을 수집한 뒤 "연결까지 완료"인지 별도 확인.
2. **REVIEW 값의 사용자 고지 정책 공백** — `_CHATBOT.md`가 REVIEW 미검증 값을 챗봇이 어떻게 사용자에게 알릴지 규정하지 않고 있음을 처음 확인(E58-E60 클러스터). 이번 라운드에 우연히 발견된 연락처 자기-재플래그 사례가 이 공백을 드러냈다 — 위키의 "정직한 표기"(REVIEW 플래그)가 챗봇 답변 단계에서 사라지면 의미가 없다.

**여전히 방치된 구간(누적)**:
1. **F92(프로필조건 라벨컬럼)** — 5라운드 연속 weak.
2. **B37/D74(부칙)** — 5라운드 연속 진짜 수집 공백. raw API 재수집이 유일한 해법.
3. **N/L절 생활밀착 실무**(N129·N131·N133·W8 등) — 5개 라운드 내내 사각지대.
4. **별표4↔별표5/6 장비 갭 대조표(E18/W3)** — 4라운드째 미작업.
5. **대가기준 고시 미인용(신규, W47-49/E49-51)** — 즉시 반영 가능한 저비용·고가치 항목(고시가 이미 raw에 16줄로 짧게 존재).

**300문항 목표 대비**: 누적 재질문 계보(R4→R5→R6→R7)로 세면 이번 라운드 173건(재질문134+신규39)이며, 신규 소재 발굴이 6R(36건)→7R(39건)로 소폭 반등했다(대가기준·토지출입·시스템 페이지 등 상대적으로 덜 다뤄진 영역을 이번에 겨냥한 결과). 다음 라운드는 (a) 대가기준 고시 반영(가장 저비용·고가치), (b) REVIEW 고지 정책을 `_CHATBOT.md`에 명문화, (c) F92 라벨컬럼화, (d) D74 부칙 재수집(API), (e) 손실보상 협의 불성립 시 절차(E53/W57) 보강을 신규 소재로 권한다.
