# 해양조사와 해양정보 활용에 관한 법률 위키 품질감사 — 3라운드(재감사) 상세 로그

## 0. 2라운드 이후 변화 (먼저 확인 — 놀라울 정도로 광범위한 보완)

2라운드 감사(2026-07-16) 직후 위키가 **적극적으로 보완**됐다. 신규 페이지 2개(전문교육기관지정과업무정지, 해양예측정보의생산)가 생성됐고, 기존 페이지 다수에 2라운드가 지적한 collection_hole·missing이 반영됐다. 확인된 주요 보완:

| 2라운드 지적 | 보완 여부 | 확인 |
|---|---|---|
| 전문교육기관(제29조④~⑥, 별표3) 완전 미반영 | ✅ 해결 | 신규 페이지, 지정요건·1~3차 처분표·1년 산정기간·청문공백 모두 반영 |
| 해양예측정보(제17조, 이안류) 완전 미반영 | ✅ 해결 | 신규 페이지, 기상청과의 경계까지 명시 |
| 처벌 없는 행정조항 7개(제14·15·18·19·40·53·59조) 미반영 | ✅ 해결 | 신규 페이지 "처벌없는행정조항모음", 제59조 vs 제60조 방향 혼동도 해소 |
| 시행령 별표5(업종별 업무범위) 미반영 | ✅ 해결 | 해양조사정보업등록.md에 표 전체 반영, "위성사진 판매" 등 예시 답변 가능 |
| 시행규칙 별표8(사본심사 수수료 계산식) 미반영 | ✅ 해결 | 일반수로측량공사후측량의무.md에 계산식·구성요소 반영 |
| 시행규칙 별표9(경력증·등록·등록증 수수료) 불균등 반영 | ✅ 해결 | 3개 페이지에 3천원/2만원/2천원 모두 반영 |
| 성능검사확인증 미부착 처벌 불명 | ✅ 해결 | "처벌 없음"을 정직하게 확인·서술 |
| 부칙·경과규정 존재여부 미확인 | ✅ 해결(수집단계 이슈로 명확화) | 정의허브.md에 "raw 자체에 부칙 없음, 수집단계 재확인 필요"로 명시 |
| 이미지전용 고시 2건 | ✅ 해결(수집단계 이슈로 명확화) | 동일하게 still_missing 명시, 향후 재조사 방지 |
| 재정경제부장관 개명추적 미이행 | ✅ 해결 | 해양조사연구개발과대가기준.md, 기획재정부로 개명추적 완료(REVIEW 완화) |
| 성능검사·영리사본 수수료 위임 고시 미수집 확인 | ✅ 확인(still_missing 유지) | 원본 고시 자체가 raw에 없음을 명시적으로 확인 |

**총평**: 2라운드가 지적한 핵심 구멍(특히 제3의 행정처분 축·업무범위·수수료 3종 세트)이 **거의 전부 회귀 테스트를 통과**했다. 다만 3라운드에서 더 깊이 들어가 보니, ① 절차법 일반론(불복·시효·경합) 공백은 여전히 방치돼 있고, ② 페이지가 개별적으로는 완비돼도 **페이지 간 통합 비교(3개 사업유형 처벌축 비교, 결격사유 비교)가 없어** 여전히 답이 끊기는 지점이 있으며, ③ 협회·판매대행업 관련 세부(위탁계약 기간·판매가격 재검토주기)처럼 **고시 반영이 들쭉날쭉한 잔여 구멍**도 발견됐다. 아래 상세.
