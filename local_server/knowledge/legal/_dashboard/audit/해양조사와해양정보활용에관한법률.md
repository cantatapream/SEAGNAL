## 4. 총평 및 잔여 최우선 과제

**6라운드도 5라운드와 같은 패턴을 재확인했다** — 감사 리포트가 저장되는 시점과 사서의 자동 파이프라인(`collect6`, "35-wide 재빌드") 실행 시점이 어긋나, 매 라운드 직후 몇 시간~하루 안에 추가 보완이 들어오고 다음 라운드가 그것을 최초로 검증하는 구조가 반복되고 있다. 이번엔 **collection_hole 3건(수수료 고시)과 2건(이미지 전용 고시)이 모두 실제로 해소**됐음을 확인한 것이 가장 큰 성과다.

**신규로 발견한 문제 — 위키 내부 기록의 정확성 자체**: `정의허브.md`의 2026-07-18 changelog가 "부칙 재수집 해소됨"이라고 적었으나 raw 원문에는 실제로 부칙이 없다(0절). 이는 **처음으로 확인된 "메타(changelog) 오기" 유형의 결함**이다 — 지금까지의 감사는 위키 "본문" 서술의 정확성만 봤는데, **changelog(변경이력) 자체도 검증 대상**이어야 함을 시사한다. 다음 라운드부터 changelog 서술도 원문 대조 검증 항목에 포함할 것을 제안한다.

**여전히 방치된 구간**:
1. **F92(프로필조건 라벨컬럼)** — 4라운드 연속 weak. 이 법의 특성(톤수 무관 조문 다수)을 감안해도 "항만구역 안/밖" 같은 지역 조건 정도는 컬럼화가 가능한데 손대지 않고 있음.
2. **D74/B37(부칙) — 진짜 수집 공백**: raw API 재수집이 필요한 유일하게 남은 순수 수집단계 이슈. 4~6라운드 연속 그대로이며, 이번엔 위키가 "해소됐다"고 잘못 기록까지 했으므로 우선순위를 올려야 한다.
3. **N/L절 생활밀착 실무**(등록증 재발급 N129, 강등 재교육 N133, 근무처변경소급 N131, 겸업 인력공유 W8 등) — 4개 라운드 내내 거의 손대지 않은 사각지대.
4. **별표4(등록기준 장비)↔별표5/6(성능검사 장비) 갭 대조표** — 3라운드째 "저비용·고가치"로 지목됐으나 아직 미작업(E18/W3).
5. **산식 기호 정의(E48)** — 이번 라운드 새로 발견. OCR로 산식 자체는 옮겨졌으나 변수 기호(S1·P1·P0 등)의 뜻풀이가 없어 전문가도 산식을 못 씀 — 원본 고시에 기호 정의가 있는지 재확인해 보강 필요.

**300문항 목표 대비**: 누적 재질문 계보(R4→R5→R6)로 세면 이번 라운드 162건(재질문126+신규36)이며, 라운드를 거듭할수록 "신규 콘텐츠 소재가 줄어드는" 자연스러운 수렴 현상이 보인다(5라운드 신규65건 → 6라운드 신규36건). 다음 라운드는 (a) F92 라벨컬럼화 실제 착수, (b) D74 부칙 재수집(API 레벨), (c) N/L절 생활밀착 세부, (d) 별표4↔5/6 장비 갭 대조표, (e) changelog 자체의 원문 재대조를 신규 소재로 삼을 것을 권한다.
