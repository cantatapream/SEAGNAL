## 7. 답변방식 준수 감사 — 5R 갱신분

4R의 method_compliance 판정(정의우선ok·행정처분차수ok·벌칙항별구간ok·처벌정밀도ok(부분weak)·타법연결ok·프로필조건weak·점진공개구조ok·출처표기ok(경미한예외))은 **5R 재확인 결과 대체로 유지**된다. 5R에서 새로 발견한 사항만 추가:

- **처벌정밀도**: 4R이 지적한 "과태료 감경사유 5개 호 요약" 문제(E36/E37)는 **완전히 해소 확인**(raw 원문과 문구까지 일치 대조 완료) — 이 항목은 4R의 weak에서 **ok로 격상**.
- **출처표기 — 신규 경미 발견**: `연안사고안전관리규정과위험구역관리.md`·`연안사고예방기본계획및협의회.md`·`연안순찰대와연안안전지킴이.md` **3개 페이지의 frontmatter `updated` 필드(2026-07-15)가 실제 최신 변경이력(2026-07-17 항목 존재)과 불일치**한다(파일 직접 대조로 확인). 내용 자체는 옳으나 메타데이터 정합성 규율(SCHEMA 8절 체크리스트 "출처·갱신일 정확성")이 느슨해진 사례 — `method_notes`에 반영.
- **프로필조건**: 4R의 weak 판정(톤수 컬럼 상시 공란, 지역 컬럼도 출입통제 페이지 1곳뿐) **5R도 동일하게 weak 유지** — 이번 라운드 수정분 어디에도 톤수·지역 컬럼 보강은 없었음(수정된 10개 페이지 모두 확인).
- **점진공개구조**: 안전교육 수수료(해경직접 8,000원 vs 위탁기관 7,500원) 트리거는 여전히 우수 사례로 유지. 신규로 확인한 것은 **행정처분(위탁기관 지정취소·업무정지) 1~4차 escalation 표**가 5R에서도 그대로 완비 — ok 유지.

## 8. 요약 통계 (5라운드)

- 회귀 재검증: 4R OPEN 122건 전량 → **완전 FIXED 약 23~25건 + 부분FIXED(구조화, 실질 OPEN) 약 15건 + 완전 OPEN 유지 약 82~84건**(개선율 약 31%, 3R→4R 23%보다 상승)
- 신규 질문: 30건(전문가10·일반인10·종사자10) → full 7건 · thin 4건 · missing 18건 · awkward 1건
- 이번 라운드 실측 총 문항: **152건**(재검증 122 + 신규 30)
- 누적(1~5라운드, 중복 제외 추정): 약 500문항 규모(1R 111 + 2R 169 + 3R 신규 111 + 4R 신규 30 + 5R 신규 30, 재검증은 중복 집계 제외)
- **핵심 패턴(1~5R 일관)**: 이 법의 "진짜" 수집 구멍(5개 고시 별표 본문)은 5라운드 내내 변화 없음 — raw 재수집(HWP/PDF 원본 재다운로드) 없이는 구조적으로 해소 불가능. 반면 "규정이 없다는 사실 자체를 명시하지 않은" 유형의 missing/thin은 라운드가 거듭될수록 "확인됨—규정없음" 패턴으로 빠르게 전환되고 있어, **위키의 실질 커버리지는 향상 중이나 순수 법리판단·통계/정보공개 채널·서식/송달 일반 3개 영역은 구조적으로 정체**되어 있다.

## 3. 답변방식 준수 감사 — 6R 갱신분

5R의 method_compliance 판정(정의우선ok·행정처분차수ok·벌칙항별구간ok·처벌정밀도ok(5R서 완전 ok로 격상)·타법연결ok·프로필조건weak·점진공개구조ok·출처표기ok(경미한예외))은 **6R 재확인 결과 변화 없이 유지**된다(5R 이후 실질 콘텐츠 변경이 3개 페이지의 서식링크 추가뿐이었으므로 당연한 결과). 6R에서 새로 발견한 사항만 추가:

- **서식표기(신규 항목, 긍정적 진전)**: 5R까지는 없던 항목 — 6R 확인 결과 14개 페이지 중 3개(`연안체험활동신고`·`안전교육위탁기관지정및처분`·`안전점검및시정명령`)에 `서식링크` frontmatter + "제출 서식(다운로드)" 절이 신설돼 `_CHATBOT.md` 5-5(서식 원버튼 다운로드) 요건을 충족하기 시작했다. 나머지 11개 페이지는 서식(별지)이 없거나 아직 미반영이라 이 항목은 **적용 대상 페이지 한정 ok, 전체로는 부분 적용**으로 본다.
- **처벌정밀도**: 5R에서 ok로 격상된 상태 유지(6R 재확인 결과 변화 없음).
- **프로필조건**: 5R의 weak 판정 **6R도 동일 유지** — 3개 페이지 수정분 어디에도 톤수·지역 컬럼 보강은 없었음(서식링크만 추가).

## 3. 답변방식 준수 감사 — 8R 갱신분

7R의 method_compliance 판정(정의우선ok·행정처분차수ok·벌칙항별구간ok·처벌정밀도ok·타법연결ok(경미갭)·프로필조건weak·점진공개구조ok·출처표기ok(신규심각도상향 "raw-위키 동기화" 이슈))에 대해 8R에서 변경·추가되는 사항:

- **출처표기 — "raw-위키 동기화" 이슈 해소**: 7R이 지적한 "raw는 갱신됐는데 위키가 모르는 활성 오답" 상태가 **완전히 해소**됨을 이번 라운드에서 원문 대조로 확인(1-A절). 이 항목은 7R의 "심각도 상향"에서 **8R "ok로 복귀"**로 정정한다.
- **처벌정밀도·타법연결**: annex 4종이 벌칙·과태료 조문이 아니라 안전기준·명단이라 직접 관련 없음(불변, ok 유지). 다만 신규 발견 **E88(KS 규격 원문 미수집)·E94(자격기본법 원문 미수집)**은 "인용은 있으나 원문까지 확보 못한" 경미한 타법연결 갭으로 `method_notes`에 추가.
- **프로필조건**: 7R의 weak 판정 **8R도 동일 유지** — annex 4종 모두 톤수·조업형태·지역 컬럼과 무관한 시설·명단 자료라 이 항목 개선과는 무관.
- **소관부서·연락처 필드 — 신규 긍정 발견**: `__수중단체지정명단별표.md`가 frontmatter에 `소관부서: 해양경찰청(해양안전과)`·`연락처: 032-835-2239`를 명시(SCHEMA 0-A "소관부서·연락처 필드" 요건 충족). 다른 3개 annex는 소관부서만 있고 연락처 필드가 빠져 있어(`__위험구역평가기준별표`·`__안전관리시설물제작기준별표`·`__위탁기관명단별표`) **부분 적용**으로 본다.
- **정의우선·행정처분차수·벌칙항별구간·점진공개구조**: 변화 없음(ok 유지, 이번 라운드 콘텐츠와 무관).

## 3. 답변방식 준수 감사 — 9R 갱신분

8R의 method_compliance 판정(정의우선ok·행정처분차수ok·벌칙항별구간ok·처벌정밀도ok·타법연결ok(경미갭 E88·E94)·프로필조건weak·점진공개구조ok·출처표기ok(7R "raw-위키 동기화" 문제 해소 확인))에 대해 9R에서 변경·추가되는 사항:

- **★신규 항목 제안 — "canonical 배포가능성"(출처표기와 별개 축)**: 이번 라운드 헤드라인 발견(0절 #3)이 기존 8개 체크 항목 어디에도 딱 들어맞지 않는다 — `벌칙및과태료체계총괄.md`은 **내용은 충실**(정의우선ok·처벌정밀도ok·타법연결에 「지방행정제재법」·「행정조사기본법」까지 연결)하지만 **status가 draft**라 `_CHATBOT.md` 3절 "canonical 필터"가 켜지면 이 법의 **형벌·과태료 총괄 답변 전체가 답변 근거에서 빠진다.** 이는 "위키에 답이 있는가"(기존 체크)와 "그 답이 실제로 사용자에게 나갈 수 있는가"(배포가능성)가 별개 질문임을 드러낸 사례다. `method_notes`에 **"canonical 배포가능성 — weak(허브 페이지 1개 draft 상태)"**로 신규 반영을 권고한다.
- **정의우선·행정처분차수·벌칙항별구간·처벌정밀도**: 변화 없음(ok 유지) — 이번 라운드 신규 발견(위탁기관 18개교 교체 등)은 이 항목들과 직접 관련 없음.
