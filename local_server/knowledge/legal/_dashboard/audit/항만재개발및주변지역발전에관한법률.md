## 3. ★답변방식 준수 감사 (4단계 — 5라운드 재평가)

| 항목 | 4R 판정 | 5R 판정 | 근거 |
|---|---|---|---|
| 정의우선 | ok(3연속) | **ok (4라운드 연속 유지)** | 새 섹션("사업계획 공모·평가·협상 절차")이 정의블록 뒤에 붙긴 했으나 정의·적용범위·예외 자체의 순서·내용은 훼손 없음 |
| 행정처분차수 | ok(유지) | **ok (유지)** | 1~3차 이상 구간 정확, 4차 없음 지어내지 않음. 변동 없음 |
| 벌칙항별구간 | na(유지) | **na (유지)** | 변동 없음 |
| 처벌정밀도 | ok — 미세누락 미해결 | **weak (하향)** | **3라운드째 동일 지적**(3R→4R→5R)이 계속 미해결이면 "미세 누락"이 아니라 구조적 약점으로 봐야 한다 — 시행규칙 별표0 일반기준 **가목**(경합 시 무거운 기준 적용)이 5R 직접 원문대조로도 위키에 없음을 재확인(§1-A/U섹션 401~412). 3라운드 연속 미이행이므로 ok에서 **weak로 하향** |
| 타법연결 | weak(4R 하향) | **weak (유지, 개선 없음)** | 5R에서 grep 재확인 결과 경합 타법(해양환경관리법·연안관리법·어촌어항법·신항만건설촉진법 등) 매칭 **여전히 0건** — 4R 지적 이후 아무 개선 없이 그대로. 오히려 5R에서 2차 수집 구멍(예규 86호)까지 새로 발견돼 타법·타문서 연결의 구조적 약점이 심화됨 |
| 프로필조건 | ok(유지) | **ok (유지)** | 변동 없음, 이 법 특성상 톤수 대신 사업구역·자격요건 컬럼이 실질 프로필조건 역할 |
| 점진공개구조 | ok(유지) | **ok (유지)** | 행정처분·과태료·생계지원금 차수/구간형 데이터 유지, 신규 배점표도 구조화된 표 형태로 반영(점진공개에 활용 가능) |
| 출처표기 | ok(유지) | **ok (유지)** | 신규 섹션(배점표·업무담당관·협상단 등)도 전부 `(고시 제N조)` 형식 출처 부착 확인(471·475·476) |

**5R 신규 지적**: 6개 항목(정의우선·행정처분차수·벌칙항별구간·프로필조건·점진공개구조·출처표기)은 **4라운드 연속 안정**. 반면 **처벌정밀도는 3라운드째 동일 결함(가목 누락)이 반복돼 4R의 "ok, 미세누락 있음" 평가를 유지하기 어려워 5R에서 weak로 하향**했다. **타법연결은 4R의 weak가 5R에서도 전혀 개선되지 않았고**, 오히려 새 콘텐츠(배점표)를 채우는 과정에서 **2차 수집 구멍**(예규 86호 미수집)이라는 같은 계열의 새 문제가 드러났다 — 이는 "위키가 인용하는 문서는 그 문서까지 실제로 읽어야 한다"는 `_SCHEMA.md` 0-A·전파 원칙("타법 인용은 링크만 걸고 끝내지 않는다")이 **행정규칙 내부 인용(예규 인용)에도 동일하게 적용돼야 함**을 보여주는 사례.
