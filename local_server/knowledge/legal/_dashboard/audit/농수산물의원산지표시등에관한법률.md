## 4. 방법 미흡 사례 상세 (method_notes)

1. **벌칙 표 형식 불일치(〰 awkward)**: `_SCHEMA.md` 4-B는 `| 조·항 | 형량/금액 | 성격(벌칙/과태료) | 대상 위반(수) |` 4컬럼 고정 표를 요구하나, 실제 3개 concept 페이지는 각기 "품목×차수 매트릭스"(수산물/음식점 페이지)와 "구분×형량"(거짓표시 페이지)으로 서로 다른 표 구조를 씀. 내용은 맞지만 페이지 간 통일성이 없어 자동 파싱(챗봇 검색 엔진)이 어려울 수 있음.
2. **개념 페이지 간 정보 분산**: `수산물원산지표시.md`(일반 판매자용)에는 `## 행정처분 체계` 섹션이 없음. 시정명령 외 "거래행위 금지"까지 가능하다는 사실은 statute 페이지에만 있어, 이 개념 페이지만 검색·인용될 경우 반쪽 답이 나올 위험(80번 질문 참조).
3. **표시대상 품목 고시 미인용(collection_hole)**: `(농림축산식품부)농수산물의원산지표시요령.txt`(raw에 이미 수집됨, 수산물 192개 분류·수입 24개 HS류)가 법·시행령·시행규칙 어디의 위키 페이지에서도 인용되지 않음. "공동고시로 정한다"는 서술만 반복됨 — 정작 그 고시가 이미 raw에 있는데 편입이 안 된 전형적 사례.
4. **뭉개진 과태료 금액**: 대규모점포·방송채널 방치(제18조①3·3의2호), 유통이력 관련(제18조②2~5호), 교육 미이수(제18조②1호)의 1~4차 실제 금액이 statute 페이지에 "1천만원 이하"/"500만원 이하"로만 요약되고 별표2 원문 숫자가 옮겨지지 않음. 넙치·쇠고기 등 표시 관련 항목만 정밀 표가 있고, 그 외 항목은 상한선만 존재.
5. **가공품 원료 배합비율 규칙 전무**: 시행령 제3조②(98% 이상 1개/두 개 합 98% 이상 2개/그 외 3개까지, 김치류 특칙)가 표시대상 판정의 핵심 로직인데 위키 어디에도 없음. 수산물 가공품(예: 어묵, 젓갈)의 원산지 표시 개수를 묻는 질문에 답 불가.
6. **혼합 표시 규칙 전무**: 시행령 별표1 다목(원산지 다른 동일품목 혼합 시 표시법)이 위키에 없음.
7. **포상금·명예감시원·심의회·정보제공(제10~12조) 전면 누락**: 법 제3장(보칙) 대부분이 위키에 반영되지 않음. 처벌·표시 의무만 편중되어 다뤄지고, 사용자가 "신고하면 얼마 받나"를 물으면 답이 아예 없음.
8. **구어 매핑 미확인**: "광어=넙치", "우럭=조피볼락" 같은 어종 구어-법률명 매핑이 이 3개 개념 페이지 안에는 없음(`wiki/_glossary.md` 자체는 이번 감사 범위에서 별도 확인 안 함 — 후속 점검 필요).

## 6. 결론

이 법의 위키는 **표시의무·거짓표시 처벌(3축: 형벌/과징금/과태료)이라는 이 법의 핵심 위험 구간에서는 매우 정밀**하다(넙치 등 20종 품목별 1~4차 과태료, 과징금 배율표, 초범/재범 형량 분리 모두 raw와 정확히 일치 확인). 그러나 **법 제3장 보칙(심의회·명예감시원·포상금·정보제공)과 표시대상 결정 로직(고시 품목 목록, 가공품 배합비율 규칙, 혼합표시 규칙)이 통째로 빠져** 있어, "이 어종도 표시대상인가", "신고하면 얼마 받나", "젓갈 원료는 몇 개까지 표시하나" 같은 실사용 질문에는 답을 못 한다. 우선순위: (1) 고시 품목 목록 편입(collection_hole 해소), (2) 시행령 제3조② 배합비율 규칙 편입, (3) 제10~12조 보칙 페이지 신설 또는 statute 페이지 보강.
