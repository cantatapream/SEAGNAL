1. **10R 이후 실제 변경 파일부터 git log로 식별**: `git log --since="2026-07-29"`로 이 법 관련 wiki 파일을 전수 확인한 결과, 10R-후속(2026-07-29) 이후 **3개 concept 파일만** 실질 변경됨 — ①`수상레저사업.md`(2026-07-30 H-33 이용요금 신고·게시 의무 추가, 2026-08-05 Track B 과태료 금액 정정·안전검사원 교육내용 추가, 2026-08-05 Track C **인명구조요원 관련 중대 정정** — 아래 §1 참조, status **canonical→draft 환원**) ②`수상안전교육.md`(2026-07-30 **환각 발견·시정**, 2026-08-05 과징금 절차·안전검사원 교육내용 추가) ③`안전준수의무.md`(2026-08-06 금지구역 고시 개수 "18개서→20개서" 정정). **나머지 3개 concept(조종면허·주취중조종·보칙및협회)·17개 annex·3개 comparison은 10R-후속 이후 완전히 무변경**임을 git log로 확인 — 이 파일들에 뿌리를 둔 회귀 항목은 재원문검증 없이 그대로 이월한다(10R §0-2와 동일 절차, 근거 재확인 완료).
2. **★핵심 발견 — 10R 자신이 "환각(hallucinated) 법령개정"에 속아 false full 판정을 냈다**: 10R §1 R3("종사자 재교육 평가배점 이론50·실기35·교육태도15 → 지금도 그런가요?")는 "2024-11-26 개정(해양경찰청고시 제2024-11호)으로 교육태도 폐지, 이론50·실기50"이라며 **✅full(정정확인)**으로 판정했다. 그러나 이 "2024-11-26 개정"·"고시 제2024-11호"라는 사실 자체가 **raw 전체 어디에도 없는 완전한 창작**이었음이 2026-07-30 위키 자체 재대조(사서 세션, 감사 아님)로 드러났다 — raw 원문은 처음부터 끝까지 "교육태도" 항목·별표4·별표5를 그대로 유지하고 있었다. 10R 감사는 이 개정 자체를 의심하지 않고 위키의 자기보고(remediation changelog)를 그대로 신뢰해 통과시켰다. **이는 감사 방법론의 구멍이다**: "9R 이후 실제 변경분만 git log로 골라 재검증"하는 절차는 위키가 스스로 "개정 반영"이라고 적어놓은 항목을 사실로 전제하고 검증했을 뿐, **그 "개정"이 실재하는지 자체는 raw 원문 전체 재검색으로 대조하지 않았다**. 이번 12R은 이 구멍을 메우기 위해 §1에서 10R의 모든 "✅full" 판정 중 raw의 "개정 이력"을 인용한 항목(R2·R3·R5·R6·R7·R8)을 원문 재검색으로 다시 대조했다. 결과: R5·R6(수상레저기구 종류 고시 2024-12-02 개정)는 raw에 발령일자·조항이 실제로 존재해 **진짜**임을 재확인(그대로 full 유지). R2·R7·R8은 부분 정정 필요(§1 참조). R3만 순수 환각이었다(다만 위키 자체가 이미 시정 완료, 아래 참조).
3. **위키의 자율 시정(2026-07-30·2026-08-05) 자체는 감사가 아니라 별도 사서 세션(Track B/C)이 한 것** — 이번 12R 감사는 그 결과물을 원문과 재대조해 "정말 고쳐졌는지" 독립 검증했을 뿐, 이 감사 세션이 직접 고친 것은 없다(카파시 4번 — 검증 가능한 성공기준 재확인).
4. **신규 90문항 중 70문항만 채택**(§3): 별표2(필기과목)·별표3(실기기구규격)·보칙(수수료·기본계획·협회·안전협의회·전산시스템·공무원의제)·주취중조종(약물·죄수관계)·마리나 비교표·수상구조사 비교표 등 10R까지 후보로만 남아있던 영역을 훑어 police 24·layperson 24·worker 22 = 70개를 뽑았다. 20문항은 이미 커버된 논점의 표현만 다른 사실상 중복으로 판단해 카파시 2번(padding 금지)에 따라 제외했다.
5. **300문항 하드목표 대비 미달 사유(H-21 정직 표기)**: 회귀재검증 41 + 신규 70 = **111문항**. 12라운드 연속 감사·remediation을 거쳐 6개 concept 중 5개 canonical·annex 17/17 canonical로 이 위키의 규제표면은 사실상 소진 상태다(10R도 87신규로 동일 사유 기록). 남은 미탐색 영역은 §7에 명시.
6. **누적**: 10R까지 573건 + 12R 111건 = **누적 684건**.
