## 4. method_notes

1. **12R 감사 직후 자율진행 파이프라인(통합수정→lint_full)이 12R의 지적 다수를 실제로 반영했음을 13R이 확인**했다 — R2 인과관계 보강, NP15/NL11/NW7 gap 완전 해소(부칙 경과조치), NL10/NL23/NW17 scope_out 3건 그레이스풀 처리(§6-B 실사례). 감사→수정→재검증 루프가 정상 작동 중임을 실측으로 재확인.
2. **annex 원문 직접 재대조로 12R의 과소평가 1건(NP19) 해소** — 12R은 시행령 별표9 "시험관 4명 이상" 조항을 "불명확"으로 thin 판정했으나, 13R이 annex 파일을 직접 열어 재확인한 결과 표준 법령 어법상 명확히 해석 가능함을 확인해 full로 상향. **교훈**: annex 파일을 인용 링크(`[[...]]`)로만 참조하고 실제로 열어보지 않으면 이런 오판정이 반복될 수 있다 — 향후 감사도 annex는 링크만 보고 넘기지 말고 실제 내용을 열어 확인해야 한다.
3. **canonical/draft 페이지 단위 이진 상태관리 문제가 13R에서도 여전히 미해결**로 확인됨(§3) — Phase F(관리자 검증 UI) 착수 전까지는 구조적 한계로 남을 전망.
4. **13R은 300문항 하드목표에 미달**(총 169건: 회귀54+신규115) — annex 17개 전량을 이번에 직접 열람해 세부 항목을 최대한 문항화했으나(12R까지 다루지 않은 새 소재), 6개 concept·17개 annex·3개 comparisons로 구성된 이 위키의 규제표면은 13라운드째 누적으로 상당히 소진된 상태다. 다음 라운드 신규 소재는 §7 참조.
