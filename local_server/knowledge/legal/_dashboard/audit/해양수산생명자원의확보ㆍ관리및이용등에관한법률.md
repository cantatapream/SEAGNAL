## 0. 총평 (먼저 읽을 것)

1. **★핵심 회귀 성공 — 6라운드가 지적한 두 최우선 항목이 모두 해소됨**:
   - **(a) 공소시효(형사소송법 제249조) cross-page 전파 — 마침내 반영.** 6라운드까지 2회 연속(5·6라운드) 미반영이던 항목이, 이번 라운드 대상 기간(07-19)에 외국인등획득허가·국외반출승인 두 페이지 모두에 「형사소송법」 제249조 타법연결 행이 추가됐다. raw 재대조 결과 산정 로직도 정확함을 확인: 제40조(5년 이하 징역=장기10년 미만→제4호)=**7년**, 제41조제1항(3년 이하 징역=장기5년 미만→제5호)=**5년**, 제42조(2년 이하 징역=장기5년 미만→제5호)=**5년**(비밀엄수벌칙 페이지 기존 계산과 일치). 3개 페이지 산정치가 서로 정합적이라 cross-page 동기화가 실제로 완결됐음을 확인했다(단, AI 종합연결이라 ⚠REVIEW 유지는 타당·유지).
   - **(b) NA7(시행령 제6조①1~6호 분석·평가 항목·②공고·③협조요청) — 반영 완료.** 기본계획및인프라 페이지에 6개호 전문("①명칭·학명·서식지 ②유전체·전사체·단백질체 ③생육·생산 보존 ④질병·저항성 관리 ⑤산업적 유용성 ⑥그 밖의 필요사항"), 공고(홈페이지, 시행령 제6조②), 협조요청(관계기관·전문가, 제6조③)이 그대로 반영됨을 raw `시행령.txt` 제6조 재대조로 확인. 6라운드가 지적한 "메모만 있고 실제 반영 안 됨" 패턴이 이번엔 실제로 고쳐졌다.
   - 두 항목 모두 **격상**: 관련 재질문 3건을 ❌missing/⚠thin → ✅full로 판정(§1).
2. **여전히 미해소 — 4~7라운드 연속 방치되는 항목 2건**:
   - **R22(고시 제4조 예산운용계획서 vs 시행령 제14조② 2021년 삭제 불일치)** — 기탁등록보존기관 페이지가 6라운드 이후 전혀 갱신되지 않아 그대로. **이번이 5라운드째 미해소**(3·4·5·6·7라운드).
   - **분양승인 고시 제3조③ vs 시행규칙 별표2 분양수량 불일치**(최대 10배차) — 분양승인 페이지도 갱신 없어 그대로. 6라운드에 처음 정량 확인된 이후 이번이 2라운드째 미해소.
3. **신규 발견 3건(7라운드)** — 모두 raw에 규정이 없어 확인 자체가 불가능한 "구조적 공백"이지 사서 누락이 아님:
   - 기탁등록보존기관 **시설·장비 변경 시 재신청/변경신고 의무 조문 부재**(원문에 변경신고 절차 없음).
   - 등급부여심의위원회 **위촉직 위원 제척·기피·회피(이해충돌 방지) 규정 부재**(고시 제6·7조는 구성·의결정족수만).
   - 국립수산과학원(위임)·국립해양생물자원관(위탁) **관할 경계가 겹치는 자원의 판정기준 부재**(시행령 제29조가 "분야 한정"이라고만 함).
4. **긍정적 재확인** — 이번 라운드가 신규로 검증한 "미수범 불처벌 원칙"·"필요적 몰수"·"임의적 전치주의(불복절차)"는 세 벌칙 페이지(외국인등획득허가·국외반출승인·비밀엄수벌칙) + 절차 페이지(기탁등록보존기관·분양승인) 전부에 **일관되게 cross-page 동기화**돼 있음을 확인(4라운드 NJ4·NB6·NB7 대응이 계속 견고).
5. **status: draft 7/7 — 7라운드째 미승인.** 내용 완성도는 이번 라운드로 더 높아졌음(공소시효·NA7 해소)에도 승인 절차 병목은 그대로.
