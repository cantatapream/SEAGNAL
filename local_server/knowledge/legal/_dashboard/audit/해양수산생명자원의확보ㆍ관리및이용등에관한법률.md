## 0. 총평 (먼저 읽을 것)

1. **위키 커버리지가 법 전체의 일부(약 3개 조문군)에만 그친다.** 이 법은 총 44개 조문(§1~44)인데, 개념 페이지는 §11~14(외국인등 획득허가), §20~21(분양승인), §22~23(국외반출승인) 세 묶음만 다룬다. §17~19(책임기관·기탁등록보존기관 지정·취소, 행정처분 1~3차 별표 보유), §34·35·42(비밀엄수 벌칙 2년/2천만원), §7~10·24~33(조사·기본계획·이익공유·전통지식·통합정보시스템 등 정책성 조문)은 **개념 페이지가 아예 없다.**
2. **3개 페이지 모두 `status: draft`다.** `_SCHEMA.md` 5절 규정상 draft는 "챗봇이 인용하면 안 됨". 즉 지금 상태로는 이 법에 대해 챗봇이 **원칙적으로 아무 것도 인용해서는 안 되는 상태**다(내용 품질과 별개의 승인 프로세스 문제). 아래 판정(✅full 등)은 "위키에 내용이 있는가"를 기준으로 하되, 이 draft 문제는 별도로 `answer_issues`에 기록한다.
3. **3개 페이지 자체의 내용 품질은 스키마 형식(정의→적용범위·제외→예외→의무→벌칙체계→행정처분체계→근거조문→타법연결→관련개념→변경이력)을 잘 지켰다.** 항별 벌칙 구간 분리, 조·항·호·금액 정밀 인용, 타법 연결 REVIEW 플래그 등은 양호.
4. **collection_hole 1건**: 국외반출승인대상 목록 고시(`국외반출승인대상해양수산생명자원지정고시.txt`)에 "[별표] 국외반출 승인대상 해양수산생명자원 목록" 표제만 있고 **실제 종 목록 표 본문이 raw에 없다**(추출 누락으로 추정). 위키 페이지도 이 고시를 인용하지 않고 있어 이중으로 비어 있다.

### method_notes (구체 미흡 사례)

1. `status: draft` 3/3 — 스키마 5절상 draft는 "챗봇이 인용하면 안 됨". 내용 품질은 양호하나 **승인 절차(사람 확인 후 canonical 전환)가 이 법 전체에서 진행되지 않아 실사용(챗봇 인용) 자체가 불가**한 상태. REVIEW 대시보드에 이 3개 페이지에 대한 승인 요청이 등록됐는지 별도 확인 필요.
2. 행정처분 차수표 누락: 시행령 별표1(기탁등록보존기관 지정취소기준, 나·다목 "시정명령→시정명령→지정취소") 원문이 raw에 온전히 있는데도 `## 행정처분 체계`로 옮긴 개념 페이지가 없음.
3. 톤수 조건 컬럼은 이 법 성격상 원천적으로 없음(na)이 맞으나, "지역(EEZ 내/외)" 조건이 산문 서술이라 프로필 필터용 구조화 컬럼이 아님.
4. 국외반출승인대상목록 고시 원문 자체가 별표 표제만 있고 표 본문이 없음(수집 단계 구멍, `collection_holes` 참고) — 위키도 이 고시를 아예 인용하지 않아 이중 공백.
5. §34·35·42(비밀엄수 벌칙, 2년/2천만원)는 이 법에서 유일하게 형벌이 걸리는 세 번째 벌칙 조문인데 개념 페이지가 전혀 없어 "이 법 벌칙 전체"를 묻는 질문(#74)에 위키만으로 완전한 답이 불가능.
6. §17~19(책임기관·기탁등록보존기관 지정·취소) 전체가 개념 페이지 미존재 — 분양승인 페이지 안에 "행정처분 체계 (분양기관 대상)" 절로 일부만 곁다리로 들어가 있어, 정작 "우리 기관도 지정받고 싶은데" 같은 T1 질문(#60~71)에 답할 근거가 위키에 없음.
7. 정의(제2조) 자체를 다루는 허브 개념 페이지 부재로, "정의가 정의를 부르는" 사슬(수산자원관리법과의 경계 등)이 스키마 0순위 원칙대로 진행되지 않음.
8. 타법 연결 중 "raw 미수집, 편입 예정"으로 REVIEW만 걸린 항목(생물다양성법, 국립해양생물자원관법)은 링크만 걸고 실제 조문을 못 가져온 상태 — 스키마 0-B 원칙(반드시 읽어서 가져온다) 미이행이 대시보드에 후속 작업으로 등록됐는지 확인 필요.
