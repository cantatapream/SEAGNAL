## 0. 총평 (핵심 발견)

이 법은 raw 수집(원문) 자체는 매우 두텁다 — 별표 34종·서식 84종·행정규칙(고시) 27종이 모두 텍스트로 확보돼 있고, 표시정지·과태료 세부수치(시행령 별표1·2·4, 시행규칙 별표9·26 등)도 원문에 실제 존재한다. **문제는 사서(wiki 작성) 단계다.** 법 전체 123개 조문 중 위키 개념 페이지가 커버하는 것은 3개 주제(품질인증·지정해역위생관리·지리적표시) — 대략 **제14~19조, 제32~40조, 제69~78조** 뿐이다. 다음 주요 축이 **위키에 통째로 없다**:

- **제7장 검사·검정** (제79~101조): 농산물 검사, **수산물 등에 대한 검사**(제88~97조), 검정(제98조), **부정행위의 금지**(제101조 — 벌칙 제119·120조의 근거 조문 자체)
- **제4장 유전자변형농수산물의 표시** (제56~59조) — 이 법에서 **형량이 가장 높은 조문**(제117조, 7년/1억원)의 근거인데 개념 페이지 전무
- **제5장 안전성조사 등** (제60~68조) — 안전관리계획·안전성조사·위험평가·잔류조사
- **농산물품질관리사·수산물품질관리사** (제105~109조)
- **농산물의 표준규격·우수관리인증(GAP)·이력추적관리** (제5~13조, 제24~27조) — 수산물은 이력추적관리 대상에서 원칙 제외(제24조는 "농산물"만 명시)라는 사실 자체가 어디에도 명시돼 있지 않음
- **품질인증기관·검사기관·검정기관 자체의 지정취소 처분기준**(시행규칙 별표8·9·20·26·31·32) — 기존 3개 개념페이지는 "인증받은 물품(품질인증품 등)"의 사후관리만 다루고, "인증기관 자체"가 거짓지정·업무정지 위반 시의 1~3차 처분표(예: 별표9)는 다루지 않음

즉 이번 감사에서 나온 missing 다수는 "위키가 얇아서"가 아니라 "해당 주제의 개념 페이지가 아예 없어서"이며, 원문(raw)은 존재하므로 재수집이 아니라 **사서 집필(ingest)** 이 필요하다.

## 3. ★답변방식 준수 감사 (method_compliance)

| 항목 | 판정 | 근거/미흡 사례 |
|---|---|---|
| **정의우선** | ok | 3개 개념페이지 모두 `## 정의` → `## 적용범위·제외` → `## 예외 규정` 순서를 최상단에 정확히 배치(스키마 3절 형식 그대로 준수) |
| **행정처분차수** | weak | 존재하는 3개 페이지는 1~3차 표를 정확히 옮겼다(4차는 이 법 자체에 없음 — 법 특성상 정상). 그러나 **품질인증기관·검사기관·검정기관 "자체"의 지정취소 1~3차 표(시행규칙 별표8·9·20·26·31·32)는 어느 개념페이지에도 없다** — "인증받은 물품"의 사후관리만 옮기고 "인증기관"의 제재는 누락(질문 31·40·41·43·44·45 참조) |
| **벌칙항별구간** | ok | 제118/119/120조를 항·호별로 정확히 분리해 표로 제시(예: 제119조5호=폐기물 3년/3천만원 vs 제118조=기름 5년/5천만원을 같은 배출행위라도 물질 종류로 구분). 뭉개기 없음 |
| **처벌정밀도** | ok(부분) | 존재하는 3개 개념 내에서는 조·항·호·금액 뭉개기 없이 정확. 다만 이는 **커버된 3개 주제 한정**이며, 미작성 주제(GMO 제117조 7년/1억, 검사 제119조6~9호 등)는 애초에 정밀도를 평가할 위키 텍스트 자체가 없음 |
| **타법연결** | ok | 3개 페이지 모두 `## 타법 연결` 표 보유(해양환경관리법·양식산업발전법·가축분뇨법·수산업법·상표법·특허법 등). 다만 지정해역↔해양폐기물관리법, 지리적표시↔민사소송법 등 일부 연결은 "인접 링크"만 있고 조문 대응 근거가 비어 thin(질문 88·91) |
| **프로필조건** | weak | 적용범위 표에 스키마 표준 컬럼(적용대상/제외대상/근거조문/제외위임)은 있으나, **톤수·조업형태·지역의 실제 조건값**은 이 법의 3개 주제 모두 "누구든지"/"톤수 무관"으로 귀결돼 컬럼이 사실상 비어있다. 이 법 안에 톤수·조업형태 조건이 실재하는 조문(예: 제88조④3호 원양어업허가 어선 검사생략, 제79조 대통령령 지정 농산물)은 정작 위키가 없는 검사 챕터에 있어 검증 불가 — "이 법엔 톤수조건이 없다"고 단정하기엔 이르다 |
