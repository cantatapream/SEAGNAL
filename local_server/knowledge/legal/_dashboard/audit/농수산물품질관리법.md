## 0. 총평 (핵심 발견)

**3라운드 종료 직후~4라운드 사이 위키가 13개 → 18개 개념페이지 + 3개 비교표로 확장됐다.** 3라운드가 `wiki_gaps` 1순위로 지목한 항목이 거의 전부 페이지화됐다:
- **지위승계**(제28조·제28조의2) — E1~E3·L9·L27·W63이 지목한 gap → 신규 페이지로 **완전 해결**
- **심의회**(제3·4조) — E52·E53이 지목한 gap → 신규 페이지로 **완전 해결**, 지리적표시심판위원회와의 구분도 양쪽 페이지에 상호 명시
- **수수료·자금지원·우선구매·포상금**(제110~113조) — L3·L66·E46~E49·W43·W58이 지목한 gap → 신규 페이지 생성, 다만 **금액 자체(별표33·34)는 여전히 미수집** — "누가 내는지"는 답변 가능해졌지만 "얼마"는 여전히 확인불가(정직하게 명시됨, 지어내지 않음)
- **양벌규정**(제122조) — 13개 페이지 공통 지적사항(E13·E14, answer_issues) → 신규 통합 페이지로 면책단서·개인사업자 포함 문구를 원문 전체 보존, 각 페이지가 이 페이지로 링크
- **확인·조사·점검/정보제공**(제102·103조) — W44·E50·E51이 지목한 gap → 신규 페이지로 **해결**
- **형사법총칙적용**(신규 교차테마 허브, `_SCHEMA.md` "교차 테마 허브" 절 취지) — 공소시효(E10)·미수범(E61)·경합(E12·E33)·양벌면책(E13·E14)이라는 이 법 벌칙이 실제로 부딪히는 형사법 총칙 4개 지점만 최소 인용(2·3군 stub 원칙 준수)으로 모은 허브. **모범적**.

이번 4라운드에서 실제로 재검증한 결과:
- **재검증 164건 중 약 34건이 이번에 FIXED(✅full 전환)**, 약 10건이 PARTIAL(정직한 "확인불가" 명시로 개선, 완전 full은 아님)로 개선됐다. **나머지 약 120건은 3라운드와 verdict가 그대로**(대부분 운영정보·절차 세부·타법 정의까지 더 파고들어야 하는 저빈도 실무질문 — 원문 자체에 없거나 이 법 원문만으로 확정 불가능한 영역).
- **★퇴행(regression) 발견**: 3라운드가 "재작업만 하면 즉시 해결"이라고 최우선으로 지목한 **Section C 8건(GAP 별표4·6, 이력추적관리 별표14, 수산물등검사 별표20·21·27, 검정 별표30·31 — 원문에 수치가 이미 있음을 3라운드가 직접 대조 확인)**이 **이번 4라운드에서도 그대로 "still_missing"으로 남아 있다.** 신규 페이지 5개·허브 1개를 만드는 작업은 이뤄졌지만, 정작 3라운드가 "가장 우선순위 높다"고 못박은 이 8건(=6개 페이지의 6개 섹션)은 손대지 않았다 — **다음 사서 세션 최우선 과제로 재확인**.
- Q52(농산물검사관 전형시험 종류)는 이번에 **FIXED**(수산물등검사 페이지에 제82조①②·전형시험 구분·명의대여금지까지 보강됨) — Section C와 달리 이 항목은 실제로 해결됐다.
