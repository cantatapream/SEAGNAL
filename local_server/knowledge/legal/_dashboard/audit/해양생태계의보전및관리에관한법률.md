## 2. 답변방식 준수 감사 (4단계 — 이번 감사의 중점)

| 항목 | 판정 | 근거 |
|---|---|---|
| **정의우선** | ok | 기존 3개 페이지 모두 "★ 정의부터 → 적용범위·제외 → 예외 규정" 순서를 최상단에 고정 배치. 스키마 원칙 100% 준수. |
| **행정처분차수** | na | 이 법에는 영업정지·자격정지 등 **횟수별(1~4차) escalation 별표가 원천적으로 존재하지 않는다**(서식지외보전기관·구조치료기관·포획허가 지정취소는 모두 "취소 또는 6개월 이내 정지"의 단일 처분이며 위반횟수에 따른 단계 구분이 없음). 포획금지 페이지가 "별도의 횟수별 escalation 별표는 없음"이라고 정확히 명기한 점은 모범적이나, 이 사실이 다른 2개 페이지·미작성 개념(서식지외보전기관 등)에는 반복 언급되지 않아 통일성이 약함. |
| **벌칙항별구간** | ok | 제61·62·63조처럼 같은 형벌 계열이라도 조·호별로 형량이 다른 경우(3년/2년/1년)를 표로 정확히 분리했다. 다만 이 구분은 **커버된 3개 개념에 한정**되며, 제62조7·8호·제63조5·6호(해양생물 수출입 위반)는 어느 페이지에도 등재되지 않아 실제로는 "일부 조문만 항별 구간화됨". |
| **처벌정밀도** | weak | 커버된 범위 내에서는 조·항·호·금액이 정확하다(뭉개기 없음). 그러나 법 전체 기준으로 보면 처벌조문 중 상당수(제62조7·8호, 제63조5·6호, 과태료 제65조2항1호 등)가 위키에 아예 없어 "정밀"이 성립하는 범위 자체가 좁다. 커버리지 문제와 결합해 전체 등급은 weak로 낮춤. |
| **타법연결** | ok | 3개 페이지 모두 `## 타법 연결` 표(정밀인용/포괄준용/적용제외 구분)를 갖추고 있고, 인용 조문을 실제로 열어 내용까지 반영(예: 야생생물보호법 허가의제, 화학물질관리법 유해물질 정의)했다. 스키마의 "인용만 하고 끝내지 않는다" 원칙을 잘 지켰다. |
| **프로필조건** | weak | 적용범위·예외 표는 있으나 **톤수·조업형태·지역** 3필드를 표준 컬럼으로 명시한 곳이 없다. 이 법의 규제 축이 주로 "구역(해양보호구역 지정여부·세부구역 종류)"이라 톤수 조건은 애초에 희박하지만, "지역" 조건(어느 세부구역·어느 보호구역인지)조차 예외표 산문 속에 흩어져 있어 챗봇이 필터 컬럼으로 바로 쓰기 어렵다. 양식장·낚시어선 등 조업형태 조건도 예외 서술에 명시적 컬럼화가 안 됨. |
| **점진공개구조** | weak | 관찰관광제한 페이지에 과태료 가중·감경 규정(1/2 가중·감경, 1년 내 재범 가중)이 있으나 "1차 답변 → 되물음 → 확장" 형태가 아니라 "일반기준 나열"식이라 챗봇이 바로 우려먹기 어렵다. 애초에 이 법 자체에 행정처분차수 데이터가 없어(na) 점진공개할 다차수 데이터 총량이 적다는 점도 원인이나, 있는 가중·감경 데이터라도 절진공개 포맷(기본값 우선 제시 → 조건부 확장)으로 재구조화가 필요하다. |
| **출처표기** | ok | 모든 서술문에 (조문, 시행일) 출처가 계속 붙어 있다. 3개 페이지 공통으로 잘 지켜짐. |

### method_notes (구체적 미흡 사례)

1. **행정처분 차수표 표기 불균일**: "별도의 escalation 별표 없음"이라는 na 판정 근거가 포획금지 페이지에만 있고, 다른 페이지·미작성 개념에는 반복되지 않음 → 신규 페이지 작성 시 이 판정근거를 표준 문구로 넣을 것.
2. **프로필조건 컬럼 부재**: 예외표에 "톤수·조업형태·지역" 표준 컬럼이 없다. 특히 "인접지역 주민의 생활양식 유지" 예외(제27조2항3호, 시행령 제12조3항)는 지역조건 그 자체인데도 산문으로만 서술됨.
3. **점진공개 포맷 미흡**: 과태료 가중·감경 규정이 있지만 "기본값(통상 사례) 우선 제시 → 조건부 확장" 형태로 재구조화돼 있지 않음.
4. **수집구멍(📛) 2건 발견**: (a) 제27조1항8호 "대통령령으로 정하는 행위"의 시행령 제12조1항 구체 내용(소리·빛·진동·악취, 산란지 훼손) 미반영, (b) 제27조2항3호 "대통령령으로 정하는 경우"의 시행령 제12조3항 구체 내용(인접지역 주민의 지속가능한 어로·채취) 미반영. 둘 다 시행령 원문은 raw에 이미 있으므로 사서 작업만 하면 즉시 해결 가능.
5. **완전 누락 벌칙**: 제62조7·8호(무허가 해양동물·해양보호생물 수출입), 제63조5·6호(거짓 수출입허가)는 raw 법률.txt엔 있으나 3개 위키 페이지 어디에도 언급되지 않음. "해양보호생물 수출입 제한(제42조)" 개념 페이지 자체가 없기 때문.
6. **규제표면 커버리지 45%가 미작성**: 107개 질문 중 47개(44%)가 missing으로 판정됨. 특히 사업자·개발자에게 중요한 **해양생태계보전부담금(제49~51조, 지역계수 최대 40배)**, 도서지역 주민에게 중요한 **시·도해양보호구역(제36조)**, 어민에게 중요한 **해양생태계교란생물·유해해양생물 관리(제23·24조)**, 손상동물 신고체계인 **서식지외보전기관·구조치료기관(제17·18조)** 이 전부 위키 미작성.
7. **종 목록 뭉개기**: 포획금지 페이지가 해양보호생물을 "약 91종"으로 요약하며 대표 예시만 나열, 시행규칙 별표3의 분류군별 전체 목록(포유류/무척추동물/해조류/파충류/어류/조류)이 위키에 옮겨지지 않아 "산호 만져도 되나", "조개껍데기 주워도 되나" 같은 구체종 질문에 즉답이 어려움.
