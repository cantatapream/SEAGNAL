# 품질감사 — 「수산업ㆍ어촌 발전 기본법」

- 감사일: 2026-07-15
- 감사 대상 위키: `wiki/concepts/수산업ㆍ어촌발전기본법__*.md` (3개: 수산업수산인어업인정의 / 어촌의정의 / 수산발전기금)
- 원문: `raw/12_수산물유통/수산업ㆍ어촌발전기본법/` (법률·시행령·시행규칙 + 행정규칙 5종, **별표수: 0**)
- 법 성격: **기본법(基本法)** — 정책 선언·계획수립·기금 조항이 대부분이고 **벌칙·과태료·행정처분(영업정지 등) 조문이 원칙적으로 없다.** 유일한 처벌 관련 조문은 제52조(벌칙 적용 시 공무원 의제 → 형법 뇌물죄 연결)뿐. 이 점이 이 법의 감사 결과 전반을 지배한다.

## 총평 (한줄)

기존 3개 위키 페이지(정의·어촌·기금)는 스키마 형식(정의→적용범위·제외→예외→...→타법연결)을 잘 지켜 **작성된 부분은 품질이 높다.** 그러나 (1) 법 전체 조문의 절반 이상(기본계획·심의회·전업수산인·수산신지식인·전담기관·귀어업인·여성수산인·후계수산업경영인·벌칙적용공무원의제 전체범위 등)이 **개념 페이지 자체가 없고**, (2) 특히 **수산발전기금 부정수급 시 실제로 존재하는 단계별 제재(지원제한 1년/1년6개월/2년)가 통째로 누락**되어 "이 법엔 처벌이 없다"는 서술이 사실상 반쪽 진실이 되는 심각한 구멍이 있다.

## method_notes (구체적 미흡 사례)

1. **[최중요] 수산발전기금 페이지의 "위반 시 처벌" 표가 실제 존재하는 제재를 놓침** — `수산발전기금.md`는 "이 법 자체에는 벌칙·과태료 조문이 없다"고 단정하지만, 이 법의 하위 고시(「수산발전기금운용관리요령」 제35~38조)에는 **부당사용 금액 구간별 지원제한 기간(3천만원 미만 1년 / 3천만원~1억원 1년6개월 / 1억원 이상 2년)**, 회수, 연체이자, 위약금 규정이 상세히 존재한다. 이는 사실상 이 법 생태계의 유일한 "차수/구간형 제재"이며 완전히 누락됐다.
2. **어업인 확인서발급규정(고시)의 실무 기준 미반영** — 시행령 제3조제3항이 위임한 고시의 확인절차·유효기간(3개월)·처리기한(10일)·가족원 기준(6개월 동거)·낚시어선 출항일수 제외 단서가 정의 페이지에 반영되지 않음.
3. **개념 페이지 커버리지가 법 전체의 일부에 그침** — 52개 조문 중 정의(제3조)·어촌(제3조6호)·기금(제46~50조)만 편입되고, 기본계획/심의회(제7·8조), 전업수산인(제17조), 수산신지식인(제17조의2), 후계수산업경영인·청년수산인(제16조), 여성수산인(제18조), 벤처수산업(제20조), 귀어업인(제21조), 전담기관(제33조), 기후영향평가(제35조의2), 다른 법률과의 관계(제6조), 국제협력·통상·수출진흥·북한조사(제42~45조) 등은 개념 페이지가 전혀 없다.
4. **제52조(공무원 의제) 커버리지가 부분적** — 이 조는 ①심의회 위원 ②전담기관 임직원 ③기금 위탁 수협중앙회 임직원 3그룹을 규율하는데, 위키(기금 페이지)는 ③만 다루고 ①②는 어디에도 없다. 대응 개념 페이지(심의회·전담기관)가 없으니 연쇄적으로 빠진 것.
5. **정의 사슬 미완결** — 어촌 정의의 "동 지역 중 상업·공업지역 제외"를 판정하는 「국토의 계획 및 이용에 관한 법률」 제36조가 "⏳ 미편입"으로 남아, `_SCHEMA.md`의 "정의 사슬 전파(멀티홉)" 원칙이 이 지점에서 끝까지 완결되지 않았다(위키 스스로 정직하게 REVIEW 표시는 해둠).
6. **프로필 조건 컬럼의 형식 불일치** — 이 법의 적용범위 표는 "연간판매액 120만원", "60일 종사" 같은 소득/기간 기준이라, `_SCHEMA.md`가 표준으로 요구하는 "톤수·조업형태·지역" 컬럼과 다르다. 톤수 기반 질문(Q95)에 위키가 "이 법은 톤수 기준이 아니다"라고 명시적으로 답해주지 못해 사용자가 헷갈릴 수 있다.
7. **생산자단체 정의의 세부 요건 누락** — 시행규칙 제2조(자본금 1억원 이상 영어조합법인/어업회사법인, 염업조합, 협동조합연합회 등 6개호)가 정의 페이지에 "수협·수협중앙회"로만 요약되어 실제 세부요건이 빠짐.

## 결론

이 법은 **처벌 축이 거의 없는 기본법**이라는 특수성 때문에 T2/T3(벌칙·별표) 유형 질문의 상당수가 "정확히 없음"으로 ✅full 판정을 받는다(오히려 스키마가 요구하는 "처벌 뭉개기 금지"를 잘 지킨 정직한 사례). 그러나 **딱 하나 존재하는 실질적 제재 축(기금 부정수급 지원제한)을 놓친 것**과 **법 조문의 절반 이상에 개념 페이지가 아예 없는 것**이 이번 감사의 핵심 구멍이다. 우선순위: ① 수산발전기금 페이지에 요령 제35~39조 반영, ② 심의회·전담기관·기본계획 개념 페이지 신설(제52조 공무원의제 완결을 위해서도 필요), ③ 어업인확인서발급규정 세부기준을 정의 페이지 예외표에 반영.
