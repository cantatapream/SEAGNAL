### R5 신규 발견

1. **fix4의 겨냥 정확도는 높으나 범위가 좁다** — R4가 지적한 다수(E73·E76·E77·E79·E81·E88·E100~E109 등)를 놔두고 특정 7건(E72·75·85·93·110·116 + 헤딩)만 정확히 고쳤다. 우선순위 근거가 불분명 — 다음 라운드 전 "어떤 기준으로 다음 수정 파도를 고르는지" 명문화 권고.
2. **일반법 연결(행정절차법·행정심판법·행정소송법·개인정보보호법) 패턴 신설은 긍정적**이나, 아직 이 법의 8개 페이지 중 3곳에만 적용됨 — 나머지 페이지(예: `기후변화영향평가.md`, `통계DB및정보화.md`의 개인정보 관련 W82/W99 등)에도 같은 패턴 확산 필요.
3. **부칙 문제의 성격이 바뀌었다** — R4까지는 "위키가 부칙을 안 다룸(wiki_gap)"이었으나, R5에서 raw 원문을 끝까지 재확인한 결과 **raw 자체에 부칙이 없다**(수집 문제 가능성) — `collection_hole`로 재분류. 위키 사서 작업으로는 해결 불가, 수집 스크립트 재점검이 선행돼야 함.
4. **자치법규·교차허브는 4번째/3번째 라운드 연속 완전 미해결** — fix4가 8개 페이지를 건드리면서도 이 두 구조적 항목은 전혀 손대지 않음. 우선순위를 격상해도 실제 반영되지 않고 있어, 리포트에 "권고"로만 남기지 말고 구체 작업 티켓화가 필요해 보인다(감사자 권한 밖 제안).

## answer_issues

- fix4가 R4 지적사항 중 7건(E72·E75·E85·E93·E110·E111·E116)과 method_compliance 1건(행정처분차수 헤딩)을 **정확히 겨냥**해 반영 — 재감사 루프가 실제로 작동하고 있음을 확인(감사→수정→재감사 사이클의 유효성 재확인).
- E111(지원제한처분 처분성)은 절차·불복 경로 안내로 실사용 리스크가 줄었으나, "처분성 자체"는 여전히 미판정 — 사용자가 "이의신청 어떻게 하나요"라고 물으면 이제 일반법 경로(행정심판/행정소송)라도 안내 가능해져 R4 대비 개선.
- 자치법규 질문(L119/W118 등)은 여전히 "raw엔 있으나 위키가 못 찾아 없다고 오답할 위험"이 그대로 남아있음 — **4라운드 연속** 최우선 과제, 다음 라운드에서도 미해결이면 감사 리포트만으로는 개선 유인이 부족하다는 뜻이므로 별도 작업 트래킹 권고.
- 부칙 raw 부재는 "사서(ingest) 문제"가 아니라 "API 수집 스크립트 재검토 대상"일 수 있음 — 이 감사(위키 품질 감사) 범위를 벗어나므로, 결과만 정직하게 보고하고 판단은 사용자/개발팀에 넘긴다.

## 결론 및 우선순위 (R5)

fix4는 R4가 정확히 지적한 좁은 범위(7개 세부 질문 + 헤딩 1건)를 신속·정확하게 처리했다 — 재감사 루프의 유효성이 재확인됐다. 그러나 **구조적 3대 과제(자치법규·교차허브·부칙)는 이번에도 손대지 않았고**, 그중 부칙은 성격이 "위키 미기재"에서 "raw 수집 구멍(추정)"으로 격상됐다.

우선순위:
1. **자치법규 85건 → `wiki/comparisons/`에 지역별 비교표로 편입** (4라운드 연속 최우선 과제, 이번에도 미착수)
2. **`wiki/comparisons/`에 이 법 5~6개 타법 교차 허브 신설** (3라운드 연속)
3. **부칙 raw 재수집 확인** — API 원본에 부칙이 실제로 있는지 재조회, 있으면 raw에 편입 후 위키 반영. 없으면(정책선언 기본법 특성상 실제로 부칙이 간단할 수 있음) "부칙 없음"을 위키에 명시해 collection_hole을 종료
4. **제30·31조 지식재산권 귀속, 제34조 자원조성 사업 중복, 제23조 재원 우선순위** — 3개 세부 미해결 항목 다음 파도 후보
5. **일반법 연결(행정절차법 등) 패턴을 나머지 페이지로 확산** — 이번 fix4에서 도입된 좋은 패턴을 8개 페이지 중 나머지 5개+미변경 9개에도 순차 적용
