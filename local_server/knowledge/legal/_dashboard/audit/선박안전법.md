## 0. 총평

위키 콘텐츠 자체의 정확도는 매우 높다. 처벌 조문(제83~89조)을 원문과 항목별로 전수 대조한 결과 **누락·오기 없이 100% 일치**(삭제된 호까지 정확히 제외). 정의→적용범위→예외→의무→처벌(항별 구간)→행정처분→근거→타법연결 순서의 스키마 고정 형식도 17개 페이지 전부가 준수했다.

다만 두 가지 구조적 문제가 있다:
1. **전 페이지가 `status: draft`.** 스키마 5절에 따르면 draft는 "챗봇이 인용하면 안 됨"이다. 즉 지금 이 순간 챗봇은 선박안전법에 관해 **한 글자도 인용해서 답할 수 없다** — 콘텐츠 품질과 무관하게 서비스 가능 여부가 0이다. 가장 시급한 이슈.
2. **선박용물건 실체 기준(고시 29종) 전부 미편입.** 형식승인·검정은 "승인 절차"만 다루고, 실제 "구명조끼 몇 벌·소화기 몇 개·복원성 계산기준" 같은 사용자가 실제로 물을 수치는 raw에 215줄(구명설비기준)~52줄(복원성기준) 등으로 존재하지만 위키 어디에도 인용되지 않았다.

## 4. 핵심 발견 (method_notes 상세)

1. **[치명적] 전체 페이지가 `status: draft`.** `_SCHEMA.md` 5절: "draft = 챗봇이 인용하면 안 됨." 17개 개념 페이지 + statute 페이지 전부 draft이므로, 콘텐츠 정확도와 무관하게 **현재 챗봇은 선박안전법 관련 질문에 이 위키를 근거로 답할 수 없는 상태**다. 승인(canonical 전환) 절차가 감사 시점 기준 전혀 진행되지 않음.
2. **[collection hole] 선박용물건 실체 기준 29개 고시 전량 미편입.** `raw/.../행정규칙/`에 선박구명설비기준(215줄)·선박소방설비기준·선박복원성기준(52줄)·강선의구조기준 등 실제 수치가 담긴 고시가 있으나, `선박안전법__형식승인및검정.md`·`선박안전법__만재흘수선복원성.md` 등 관련 개념 페이지 어디에도 이 고시들이 인용되지 않는다. "구명조끼 몇 벌 있어야 하나", "복원성 계산 기준이 뭔가" 같은 실사용자 질문에 위키가 별표·고시 번호만 대고 실제 수치를 못 준다.
3. **[collection hole] 「위험물 선박운송 및 저장규칙」 미수집.** `선박안전법__산적화물위험물운송.md`이 스스로 정직하게 REVIEW 표시. 위험물 등급별 포장·용기·적재 세부기준이 위키에 없다.
4. **[비대칭 링크] 무선설비 페이지 ↔ 야간운항_장비 허브.** `선박안전법__무선설비및선박위치발신장치.md`은 "(테마 허브) [[comparisons/야간운항_장비]] — 편입 예정"이라 적었지만, 실제 `wiki/comparisons/야간운항_장비.md` 파일에는 선박안전법이 전혀 언급되지 않는다(낚시·수상레저·유도선 3법만 수록). 스키마 9절 "비대칭 링크 교정" lint가 아직 이 법에 대해 실행되지 않은 것으로 보인다.
5. **[비대칭 링크] 형식승인및검정 ↔ 안전장구_구명설비 허브.** 같은 패턴 — 링크는 있으나 허브 반대쪽에 선박안전법 행이 없음.
