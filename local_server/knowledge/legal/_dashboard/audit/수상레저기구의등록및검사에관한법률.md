## 3. 위키 갭 (개념 페이지 부재 — 우선순위순)

1. **시험운항허가 (제14조)** — 형벌(제30조2호)까지 있는 실질 의무인데 전용 개념 페이지 없음. 신청처·기간(7일)·거리(10해리)·안전장비 3종(구명조끼·소화기·통신기기)이 raw에만 있고 위키에 전혀 없음. **최우선 신규 작성 대상.**
2. **안전검사원 교육 (제20조)** — 정기교육(매년 14시간)·이수시험(60점)·과태료(100만원, 별표5 파목) 전부 위키 부재.
3. **검사대행자 지정 절차 (제18조, 시행령 제12조, 시행규칙 제18조)** — 위반 시 처분(별표3/4)은 잘 옮겨졌으나, 애초 "어떻게 지정받나"의 적극 요건은 없음.
4. **전기추진 동력수상레저기구 특례** — 「전기추진 동력수상레저기구 설비기준」(고시)이 통째로 위키 미반영. 전기보트 보급 추세상 실사용 질문 빈도 높아질 주제.
5. **압류등록·저당권 (제11·12조)** — 원문은 raw에 있으나 개념 페이지·statute.md 핵심의무표 어디에도 없음.
6. **구조·설비 안전기준 (제21·24조, 시행규칙 제22·25조)** — 8개 항목(선체~구명소방설비) 나열 자체가 statute.md에도 빠짐. 안전검사 통과 요건인데 "뭘 갖춰야 검사에 합격하나"를 구체적으로 답할 수 없음.
7. **등록번호판 규격·제작 주체 (시행규칙 별표2, 제4조)** — annexes 미보존, HWP 링크만.
8. **수수료 (별표6)** — 아래 collection_hole 참조.

## 4. 수집 구멍 (collection_hole)

- **수수료 (제26조, 시행규칙 별표6)**: raw에는 등록 1,500원·번호판 13,500원 등 구체 금액이 텍스트로 전부 있는데(확인 완료, `시행규칙_별표6.txt`), 위키(`statute.md` 별표 인덱스)는 "수수료" 성격만 표기하고 HWP 원본 링크만 제공한다. **원문 텍스트가 raw에 이미 있으므로 옮기기만 하면 되는데도 안 옮겨진, 전형적인 수집 구멍**(스키마 정의상 "고시/별표로 정한다는데 원문 수치가 없다"의 변형 — 이 경우는 아예 annexes/ 이관 자체가 누락).

## ★5. 답변방식 준수 감사 (4단계 — 이번 감사의 중점)

| 항목 | 판정 | 근거/미흡 사례 |
|---|---|---|
| **정의우선** | ok | 4개 concept 모두 `정의`→`적용범위·제외`→`예외 규정` 순서를 최상단에 정확히 유지(스키마 3절 형식 100% 준수). statute.md도 "정의(핵심 용어 표)"를 최상단에 두어 멀티홉(수상레저안전법 제2조)까지 원문 인용. **단, 시험운항허가·안전검사원교육·압류등록 등 6개 미작성 개념은 이 구조 자체가 없어 "정의우선" 원칙이 해당 주제엔 적용될 수 없음**(개념 페이지가 없으니 판정 불가) |
| **행정처분차수** | ok | `[[안전검사]]` 개념·`statute.md` 모두 검사대행자 지정취소·업무정지를 **1→2→3→4차 escalation 표**로 정확히 옮김(별표3 원문과 1:1 대조 완료, 오차 없음). 과징금(별표4)도 1~3차 escalation 표 있음. 다만 **이 법의 유일한 행정처분 대상이 "검사대행자"뿐이라 일반 사용자(레저인) 대상 행정처분표는 애초 존재하지 않음**(해당없음 아니라 "정확히 옮김" ok) |
| **벌칙항별구간** | ok | 제32조 ①100만원/②50만원 구간을 concept·statute.md 모두 분리 표기. 같은 제6조1항 위반도 "형벌(운항 시)"과 "과태료(등록만 지각 시)"를 명확히 분리한 "핵심 구분" 박스가 3개 concept에 반복돼 있어(등록·안전검사 개념) 항별 구간 분리 규율이 특히 잘 지켜짐 |
| **처벌정밀도** | ok(부분weak) | 별표5 개별기준(가~거목) 15개 항목 전부 위키(statute.md)와 원문을 대조한 결과 **금액 100% 일치**(50/30/20/100만원 등, 오차 0건). 그러나 **시험운항 관련 4개 항목(제30조2호, 제32조②4·5호)은 statute.md에만 있고 concept 페이지엔 없어 "조·항·호·금액까지 정확히" 원칙이 concept 레벨에서는 weak** — 챗봇이 concept 검색을 우선하면 이 4개 처벌을 놓칠 위험 |
| **타법연결** | ok | 4개 concept 모두 `## 타법 연결` 표 존재, 정밀인용 표시(「수상레저안전법」·「선박법」·「전파법」·「자동차 등 특정동산 저당법」 등). statute.md는 13개 타법 인용을 표로 총정리해 특히 우수. 단 낚시관리법 링크 1건이 "편입 예정"으로 미완결(적용대상판정 개념) |
| **프로필조건** | ok | 적용범위·예외 표에 **톤수(20톤)·마력(30마력/22kW)·형태(접이식 고무보트)·운항구역(평수/한정연해/내수면)·조업형태(수상레저사업 여부)** 컬럼이 실제로 존재해 프로필 필터가 바로 매칭 가능. `[[검사_등록]]` 허브의 "프로필 필터 가이드" 섹션이 이 법의 조건을 다른 4개 법과 나란히 정리해 특히 모범적 |
| **점진공개구조** | weak | 안전검사 개념에 "핵심 구분(REVIEW 대상)" 박스로 1차 정보(통상 사례)를 먼저 주는 톤은 있으나, **명시적으로 "차수/조건에 따라 갈린다 → 되물음 → 확장"의 3단계 UX가 데이터로 구조화된 곳은 검사대행자 행정처분(1~4차) 표뿐**이다. 일반 사용자가 물을 법한 "과태료 얼마?"류 질문(예: 변경등록 지각 며칠?) 은 위반일수 계산식(별표5 나·자목)이 그대로 표에 있어 챗봇이 점진공개할 재료는 있으나, **concept 문서 자체에 "1차 답 → 되물음" 문구·구조가 없어 챗봇 프롬프트 엔지니어링에 전적으로 의존**(데이터는 있지만 "통상값 vs 전체" 구분 라벨이 표에 없음) |
| **출처표기** | ok | 거의 모든 서술 문장에 `(제N조, 시행일)` 형식 출처가 붙어 있음. 예외: `## 벌칙 체계`·`## 행정처분 체계` 표의 셀 단위에는 개별 출처가 없고 표 상단 1회 출처만 있음(표 형식상 불가피, 스키마도 표 형식을 허용하므로 weak는 아님) |

### method_notes (구체적 미흡 사례)

1. 시험운항허가(제14조)의 벌칙(제30조2호, 형벌 6개월/500만원)과 과태료(제32조②4·5호)가 **concept 페이지 어디에도 없고 statute.md에만 있어**, "위키 개념 페이지 우선 검색" 원칙(스키마 2절 1항)을 따르는 챗봇 검색 흐름에서 누락될 위험이 크다.
2. 안전검사원 교육(제20조)의 과태료(별표5 파목 100만원)는 statute.md 과태료 표에는 있으나, **어떤 의무를 위반한 것인지(정기교육 자체)에 대한 설명이 위키 전체에 없어** "무엇을 안 하면 100만원인지" 답이 불완전(뭉개기는 아니지만 맥락 없는 뜯긴 조각).
3. 검사대행자 지정취소 관련 과태료 2건(별표5 카·타목, 각 100만원 — 부정 지정·부실검사)이 **안전검사 concept의 "행정처분 체계" 섹션(업무정지·지정취소)과 짝을 이루는 과태료임에도 그 옆에 나란히 안 실려** 사용자가 "지정취소 됐는데 과태료도 내나?"를 물으면 위키 내 교차 확인이 안 됨(같은 개념 페이지 안에서 벌칙 체계 표와 행정처분 체계 표가 서로의 존재를 언급하지 않음).
4. 압류등록(제12조)·소유권변동효력(제11조)이 등록 개념의 "의무 내용"·"위반 시 처벌" 어디에도 없어(타법연결 표에 저당권법 인용만 있음), "압류/저당 잡힌 배 등록이 어떻게 되나"라는 실무 질문에 개념 페이지가 침묵.
5. 「전기추진 동력수상레저기구 설비기준」(행정규칙, 30만자)이 raw엔 수집돼 있으나 **위키 어디에도 존재 자체가 언급되지 않음**(4개 concept의 타법연결·관련개념 어디에도 링크 없음) — 전기 모터보트 사용자 질문에 완전 침묵.
6. 수수료(별표6)는 raw 텍스트가 이미 확보돼 있음에도 위키에 옮겨지지 않은 **순수 작업 누락**(collection_hole이라기보다 ingest 누락에 가까움).
7. 별표5 일반기준(1호 — 사소한 위반 1/2 감경, 6개월 이상 지속 시 1/2 가중)이 과태료 관련 어느 concept에도 안 옮겨져 "왜 내 과태료가 표준액보다 적게/많이 나왔나" 질문에 답 불가.
8. 시험운항허가 데이터 공백과 별개로, `[[검사_등록]]` 허브 비교표에는 "수상레저기구등록법 (안전검사)" 행만 있고 "수상레저기구등록법 (시험운항허가)" 행이 없어 **교차허브에서도 이 주제가 완전히 빠짐**(lint 패스에서도 놓친 것으로 추정).

## 6. 답변 이슈 요약 (핵심 3가지)

1. 시험운항허가(제14조) 전용 개념 페이지 부재 — 형벌까지 있는 의무인데 구조화 안 됨 (최우선)
2. 전기추진 특례 고시가 위키에 전혀 반영되지 않음 — 신규 활동 대응 공백
3. 수수료(별표6)는 원문 확보돼 있음에도 위키 미이관 — 즉시 해결 가능한 작업 누락
