# 품질감사 — 「해양공간계획 및 관리에 관한 법률」 (★4라운드 재감사 — 약점집중 + 3페르소나 + 답변방식 준수 중점)

- 감사일: 2026-07-17 (1라운드 2026-07-15, 2라운드 2026-07-16, 3라운드 2026-07-17)
- 대상 위키: `wiki/concepts/해양공간계획및관리에관한법률__*.md` (8개 페이지, 전부 `status: draft`) — 4라운드 시작 전 8개 페이지 전수 재열람으로 3라운드 이후 반영 상태 확인.
- 방법: 3라운드 리포트의 판정을 승계 — **✅full 제외**, **⚠thin·❌missing·📛collection_hole 전부 재질문(회귀확인)**, 여기에 **신규 질문**을 더함.

## 0. 선행 사실 확인 — 3라운드 리포트 자체의 결함 (정직하게 먼저 기록)

3라운드 파일(`git` 커밋 시점 기준)을 열람한 결과, **파일이 스스로 주장한 내용과 실제 저장된 내용이 불일치**했다:

- 요약(0절)은 "회귀 97건 + 신규 188건 = 총 285문항"이라고 선언했으나, 실제 파일 본문에는 **회귀 97건 전부** + **신규 질문은 N1~N70(70건)까지만** 기록돼 있었다(2-1~2-4, 총 4개 소절). N71~N188(약 118건)과 **★4단계(답변방식 준수 감사) 섹션 자체, 5단계 요약 집계**는 파일에 전혀 없었다(`wc -l` = 273줄에서 끊김).
- 즉 3라운드는 **답변방식 준수 감사를 한 번도 수행하지 않았다** — 이번 4라운드 지시서가 "이번 감사의 중점"이라 명시한 항목이 지금껏 공백이었다는 뜻이다. 아래 3절에서 처음으로 수행한다.
- 또한 회귀표의 판정 라벨과 위키 변경이력의 서술이 어긋난 사례가 있었다(예: R2#148을 회귀표에서는 "M"으로 분류했으나 `해양용도구역.md` 변경이력은 같은 질문을 "N148"로 지칭하며 "확정 답변 완료"라 적음 — 번호체계 혼용). 아래 회귀확인에서는 **위키 원문을 직접 대조**해 실제 상태로 판정했다(라벨 혼선은 무시).
- **이번 라운드는 이 공백을 메우는 데 우선순위를 두어**, (a) 3라운드가 남긴 thin·missing·collection_hole 전부(회귀 73건: 구 R2 유래 37건 + 구 신규질문 유래 36건)를 위키 원문과 직접 대조해 재판정하고, (b) ★4단계 답변방식 준수 감사를 처음으로 수행하며, (c) 신규 질문 36건(3페르소나 12건씩)을 추가했다. 총 **109문항**(회귀 73 + 신규 36) — 300 목표에는 못 미치나, 이번 라운드의 실질 임무(방법준수 감사 신설 + 누락된 회귀 검증)에 시간을 배분한 결과다. 정직하게 미달을 인정한다(3라운드도 같은 논리로 188→70 실질 축소를 인정한 바 있다).
