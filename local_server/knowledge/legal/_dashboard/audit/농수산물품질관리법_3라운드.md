## 0. 총평 (핵심 발견)

1. **2라운드가 지적한 결함이 하나도 고쳐지지 않았다.** 10개 개념 페이지 모두 `updated: 2026-07-16`으로 2라운드 감사 시점과 동일 — 즉 2라운드 감사 이후 **아무 수정도 반영되지 않은 상태**에서 이번 3라운드가 진행됐다. 2라운드가 발견한 "still_missing 5건 오표기"(GAP 별표4·6, 이력추적관리 별표14, 수산물등검사 별표27), collection_hole 1건(안전성검사기관 총리령), method_compliance weak 3개(행정처분차수·타법연결·프로필조건) 전부 **그대로 재확인**됐다(아래 회귀 문항 참조).
2. **새로 발견한 가장 중요한 결함**: 벌칙 조문 **제120조제2호의 괄호 예외**("제31조제1항제3호 또는 제40조제2호에 따른 **표시방법**에 대한 시정명령은 제외한다")가 세 개념 페이지(품질인증·지리적표시·GAP) 어디에도 반영되지 않았다. 즉 시정명령 불이행이 "표시방법 위반"이면 **형벌(제120조2호, 1년/1천만원)에서 제외되고 과태료(제123조①5호)로만** 처리되는데, 위키는 이 배제조항 자체를 언급하지 않아 "시정명령 안 지키면 형사처벌도 받나?"에 **오답 위험**이 있다(품질기준미달 시정명령 불이행 vs 표시방법 시정명령 불이행을 구분 못 함).
3. 또한 **제120조제2호·3호(시정명령·판매금지 불이행 1년/1천만원 벌칙)가 품질인증·지리적표시·GAP 세 개념 페이지의 "벌칙 체계" 표 어디에도 없다** — 세 페이지 모두 표시 위반(제119조)만 다루고, "행정처분(시정명령·판매금지) 자체를 어기면 형사처벌도 받는다"는 축을 놓쳤다.
4. **제114조(청문) 목록 16개 항목**을 이 법 원문에서 처음 전체 확인한 결과, 안전성검사기관 지정취소(9호)·수산물검사기관 지정취소(13호)·검사판정취소(12·14호)가 전부 청문 대상인데 관련 개념 페이지 어디에도 "청문 대상"이라는 언급이 없다(2라운드 Q122가 "미확인"으로 남겼던 것의 답이 확정됨 — 청문 대상 **맞음**).
5. **명예감시원(제104조)**은 2라운드 wiki_gaps에서 지적된 그대로 여전히 미작성.
