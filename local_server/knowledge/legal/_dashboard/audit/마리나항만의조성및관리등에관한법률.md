## 0. 총평 (먼저 결론)

**직전 감사에서 지적한 4대 축(정비사·안전점검·분양회원모집·승계) + 2라운드 wiki_gaps 6건이 전부 위키 페이지로 신설됐다.** 원문(법률·시행령·시행규칙·행정규칙)과 대조한 결과 페이지 품질은 1라운드 3페이지와 동등하게 높다 — 정의→적용범위→예외→의무→처벌→벌칙체계→행정처분체계→근거→타법연결 순서를 지켰고, 처벌은 조·항·호·금액까지 정밀하다. **회귀 확인 결과 51건 중 43건(84%)이 full로 전환됐고, 8건은 여전히 thin(6)·missing(2)로 남았다** — 즉 수정이 대부분 실제로 구멍을 막았다.

다만 3라운드 신규 300문항 감사에서 **새로운 미흡 지점**을 추가로 발견했다:
1. **양벌규정(법 제40조) 면책조항이 어느 페이지에도 인용되지 않는다** — 모든 벌칙표가 "법 제40조(적용)"이라고만 표기하고, 정작 조문의 핵심("법인이 위반행위 방지를 위해 상당한 주의·감독을 게을리하지 않았다면 면책")을 옮기지 않았다. 사업주가 "직원이 몰래 무등록 영업했는데 나도 처벌받나?"를 물으면 위키만으로는 "예"라고만 답하게 되어 **면책 가능성을 빠뜨린 반쪽 답**이 된다. 8개 페이지 전부에 공통되는 구조적 누락.
2. **부칙(附則)이 raw에 수집되지 않았다** — 공포일·시행일 개정경과·적용례·경과조치가 원문에 없어, 소급적용·개정 전후 사건 처리 같은 질문에 위키가 답을 못 한다(raw 수집 단계의 구멍).
3. **등록증·자격증 실물 행정 절차의 자잘한 결락**: 등록증 재발급(분실·훼손), 마리나업 등록 수수료 규정(원문에도 없음 확인 — "없다"는 사실 자체를 위키가 명시하지 않음), 정비사 자격증 유효기간(원문에도 만료 규정이 없음 — 역시 "없다"는 사실 미표기).
4. 회귀에서도 못 막은 6개 thin은 여전히: 마리나항만구역 vs 「항만법」항만구역 경계 비교, 외국인 등록 가능여부(REVIEW 미해소), 무자격 아르바이트 정비 개인책임, 정비 중 발생 폐기물의 폐기물관리법 연결, 외국인근로자 출입국관리법, 보험 대신 공제조합 가입 시 세부기준(시행령 제32조의4 가입기간·가입금액 — 원문엔 있으나 위키 미반영).
