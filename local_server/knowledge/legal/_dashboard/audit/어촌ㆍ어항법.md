## 핵심 발견 요약 (먼저 읽을 것)

**존재하는 5개 페이지 자체의 완성도는 높다.** 정의·적용범위·예외·의무·벌칙(항·호·금액)·타법연결까지 스키마 형식을 충실히 따르고, 어항구역금지행위·어항시설사용점용허가 페이지는 "형벌 vs 과태료" 축 구분과 과태료 1~3차 escalation(시행령 별표)까지 정확히 반영했다.

**진짜 문제는 법 전체 62개 조문 중 절반 가까운 분량(약 6개 장·절)이 개념 페이지 자체가 없다는 것.** 그런데 정작 존재하는 5개 페이지가 이 누락된 주제를 `[[링크]]`로 이미 가리키고 있어(**깨진 링크 다수**), 사서 스스로 구조는 설계했지만 채우지 못한 상태다.

### ❌ 완전 미수집 뭉치 (개념 페이지 자체 부재 — 깨진 링크 포함)

1. **제4장의2 어촌ㆍ어항재생 (제2조9·10호, 제47조의2~제47조의7, 6개 조문)** — 어촌종합개발사업과 병행하는 별개의 사업체계(재생개발계획→재생사업계획→지원단→협의체→시행)인데 개념 페이지가 전혀 없다. [[어촌ㆍ어항법__어촌종합개발사업]]과 [[어촌ㆍ어항법__어항개발사업]] 두 페이지가 각각 `[[어촌ㆍ어항법__어촌어항재생사업]]`을 관련개념으로 링크하지만 그 파일이 없다 — **깨진 링크**. 처벌 구조(제8·10~15조 준용)도 유추만 가능하고 명문 페이지가 없다.
2. **제5장 한국어촌어항공단 (제57조~제58조의9, 12개 조문 전체 장)** — 설립·사업·정관·임원·자금조달·지도감독·유사명칭금지·비밀유지의무까지 통째로 미수집. 공단 고유 벌칙(제58조의9 비밀누설 → 제60조제2항제7호, 2년/2천만원)과 공무원 의제(제59조, 형법 뇌물죄 적용)도 전혀 안 다뤄짐. [[어촌ㆍ어항법__어촌종합개발사업]]이 `[[어촌ㆍ어항법__한국어촌어항공단]]`을 링크하지만 파일 없음 — **깨진 링크**. 다만 유사명칭 사용 시 과태료(제62조①, 250/375/500만원)만 [[어촌ㆍ어항법__어항시설사용점용허가]] 페이지의 "행정처분 체계" 표 한 줄에 엉뚱하게 끼워 넣어져 있어 실제로 공단을 찾는 사용자는 발견하기 어렵다.
3. **어항시설의 귀속·매각·양여·관리운영권 (제26~32조, 7개 조문)** — 비지정권자 귀속 원칙(제26조①), 30년 무상사용 상한(제26조⑦), 어항시설관리운영권의 물권성·등록·저당권 특례(제29~32조)가 완전 미수집. [[어촌ㆍ어항법__어항개발사업]]이 `[[어촌ㆍ어항법__어항시설귀속과운영권]]`을 링크하지만 파일 없음 — **깨진 링크**.
4. **인허가의제 상세 (제8조, 34조 준용 — 18개 법률 인허가 의제)** — 두 페이지(어촌종합개발사업·어항개발사업)가 모두 `[[어촌ㆍ어항법__인허가의제]]`를 링크하지만 파일이 없어, 실제 18개 법률의 어느 조문이 무엇으로 의제되는지(국토계획법 도시관리계획, 공유수면법 점용허가, 하천법 등) 원문이 위키화되지 않았다 — **깨진 링크**.
5. **어항시설 안전점검·내진설계 (제24조, 시행규칙 별표2)** — 안전점검 대상·주기(정기 반기/연1회, 정밀 4년/6년)·A~E 등급 기준표가 raw에 이미 텍스트로 있는데 위키 어디에도 없다. [[어촌ㆍ어항법__어항개발사업]]이 `[[어촌ㆍ어항법__어항시설안전점검및내진설계]]`를 링크하지만 파일 없음 — **깨진 링크**.
6. **법령위반처분·공익처분·청문·손실보상·비상재해조치 통합 (제50·51·52·53·54조)** — 5개 페이지 모두 제50조(법령위반처분)는 부분 인용하지만, **제51조(공익을 위한 처분 — 시행자 귀책 없이도 취소·변경·중지 가능)와 제53조(손실보상 절차)는 어디에도 없다.** [[어촌ㆍ어항법__법령위반처분및공익처분]] 링크가 3개 페이지에서 걸려 있지만 파일 없음 — **깨진 링크**.
7. **기타 절차 조문 다수** — 어항관리규정(제36조, 조례 위임사항), 어항관리협의회(제37조, 시행규칙 제19조 구성), 어촌관광구역 설정(제18조), 권리·의무 승계신고(제55조, 시행규칙 제28조 "60일 이내"), 권한 위임·위탁(제56조), 어촌·어항 관광 활성화(제49조의2), 교육훈련(제49조의3), 바다해설사(제49조의4, 시행규칙 별표3 교육시간표)까지 전부 개념 페이지 없이 raw에만 존재.

이 7개 뭉치가 이번 감사의 핵심 `wiki_gaps`다. 특히 2·5·7(공단 벌칙·안전점검 등급표·바다해설사 교육시간)은 **별표·고시 수치가 raw에 이미 존재하는데 위키에 반영되지 않은 경우**로 `collection_hole`이다.

## answer_issues (챗봇 답변 방식 자체의 문제)

1. 5개 페이지가 존재하지 않는 6개 개념을 `[[링크]]`로 이미 가리키고 있어 사용자가 "관련 개념"을 눌러도 404에 해당하는 빈 페이지에 도달 — lint(9절 교차연결 정합화) 미실행 상태로 추정
2. "행정처분 체계" 섹션 헤더가 실제로는 "과태료 escalation"(4-B 벌칙체계 성격)인데 4-C 헤더 아래 배치되어, 스키마가 요구하는 벌칙(4-B)/행정처분(4-C) 두 축 구분이 문서 형식상 흐려짐
3. 제51조(공익을 위한 처분)·제53조(손실보상)처럼 시행자에게 귀책사유가 없는데도 취소·변경될 수 있는 조문이 통째로 빠져 있어, "내가 잘못한 것도 없는데 사업이 취소될 수 있는지" 같은 T5 질문에 답을 못 함 — 사용자 체감 리스크가 큰 공백
