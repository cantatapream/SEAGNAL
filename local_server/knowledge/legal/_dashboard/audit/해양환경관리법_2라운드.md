## 0. 총평 — 2라운드 핵심 발견

**성과 확인**: 1라운드가 "❌ 전무"로 못 박은 8개 장(선박 오염방지설비·해양시설·수거처리저장시설·유해방오도료·대기오염방지·선박검사·해양오염영향조사·환경관리해역부담금) 전부에 신규 개념 페이지가 생겼고, 각 페이지는 이 위키가 이미 확립한 형식(★정의부터 → 적용범위·제외 → 예외규정 → 의무내용 → 위반시처벌 → 벌칙체계 → 행정처분체계 → 근거조문전체사슬 → 타법연결)을 충실히 따른다. 1라운드가 지적한 "등록기준 별표14 수치 누락"·"저장시설 행정처분 별표10의3 미반영"·"조사기관 지정취소 별표16 미반영" 등 collection_hole 사례도 이번엔 **실제 수치·표까지 옮겨 해소**됐다(2절 회귀표 참조).

**2라운드에서 새로 드러난 구조적 결함 4가지**:

1. **시행령(대통령령) 자체가 여전히 미수집** — 1라운드가 최우선 과제로 지목했는데 이번에도 그대로다. 8개 신규 페이지 각각이 스스로 `still_missing`을 정직하게 자백해뒀지만(ECA 범위, 황함유량 수치, 부담금 산정계수, 조사대상규모 등), 근본 원인인 시행령 재수집은 일어나지 않아 **동일한 유형의 collection_hole이 페이지 수만큼 그대로 반복**된다.
2. **11장 보칙(제110~124조)·1장 2절(제9~13조)·10장 해양환경공단(제96~109조)은 1라운드 그대로 완전 공백** — 형식승인/성능인증·선박해체신고·출입검사·해양환경감시원·정선검색나포·신고포상금·해양환경측정망·정도관리·공단 조직, 어느 것도 새 페이지가 생기지 않았다. 특히 **선박해체신고(제111조)**는 실사용 빈도가 낮지 않은데 1·2라운드 모두 완전 누락으로 남아있다.
3. **새로 발견된 완전 누락 주제 2건** — ① 폐기물의 배출률 승인(제22조의2, 흘수·속력별 분쇄배출 승인제) — 1라운드는 이 조문 자체를 질문하지 않아 몰랐던 gap. ② 방사성물질 관련 적용제외(제3조① 단서, 원자력안전법 우선) — 정의허브·배출금지 페이지 어디에도 없음.
4. **처벌 누락 1건 신규 확인**: `해양환경관리업.md`가 승계신고 절차(1개월 이내)는 서술하면서 그 미이행 처벌(제132조②8호, 500만원 과태료)은 "위반 시 처벌" 표에서 빠뜨렸다 — 페이지 내부 정합성 문제.
5. **해역명 자체가 텍스트로 없는 좌표 데이터**: 환경보전/특별관리해역 지정 행정규칙 원문이 좌표만 있고 해역명 라벨이 없다(추출손실 추정) — "우리 마을 앞바다가 환경보전해역인지" 질문(1라운드 Q52와 동일 유형)이 이번에도 여전히 막힌다.
