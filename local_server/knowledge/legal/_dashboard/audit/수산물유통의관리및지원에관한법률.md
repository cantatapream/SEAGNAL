## 0. 총평 (핵심 발견)

이 법은 크게 4개 축으로 구성된다: ①위판장(제10~26조, 처벌 3축 완비) ②이력추적관리(제27~34조, 처벌 3축) ③불법수산물유통금지(제37조, 형벌 단일축) ④수급관리·유통기반조성(제35, 38~55조, 처벌 없는 지원행정). 위키는 ①②③만 개념 페이지로 만들었고 **④는 전혀 편입되지 않았다.** 또한 ①②에도 **실제 사용자가 물을 법한 구체 조문 2개(제13조의2 뱀장어 매매장소 제한, 제13조의3 위판장 위생관리기준)가 통째로 빠져 있다.**

가장 심각한 개별 결함은 **이력추적관리 개념페이지의 `## 행정처분 체계`가 시행규칙 별표4의 1~3차 escalation 표를 옮기지 않고 "등록취소 또는 표시금지(재량)"로 뭉갠 것**이다(4단계 참조). 이는 이 감사가 정의한 "행정처분차수" 준수 기준을 정면으로 위반한다.

## 2. ★답변방식 준수 감사 (method_compliance)

| 항목 | 판정 | 근거/미흡 사례 |
|---|---|---|
| **정의우선** | ok | 3개 페이지 모두 `## 정의`→`## 적용범위·제외`→`## 예외 규정` 순서 고정, 최상단 배치 확인. 다만 "이 법의 수산물 정의(시행령 제2조: 어업·양식업 활동 산물)"가 3개 개념페이지 어디에도 재수록되지 않아 "수산업활동" 여부 판정(Q26,38,39,102)이 매번 막힘 — 최상위 법 정의(제2조) 자체를 다루는 개념페이지가 없음 |
| **행정처분차수** | **weak** | 위판장 페이지는 1~3차 escalation을 대부분 정확히 옮겼으나(Q17,31,32 확인), 산지중도매인 최저거래금액 세부단계(Q16/33) 일부 누락. **이력추적관리 페이지는 치명적** — 별표4의 1→2→3차 escalation(시정명령→표시금지1개월→표시금지3개월/6개월/등록취소)을 통째로 "등록취소 또는 표시금지(재량)"로 뭉개 Q72~75가 전부 missing/thin 처리됨. 이는 스키마 4-C절이 요구하는 "표: 위반행위\|근거조문\|1차\|2차\|3차(4차)"를 지키지 않은 것 |
| **벌칙항별구간** | ok | 제59/60/61조 3단 구간(3년·2년·1년)과 제63조①/② 2단 과태료 구간을 조문별로 정확히 분리해 표에 담음(Q60~67 확인). 위판장 페이지도 제60/61조를 형량별로 분리 |
| **처벌정밀도** | **weak** | 대부분 조·항·호·금액까지 정확(양벌규정 포함)하나, 과징금(Q35 연간거래액 구간표), 산지중도매인 무실적 세부단계(Q33), 이력추적 등록취소기준 세부(Q72~75)에서 별표 수치를 뭉개거나 누락 — "뭉개기 금지" 원칙이 별표 데이터 전사(轉寫) 단계에서 깨짐 |
| **타법연결** | ok (구조는 있음, 내용은 weak) | 3개 페이지 모두 `## 타법 연결` 표 존재. 다만 실제 연결 폭이 좁음 — 농수산물유통및가격안정법(도매시장·공판장), 전통시장특별법, 수입유통이력고시-원산지표시법 경합(Q77,99,100) 등 원문에 명시된 타법 인용이 다수 누락됨 |
| **프로필조건** | **weak / 부분 na** | 이 법의 규제축이 "톤수·조업형태·지역"이 아니라 "생산자단체 자격·품목·거래횟수"라서 스키마가 요구하는 톤수 컬럼은 대부분 해당없음(na)인데, 이 사실 자체가 위키에 서술돼 있지 않아 챗봇이 불필요하게 톤수를 되물을 위험(Q37). 유일하게 살아있는 프로필축(품목별 지정 대상, 위판장 개설구역=지역)도 컬럼화되지 않고 서술형으로만 존재 |
| **점진공개구조** | ok (위판장) / **weak (이력추적)** | 위판장 페이지는 1~3차 표가 그대로 있어 챗봇이 "1차만 먼저 → 되물음 → 전체" 화법을 쓸 데이터가 있음. 이력추적관리 페이지는 애초에 차수 데이터가 없어 점진공개를 걸 수조차 없음(데이터 부재가 UX 규칙보다 앞서 막힘) |
| **출처표기** | ok | 거의 모든 문장에 "(법 제N조)" 형식이 붙어 있음. 다만 시행규칙·시행령의 세부 조번호(예: 시행규칙 제7조의2, 제30조, 별표2)처럼 **참조를 아예 안 한 항목은 출처 누락이 아니라 항목 자체가 없음**(missing과 구분 필요) |
