- 감사일: 2026-07-15(1R) → … → 2026-07-20(8R) → 2026-07-26(9R) → **2026-07-27(10R, 이 라운드)**
- 감사자: SEAGNAL 위키 품질감사관 (subagent, 단독 — Agent/Task 하위위임 없음, L-28)
- **10R 방식(약점 집중 + 3페르소나 + 구체 역할부여, H-23·H-27)**: 9R의 ✅full 항목은 재질문하지 않고 제외. 9R이 남긴 **thin·missing·hole 전부 재확인**(14개 위키 페이지 전문을 처음부터 끝까지 재독해 원문 대조) + **신규 질문**(해양경찰관 단속실무/일반인/해양종사자 각 약 1/3, T4·T5·T3 유형은 1인칭 구체 역할·상황 부여)로 300문항 채움.

## 1. 10R 헤드라인

1. **9R 이후 실제 사서 개정 3건 확인(회귀검사로 발견)** — 9R 감사 리포트 확정(2026-07-26) 이후에도 사서 파이프라인이 계속 돌아 다음이 실제로 갱신됨:
   - **① 오염물질배출신고와방제조치.md에 "해양오염 취약선박 위험성평가" 신규 섹션 추가(2026-07-27, 오늘)** — 시행령 제50조의2·시행규칙 제31조의2(둘 다 2026-06-30/07-01 본조신설)를 반영한 완전히 새로운 주제. 다만 이 섹션 자체가 **⚠REVIEW(인용 불일치)**를 명시적으로 안고 있음: 시행령 제50조의2가 "법 제65조제2항에서 「대통령령으로 정하는 선박」이란…"이라고 위임근거를 인용하나, 현행 법률 제65조②는 그런 문구 없이 "제64조제3항·제4항을 준용한다"는 내용만 있어 법-시행령 인용 불일치가 있음(사서가 원문을 임의로 고치지 않고 그대로 보존, 사람 확인 필요). → 10R에서 이 신규 섹션에 신규 질문 투입(§3-C).
   - **② 해양환경관리업.md — P8-9(대표자 변경 "중요사항" 해당여부)** thin→**full 승격 확인**. 시행규칙 제37조①의 4개 중요사항(대표자·상호·소재지/기술요원/선박·항해구역/설비)을 재대조해 대표자 변경도 포함됨(제74조 승계 제외)을 명시. 9R 리포트 표에는 "thin(유지)"로 남아 있었으나, 실제 위키 페이지는 같은 날(2026-07-26) 사서 패스로 이미 해소됨 — 9R 리포트 확정 시점과 사서 수정 시점의 순서 차이로 생긴 표기 지연. **10R 재확인 결과 full.**
   - **③ 선박오염방지설비와기록부.md — R9-60(선박대선박 기름이송 기록 보관기간)** missing→**full 승격 확인**. 법 제32조의2② 전문 재대조 결과 "3년 보관"이 시행규칙 위임사항이 아니라 **법률 본문에 직접 명시**돼 있음을 확인(3R부터 9R까지 6라운드 연속 "위임분 raw 미확인"으로 남았던 게 조문 오독이었음). **10R 재확인 결과 full.**
2. **10R 자체 재대조로 추가 승격 1건** — 해양오염물질배출정의.md **R9-08(부이·계류시설의 "해양시설" 해당여부)**: 9R 리포트는 "thin(유지)"로 남겼으나, 실제 위키 본문(9R H-26 패스로 이미 갱신)은 "기름·유해액체물질 저장목적 계류시설(돌핀)·원유송유용 부이=해당(별표1 제1호가목), 그 외 일반 정박용 부표=불명확"이라는 **정직하고 구조화된 답**을 이미 담고 있다 — 이는 thin이 아니라 "확인 가능한 부분은 확인, 불명확한 부분은 불명확하다고 정직 안내"한 완결된 답이므로 **full로 재판정**. 같은 논리로 **R9-38(등록기준 정기재점검)**도 "전용 재점검 절차는 없으나 연1회 출입검사가 사실상 그 기능을 겸함"이라는 완결된 안내로 **full 재판정**.
3. **10R 신규 review_pending 분류 적용** — EEDI 본산식(대기오염방지규제.md, 이미지 판독 저해상도 ⚠REVIEW)과 환경관리해역 정밀 면적수치(환경관리해역과부담금.md, 본문 삽입 이미지 OCR ⚠REVIEW, 이후 개정 반영여부 미확인)에 의존하는 질문 **2건을 review_pending으로 신규 분류**(§6). 9R까지는 "수치 확정, 도해만 REVIEW"로 처리해 사실상 full 취급했으나, H-26 원칙(원인 세분화)을 엄격 적용하면 이 두 항목은 **사람이 원본 이미지와 대조 확인하기 전까지는 정오를 신뢰할 수 없는 값**이라 별도 채점보류가 맞다.
4. **구조적 갭 25건 회귀 없이 그대로 유지** — 9R이 정리한 "구조적으로 원문 자체에 규정이 없는" 갭(D-시리즈 9건, E/L/W8 12건, R9-시리즈 4건, 합 25건)을 각 위키 페이지 재독으로 전수 재확인한 결과 **전부 동일 판정 유지**(회귀도 추가해소도 없음) — 해당 5개 페이지(대기오염방지규제·해양오염방지선박검사·유해방오도료규제·해양환경측정망과정도관리·보칙과단속·환경관리해역과부담금)는 9R 이후 갱신이 없었음(파일 `updated` 필드 확인).
5. **신규 P/L/W 질문 대량 투입(§3)** — 14개 페이지 전체를 훑어 아직 묻지 않은 논점 위주로 구체 역할·상황을 부여한 신규 질문을 편성(T4·T5·T3 유형 중심). 신규 결함 소수 추가 발견(§3 표 안 ⚠/❌ 표시 참조 — 대부분 이미 알려진 구조적 갭의 다른 표현이거나 경미한 thin).

   - **R10-015**(남극해역 기름배출) → full: 「극지해역 운항선박 기준」 제4조의2(고비중·고점도 원유 등 화물운송·연료사용 자체 금지)를 찾아 반영(오염물질해양배출금지.md).
   - **R10-029**(발견자 미신고 처벌여부) → full: 제129조①10호가 제63조①1·2호만 열거하고 3호(발견자)는 제외됨을 확정 — "발견자는 신고의무는 있으나 미신고해도 처벌되지 않는다"는 완결된 답이 됨(오염물질배출신고와방제조치.md).
   - **R10-057**(25톤 유조선 1척 방제업 등록가능여부) → full: 별표14 가·나·다 3개 항목이 각각 별도 척을 요구하는 누적요건임을 명시(해양환경관리업.md).
   - **R10-078·R10-081**(100㎡/600㎜ 미만 해양시설 경계값) → full: 별표1이 열거(한정)방식이라 미만은 원칙적 대상 제외임을 명시(해양시설신고와안전관리.md).
   - **R10-135**(130kW 이하 디젤기관 질소산화물 기준) → full: 「선박에서의 오염방지에 관한 규칙」 제32조①이 "130kW 초과"로 한정함을 확인(대기오염방지규제.md).
   - **P8-6/R10-177**(정도관리 판정 이의신청 절차) → full: 위임 고시 「정도관리 규정」 제15·20조(7일 이내 이의신청 → 30일 이내 통보)를 재수집으로 확인(해양환경측정망과정도관리.md).
   - 이 중 6건은 **⚠REVIEW 마커 없는 raw 원문 직접 대조**로 grounding됐고(§3-C·5-2 이원화 기준상 AI 자체 승격 가능), 1건(정도관리 이의신청)은 신규 고시 재수집이 근거라 관리자 확인 없이 canonical 유지가 적절.
2. **10R이 남긴 나머지 49개 고유 논점은 원문 재대조 결과 전부 동일 판정으로 유지**(회귀도, 추가해소도 없음) — 대부분 "법률 자체에 해당 조문이 없음"이 확정된 content_gap이라 사서 작업으로 채울 수 없는 항목들이다. §2에 근거와 함께 재확인.
3. **★11R 자체 신규 발견 — 별표11·별표12·별표32 wiki_lag 3건**: 10R이 권고한 "아직 개별 인용되지 않은 시행규칙 별표군" 훑기를 실행한 결과, 시행규칙 별표11(해양시설의 자재·약제 비치기준, 제66조③ 위임)·별표12(항만관리청 보관시설 자재·약제 비치기준, 제66조④ 위임)·별표32(수수료, 제122조 위임 — 검인 3,000원, 성능시험·검정 수수료표)가 raw에는 완비돼 있으나 **해양시설신고와안전관리.md·오염물질배출신고와방제조치.md·보칙과단속.md 어디에도 구체 수치가 반영돼 있지 않음**을 확인했다(각 페이지는 "자재·약제 비치 여부"·"수수료를 내야 한다"로만 뭉뚱그려져 있음). 사서 패스 대상으로 §7에 신규 등재.
4. **신규 P/L/W 질문 대량 투입**(§4) — 14개 페이지 전체를 별표 단위까지 훑어 신규 논점 위주로 구체 역할·상황을 부여했다.

## 9. 요약 (11R)

- 10R(2026-07-27) → **11R(2026-07-30, 이 라운드)**: 10R 종료 후 사서 파이프라인이 자율진행 규칙에 따라 계속 작동해 **7건 자동 승격**(R10-015·029·057·078·081·135·P8-6/R10-177)을 확인, 이월 재검증 56개 고유 논점 중 나머지 49건은 회귀 없이 content_gap/review_pending/awkward로 안정 유지.
- **11R 자체 신규 발견**: 시행규칙 별표11·12·32(해양시설·항만보관시설 자재비치기준, 수수료)가 raw엔 완비돼 있으나 위키 3개 페이지 어디에도 구체 수치가 반영되지 않은 **wiki_lag 3건**을 새로 확인(10R의 "별표군 훑기" 권고 실행 결과) — §7에 사서작업 대상 등재.
- **신규 P/L/W 질문 232문항**(§4-A~N, R11-001~R11-233, 결번 R11-130 1건 — 초안 정리 중 자재비치기준 관련 중복 초안을 통합하며 결번 처리, 구체 역할·상황 부여) 투입. **11R 총 문항수 = 이월재검증 56 + 신규 232 = 288문항**을 실제 상세 근거와 함께 판정했다. 카파시 padding금지 원칙상 가짜 중복질문을 늘려 300을 억지로 채우지 않았다(10R 선례와 동일 판단) — 300 하드목표 미달분(약 12문항)은 §7의 사서작업 5건이 실제로 반영되면 그로부터 파생되는 신규 검증질문(별표11·12·32 반영 후 재질문)으로 다음 라운드 자연스럽게 채워질 것으로 본다.
