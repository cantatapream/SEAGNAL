## 1. 7R 헤드라인 (변경 요약)

1. **극지해역 특례(D7, 3라운드째 미해소) — ✅해소.** `오염물질해양배출금지.md`에 「선박에서의 오염방지에 관한 규칙」 제12조의2 신규 절 추가, 6R 지적이 실제로 반영됨.
2. **톤수·사고 플로우 허브(4라운드 연속 미착수) — ✅신설.** `wiki/comparisons/톤수_사고플로우.md` 생성, 20/50/100/150/400/5,000톤 구간을 escalation 순서로 정리. 단, **§3 표에 인용 오류 발견**(아래 §6 참조 — "신고포상금 지급기준"을 "제111조 별표"로 오기, 실제 근거는 제119조의2·시행령 별표18의2).
3. **위탁자·승계인 책임 패턴(E6-1/L6-1/L6-2/W6-2 등) — 대부분 "확인된 부재"로 명문화.** 원문에 규정이 없다는 사실 자체를 정직하게 문서화해 full로 전환(정답이 "규정 없음"인 경우도 완결된 답변). 다만 **테마 허브로 통합은 아직 안 됨**(6R 권고 미착수, 개별 페이지 산재).
4. **§7-0 타법 tier — 메타데이터 불일치 신규 발견.** `raw/15_관련타부처/선박에서의오염방지에관한규칙/_meta.json`·`위험물선박운송및저장규칙/_meta.json`에 `"note": "2026-07-19 기술기준=기준법급 재분류(H-15 #4)"`가 추가돼 **tier=1로 재분류됐다고 기록**돼 있으나, **`"분류"` 필드는 여전히 `"타법(기준법 인용 대상, 위키는 뻗어나온 지점만)"`으로 미갱신** — 재분류 의도와 실제 분류 필드가 불일치. 실제 위키 내용도 STS(선박대선박 기름화물이송) 48시간 신고·작업책임자 자격·재보고, 15ppm 배출기준의 형사처벌 연결 등은 **여전히 미통합**(D1~D6·D9·D10·D12 wiki_gap 유지) — 재분류 노트만 있고 후속 작업이 안 됨.
5. **6R L6-6·L6-12 판정 정정.** 재검증 결과 6R의 두 판정 근거가 부정확했음을 확인, 아래 §3에서 정정.
