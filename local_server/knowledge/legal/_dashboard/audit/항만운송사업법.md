## 총평

3개 개념 페이지는 스키마 형식(정의→적용범위·제외→예외→의무→처벌→행정처분→근거조문→타법연결)을 잘 따르고 있고, 처벌·행정처분 표는 대체로 조·항·호·금액까지 정밀하다. 그러나:
1. **법이 규율하는 사업 유형 중 "항만종합서비스업"·"부두운영회사"가 개념 페이지로 전혀 편입되지 않음** (원문·별표는 이미 수집돼 있음 — 위키만 비어 있음).
2. **교육훈련 의무(제27조의3)·권리의무 승계(제23조·제26조의4)**도 독립 개념으로 다뤄지지 않음(단편적 언급뿐).
3. **미등록 항만 일시영업 위반 시 처벌(제31조제2호, 500만원)**이 예외 규정에서 "신고하면 가능"만 언급되고 정작 "안 하면?"의 벌칙이 두 페이지 모두에서 누락.
4. **과태료(제34조)가 항·호별로 뭉개짐** — 실제로는 1호(보고거부 100→200만)와 2호(검사거부 150→200만)가 금액이 다른데 위키는 "100~200만원"으로 합쳐놓음.
5. 사업등록 과징금 문장에서 **등록기준 미달(별표9 제1호, 100만원) 항목이 위키에서 누락**(관련사업 페이지에는 있으나 하역사업 페이지에는 없음).

## 위키 갭 (missing 개념)

1. **항만종합서비스업**(법 제2조제8항·제26조의2, 시행령 제11조의2·별표5의2, 시행규칙 제25조의2) — 개념 페이지 전무. 원문·별표는 이미 수집됨(별표5의2: 자본금 1급지 1.5억/2급지 1.5억/3급지 1억 등).
2. **부두운영회사·부두운영계약**(법 제2조제6항, 제26조의6~제26조의10, 시행규칙 제27~29조의5) — 선정기준·계약사항·위약금·성과평가·해지사유 전부 개념 페이지 없음.
3. **항만운송 종사자 교육훈련**(법 제27조의3·제27조의4, 시행령 별표7·8) — 검수사등자격.md에 "산업안전보건법 교육 이수 시 간주"만 파편적으로 언급. 훈련 의무 자체(안전사고 우려 작업 종사자 대상)·미이수 시 작업제한 효과는 독립 개념 없음.
4. **권리·의무의 승계**(법 제23조·제26조의4 — 상속·양도·합병·경매 시 등록 승계) — 어느 페이지에도 없음.
5. **미등록 항만 일시영업의 벌칙**(법 제31조제2호, 500만원 이하 벌금) — 예외 규정 표에 "신고하면 가능"만 있고, 신고 안 했을 때 처벌이 두 페이지(사업등록과행정처분.md/항만운송관련사업.md) 모두 벌칙 표에서 누락.
6. **관리청 정의**(법 제2조제7항 — 국가관리항=해수부장관, 지방관리항=시·도지사)가 개념 페이지 어디에도 없어 "어디에 등록/신고하나"라는 1차 질문에 위키만으로 답 불가.
7. **청문 절차**(법 제29조의3)가 검수사등자격.md(자격취소 청문)에는 있으나, 사업등록과행정처분.md·항만운송관련사업.md의 등록취소에는 청문 필수 언급 없음(원문은 제29조의3제2·3호에 모두 규정).

## 수집구멍 (📛 collection_hole — 위키가 "별표/고시로 정함"이라면서 수치 누락)

- 이번 감사에서 **엄밀한 collection_hole은 확인되지 않음**. 위키가 언급한 별표(별표1·2·4·5·6·9)는 실제 수치까지 옮겨져 있음. 다만 위 "위키 갭" 항목(항만종합서비스업 등)은 위키가 아예 그 별표(별표5의2)를 인용조차 안 해서 collection_hole이 아니라 "missing 개념"으로 분류함(원문은 이미 수집됨 — 사서가 개념화만 안 한 상태).
- 부두운영회사 위약금 산정식(시행규칙 제29조의4)은 원문에 "해양수산부령으로 정하는 바에 따라"로 위임돼 있고, 시행규칙에서 구체 산식을 규정 — 원문 확인 필요(이번 감사에서 시행규칙 제29조의4 본문까지는 열람했으나 위키 미반영이라 collection_hole보다는 missing으로 처리).

## 답변 이슈 (⚠ 구조·정밀도 문제, collection_hole 아님)

1. **과태료 제34조① 뭉개기**: "100~200만원"이 아니라 "1호(보고·자료제출 거부/거짓) 1차 100만·2차 200만" vs "2호(출입·검사 거부·방해·기피) 1차 150만·2차 200만"(시행령 별표10)으로 분리해야 함.
2. **과징금 개별기준 페이지 간 불일치**: 시행령 별표9 제1호(등록·신고기준 미달, 100만원, 1차만)는 법 제6조·제26조의3제7항 둘 다에 걸리는 공통 조항인데, 사업등록과행정처분.md 과징금 문장엔 빠지고 항만운송관련사업.md에만 있음.
3. **미등록 항만 일시영업 미신고 시 처벌 누락**(위 갭 5).
4. **하역사업 정의 세부(제2조제1항 1~13호)가 "1~13호의 행위"로만 뭉뚱그려짐**: 부선·뗏목·목재 등 하위 정의는 사업등록과행정처분.md 정의 표에 없어 "부선으로 화물 날라도 하역사업이냐" 같은 질문은 개념 페이지만으로 정확히 답하기 어려움(원문 열람 필요).
