### 이번 재검증의 핵심 발견 (감사 17라운드까지 놓쳤던 것)

1. **감사가 한 번도 안 한 대조가 구멍을 만든다** — `lsDelegated` 위임행정규칙 목록 ↔ `raw/<법>/행정규칙/` 폴더·`_admrul.json` 을 1:1 정규화 대조한 결과, 감사가 17라운드 내내 "collection_hole 0건"으로 판정해온 법에서 **신규 미수집 위임행정규칙 8건**이 나왔다(수산업법 3건, 해상교통안전법 1건, 유선및도선사업법 2건, 한국해양교통안전공단법 1건, 섬발전촉진법 1건[모법 발췌누락]).
2. **`lsDelegated`는 별표 위임을 인덱싱하지 않는다** — 유선및도선사업법 admrul 2100000281570은 *시행령 별표1*에서 위임돼 lsDelegated 응답에 안 잡혔고, 그래서 최초 누락이 발생했다. 별표 위임 고시는 lsDelegated만으로 존재확인 불가 → `lawSearch(target=admrul, query=제목단편)` 병행이 필수.
3. **이미지 층(별표 부도·가격표)이 통째로 비어 있다** — 해양조사법 별표 이미지 83개, 수산업법 별표 부도 122항목분 전량, 해양정보간행물 가격표 이미지 모두 로컬 0건. `_links.json`에 URL은 이미 기록돼 있고 `flDownload.do` 요청이 HTTP 200으로 떨어지는 것을 실측 확인 → 파이프라인(`dl_byl_images.sh`)은 있으나 **별표 층에만 미적용**.
4. **`_admrul.json = {}` 을 "하위규정 없음"의 근거로 쓰면 안 된다** — 한국해양교통안전공단법에서 감사가 1R~17R 내내 이 근거로 "위임 하위규정 없음"을 전제했으나, lsDelegated의 위임구분 `"위임규정"`(= 공단 정관)은 행정규칙 DB(admrul)가 아니라 `target=public` 로 조회되는 별개 계층이라 검색에 안 잡혔을 뿐 실재했다. 그 정관 본문이 감사가 17라운드 내내 ❌missing으로 판정해온 항목 7개(본사 위치·임원 임기·정관 변경 승인 등)를 직접 답한다.
