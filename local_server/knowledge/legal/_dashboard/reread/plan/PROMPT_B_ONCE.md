# 보조 계정(B) — 한 번만 붙여 넣고 그대로 두는 메시지

## 사장님이 할 일 (보조 계정에서 딱 한 번)
1. 보조 계정으로 로그인한 **클로드 앱**에서 새 Claude Code 세션을 연다(웹으로 연 세션에는 「워크플로우」 도구가 없을 수 있다).
2. 저장소 **`cantatapream/SEAGNAL`** 을 붙인다.
3. 권한 모드를 **「묻지 않고 진행」(자동 승인) 쪽**으로 둔다 — 사장님이 없을 때 승인 대기로 멈추지 않게.
4. 아래 상자 안 글을 **그대로** 보낸다.
5. 그 세션은 **닫거나 지우지 않고** 그대로 둔다. 로그아웃해도 된다 — 예약 작업은 서버에서 돌며 이 세션을 깨운다.

- 사용량이 99%라 붙여 넣은 직후에 한도에 걸릴 수 있다. 그래서 **예약 작업을 가장 먼저 만들게** 했다.
  예약 작업만 만들어지면, 일이 시작 전에 멈춰도 목요일 초기화 뒤 첫 확인에서 처음부터 이어서 시작한다.
- 확인 못 한 것: 한도에 막힌 동안 예약 작업이 여러 번 실패하면 플랫폼이 그 예약을 스스로 끄는지는 확인하지 못했다.
  메인 계정은 일할 때마다 보조 진행표를 보고, 보조가 목요일 이후에도 움직이지 않으면 사장님께 알리고 보조 몫을 R65 부터 거꾸로 가져간다.
