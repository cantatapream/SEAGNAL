# 해양환경관리법 — 톤수 구간별 의무 총괄표 (종합형 질문 전용 색인)

> ⚠ **draft — 미승인.** 「해양환경관리법」위키 여러 개념 페이지에 흩어진 **총톤수 20/50/100/150/400/5,000톤** 문턱값을 한곳에 모은 색인이다(감사 3R~6R, 4라운드 연속 미착수 지적). "내 배가 몇 톤인데 뭘 갖춰야 하나"를 톤수 하나로 훑어 즉답하기 위한 허브 — 각 항목의 상세 요건·예외는 출처 페이지에서 확인한다. **단일 법(해양환경관리법) 내부 통합 색인**이라 [[도선법_벌칙과태료_총괄]]과 같은 `single-law-index` 성격이며, SCHEMA 4절의 "여러 법 비교표"와는 결이 다르지만 규모가 크고 반복 요청된 테마라 `wiki/comparisons/`에 둔다.

## 2. 톤수 무관(승선인원·구조 기준) 항목 — 혼동 주의

톤수가 아니라 **승선인원·구조**를 기준으로 하는 의무도 같은 조문군에 섞여 있어 혼동하기 쉽다 — 톤수만 보고 판단하면 오답이 될 수 있다:

| 기준 | 의무 | 근거 |
|---|---|---|
| 검사증서상 최대승선인원 **16명 이상** | 분뇨오염방지설비 설치(400톤 이상 대안 기준) | 제25조①, 규칙 제14조① |
| 수상레저기구 승선정원 **16명 이상** | 분뇨오염방지설비 설치 | 규칙 제14조① |
| 승선인원 **15명 이상**(1시간 이내 단거리 항해 제외) | 기름기록부 비치 | 제30조①2호 |
| 선저폐수가 생기지 않는 구조 | 100톤 미만이라도 기름기록부 비치 **제외** | 규칙 제23조①②단서 |
| 총톤수 **2톤 미만** | 중간검사 자체를 생략 | 규칙 제40조③단서 |

## 3. 사고(방제) 축 — 유출량 기준 방제 대응

방제조치·방제선 배치는 톤수가 아니라 **유출량·용량 기준**으로 별도 체계다(직접 비교 대상이 아님, 혼동 방지):

| 항목 | 기준 | 근거 | 출처 페이지 |
|---|---|---|---|
| 방제선등 배치의무 | 선박 톤수·시설 용량 기준(구체 구간은 페이지 참조) | 제67조 | [[해양환경관리법__오염물질배출신고와방제조치]] |
| 신고포상금 지급 기준(해양배출폐기물, 지정해역 외 배출) | 10톤 이상/5~10톤/3~5톤/1~3톤/0.5~1톤 구간별 차등, 0.5톤 미만 지급 없음 | 제119조의2, 시행령 제91조의2·별표18의2 | [[해양환경관리법__보칙과단속]] |

## 4. 확인 필요 (REVIEW)

- 이 표는 각 개념 페이지에 이미 기재된 톤수 기준을 **재배열**한 색인이며, 새로운 해석·연결을 추가하지 않았다(원문 발췌 그대로 재배열 — 개별 REVIEW는 각 출처 페이지 참조).
- 제67조 방제선 배치의 구체 톤수·용량 구간은 [[해양환경관리법__오염물질배출신고와방제조치]] 원문을 직접 확인할 것(이 표는 존재만 표시, 수치는 옮기지 않음 — 출처 페이지가 최신).
