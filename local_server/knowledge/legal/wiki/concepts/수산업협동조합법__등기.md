# 지구별수협 등기 (설립·지사무소·이전·변경·행정구역변경·합병·해산·청산인·청산종결·등기부)

> ✅ **canonical** 2R 감사에서 발견된 구조적 공백. 지금까지 위키에서는 이 조문들이 **벌칙 매핑표에서 "등기 부정(제92~95·97~100·103조)은 제177조제15호"라고만 인용**돼 처벌 근거는 있으나 정작 등기 자체가 무엇인지·언제까지 해야 하는지의 절차 설명은 어디에도 없었다(정의우선 원칙의 역전 사례). 이 페이지가 그 절차를 채운다. (수산업협동조합법 제92~103조, 2026-03-31 시행)

## 정의

| 용어 | 정의 | 근거 |
|---|---|---|
| 설립등기 | 출자금 납입 완료일부터 2주 이내 주된 사무소 소재지에서 하는 조합 성립 등기 | 제92조제1항 |
| 지사무소 설치등기 | 지사무소 설치 시 주된 사무소 소재지에서 하는 등기 | 제93조제1항 |
| 이전등기 | 주된 사무소·지사무소 이전 시 하는 등기 | 제94조제1항·제2항 |
| 변경등기 | 설립등기 사항(정관 기재사항 등)이 바뀔 때 하는 등기 | 제95조제1항 |
| 해산등기·청산인등기·청산종결등기 | 조합이 해산·청산되는 각 단계마다 하는 등기(3단계) | 제98~100조 |
| 등기부 | 등기소가 갖추는 **지구별 수산업협동조합등기부** | 제102조 |

| 지사무소 설치등기·이전등기·행정구역지명변경 관련 등기 | **3주일 이내**(2024.9.20 개정으로 설치·이전은 2주→3주 연장) | 본문 — 제93조제1항·제94조제1항~제3항·제95조제1항 |
| 변경등기 중 **출자계좌수·납입출자금총액**만 바뀐 경우 | 수시 변경등기 대신 **회계연도 말 기준, 그 연도 종료 후 3개월 이내** 일괄 등기 | 본문단서 — 제95조제2항 |
| 행정구역 지명이 변경된 경우 | 등기부·정관상 지명도 **자동으로 변경된 것으로 간주**(별도 변경등기 불요, 조합은 등기소에 통지만) | 본문 — 제96조제1항·제2항 |
| 합병 시 등기 | 합병인가일부터 **2주 이내** — 존속조합은 변경등기, 소멸조합은 해산등기, 신설조합은 설립등기를 **동시에** 함 | 본문 — 제97조제1항 |
| 조합 해산(합병ㆍ파산 제외) | 주된 사무소 소재지에서 **2주일 이내** 해산등기 | 본문 — 제98조제1항 |
| 청산인 취임 | 취임일부터 **2주 이내** 성명ㆍ주민등록번호ㆍ주소 등기 | 본문 — 제99조제1항 |
| 청산 종결 | 청산인이 **2주일 이내** 청산종결등기, 결산보고서(제90조) 승인 증명서류 첨부 | 본문 — 제100조제1항·제2항 |
| 등기사항 중 해양수산부장관 인가ㆍ승인이 필요한 것 | 등기기간은 **인가ㆍ승인 문서가 도달한 날**부터 계산(의결일이 아님) | 본문 — 제101조 |
| 조합의 등기(법에서 정한 사항 외) | 「비송사건절차법」ㆍ「상업등기법」 중 등기 관련 규정 **준용** | 본문 — 제103조 |

## 의무 내용 (원문 발췌)

- 제92조제2항: 설립등기신청서 기재사항 — 정관 주요사항(제17조제1~4호·제16~18호), 총출자계좌수·납입출자금총액·1계좌금액·납입방법, 설립인가연월일, 임원 성명ㆍ주민등록번호ㆍ주소 (제92조제2항 제1~4호)
- 제92조제4항: 설립등기신청서에는 설립인가서ㆍ창립총회의사록ㆍ정관사본 첨부 (제92조제4항)
- 제92조제5항: 합병ㆍ분할로 인한 설립등기는 공고ㆍ독촉 증명서류, 채권자 이의 시 변제ㆍ담보제공 증명서류 추가 첨부 (제92조제5항 제1~3호)
- 제95조제4항·제5항: 변경등기 신청 시 변경 증명서류 첨부, 출자감소ㆍ합병ㆍ분할로 인한 변경등기는 공고ㆍ독촉ㆍ이의처리 증명서류 추가 (제95조제4항·제5항)
- 제96조제3항: 등기소는 행정구역 지명변경 통지를 받으면 등기부 기재내용을 변경 (제96조제3항)
- 제97조제2항·제3항: 합병으로 소멸되는 조합의 조합장이 해산등기 신청인, 해산사유 증명서류 첨부 (제97조제2항·제3항)

> ※ "부정하게 한 경우"의 구체 판단기준(단순 기한 도과도 포함되는지, 허위기재만인지)은 원문에 세부 기준이 없어 사례별로 판단해야 한다(이 위키가 일반적으로 단정하지 않음). 설립인가 후 **90일 내 미등기**는 이 형벌과 별개로 [[수산업협동조합법__감독_경영지도_설립인가취소]]의 **설립인가취소 사유**(제173조제1항제1호)도 된다 — 형벌과 행정처분이 **동시에** 적용 가능한 사안.
