# 해양오염방지를 위한 선박검사 (정기·중간·임시·임시항해·방오시스템·에너지효율검사·항만국통제)

> ⚠ **draft — 미승인.** 폐기물·기름·유해액체물질·대기오염방지설비(해양오염방지설비등)를 갖춘 선박이 받아야 하는 6종 검사와 검사증서 유효기간·재검사·부적합 선박 조치·항만국통제를 다룬다. 검사 대상·항목의 세부 기준은 「선박안전법」 검사체계와 유사하게 해수부령에 위임되나, **유효기간·재검사 기한 등 핵심 수치는 법률에 직접 명시**돼 있다.

## ★ 정의부터

| 용어 | 정의 | 근거 |
|---|---|---|
| **해양오염방지설비등** | 폐기물·기름·유해액체물질·대기오염방지설비(해양오염방지설비) + 제26조②의 선체 + 제27조②의 화물창 | 해양환경관리법 제49조① |
| **검사대상선박** | 해양오염방지설비등을 설치하거나 유지해야 하는 선박 | 제49조① |
| **정기검사** | 해양오염방지설비등을 최초 설치·항해사용 시 또는 유효기간(5년) 만료 시 받는 검사 | 제49조① |
| **중간검사** | 정기검사와 정기검사 사이에 받는 검사 | 제50조① |
| **임시검사** | 해양오염방지설비등을 교체·개조·수리할 때 받는 검사 | 제51조① |
| **임시항해검사** | 해양오염방지검사증서를 교부받기 전 임시로 항해에 사용하려 할 때 받는 검사 | 제52조① |
| **방오시스템검사** | 방오시스템을 선박에 설치·항해사용 시 받는 검사(변경·교체 시는 임시방오시스템검사) | 제53조①③ |
| **예비검사** | 대기오염방지설비를 제조·개조·수리·정비·수입하려는 자가 임의로 받을 수 있는 검사(합격 시 정기·중간·임시·임시항해검사 전부·일부 생략) | 제54조① |
| **에너지효율검사** | EEDI·SEEMP·에너지효율지수 대상 선박이 받는 검사 | 제54조의2① |
| **협약검사증서** | 국제항해용 선박에 대해 해양오염방지에 관한 국제협약에 따라 교부하는 검사증서(국내 검사증서와 같은 효력) | 제55·56조④ |
| **항만국통제(PSC)** | 국내 항만·연안의 외국선박이 국제협약 기술기준·황함유량기준에 부적합할 때 명령하는 조치 | 제59조① |

## 적용범위·제외

| 적용대상 | 제외 | 근거 조문 |
|---|---|---|
| 해양오염방지설비등을 설치·유지해야 하는 **검사대상선박** 전체 | — | 제49조① |
| 국제항해 외국선박 | **정기·중간·임시·임시항해·방오시스템검사(제49~54조)·에너지효율검사(제54조의2)·재검사(제60조)는 적용 제외** | 제3조③ 단서 |

## 검사증서 유효기간 (제56조①)

| 증서 | 유효기간 |
|---|---|
| 해양오염방지검사증서 | **5년** |
| 방오시스템검사증서 | **영구** |
| 에너지효율검사증서 | **영구** |
| 협약검사증서 | **5년** |

- 해수부장관은 해양오염방지검사증서·협약검사증서의 유효기간을 해수부령이 정하는 기간 범위에서 연장 가능(제56조②).
- 중간검사·임시검사 불합격 시 해당 검사증서·협약검사증서 효력은 **합격할 때까지 정지**(제56조③).
- EEDI·에너지효율지수가 변경되는 개조를 하면 **에너지효율검사를 다시 받아야** 하며, 그 증서는 합격 때까지 효력정지(제56조④).

## 재검사 (제60조)

| 항목 | 기한 |
|---|---|
| 재검사 신청 | 검사결과 통지받은 날부터 **90일 이내** |
| 재검사 결과 통보 | 신청 접수 후 **60일 이내**(부득이한 사유 시 **30일 범위** 연장 가능) |
| 행정소송과의 관계 | 재검사 절차를 거치지 않으면 원칙적으로 행정소송 제기 불가(「행정소송법」 제18조②③ 예외 있음) |

## 부적합 선박에 대한 조치·항만국통제

| 조치 | 요건 | 근거 |
|---|---|---|
| 개선명령 | 해양오염방지설비등·방오시스템·연료유 황함유량이 설치·기술·황함유량 기준에 부적합 | 제58조① |
| **항해정지처분** | 중대한 결함으로 인한 교체 등 명령을 이행하지 않고 계속 사용(수리항 항해 등 정당사유는 예외) | 제58조② |
| 에너지효율 관련 명령 | EEDI/CII 계산방법·허용값 부적합, SEEMP 미비치 시 수정·교체·개조·비치 명령 | 제58조③ |
| **항만국통제** | 국내 항만·연안 외국선박의 설비·방오시스템·연료유·에너지효율이 국제협약 기술기준·황함유량기준 부적합 | 제59조①(「선박안전법」 제68~70조 준용) |

## 의무 내용 (원문 발췌)

- "검사대상선박의 소유자가 해양오염방지설비등을 선박에 최초로 설치하여 항해에 사용하려는 때 또는 … 유효기간이 만료한 때에는 … 해양수산부장관의 검사(정기검사)를 받아야 한다." (제49조①, 2026-07-01 시행)
- "선박의 소유자는 해양오염방지검사증서·임시해양오염방지검사증서·방오시스템검사증서 또는 에너지효율검사증서를 교부받지 아니한 검사대상선박을 항해에 사용하여서는 아니 된다." (제57조①)
- "선박의 소유자는 협약검사증서를 교부받지 아니한 선박을 국제항해에 사용하여서는 아니 된다." (제57조②)
