# 소년선원과 여성선원 보호 (제9장)

> ⚠ **draft — 미승인.** 16세 미만은 원칙적으로 선원이 될 수 없다(가족선박만 예외). 18세 미만은 위험작업·야간작업이 금지되고, 임신 중 여성선원은 원칙적으로 선내작업 자체가 금지된다 — 근로기준법보다 강한 보호수준이다.

## ★ 정의부터

이 장은 별도 정의조 없이 제2조 일반정의(선원)와 나이 기준을 그대로 사용한다.

| 용어 | 기준 | 근거 |
|---|---|---|
| 미성년자 선원 | 법정대리인 동의를 받아야 선원근로계약을 성년자와 같은 능력으로 체결 | 선원법 제90조 |
| 소년선원 | 18세 미만 선원 | 제91조제2·3항 |

## 적용범위·제외

| 적용대상 | 제외 대상 | 근거 조문 |
|---|---|---|
| 모든 선박소유자 — 16세 미만 사용금지 | **가족만 승무하는 선박**은 제외 | 제91조제1항 단서 |
| 18세 미만 선원 — 위험·위생상 해로운 작업 종사금지, 승인 필요 | — | 제91조제2·3항 |
| 여성선원 — 임신·출산에 해롭거나 위험한 작업 종사금지 | — | 제91조제4항 |
| 임신 중 여성선원 — 선내 작업 종사 원칙 금지 | 해양수산부령 정하는 항해 범위에서 신청 + 의사 무해 인정 / 항해 중 임신 사실 인지 + 선박 안전 필요 작업 | 제91조제5항 |
| 산후 1년 미경과 여성선원 — 위험·위생상 해로운 작업 종사금지 | — | 제91조제6항 |
| 가족만 승무하는 선박 | 제91조제4~6항(여성선원 보호규정) **적용 제외** | 제91조제7항 |
| 18세 미만 선원 — 야간작업 금지 | 가벼운 일 + 선원 동의 + 해양수산부장관 승인, 제60조제6항 부득이한 작업, 가족만 승무 선박 | 제92조 |

## 예외 규정

| 조건 | 효과 | 출처 |
|---|---|---|
| 가족만 승무하는 선박 | 16세 미만 사용 금지 **적용 제외**, 여성선원 위험작업 보호(제4~6항) **적용 제외**, 야간작업 금지 **적용 제외** | 제91조제1항 단서·제7항, 제92조제2항 |
| 18세 미만 선원 사용 시 | 해양항만관청 **승인** 필요 | 제91조제2항, 시행규칙 제56조 |
| 임신 중 여성선원이 해양수산부령 범위의 항해에 대해 선내작업 신청 + 의사가 무해 인정 | 선내작업 **허용** | 제91조제5항제1호 |
| 항해 중 임신 사실 인지 + 선박 안전에 필요한 작업 | 선내작업 **허용** | 제91조제5항제2호 |
| 가벼운 일 + 선원 동의 + 해양수산부장관 승인 | 18세 미만 야간작업(자정~오전5시 포함 최소 9시간) **허용** | 제92조제1항 단서 |

## 의무 내용 (원문 발췌)

- **미성년자의 능력**(제90조): 법정대리인 동의를 받은 미성년자는 선원근로계약에 관해 성년자와 같은 능력을 가짐.
- **사용제한**(제91조제1항): "선박소유자는 16세 미만인 사람을 선원으로 사용하지 못한다. 다만, 그 가족만 승무하는 선박의 경우에는 그러하지 아니하다."
- (제91조제3항): 18세 미만 선원을 위험한 선내작업·위생상 해로운 작업에 종사시켜서는 아니 됨.
- (제91조제4항): 여성선원을 임신·출산에 해롭거나 위험한 작업에 종사시켜서는 아니 됨.
- (제91조제5항): "선박소유자는 임신 중인 여성선원을 선내 작업에 종사시켜서는 아니 된다." (예외는 위 표 참조)
- (제91조제6항): 산후 1년 미경과 여성선원 위험·위생상 해로운 작업 종사 금지.
- **야간작업의 금지**(제92조제1항): "선박소유자는 18세 미만의 선원을 자정부터 오전 5시까지를 포함하는 최소 9시간 동안은 작업에 종사시키지 못한다."
- **생리휴식**(제93조): "선박소유자는 여성선원이 청구하면 월 1일의 생리휴식을 주어야 한다."
(모두 선원법, 2026-03-17 시행)
