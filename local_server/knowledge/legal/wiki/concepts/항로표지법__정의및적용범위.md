# 항로표지법 — 정의·종류·적용범위 (정의허브)

> ⚠ **draft — 미승인(9차 remediation, L-15 패턴 재확인).** 항로표지법의 모든 개별 개념 페이지가 참조하는 **정의 허브**. "등대가 뭔가요", "이 법은 내 배·내 조업구역에 적용되나요" 같은 질문의 최상단 근거. 다른 페이지에서 정의가 필요하면 여기로 [[링크]]한다. 본문 "14종 특수항로표지의 설치허가 근거조문 매핑"(AI 연결·종합, 시행규칙이 직접 명시하지 않는 매핑을 조문 대조로 도출)이 그 자리에 "사람 확인 전까지 draft 유지"라고 스스로 표시해 두었음에도 canonical로 남아있던 것을 확인해 canonical→draft 환원.

### 항로표지의 종류 (시행규칙 제2조제1항, 2025-10-28 시행)

| 구분 | 세부 종류 |
|---|---|
| 1. 광파(光波)표지 | 유인등대, 무인등대, 등표(燈標), 도등(導燈), 조사등(照射燈), 지향등(指向燈), 등주, 교량등, 통항신호등, 등부표(燈浮標), 고정부표(spar buoy), 대형 등부표(LANBY), 등선(燈船) |
| 2. 형상표지 | 입표(立標), 도표(導標), 교량표, 통항신호표, 부표 |
| 3. 음파표지 | 전기 혼, 에어 사이렌, 모터 사이렌, 다이아폰 |
| 4. 전파표지 | 레이더 비콘, 위성항법보정시스템(DGNSS), 지상파항법시스템(LORAN, R-Mode 등) |
| 5. 특수신호표지 | 해양기상신호표지, 조류신호표지, 자동위치식별신호표지(AIS AtoN) |

**특수항로표지(기능·목적별 재분류, 시행규칙 제2조제2항)**: 공사용 표지, 침선표지, 교량표지, 계선표지, 해저케이블표지, 해저송유관표지, 해양자료수집용 표지, 해양자원탐사용 표지, 해양자원시추용 표지, 해양자원채굴용 표지, 양식장표지, 해양풍력발전단지표지, 해양조력발전단지표지, 해양파력발전단지표지 (총 14종).

**14종 특수항로표지의 설치허가 근거조문 매핑** ⚠REVIEW-07(AI 연결·종합, 법 제9조제6항·제13조제1항·제14조제1항 원문 대조로 분류, 2026-07-19 — 시행규칙이 14종을 근거조문별로 직접 표로 묶어 명시하지는 않으므로, 이 매핑은 각 조문 문언 대조로 도출한 해석이다. 사람 확인 전까지 draft 유지):

| 특수항로표지 | 설치허가 근거 | 근거 조문 |
|---|---|---|
| 공사용 표지 | 지정수역에서 준설·매립·구조물 설치 등 공사 시 설치 | 법 제13조제1항제1호 → [[항로표지법__공사구역표시항로표지및설치허가]] |
| 해양풍력발전단지표지·해양조력발전단지표지·해양파력발전단지표지 | 지정수역에서 풍력·조력·파력발전단지(인공구조물) 설치 시 설치 | 법 제13조제1항제2호 → [[항로표지법__공사구역표시항로표지및설치허가]] |
| 침선표지 | 침몰·좌초 선박 소유자의 설치·신고의무 | 법 제14조제1항 → [[항로표지법__침선표지]] |
| 교량표지·계선표지·해저케이블표지·해저송유관표지·해양자료수집용 표지·해양자원탐사용 표지·해양자원시추용 표지·해양자원채굴용 표지·양식장표지 (9종) | 자기의 사업·업무에 사용하기 위한 자가설치 항로표지 | 법 제9조제6항 → [[항로표지법__공사구역표시항로표지및설치허가]] |

> 즉 14종이 하나로 통일된 게 아니라 **3갈래**로 나뉜다 — ①지정수역 안 공사·발전단지(제13조, 4종) ②침선(제14조, 1종) ③그 외 자기 사업용(제9조제6항, 9종). 교량표지가 제13조 열거(풍력·조력·파력·부두)에 직접 포함되지 않아 자가설치(제9조제6항)로 분류되는 점에 주의(부두는 인공구조물로 제13조1항2호 대상이나 "교량"은 별도 열거가 없음).

**쉽게 말하면**: 바다 위에서 흔히 보는 "등대", "빨간/초록 부표", "삐 소리 나는 표지"가 다 이 법의 "항로표지"다. 부표의 색깔·모양이 왜 그렇게 나뉘는지(좌현=녹색·우현=홍색 등)는 → [[항로표지법__해상부표식및표준형부표규격]]. 부표에 배를 묶거나 등표에 올라가는 행위의 규제는 → [[항로표지법__항로표지보호행위제한]].

### 삭제된 조문
법 **제44조는 2024.1.23 삭제**되어 현재 조문이 존재하지 않는다(원문 「제44조」 자리에 "삭제 <2024.1.23>"만 표기, 제6장 보칙 앞자리). 옛 자료·판례에서 "항로표지법 제44조"를 언급하면 더 이상 유효하지 않다는 뜻이다. (법률.txt 제44조 표기, 삭제 사유·구 조문 내용은 raw에 없음 — 확인불가)

| 항로표지의 설치·관리 일반 | **다른 법률에 특별한 규정이 있는 경우**(예: 항만법상 항만시설, 어초·양식시설 표지 등 타법 우선) | 법 제5조 | 본문 단서("다른 법률과의 관계") |

> **톤수 조건이 없는 법**: 항로표지법 전체를 통틀어 선박 **톤수를 기준으로 의무·처벌이 갈리는 조문이 없다**(다른 해양수산 법령과 달리 "5톤 미만은 제외" 같은 규정이 존재하지 않는다). 이 법의 적용 여부는 오직 **수역**(제4조 3개 수역, 제13·14조 지정수역)과 **행위/지위**(자가설치·공사·침몰좌초·위탁관리업 등)로만 갈린다. 사용자가 톤수를 물으면 "이 법은 톤수와 무관하다"고 먼저 답하고 수역·행위 조건을 확인한다.

## 의무 내용 (원문 발췌 — 정의·적용범위 관련 조문)

- **제1조(목적)**: "이 법은 항로표지를 설치하고 합리적이고 효율적으로 관리하여 해상교통의 안전을 도모하고, 선박 운항의 능률을 향상시키는 데 이바지함을 목적으로 한다." (법 제1조, 2025-10-23 시행)
- **제4조(적용범위)**: "이 법은 다음 각 호의 어느 하나에 해당하는 수역에 설치되는 항로표지에 대하여 적용한다." + 내수면·영해/내수·EEZ 3호 열거 (법 제4조)
- **제5조(다른 법률과의 관계)**: "항로표지의 설치 및 관리에 관하여 다른 법률에 특별한 규정이 있는 경우를 제외하고는 이 법에서 정하는 바에 따른다." (법 제5조)
- **제9조제1항**: "항로표지는 해양수산부장관이 설치·관리한다." (원칙 — 국가 관리. 예외가 사설항로표지, 제9조제6항)
