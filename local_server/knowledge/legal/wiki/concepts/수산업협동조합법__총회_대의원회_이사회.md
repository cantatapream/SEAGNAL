# 지구별수협 총회·대의원회·이사회 (지배구조 운영 절차)

> ✅ **canonical** 2R 감사에서 발견된 구조적 공백(제36~45조, 약 10개 조문)을 메우는 신규 페이지. 지구별수협의 3대 의사결정기구 — **총회(조합원 전체) → 대의원회(총회 갈음, 둘 수 있음) → 이사회(업무집행 관련 별도 의결)** — 의 소집·정족수·안건 절차를 다룬다. 조합원·대의원 본인이 가장 자주 묻는 기초 절차(정기총회 시기, 소집 청구, 안건 상정)가 이 페이지에 몰려 있다. 업종별수협·수산물가공수협·중앙회는 별도 준용조문이 있으므로 이 페이지는 **지구별수협 기준**이다. (수산업협동조합법 제36조~제45조, 2026-03-31 시행)

## 정의

| 용어 | 정의 | 근거 |
|---|---|---|
| 총회 | 지구별수협의 최고 의사결정기구, 조합원 전체로 구성 | 제36조제1항·제2항 |
| 대의원회 | 정관으로 정하는 사항 외에는 총회를 **갈음**할 수 있는 기구(둘 수도, 안 둘 수도 있음), 조합장+대의원으로 구성 | 제44조제1항 |
| 이사회 | 조합장을 포함한 이사로 구성, 업무집행 관련 사항을 별도로 의결하는 기구(총회와 병존, 갈음 아님) | 제45조제1항·제2항 |
| 조합원제안 | 조합원 10분의 1 이상 동의로 총회 개회 30일 전까지 서면으로 안건 상정을 요구하는 제도 | 제41조제3항 |
| 총회 의결의 특례 | 해산·합병·분할, 조합장 선출방식 변경은 총회 대신 **조합원 투표**로 갈음 가능 | 제43조제1항 |

| 조건 | 효과 | 출처 |
|---|---|---|
| 정관변경·해산합병분할(제37조제1항제1·2호) | **해양수산부장관 인가 없으면 효력 미발생**. 단, 해양수산부장관이 정하는 **표준정관례**대로 정관을 변경하는 경우는 인가 불요 | 본문단서 — 제37조제2항 |
| 조합원이 조합원 5분의 1 이상 동의를 받은 경우 | 조합장에게 서면으로 총회 소집 **청구** 가능 | 본문 — 제38조제1항 |
| 조합장이 청구받고 2주 이내 정당사유 없이 소집 안 함 | **감사가 5일 이내** 소집(감사가 의장 직무 수행) | 본문 — 제38조제3항 |
| 감사도 소집 안 함 | **소집을 청구한 조합원의 대표**가 소집(대표가 의장 직무 수행) | 본문 — 제38조제4항 |
| 정관변경·해산합병분할·제명·중앙회설립발기인가입탈퇴(제37조제1항제1~3호·제11호) 의결 | 구성원 **과반수 출석 + 출석구성원 3분의 2 이상 찬성**(일반 안건은 과반수 출석+과반수 찬성) | 본문 — 제40조 |
| 통지하지 않은 안건이라도 **긴급한 사항**(제37조제1항제1~4호 제외)이고 과반수 출석+3분의 2 이상 찬성 | 통지 없이도 총회에서 의결 가능 | 본문단서 — 제41조제1항 |
| 조합원 10분의 1 이상 동의 + 개회 30일 전 서면 제출 | **조합원제안** — 법령·정관 위반 아니면 반드시 총회 목적사항으로 상정, 제안자에게 설명 기회 부여 | 본문 — 제41조제3항 |
| 대의원 임기 만료연도 결산기 마지막달 이후 정기총회 전 임기만료 | 정기총회 끝날 때까지 임기 **연장**(임원 임기 만료도 동일 준용, 제50조제2항) | 본문단서 — 제44조제3항 |
| 이사회 안건에 특별한 이해관계 있는 이사 | 그 안건 의결에 **참여 불가**, 정족수 계산(과반수 출석)에서도 **제외** | 본문 — 제45조제7항 |

## 의무 내용 (원문 발췌)

- 제36조제3항: 정기총회는 **회계연도 경과 후 3개월 이내**에 조합장이 매년 1회 소집, 임시총회는 조합장이 필요하다고 인정할 때 소집 (제36조제3항)
- 제38조제1항: 조합원 5분의 1 이상 동의로 소집목적·이유를 서면으로 조합장에게 제출해 총회 소집 청구 가능 (제38조제1항)
- 제39조제2항: 총회 소집 시 **개회 7일 전까지** 소집통지서 발송(재소집 시 개회 전날까지) (제39조제2항)
- 제40조: 총회는 원칙 구성원 과반수 출석·출석구성원 과반수 찬성으로 의결(정관변경 등 4개 사항은 과반수 출석+3분의2 찬성) (제40조)
- 제41조제2항: 지구별수협과 총회 구성원의 이해가 상반되는 안건은 해당 구성원 의결 참여 불가 (제41조제2항)
- 제42조: 총회 의사록 작성 — 진행상황·결과 기록, 의장+조합원 3인 이상 기명날인·서명, 조합장이 주된 사무소에 비치 (제42조제1~3항)
- 제44조제3항: 대의원 정수·선출방법은 정관, **임기 2년** (제44조제3항)
- 제44조제4항: 대의원은 해당 조합의 조합장을 제외한 임직원, 다른 조합(다른 법률상 협동조합 포함)의 임직원 겸직 불가 (제44조제4항)
- 제44조제5항: 대의원회는 총회 규정 준용, 단 **대의원의 의결권은 대리인 행사 불가** (제44조제5항)
- 제45조제4항: 이사회는 구성원 과반수 출석·출석구성원 과반수 찬성으로 의결 (제45조제4항)
- 제45조제8항: 간부직원은 이사회에 출석해 의견 진술 가능(의결권 없음) (제45조제5항)
