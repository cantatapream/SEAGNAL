# 별표2·3·4 — 안전관리시설물(정보전달시설·사고예방시설·인명구조장비함) 제작방법 등

> 원문 표 구조 그대로 보존(요약 금지, `_SCHEMA.md` 2절 8호). 「연안사고 안전관리규정」(해양경찰청 훈령) 제17~19조 위임.
> 소관부처: 해양경찰청(부처명만 확인됨 — "해양안전과"는 이 훈령 원문에 근거 없어 2026-07-21 삭제, H-21④) · 2026-07-19 raw 재수집으로 신규 확보(4~6라운드 감사 내내 "표 제목만 있고 본문 없음"으로 확인됐던 collection_hole이 raw 단계에서 해소됨).

## [별표2] 안전관리시설물(정보전달시설) 제작방법 등 (제17조 관련)

**1. 정보전달시설의 종류**: 가. 위험표지판(주의표지·규제표지·보조표지) 나. 위험알림판(주의알림판·규제알림판) 다. 방송·경보장치

**2-가. 위험표지판**
- 재질: 부식되지 않고 반사 재료에 영향을 미치지 않는 재질
- 색상: 주의표지판 = 기호 노란색 바탕에 검정색, 테두리 검정색 / 규제표지판 = 기호 하얀색 바탕에 검정색, 테두리 **빨간색**
- 색채(한국산업규격 KS A 0062, KS M 6020, 허용치 △E=1 이내): 빨강 7.5R 4/14 · 노랑 5Y 8.5/14 · 검정 N 1.5 · 하양 N 9.25
- 규격(mm): 주의표지판 가로600×세로527 / 규제표지판 가로600×세로600 / 2개 이상 함께 설치 시 가로2,300×세로1,500
- **확대·축소 재량**: 설치장소 상황(시인성 고려)에 따라 **1.5배~2.5배 확대 또는 0.5배~0.8배 축소** 가능
- 문자: 본고딕 글꼴 / 반사재료 또는 야간조명 사용 / 영어 등 병기 가능
- **위험표지판 유형(19종, 일련번호·종류·설치장소)**:

| 번호 | 종류 | 설치장소 |
|---|---|---|
| 01 | 출입금지 | 사고 개연성이 높아 출입금지가 필요한 구역(대인용·차량용 구분) |
| 02 | 수영금지 | 유속·수심 등 위험요소로 수영하기 위험한 구역 |
| 03 | 다이빙금지 | 수심이 얕거나 간출암 등 위험요소가 산재한 구역 |
| 04 | 수중활동금지 | 유속이 빠르고 수중장애물 등이 많아 수중활동이 위험한 구역 |
| 05 | 갯골주의 | 갯골이 깊은 갯벌구역 |
| 06 | 너울성파도주의 | 너울성 파도가 잦은 연안해역 |
| 07 | 익사사고주의 | 익사 사고가 자주 발생하는 구역 |
| 08 | 추락사고주의 | 추락 위험이 있는 연안해역 |
| 09 | 유속주의 | 유속이 빨라 위험한 구역 |
| 10 | 미끄럼주의 | 물이끼 등이 많아 미끄러지기 쉬운 연안해역 |
| 11 | 차량 추락주의 | 안전난간·차량멈춤턱이 설치되지 않은 해안가·선착장·방파제 등 |
| 12 | 다이빙주의 | 수심이 얕거나 간출암 등 위험요소가 산재한 구역 |
| 13 | 높은 파도주의 | 높은 파도로 인명피해가 예상되는 구역 |
| 14 | 사망사고 발생 구역 | 사망사고 발생 구역 |
| 15 | 테트라포드 추락주의 | 추락 등으로 인명피해가 예상되는 테트라포드 구역 |
| 16 | 조수 간만의 차 주의 | 조수에 의해 고립사고가 자주 발생하는 구역 |
| 17 | 갯벌 고립주의 | 발 빠짐 등으로 고립사고가 자주 발생하는 구역 |
| 18 | 이안류주의 | 이안류로 인명피해가 예상되는 구역 |
| 19 | 해파리주의 | 해파리 출몰로 인명피해가 우려되는 구역 |

**2-나. 위험알림판**
- 색상: 정보표시부(공통) = 하얀색 바탕에 빨간색 또는 검정색 문자 / 주의알림판 = 제목 노란색 바탕에 검정색 문자 / 규제알림판 및 혼합알림판 = 제목 빨간색 바탕에 하얀색 문자 / 위치안내형·종합형 = 제목 진회색 바탕에 하얀색 문자
- 색채(KS 동일 기준 + 진회색 N 2)
- 규격(mm): 가로형 1,200×600 / 세로형 800×1,300 / 사망사고발생·출입통제장소 알림판·2개이상 함께설치 2,300×1,500 / 방향지시형 1,250×600 / 위치안내형 1,000×1,625 / 종합형 1,000×2,000 — 확대 1.5~2.5배·축소 0.5~0.8배 재량 동일 적용
- 설치 시 선박 운항·통행 방해 금지, 영어 등 병기 가능

**2-다. 방송·경보장치**: 위험한 장소 출입·기상악화 등 우려 시 관련 정보를 신속히 전달할 수 있도록 적절한 위치에 설치.

## [별표3] 안전관리시설물(사고예방시설) 제작방법 등 (제18조 관련)

**1. 종류**: 가. 안전난간 나. 차량멈춤턱 다. 조명장치

| 시설 | 재질 | 설계 요건 |
|---|---|---|
| 안전난간 | 부식 방지, 강도·내구성·경제성·시공성·미관 고려 | 추락 방지 충분한 높이·형상·강도 확보. 해상 인접 설치 시 월파에 의한 구조적 안전성 검토 |
| 차량멈춤턱 | 부식 방지, 강도·내구성·경제성·시공성·미관 고려 | 차량 추락 방지 충분한 높이·형상·강도 확보. 항포구 설치 시 선박 계류·하역작업 지장 없어야 함 |
| 조명장치 | 부식·방수 성능, 경제성·시공성·미관 고려 | 야간 육상·해상 경계 구분 가능한 충분한 밝기. 표지병·시선유도봉 등 추가 설치 가능 |

## [별표4] 안전관리시설물(인명구조장비함) 제작방법 등 (제19조 관련)

**1. 인명구조장비함 제작·설치**
- 재질: 부식되지 않는 견고한 구조·내구성, 쉽게 변형되지 않을 것
- 구조: 전면 투명소재(내용물 외부 식별) / 전면 문 수평 90° 이상 개방 / 별도 잠금장치 조작 없이 바로 열고 닫히는 구조 / 문은 내부 장비를 쉽게 꺼낼 수 있는 충분한 크기 / 겉면 반사소재 또는 점멸장치로 상시 식별 / 전기공급 가능 시 야간 내부조명
- 색상: 표지판명 = 빨간색 바탕에 하얀색 문자 / 안내글 = 하얀색 바탕에 검정색 문자 / 기관명·연락처 = 빨간색 바탕에 하얀색 문자 / 장소명 = 노란색 바탕에 검정색 문자
- 색채(KS 기준 동일: 빨강 7.5R 4/14·노랑 5Y 8.5/14·검정 N 1.5·하양 N 9.25)
- 반사재료 또는 야간조명 사용

**2. 인명구조장비 기본규격 (제19조②관련)**

| 장비명 | 세부 내용 |
|---|---|
| 구명조끼 | 조끼형태, 반사성능 재질 부분 사용(야간 식별). 공기주입 장치 없이 부력(70kg 초과 체중에도 적응성) — **물에 24시간 이상 잠긴 후에도 95% 부력 유지**. 외부 도움 없이 혼자 착용 가능. 매듭 없는 신속·적극적 고정방식. 한쪽 방향(또는 안→밖)으로만 명백히 착용 가능. **1미터 이상 높이에서 뛰어들어도 벗겨지거나 손상되지 않을 것**. 소재·무게·부력성능·착용 적합 사이즈를 제품에 표기 |
| 구명튜브 | 튜브형태, 외부 공기주입 없이 부력(부력성능 외면 표기). 반사성능 표지 부착(야간 식별). 염분·습기 부식 없음. 구명줄 결속 용이 구조. 측면에 끈 부착(던지거나 조난자가 쉽게 잡도록) |
| 구명줄 | 가볍고 물에 뜨는 성질. 수상 식별 용이한 색상. **두께 6mm 이상, 길이 20m 이상. 인장강도 1,000kg 이상** |

비고: 관리주체의 장은 지역 특성·사고발생 빈도·유형 등에 따라 위 규격을 포함해 세부규격을 따로 정할 수 있다.

**3. 인명구조장비 사용방법·주의사항 표시(제19조③④ 관련)**: 전면에 관리주체명·연락처·사물주소(위경도 좌표), 사용방법·주의사항(그림문자 포함)을 표시. 표준 주의문구: "①누구나 사용 가능 ②사고 시 119 신고 및 주변 도움 요청 ③제품 표기 사용방법·주의사항 확인 후 사용 ④**구조장비 용도 이외 목적 사용 금지, 파손 시 처벌을 받을 수 있음**".

> ⚠ 위 "파손 시 처벌"은 **인명구조장비함 표지에 부착되는 안내문구**일 뿐이며, 이 법(제23·25조) 벌칙·과태료 조문에 인명구조장비 무단사용·미반납·파손에 대한 별도 처벌 규정은 없다(원문 재확인 결과 확인됨 — 규정 없음). 표지문구와 법정 처벌조문은 별개다.
