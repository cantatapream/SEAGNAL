# [별표] 실기시험용 동력수상레저기구의 규격 (수상레저안전법 시행령 별표3, 제9조제4항 관련)

> 원문 표 구조 그대로 보존. 요약·재해석 금지(스키마 8절). 사용처: [[수상레저안전법__조종면허]]

## 1. 일반조종면허 실기시험용 동력수상레저기구

| 구분 | 세부 규격 |
|---|---|
| 가. 선체 | 빗물이나 햇빛을 차단할 수 있도록 조종석에 지붕이 설치되어 있을 것 |
| 나. 길이 | 5미터 이상 |
| 다. 전폭 | 2미터 이상 |
| 라. 최대출력 | 100마력 이상 |
| 마. 최대속도 | 30노트 이상 |
| 바. 탑승인원 | 4인승 이상 |
| 사. 기관 | 제한 없음 |
| 아. 그 밖의 장비 | 나침반(지름 10cm 이상) 1개, 속도계(MPH) 1개, 회전속도계(RPM GAUGE) 1개, 예비용 노, 소화기 및 자동 정지줄 |
