# [별표] 검정기관의 지정기준 및 평가기준 (농수산물 품질관리법 시행규칙 별표31, 제129조 관련)

## 1. 농산물 검정기관의 지정기준

### 가. 일반기준
국립농산물품질관리원장은 농산물 검정기관을 지정하는 경우에는 별표30에 따른 분야 및 검정항목별로 구분하여 지정할 수 있다. 이 경우 농산물 및 농산가공품 중 무기성분·유해물질 분야의 검정기관을 지정할 때에는 잔류농약 검정항목은 반드시 포함하고, 그 외의 항목만 신청에 따라 검정항목별로 지정할 수 있다.

### 나. 품위·품종·일반성분 검정 (품위, 발아율, 도정률, 품종, 일반성분)

| 구분 | 기준 |
|---|---|
| 검정실 면적 | 품위·품종·일반성분 검정 업무 수행에 지장이 없어야 함 |
| 검정인력 일반자격 | 다음 중 하나에 해당하는 자격을 갖춘 사람 **2명 이상**: ①「고등교육법」상 전문대학의 농학·식품과학·자연과학 계열 관련 학과 졸업(예정 포함) 또는 동등 학력 인정자 ②농산물품질관리사·농산물검사관·종자기사·생물공학기사 등 관련 자격 소지자 또는 동등 자격자 ③농산물검사·검정 분야 2년 이상 종사 경력자 |
| 검정인력 개별자격 | (1) 품위 검정 담당자 1명 이상은 국립농산물품질관리원 농산물검사관 자격(곡류·특작서류·과실채소류)을 갖추거나 품위검사·검정 관련기관 3년 이상 경력. (2) 품종 검정 담당자 1명 이상은 국립농산물품질관리원 유전자분석 교육 이수, 또는 4년제 졸업+관련기관 2년 이상 경력, 또는 전문대졸+관련기관 4년 이상 경력. (3) 일반성분 검정 담당자 1명 이상은 4년제 졸업+관련기관 2년 이상 경력, 또는 전문대졸(또는 가)(2) 자격)+관련기관 3년 이상 경력 |
| 시설·장비 | 검정시설은 전처리실·일반실험실·조사분석실 등으로 구분해 오염 방지. 장비는 검정항목별 필요 최소한의 기본 장비 구비 |

### 다. 무기성분·유해물질 검정 (농산물·농산가공품의 무기성분·유해중금속·잔류농약·곰팡이독소·항생물질·방사능·병원성미생물, 농지·용수·자재의 무기성분·유해물질)

| 구분 | 기준 |
|---|---|
| 검정실 면적 | 무기성분·유해물질 검정 업무 수행에 지장이 없어야 함 |
| 검정인력 일반자격 | 관련 학과 졸업(예정 포함)·동등 학력자, 또는 식품기술사·식품기사·식품산업기사·농화학기술사·농화학기사·위생사·위생시험사·농림토양평가관리기사 등 동등 자격자, 또는 검사·검정 2년 이상 경력자 중 **4명 이상** |
| 검정인력 개별자격 | 이화학 분야 담당자 1명, 미생물 분야 담당자 1명은 각각 4년제 졸업+관련기관 2년 이상 경력, 또는 전문대졸(또는 나)(2) 자격)+관련기관 4년 이상 경력 |
| 시설·장비 | 전처리실·일반실험실·기기분석실 등으로 구분해 오염 방지. 필요 최소한의 기본 장비 구비. 방사능 분석 장비는 보유기관과 이용계약 체결 시 자체 보유 생략 가능 |

### 라. 검정기관의 품질관리기준 (11개 항목)
1) 상부 기관의 이해상충 방지: 검정기관이 상부 조직 일부인 경우 이해상충 파악·방지를 위한 주요직원 책임사항·조직적 합의 규정, 검정인력의 독립적 업무수행 보장, 부당압력 방지책(매뉴얼·서약서) 및 배포·숙지.
2) 검정 기록의 관리: 관찰·데이터·계산결과 즉시 기록, 오류 발생 시 가로줄 긋고 정정 기록 후 서명.
3) 검정 인력의 기술적 능력: 자격요건(학력·기술자격·경력·교육훈련) 세부 규정, 기술능력평가·자격부여 절차, 검정증명서 서명자의 품목·기술·법령 지식 보유.
4) 교육·훈련의 목표설정·방침·절차 수립 및 효과성 평가.
5) 검정방법의 선정: 국립농산물품질관리원장 고시(「농수산물 품질관리법」·「식품위생법」 등)·공인분석법 등 국제통용 분석법 우선 사용, 최신판 사용 보장, 사전 검증.
6) 장비의 중간점검: 정해진 절차에 따른 점검, 항목·기준 선정, 결과 기록·보존.
7) 검정시료의 취급: 운반·수령·취급·보호·저장·보관·처분 절차, 식별시스템, 인수 시 특이·결함사항 기록, 적절성 의문 시 신청인과 상의·기록, 변질·분실·손상 방지 절차·시설.
8) 표준물질(RM)·인증표준물질(CRM) 사용: 특성화된 물질 사용, 미지정 시 국제·국가기구 제공 물질 검증 없이 사용 가능, 다른 물질과 구분 관리·유효기한 관리.
9) 표준용액 사용: 품명·조제일·조제자 표식 부착, 유효기한 관리, 다른 물질과 식별 구분, 조제 관련 정보 기록·보관.
10) 표준 미생물: 승인기관 분양 표준균주 보유, 공인 검정방법에 따른 동정시험, 보관용/작업용 균주 구분(재동결·재사용 금지), 사용정보 기록, 균주관리 문서화 지침.
11) 그 밖의 품질관리기준: 필요 시 한국인정기구(KOLAS) KS Q ISO/IEC 17025 및 관련 지침 준용 가능, 동등 수준 입증서류 제출 시 품질관리기준 평가 생략 가능.

## 2. 수산물 검정기관의 지정기준

| 구분 | 기준 |
|---|---|
| 조직·인력 | 검사관리 부서 설치, 검사대상 종류별 **3명 이상** 검사인력 확보 |
| 시설 | 검사현장 관할 사무소별 **10㎡ 이상** 분석실 설치 |
| 장비 | 기본 검사장비·종류별 검사장비 구비. 세부기준은 **국립수산물품질관리원장 고시**로 위임 |

## 3. 검정기관의 평가기준 및 방법

### 가. 검정능력 평가 항목별 배점기준 (100점 만점)

| 구분 | 평가항목 | 배점 |
|---|---|---|

| | 검정장비 보유·정상가동·적절설치 여부 | 3 |
| | 시약·장비 관리지침 및 관리(검정·교정 등) 여부 | 3 |

| | 기기운용·분석결과 이해도·숙련도 | 3 |
| | 분야별 용어개념·검정결과 이해도 | 3 |
| 검정능력 | 시료 검정능력 평가 결과 | 10 |
| 품질관리 | 상부조직 주요직원 책임사항 규정 여부 | 3 |
| | 직원 자격부여(학력·기술자격·경력·교육훈련) 여부 | 5 |
| | 검정인력 교육·훈련 목표설정·절차·효과성평가 여부 | 3 |
| | 장비 중간점검 시행 여부 | 3 |
| | 검정시료 운반·수령·취급·보호·저장·보관·처분 절차·시설 여부 | 3 |
| | 표준물질·인증표준물질 사용 및 분류·기록 여부 | 3 |
| | 표준물질 기록·식별구분, 조제정보 기록·적합성 | 3 |
| | 추적성 보장 표준물질 보유, 보관용/작업용 적합사용 여부 | 3 |
| **합계** | | **100** |

> 배점별 평가점수 5단계: 우수 100% / 양호 80% / 보통 60% / 미흡 40% / 불량 20%.

### 나. 평가방법
1) 배점기준 표에 따라 평가점수 부여. 단, 검정기관 품질관리기준 규정에 따라 품질관리 평가를 생략할 경우 품질관리 분야 배점 100% 부여 가능.
2) 평가 결과:
   - **평점평균 80점 이상 = 적합.** 다만 평점평균 80점 이상이라도 시료 검정능력 평가가 배점기준 60% 이하이거나, 검정능력 외 항목 중 1개 이상이 배점기준 40% 이하면 **부적합**.
   - **평점평균 80점 미만 = 부적합.**
