## [별표1] 위험구역 평가 기준 (연안사고 안전관리규정 제6조 관련)

| 위험 구역 | 분류 기준 |
|---|---|
| 사망사고 발생구역 | 최근 3년간 연안 인명(사망·실종)사고가 발생한 구역 (근거: 연안사고 통계 결과 기준) |
| 연안사고 다발구역 | 최근 3년간 3건 이상 연안사고가 발생한 구역 (근거: 연안사고 통계 결과 기준, 사망사고 발생구역 제외) |

**"최근 3년"의 기산점(확인됨 — 규정 없음, E85 대응)**: 조사일 기준인지 위험구역 지정(재지정)일 기준인지를 정하는 문구가 별표1 원문에 없다.

**"3건 이상"의 사고 종류 합산 기준(확인됨 — 규정 없음, L142 대응)**: 별표1은 "연안사고 다발구역"의 "3건 이상"을 정의(법 제2조제2호)상 "연안사고"(가목·나목 통틀어)로만 표기할 뿐, 서로 다른 원인·유형의 사고를 합산해도 되는지, 같은 유형끼리만 세어야 하는지를 구분하는 문구가 없다 — 법 제2조제2호의 "연안사고" 정의 자체가 원인을 가리지 않으므로 유형 무관 합산으로 보이나, 별표1이 이를 명시적으로 확정하지는 않는다.
| 연안사고 관리구역 | 연안 사망·실종사고 및 연안사고 발생 위험성이 높은 구역 (근거: 아래 별표1의2 연안사고 발생 위험성 평가 항목) |

## [별표1의2] 연안사고 발생 위험성 평가 항목 (연안사고 안전관리규정 제6조 관련)

| 평가항목(배점) | 점수 | 평가 가이드라인 |
|---|---|---|
| 사고예방시설(3점) | 3점 | 사고예방 시설물 미설치 — 예: 위험구역에 시설물이 없어 야간·부주의에도 인명사고 위험성이 높아 시급 설치 요구 |
| | 2점 | 사고예방 시설물 부족 — 예: 있으나 개수·범위 부족 또는 위치 부적정 |
| | 1점 | 사고예방 시설물 보수·교체 필요 — 예: 위치·개수는 적정하나 노후화(균열·마모)로 기능 약화 |
| | 0점 | 사고예방 시설물 적정 |
| 정보전달시설(2점) | 2점 | 정보전달 시설물 미설치 — 예: 없어 사고위험성 높고 외지인·관광객 사전 인지 곤란 |
| | 1점 | 정보전달 시설물 부족·보수·교체 필요 |
| | 0점 | 정보전달 시설물 적정 |
| 구난시설(2점, 원문 정의: **인명구조함·대피로 등** — L84·W87·E117 대응, wiki_lag 반영) | 2점 | 구난 시설물 미설치 — 예: 없거나 부족해 인명구조 어려움 |
| | 1점 | 구난 시설물 부족·보수·교체 필요 |
| | 0점 | 구난 시설물 적정 |
| 사고대응시간(2점) | 30분 초과=2점 / 10~29분=1점 / 10분 미만=0점 | 파출소·출장소(상주형)에서 위험구역까지 차량·연안구조정 이용 이동시간(출소부터 현장 도착까지) 측정 |
| 이용객 증감(1점) | 1점 | 이용객 증가 — 예: 관광지 유행·도로(연륙교) 개통 등 접근성 개선으로 전년대비 증가 |
| | 0점 | 이용객 감소 및 증감 없음 |

**평가**: 각 항목의 평가점수를 **합산하여 5점 이상**의 경우 **위험구역으로 지정**한다. 단, **지방자치단체 의견 및 지역주민 요청사항을 고려하여 최종 결정**한다(별표1의2 하단, 5점 미만이어도 지정 가능한지·5점 이상이어도 지정하지 않을 재량이 있는지는 조문에 명시되지 않음 — ⚠REVIEW, AI가 재량범위를 임의 확정하지 않음).

**사업자의 선제적 자체점검 자료 제출로 지정 회피 가능 여부(확인됨 — 규정 없음, W69 대응)**: 위험성조사(고시 제5조)는 **해양경찰서장이 주체**가 되어 실시하고, 필요 시 **관할 지방자치단체의 장에게만** 합동조사·서류제출을 요청할 수 있다(제5조②) — 사업자(운영자)가 자체 점검자료를 미리 작성해 해양경찰서에 제출함으로써 위험구역 지정 절차에 영향을 주거나 지정을 피할 수 있는 절차는 고시 원문 어디에도 없다.

**재분류·승급 절차(확인됨 — 규정 없음, E97 대응)**: 한번 "연안사고 관리구역"으로 분류된 곳이 이후 사고 증가로 "연안사고 다발구역"·"사망사고 발생구역"으로 재분류(승급)되는 별도 절차·재평가 주기는 별표1·별표1의2 어디에도 없다. 훈령 제4조①이 정하는 **연 1회 이상 위험성조사** 자체가 사실상의 재평가 계기이나, 이를 "재분류 승급 절차"로 명명해 정하는 조문은 없다.

**"연안사고 관리구역"으로 분류되면 무슨 관리를 받나(확인됨 — 규정 없음, L123 대응)**: 훈령 제7조①은 "위험한 장소에 대하여 인명사고 위험구역으로 지정·관리할 수 있다"고만 정할 뿐, 3분류(사망사고 발생구역·다발구역·관리구역) 각각에 따라 순찰 강화·시설 우선설치 등 구체적으로 다른 관리조치가 부여되는지는 정하지 않는다 — 3분류는 평가·분류 기준일 뿐, 분류별 차등 관리조치를 규정하지 않는다.

**계획신고서에 위험구역 지정여부 기재의무(확인됨 — 규정 없음, W82 대응)**: 연안체험활동 계획신고서 첨부서류(시행규칙 제7조①1~4호: 안전관리계획서·요원배치서류·안전교육이수증명·보험가입증명)에 해당 장소가 위험구역으로 지정돼 있는지를 기재하는 항목은 없다.

**"사고대응시간" 항목이 사업자 조치와 무관함(확인됨, W84 대응)**: 이 항목(30분 초과=2점 등)은 위 표 그대로 "**파출소·출장소(상주형)에서 위험구역까지**" 이동시간을 측정하는 것으로, 사업자(운영자)가 자체 구조선을 배치하는 것과는 무관하다 — 사업자 조치로 이 점수를 낮출 수 있는 절차는 없다.

**"이용객 증감" 항목의 증가율 기준(확인됨 — 규정 없음, E128 대응)**: 이 항목은 "전년대비 증가/감소·증감없음"이라는 **증감 방향**만 배점 기준으로 삼을 뿐, 몇 % 이상 증가해야 1점을 주는지의 정량적 기준은 별표1의2 원문에 없다.
