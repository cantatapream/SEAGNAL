## [별표1의2] 연안사고 발생 위험성 평가 항목 (연안사고 안전관리규정 제6조 관련)

| 평가항목(배점) | 점수 | 평가 가이드라인 |
|---|---|---|
| 사고예방시설(3점) | 3점 | 사고예방 시설물 미설치 — 예: 위험구역에 시설물이 없어 야간·부주의에도 인명사고 위험성이 높아 시급 설치 요구 |
| | 2점 | 사고예방 시설물 부족 — 예: 있으나 개수·범위 부족 또는 위치 부적정 |
| | 1점 | 사고예방 시설물 보수·교체 필요 — 예: 위치·개수는 적정하나 노후화(균열·마모)로 기능 약화 |
| | 0점 | 사고예방 시설물 적정 |
| 정보전달시설(2점) | 2점 | 정보전달 시설물 미설치 — 예: 없어 사고위험성 높고 외지인·관광객 사전 인지 곤란 |
| | 1점 | 정보전달 시설물 부족·보수·교체 필요 |
| | 0점 | 정보전달 시설물 적정 |
| 구난시설(2점) | 2점 | 구난 시설물 미설치 — 예: 없거나 부족해 인명구조 어려움 |
| | 1점 | 구난 시설물 부족·보수·교체 필요 |
| | 0점 | 구난 시설물 적정 |
| 사고대응시간(2점) | 30분 초과=2점 / 10~29분=1점 / 10분 미만=0점 | 파출소·출장소(상주형)에서 위험구역까지 차량·연안구조정 이용 이동시간(출소부터 현장 도착까지) 측정 |
| 이용객 증감(1점) | 1점 | 이용객 증가 — 예: 관광지 유행·도로(연륙교) 개통 등 접근성 개선으로 전년대비 증가 |
| | 0점 | 이용객 감소 및 증감 없음 |

**평가**: 각 항목의 평가점수를 **합산하여 5점 이상**의 경우 **위험구역으로 지정**한다. 단, **지방자치단체 의견 및 지역주민 요청사항을 고려하여 최종 결정**한다(별표1의2 하단, 5점 미만이어도 지정 가능한지·5점 이상이어도 지정하지 않을 재량이 있는지는 조문에 명시되지 않음 — ⚠REVIEW, AI가 재량범위를 임의 확정하지 않음).
