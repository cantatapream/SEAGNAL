|---|---|
| 1. 가공미끼[어분(생선가루)·감자전분 등 동물성·식물성 물질을 주원료로 하여 열처리·혼합 등의 제조과정을 거쳐 생산된 것을 말한다. 이하 같다] | 가. 다음의 물질은 가공미끼의 원료 등으로 사용해서는 안된다. |
| | &nbsp;&nbsp;1) 인체 또는 수산동물 등의 질병의 원인이 되는 병원체에 오염되었거나 현저히 부패 또는 변질된 물질 |
| | &nbsp;&nbsp;2) 생배설물, 소변, 장 내용물, 수술 후 적출물(반추위추출물은 제외한다) |
| | &nbsp;&nbsp;3) 목재보호제(약품) 처리를 한 나무 또는 톱밥 |
| | &nbsp;&nbsp;4) 하수종말처리장에서 배출된 하수 슬러지 |
| | &nbsp;&nbsp;5) 비닐 등 농어업용 포장재 |
| | 나. 다음의 물질은 허용기준 범위 내에서만 가공미끼의 원료 등으로 사용될 수 있다. |

### 1-나. 가공미끼 허용기준

| 물질명 | 허용기준 |
|---|---|
| 비소(As) | 10㎎/㎏ 이하 |
| 크로뮴(Cr) | 100㎎/㎏ 이하 |
| 카드뮴(Cd) | 2.5㎎/㎏ 이하 |
| 인(P) | 2.7% 이하 |

### 2. 인조미끼(납·철·세라믹 등 금속성·비금속성 물질을 주원료로 하여 제조된 것) — 특정물질 용출 허용기준

| 물질명 | 용출 허용기준(㎎/kg) |
|---|---|
| 납(Pb) | 90 이하 |
| 비소(As) | 25 이하 |
| 크로뮴(Cr) | 60 이하 |
| 카드뮴(Cd) | 75 이하 |

인조미끼는 위 특정물질 용출 허용기준을 충족하여야 한다.
