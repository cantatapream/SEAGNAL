# 양식산업발전법

> ⚠ **draft — 미승인.** 양식업을 **면허(제10조, 바다 구획양식 7종)** 와 **허가(제43조, 육상양식 2종)** 로 나누어 규율하는 근간법. 종전 「수산업법」의 양식 관련 규정이 2019년 이 법으로 분리·독립했다. "양식업권"은 물권(제28조).
> 처벌은 두 축 — **형벌(제78~80조)** 과 **과태료(제81조 + 시행령 별표3)**. 면허취소·정지(제26·27·51조)는 형벌과 별개의 행정처분 축이지만, 세부기준 별표 대신 **법 본문에 사유가 직접 열거**되어 있다(음주운항식 횟수별 escalation 표는 없음).

## 정의 (제2조, 2025-01-24 시행)

| 용어 | 정의 | 근거 |
|---|---|---|
| **양식** | 수산동식물을 인공적으로 길러 거두어들이는 행위(수산종자 생산 포함) + 이를 위해 어선·어구를 쓰거나 양식시설물을 설치·운영하는 행위 | 제2조제1호 |
| 양식업 | 수산동식물을 양식하는 사업 | 제2조제2호 |
| 양식관련사업 | 양식용 종자·사료·약품·기자재 제조·생산업, 양식수산물 운반·가공·유통·판매 등(+시행령 제2조: 갯벌 이용 양식업 등) | 제2조제3호 |
| **해수면** | 바다 + 바닷가(만조수위선~지적공부상 토지의 바다쪽 경계선) + 인공 해수 육상수면 | 제2조제5호 |
| **외해(外海)** | 육지에 둘러싸이지 않은 개방 해수면 → **기본수준면 기준 수심 35m 이상**(시행령 제3조) | 제2조제6호 + 시행령 제3조 |
| 내수면 | 하천·댐·호수·늪·저수지 및 인공 담수/기수 수면 | 제2조제7호 |
| **양식업권** | 제10조 면허를 받아 양식업을 경영할 수 있는 권리 (**물권** — 제28조제2항) | 제2조제8호 |
| 양식장 | 면허(제10조) 또는 허가(제43조)를 받아 양식하는 일정한 수면 | 제2조제9호 |
| 양식수산물 | 양식을 통해 생산 중이거나 생산된 수산동식물 | 제2조제11호 |

> ※연결: "외해 = 수심 35m 이상"은 법 본문에 없고 **시행령 제3조**에서 확정된다(대통령령 위임). 외해양식업은 유일하게 **시·도지사** 면허(제10조제1항 단서).

부과·징수 = 행정관청(제81조제2항). 세부 금액은 **시행령 별표3(과태료 부과기준, 제55조 관련)** — 1차/2차/3차 이상 가중.

| 무신고 휴업 3개월 미만/3~6개월/6개월↑(제22조) | 2호 | 25 / 50 / 100 | | |

## 행정처분 체계 (면허·허가의 제한·정지·취소 — 법 본문 직접규정)

형벌·과태료와 **별개 축**. 별도 "행정처분 세부기준 별표"는 없고 사유가 법에 열거된다.

| 처분 | 사유 | 근거 |
|---|---|---|
| 면허 **제한·정지** | 수산자원보호·군사·국방·항행·폐기물배출해역위생·공익사업·안전사고·수산법령 위반·국제법규 위반(9개) | 제26조제1항 |
| 면허 **취소** | ①거짓면허(필요적 취소) ②결격사유 해당 ③휴업의무 위반 ④경영지배 ⑤임대 ⑥제26조 사유 | 제27조제1항 |
| 허가 **취소** | ①거짓허가(필요적) ②개시·휴업의무 위반 ③경영지배 ④제26조 준용사유 | 제51조 |
| 재면허·재허가 **제한기간** | 취소 후 면허 2년(제13조①) / 허가 최대 1년(제44조① + **시행규칙 별표7**: 사유별 1년~6개월) | 제13조·제44조·별표7 |
