# 항만법

> ⚠ **draft — 미승인.** 항만의 지정·개발·관리·사용을 규율하는 해양수산부 소관 기본법(2026.2.27 시행). 무역항·연안항 구분, 항만시설 정의, 항만개발사업 허가, 항만배후단지, 시설장비 검사, 금지행위·출입통제까지 포괄한다. 일반 이용자(어민·낚시인·레저인)와 가장 맞닿는 부분은 **제28조(금지행위·출입통제)와 제41조(항만시설 사용)**다.

## 정의 (핵심 용어 표) — 항만법 제2조 (2026-02-27 시행)

| 용어 | 정의 | 근거 |
|---|---|---|
| **항만** | 선박의 출입, 사람의 승·하선, 화물의 하역·보관·처리, **해양친수활동** 등을 위한 시설과 화물 가공·제조 등 부가가치 창출 시설이 갖추어진 곳 | 제2조제1호 |
| **무역항** | 국민경제·공공 이해와 밀접, 주로 외항선이 입·출항하는 항만(제3조제1항 대통령령 지정) | 제2조제2호 |
| **연안항** | 주로 국내항 간 운항 선박이 입·출항하는 항만(대통령령 지정) | 제2조제3호 |
| **항만구역** | 항만의 **수상구역과 육상구역** | 제2조제4호 |
| **항만시설** | 기본시설(수역·외곽·임항교통·계류) / 기능시설(항행보조·하역·여객·보급 등) / 지원시설 / **항만친수시설**(낚시터·유람선·낚시어선·모터보트·요트 수용 해양레저시설, 해양박물관·갯벌체험장, 산책로 등) / 항만배후단지 / 심의회 지정시설. 항만구역 밖은 해수부장관 지정·고시분만 | 제2조제5호 |
| **관리청** | 국가관리항(무역·연안)=해양수산부장관 / 지방관리항=시·도지사 | 제2조제6호 |
| **항만개발사업** | 항만시설의 신설·개축·보강·유지·보수·준설 등을 하는 사업 | 제2조제7호 |
| **항만배후단지** | 항만구역 등에 지원시설·친수시설·일반업무·판매·주거시설을 집단 설치한 구역(제45조 지정) | 제2조제11호 |
| **입주기업체** | 1종 항만배후단지 입주계약(제71조)을 체결한 자 | 제2조제15호 |

> ※연결: "항만" 정의에 **해양친수활동**, "항만친수시설"에 **낚시터·낚시어선·요트·갯벌체험장**이 명시 → 낚시·해양레저가 항만법 적용면과 겹친다. 무역항/연안항의 실제 명칭·위치·구역은 **대통령령(항만법 시행령)** 위임(제3조제1항) — 시행령 raw 미수집, reviews 기록.
