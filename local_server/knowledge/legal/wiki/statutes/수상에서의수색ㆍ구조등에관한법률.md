# 수상에서의 수색ㆍ구조 등에 관한 법률 (약칭: 수상구조법)

> ⚠ **draft — 미승인.** 해양경찰청 소관 1군 핵심법. 수상(해수면+내수면)에서 조난된 사람·선박·항공기·수상레저기구의 **수색ㆍ구조ㆍ구난ㆍ보호**를 규율한다. 일반 어민·낚시인·레저인에게 **직접 걸리는 의무는 ① 조난사실 신고 ② 인근 선박의 구조지원 ③ 구난작업 신고·보험** 세 가지이며, 미이행 시 최고 **7년 이하 징역**까지 간다.

## 정의 (수상구조법 제2조, 2025-12-21 시행)

| 용어 | 정의 | 근거 |
|---|---|---|
| 수상 | **해수면 + 내수면** | 제2조제1호 |
| 해수면 | [[statutes/수상레저안전법|수상레저안전법]] 제2조제7호에 따른 바다의 수류·수면 | 제2조제2호 |
| 내수면 | [[statutes/수상레저안전법|수상레저안전법]] 제2조제8호에 따른 하천·댐·호수·늪·저수지 등 인공 담수·기수 수류·수면 | 제2조제3호 |
| 선박등 | 선박 + 항공기 + 수상레저기구 등 | 제2조제4호 |
| 수난구호 | 선박등의 **수색ㆍ구조ㆍ구난** + 구조된 사람·선박·물건의 보호·관리·사후처리 | 제2조제4호 |
| **조난사고** | 수상에서 ① 사람의 익수·추락·고립·표류 ② 선박등의 침몰·좌초·전복·충돌·화재·기관고장·추락 등으로 생명·신체·선박 안전이 위험에 처한 상태 | 제2조제5호 |
| 수색 | 조난자·조난 추정 선박등을 찾는 활동 | 제2조제7호 |
| 구조 | 조난자를 구출·응급조치하여 안전한 장소로 인도 | 제2조제8호 |
| 구난 | 조난된 선박등·재산(화물 포함)에 관한 원조 행위·활동 | 제2조제9호 |
| 표류물 | 점유 이탈하여 수상에 떠 있는 물건 | 제2조제12호 |
| 침몰품 | 점유 이탈하여 수상에 가라앉은 물건 | 제2조제13호 |

## 적용범위·제외

| 항목 | 내용 | 근거 |
|---|---|---|
| 관할 원칙 | **해수면 = 구조본부의 장(해양경찰)**, **내수면 = 소방관서의 장** | 제13조 |
| 다른 법률과의 관계 | 수상 조난사고는 다른 법률에 따로 정한 경우를 제외하고 이 법 적용 | 제3조 |
| 선박소유자 규정 | 공유·선박관리인 임명 시 관리인, 임차 시 임차인에게 적용 / 선장 대행자 있으면 그 사람 | 제2조의2 |
| 외국선박 이동·대피명령 제외 | 영해 및 내수([[내수면어업법__정의와적용범위|내수면어업법]] 제2조제1호 내수면은 제외)에서만 실시 | 제10조 단서 |

## 핵심 의무 조문 (사용자 직접 관련)

| 의무 | 대상 | 근거 |
|---|---|---|
| 조난사실 신고 | 조난선박 선장·기장·소유자 / 발견자 / 조난신호 수신자 / **원인 제공 선박 선장·승무원** | 제15조제1항 |
| 실종위험 신고 | 소재 불명·통신 두절 선박의 소유자·운항자·관리자 | 제15조제2항 |
| 인근 선박 구조지원 | 조난현장 부근 선박 선장·기장 (구조요청 시) / **원인 제공·조난 선박은 요청 없어도** | 제18조 |
| 구난작업 신고 | 영해·내수·EEZ에서 조난선박 구난하려는 자 (24시간 전) | 제19조, 시행규칙 제8조 |
| 구난작업 보험가입 | 조난선박 구난하려는 자 (안전사고·해양오염 대비) | 제20조 |
| 여객선비상수색구조계획서 신고·비치·훈련 | 국제항해 여객선 소유자 | 제9조 |
| 이동·대피명령 이행 | 태풍·풍랑 조난우려 선박, 구난 방해 선박 | 제10조 |
| 선박위치통보 | 국제항해 여객선·300톤 이상 등 (시행규칙 제13조 범위) | 제33조 |

## 위반 시 처벌 (벌칙 — 형벌)

|---|---|---|

| 제44조 | 구조본부의 장·소방관서의 장의 **수난구호를 방해**한 자 | **5년 이하 징역 또는 5천만원 이하 벌금** |
| 제44조의2 | 수상구조사 명의사용·자격증 대여(제30조의5) 위반 | **1년 이하 징역 또는 1천만원 이하 벌금** |
| 제45조 | 정당한 사유 없이 종사명령 불응·물건 일시사용 거부(제29조제1항) | **300만원 이하 벌금** |
