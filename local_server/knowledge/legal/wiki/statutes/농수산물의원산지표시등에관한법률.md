# 농수산물의 원산지 표시 등에 관한 법률

> ⚠ **draft — 미승인.** 농수산물·가공품의 원산지 표시와 수입농산물 유통이력 관리를 규율하는 법. **다른 법률에 우선 적용**(제3조). 처벌이 3축(**형벌 7년/1억 · 과징금 위반금액 5배 · 과태료 1천만원**)으로 무겁고, 수산물(넙치·고등어·오징어 등)·음식점·통신판매까지 폭넓게 걸린다.
> 본 페이지는 raw 조문(법률 시행 2022-01-01, 시행령 시행 2025-10-01, 시행규칙 시행 2025-01-09) 기준.

## 정의 (핵심 용어)

| 용어 | 정의 | 근거 |
|---|---|---|
| **수산물** | 「수산업ㆍ어촌 발전 기본법」 제3조제1호**가목(어업활동)** 및 **마목(양식업활동)**으로부터 생산되는 산물 | 법 제2조제2호 → 수산업·어촌발전기본법 제3조(시행 2026-03-17) |
| **농수산물** | 농산물 + 수산물 | 법 제2조제3호 |
| **원산지** | 농산물·수산물이 **생산ㆍ채취ㆍ포획된 국가ㆍ지역이나 해역** | 법 제2조제4호 |
| **유통이력** | 수입 농산물·가공품의 수입 이후~소비자 판매 이전까지 유통단계별 거래명세(범위는 농식품부령) | 법 제2조제4호의2 |
| **식품접객업** | 「식품위생법」 제36조제1항제3호 식품접객업 | 법 제2조제5호 |
| **집단급식소** | 「식품위생법」 제2조제12호 집단급식소 | 법 제2조제6호 |
| **통신판매** | 「전자상거래법」 제2조제2호 통신판매 중 신고 통신판매업자의 판매·통신판매중개업자 사이버몰 판매(전단지 판매 제외) | 법 제2조제7호 → 시행령 제2조 |

> ※연결: 이 법에 특별 규정이 없는 용어는 「농수산물 품질관리법」·「식품위생법」·「대외무역법」·「축산물 위생관리법」 정의를 따른다(법 제2조제8호).

## 적용범위·제외

| 구분 | 내용 | 근거 |
|---|---|---|
| 우선 적용 | 원산지 표시·수입농산물 유통이력 관리에 대해 **다른 법률에 우선하여 적용** | 법 제3조 |
| 표시 대상자 | 농수산물·가공품을 **수입/생산·가공하여 출하·판매(통신판매 포함)/보관·진열하는 자** | 법 제5조제1항 |
| 음식점 표시 대상 | 휴게음식점·일반음식점·위탁급식영업 영업소 + 집단급식소 설치·운영자 | 법 제5조제3항 → 시행령 제4조 |
| 표시대상 품목 위임 | 농식품부·해수부 공동고시 품목, 대외무역법 공고 수입 농수산물 | 시행령 제3조제1항 |
| 표시 생략(제외) | 대외무역법 시행령 제56조제2항으로 원산지 표시 생략 가능한 수입품, 물·식품첨가물·주정·당류(가공품 원료 배합비율 대상 제외) | 시행령 제3조제1항제2호 단서·제2항 단서 |
| 표시 간주(별도 인증) | 표준규격품·우수관리인증·지리적표시·이력추적관리·수출입 원산지표시(대외무역법 제33조) 등 표시 시 원산지 표시한 것으로 간주 | 법 제5조제2항 |

## 과징금 (제6조의2 · 시행령 별표1의2)

- **2년 이내 2회 이상** 제6조제1항·제2항 위반 시 **위반금액의 5배 이하** 과징금 부과·징수(제6조제1항·제2항 위반 횟수 합산).
- 통관단계 위반금액 = 수입신고 금액. 산정기준표(시행령 별표1의2):

| 위반금액 구간 | 과징금 |
|---|---|
| 100만원 이하 | 위반금액 × 0.5 |
| 100만~500만원 | × 0.7 |
| 500만~1,000만원 | × 1.0 |
| 1,000만~2,000만원 | × 1.5 |
| 2,000만~3,000만원 | × 2.0 |
| 3,000만~4,500만원 | × 2.5 |
| 4,500만~6,000만원 | × 3.0 |
| 6,000만원 초과 | × 4.0 (최고 3억원) |
| 통관단계 수입·반입농수산물 | 수입신고금액의 10% 또는 3억원 중 **적은 금액** |

## 벌칙 체계 — 과태료 (제18조 · 시행령 별표2, 1~4차)

> 제18조①은 **1천만원 이하**, ②는 **500만원 이하**가 상한이며, 실제 부과액은 시행령 별표2 개별기준이 위반행위·차수별로 정한다. 품목별(넙치 등 20종·쇠고기 등) 상세 금액은 → [[농수산물의원산지표시등에관한법률__수산물원산지표시]]·[[농수산물의원산지표시등에관한법률__음식점원산지표시]]. 여기서는 **호별(라~타) 정액 부과 항목**을 항·호까지 정밀하게 정리한다(뭉개기 금지).

## 행정처분 체계 (제9조·제9조의2)

| 처분 | 근거 | 내용 |
|---|---|---|
| 시정명령(이행·변경·삭제) | 법 제9조제1항제1호 | 제5조·제6조 위반 시. 제5조제3항 위반은 **이행명령에 한정** |
| 거래행위 금지 | 법 제9조제1항제2호 | 위반 농수산물·가공품 판매 등 거래 금지 |
| 공표 | 법 제9조제2항 → 시행령 제7조 | 제5조 2년 내 2회 미표시 또는 제6조 위반 처분 확정 시. **공표기간 12개월**, 농식품부·해수부·관세청·품질관리원·시도·소비자원 홈페이지 |
| 교육 이수명령 | 법 제9조의2 → 시행령 제7조의2 | 처분 확정 시 원산지 표시제도 교육(2시간 이상) 이수. 이행기간 최대 4개월 |

> 이 법의 행정처분은 영업정지·허가취소식 escalation이 아니라 **시정명령·거래금지·공표·교육이수** 중심이며, 반복 위반의 escalation은 **과태료 별표2(1/2/3/4차)와 과징금(위반금액 5배)** 로 구현된다.
