# 해상교통안전법

> ⚠ **draft — 미승인.** 옛 「해사안전법」이 2023.7.25 「해사안전기본법」과 「해상교통안전법」으로 분리 제정되어 2024.7.26 시행된 법이다. 이 법은 **수역 안전관리·해상교통 안전관리·선박/사업장 안전관리·선박의 항법(피항·등화·음향신호)**을 규정한다. 소관은 해양수산부이나 **음주운항 측정·항로보전·해산명령 등 현장 단속은 해양경찰(해양경찰서장·해양경찰청장)** 권한이다.
>
> **정의 허브 성격**: "선박"·"해사안전관리"·"해양시설"의 정의를 **「해사안전기본법」 제3조**에서, "대한민국선박"을 **「선박법」 제2조**에서 가져온다(정의 사슬 아웃바운드). 반대로 이 법의 **항법(제69~103조)·음주운항(제39조)**은 어선·낚시어선·레저기구에 폭넓게 적용된다.

## 정의 (핵심 용어)

| 용어 | 정의 | 근거 |
|---|---|---|
| 해사안전관리 | 「해사안전기본법」 제3조제1호에 따른 안전관리 (타법 정의 인용) | 제2조제1호 |
| 선박 | 「해사안전기본법」 제3조제2호에 따른 선박 (타법 정의 인용) | 제2조제2호 |
| 대한민국선박 | 「선박법」 제2조 각 호에 따른 선박 | 제2조제3호 |
| 위험화물운반선 | 해양수산부령으로 정하는 위험물을 싣고 운반하는 선박 | 제2조제4호 |
| 거대선 | **길이 200미터 이상**의 선박 | 제2조제5호 |
| 고속여객선 | **시속 15노트 이상**으로 항행하는 여객선 | 제2조제6호 |
| 동력선 | 기관을 사용하여 추진하는 선박(돛이 있어도 주로 기관이면 동력선) | 제2조제7호 |
| 범선 | 돛을 사용하여 추진하는 선박(기관이 있어도 주로 돛이면 범선) | 제2조제8호 |
| 어로에 종사하고 있는 선박 | 그물·낚싯줄·트롤망 등 조종성능을 제한하는 어구로 어로작업 중인 선박 | 제2조제9호 |
| 조종불능선 | 고장 등으로 조종이 불가하여 다른 선박 진로를 피할 수 없는 선박 | 제2조제10호 |
| 조종제한선 | 작업 성질상 조종성능이 제한되어 다른 선박 진로를 피할 수 없는 선박 | 제2조제11호 |
| 흘수제약선 | 수심·폭 대비 흘수 관계로 진로 이탈능력이 매우 제한된 동력선 | 제2조제12호 |
| 항행 중 | 정박·계류·얹혀 있는 상태 등이 아닌 상태 | 제2조제19호 |
| 길이 | 선수 끝단~선미 끝단 최대 수평거리 | 제2조제20호 |
| 통항분리제도 | 통항로를 분리해 한쪽 방향으로만 항행하게 하는 제도 | 제2조제22호 |
| 제한된 시계 | 안개·연기·눈·비 등으로 시계가 제한된 상태 | 제2조제17호 |

> ※연결: "선박"의 실체 정의는 이 법에 없고 「해사안전기본법」 제3조로 넘어간다([[statutes/해사안전기본법|해사안전기본법]]). 마찬가지로 "대한민국선박"은 [[statutes/선박법|선박법]] 제2조.

## 적용범위·제외

| 구분 | 내용 | 근거 |
|---|---|---|
| 적용 | ① 영해·내수의 선박/해양시설 ② 영해·내수 밖의 대한민국선박 ③ 배타적경제수역에서 항행장애물을 발생시킨 선박 ④ EEZ·대륙붕의 해양시설 | 제3조제1항 |
| 내수 제외 | 해상항행선박이 항행을 계속할 수 없는 하천·호수·늪 등은 "내수"에서 제외 | 제3조제1항제1호 |
| 외국선박 일부적용 | 외국선박에 제46~52조를 적용할 때는 대통령령으로 이 법의 일부만 적용 | 제3조제1항제1호 단서 |
| 소유자 규정 확장 | 공유·선박관리인 선임 시 관리인, 임차 시 임차인, 선장 대행자에게도 적용 | 제3조제2·3항 |
| 다른 법률 우선 | 안전운항 관리체계 등에 다른 법률의 특별규정이 있으면 그 법 우선 | 제4조 |

## 행정처분 체계 (시행규칙 별표5 — 1/2/3/4차 escalation)

처벌의 제3축. 벌칙·과태료와 별개(병과 가능). **시행규칙 별표5 "행정처분의 세부 기준"**(제9·22·48·56·65조 관련)에 위반횟수별 표가 있다.

| 대상 | 근거 | 대표 예시(1차 → 4차) |
|---|---|---|
| 공사·작업 허가자 | 법 제10조제3항 / 별표5 가 | 허가조건 위반: 경고 → 업무정지 3개월 → 6개월 → 허가취소 |
| 안전진단대행업자 | 법 제22조 / 별표5 나 | 변경등록 미이행: 개선명령 → 영업정지 1개월 → 3개월 → 등록취소 |
| 정부대행기관 | 법 제50조제6항 / 별표5 다 | 지정기준 미충족: 개선명령 → 업무정지 → 지정취소 |
| 안전관리대행업자 | 법 제56조 / 별표5 라 | 거짓서류: 영업정지 1개월 → 3개월 → 등록취소 |
| 선박안전관리사 | 법 제67조 / 별표5 마 | 자격증 대여: **1차 즉시 자격취소** / 자격정지중 업무: 180일 → 1년 → 2년 |

- 감경: 소상공인·경미위반·3년 모범사업 등은 1/2 또는 100분의 70 범위 감경(별표5 1. 일반기준). 단, 거짓·부정등록 등 취소사유는 감경 제외.
- 음주운항자에 대한 **해기사 면허 취소·정지는 이 법이 아니라 제42조 → 해양경찰청장 요청 → 선박직원법 별표2**로 처리된다. → [[해상교통안전법__음주운항조타]]
