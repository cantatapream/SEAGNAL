# 해루질 (활동·구어)

> ⚠ **draft — 미승인.** "해루질"은 법률에 없는 구어. 아래 법령 매핑·단속 해석은 사서가 연결한 결과 → 사람 승인(REVIEW) 후 이동.
> 챗봇 처리: 위키에 없으면 → 웹검색으로 뜻 파악 → "맞나요?" 확인 → 유형 구분 → 키워드 분해 → 다중 법 탐색.

## 정의(구어) — 두 가지 유형

법률에 정의된 용어가 아니며, 실제로는 **"비어업인의 포획·채취"**(수산자원관리법 제18조)로 규율된다. 현장에서는 두 유형으로 나뉜다:

| 유형 | 설명 | 추가로 걸리는 규정 |
|---|---|---|
| **① 도보형** | 물 빠진 갯벌·얕은 바다를 **걸어 다니며** 맨손·간단한 도구로 채취 | 어구·장비 기준(시행령 제7조) |
| **② 스킨잠수형** | **잠수통(공기통) 없이** 야간에 라이트로 물속에 들어가 채취(스킨 해루질) | 위 + **수중레저장비 기준·야간 입수 안전** |

*(용어 뜻·유형은 웹 출처 기준, 사용자 확인 대상)*

## 단속 3대 중점 (현장 확인 사항)

| 중점 | 무엇을 보나 | 근거 |
|---|---|---|
| **① 허용 어구·장비 준수** | 정해진 어구 8종·장비 6종 **외의 도구**를 쓰는지 (예: 웨이트벨트·수중스쿠터·작살 등) | 수산자원관리법 시행령 제7조제1항 |
| **② 금지체장·금어기** | 작은 개체(금지체장 미달)·금어기·금지구역에서 잡는지 | 수산자원관리법 제14조 + 시행령 별표1·2 |
| **③ 판매·수량 초과** | 자가소비 넘는 수량·판매 목적인지 | 수산자원관리법 제18조제4항 |
| (안전) **야간 입수 자격·장구** | 야간·잠수 입수 시 안전 자격·필수 안전장구 여부 | 수중레저법 (※ 자격 범위 확인 필요 — REVIEW) |

## 허용 어구·장비 (비어업인) — 이것만 가능

**허용 어구·방법 (시행령 제7조제1항제1호)** — 아래만 사용 가능:
- 가. 투망 · 나. 뜰채(쪽지)·반두(쪽대)·손들망 · 다. 외줄낚시(대낚시·손줄낚시) · 라. 가리·통발 · 마. 낫대(비료용 해조 채취 한정) · 바. 집게·갈고리·호미·삽 · 사. 손 · 아. 일상적 도구(1m 이내)
- ※ 다목(외줄낚시)은 「낚시 관리 및 육성법」 기준도 함께 적용

**허용 수중레저장비 (시행령 제7조제1항제2호)** — 아래 6종만 가능:

| 장비 | 이미지 |
|---|---|
| 가. 수경 | [🔍 이미지](https://www.google.com/search?tbm=isch&q=다이빙+수경) |
| 나. 숨대롱(스노클) | [🔍 이미지](https://www.google.com/search?tbm=isch&q=스노클+숨대롱) |
| 다. 잠수복 및 잠수모 | [🔍 이미지](https://www.google.com/search?tbm=isch&q=잠수복+잠수모) |
| 라. 오리발 | [🔍 이미지](https://www.google.com/search?tbm=isch&q=다이빙+오리발) |
| 마. 수중칼 | [🔍 이미지](https://www.google.com/search?tbm=isch&q=수중칼+다이브나이프) |
| 바. 호루라기 | [🔍 이미지](https://www.google.com/search?tbm=isch&q=호루라기) |

> **⚠ 웨이트벨트(납벨트)는 허용 6종에 없음** → 착용 시 단속 대상. 스킨 해루질에서 잠수를 쉽게 하려고 착용하는 경우가 있고, 단속을 피하려 일부러 벗기도 한다. **공기통(스쿠버)·수중스쿠터·작살 등도 미허용.** (근거: 시행령 제7조제1항제2호가 6종만 열거)
