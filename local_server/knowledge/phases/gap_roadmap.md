# 직군 지식 GAP(외부 연동 미구현) 로드맵

> 8개 직군 파일(`../jikgun/*.md`)의 `[GAP]` 태그 항목 전수 수집 → 외부 연동 후보·난이도·우선순위 정리.
> 보유 데이터 대조 기준: `../data_catalog.json` (datasets 16노출/5비노출 + ondemand 5 + tools 20, builtAt 2026-05-29).
> 직군 파일은 **수정하지 않음**. 본 문서는 신규 작성.

## 0. 보유 데이터 요약 (대조 기준)
앱이 **이미 보유**한 것(= GAP 아님): 해상특보, 해양기상부이(파고·풍속·**수온**·시정·파주기), 파고부이, 등표, 시정계, 해상 단기예보, 해구 시계열전망, 중기예보(3~10일), **유향·유속(해류)**, **수심(정적)**, **조석/물때**, 해무 CCTV, 태풍 통보문·경로, 바다낚시지수, 서핑지수, 바다갈라짐지수, 지명→좌표(resolve_location).

핵심 함의: **수온·파주기·해류·수심·조석·시정**은 기본 관측/예보 수준에서 이미 제공된다. 따라서 이들을 단순 언급한 GAP은 "기본값은 보유, 상세/정밀/모델만 미보유"로 재분류해야 한다.

## 2차 — 자체 검토

### 2-1. 보유 데이터를 GAP로 오분류한 항목 (재분류 필요)
직군 파일은 대체로 "기본값 보유 / 상세·정밀·모델 GAP"로 정확히 구분했으나, 다음은 **표현 보완** 권장:

- **#22 수온·해양환경**: 부이 **수온은 이미 보유**(marineBuoys.tw, fishingIndex.temp). GAP은 "측정망 상세 수질(DO·COD·영양염)"에 한정 → "수온 미보유"로 오해 금지. (fishery #9, coast_guard #12, mof #12, public_org #9 모두 `[앱매핑]`을 병기해 정확히 구분함 — 양호)
- **#5 너울 주기·방향**: **파주기(wave_period)는 marineBuoys/marineWhBuoys/zoneForecasts/surfingIndex에 보유**. 또한 **파향(zoneForecasts.waveDir)·풍향(forecasts/zoneForecasts wind_dir)도 raw 필드로 보유**하나 표준 param으로 미노출(dataParams에 wave_dir 키 없음). **돌풍(Gust)도 등표(marineLhBuoys)에 gst 필드로 관측되나 param 미노출·예보 부재**. 따라서 진짜 GAP은 "스웰의 스팟별 방향 해석 + 돌풍 예보(편차)"로 한정. marine_leisure #7은 `[앱매핑]`을 비워 전부 GAP처럼 보이나, 주기·방향은 부분충족(관측/예보 raw 보유, 노출/스웰해석 GAP)으로 표기하는 것이 정확.
- **#12 갯바위 도선/철수**: 고조 시각은 **조석(tide) 보유**로 참고 가능. angler가 "부분참고"로 표기 — 정확.
- **#21·#34 확산모델·너울경보**: 모델/경보 결과물은 미보유지만 **입력값(해류·풍향·파고 시계열)은 보유** → 자체 규칙 산출 여지 있음(완전 GAP 아님).

- **#36 해무 수치예보**: **시정 관측(marineVs)·부이 시정·해무 CCTV는 보유**하나 시정 *수치예보 모델*은 미보유 → "해무 정보 전무"로 오해 금지, 관측·CCTV는 제공됨. P1(시정 안전직결).
- **#37 상세 수온분포·염분**: 부이 **점관측 수온은 보유**, 격자 수온분포·**염분(salinity)**은 미보유. #22(측정망 상세 수질)와 인접하나 수온·염분 격자는 별 항목으로 분리.

→ **결론: 완전한 오분류(이미 보유한 것을 GAP로 단정)는 없음.** 단 위 항목들은 "부분보유"로 명시하는 편이 정확하며, 본 표 "카탈로그 보유?" 칼럼에 부분보유로 반영함. (특히 #5는 파향·풍향·돌풍이 raw 필드로는 존재하나 param 미노출인 점을 명시.)

### 2-2. 외부 소스 현실성
- **현실성 높음(하/중)**: KHOA 이안류·생활지수·해파리(수과원), 기상청 생활기상지수/과거자료 apihub, 에어코리아, 오피넷 — 모두 공개 API/딥링크. 단기 연동 권장.
- **인증·크롤링 필요(중)**: 적조속보, 수산통계(fips/KOSIS), 위판가, 금지구역 공간정보 — 가능하나 파싱·키 발급 필요.
- **보안망·상용·고난도(상)**: VMS/GICOMS·AIS·VTS·국군기상단·SVP·확산모델·디지털트윈 — 기관 협약/보안 등급 필요, 단기 연동 비현실적. 다수는 **딥링크 안내 + 자체 규칙**으로 우회 권장(예: COSS·boat.kcg.go.kr 링크 안내).
- **자체 구축(외부 불필요)**: 미끼·채비, 안전 리마인더, 너울 경보기준, 규정 텍스트 — 외부 의존 없이 콘텐츠/규칙으로 해결.

### 2-3. 직군 누락 점검
`_SCHEMA.md` 고정 8직군(coast_guard·fishery·marine_leisure·mof·navy·local_gov·public_org·angler) **전부 수집 완료, 누락 없음**. 각 직군 GAP 반영 여부: angler·fishery·mof·marine_leisure(다수), local_gov·public_org(중간), coast_guard(4건), navy(SVP 등 군 특수). 모든 직군이 표에 등장.
