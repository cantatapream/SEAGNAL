## 7. 2차 자체검토 결과

> 1차 정의 후 (i) SLO 수치가 실측과 정합한가 (ii) 빠진 축 없나 (iii) P2b DoD 연결을 점검.

### 7.1 SLO 실측 정합성
- **p95 ≤ 5000ms**: 평가셋 만점 라운드 p95 3255ms·v4 패치 후 4691ms로 **달성권**. 그러나 **자유변칙 v2 p95 6712ms는 목표를 +1712ms(+34%) 초과 — 현재 명백한 미달 항목.** P2b DoD가 측정하는 대상은 자유변칙(440케이스)이므로 이 값이 게이트 기준이다. 직렬 러너의 429 백오프 대기가 측정값을 부풀릴 수 있으나, (i) 백오프 노이즈를 분리한 순수 자체로직 p95는 **아직 별도 산출되지 않았고**(러너가 백오프 시간 제외 집계 미구현, §6 #8 연계 잔여), (ii) 자유변칙 v4 p95도 미재측정이다. **결론: 임계값 자체(5000ms)는 평가셋 실측과 정합하나, 게이트 판정 대상인 자유변칙 p95는 현재 초과 상태이며 (a)러너의 백오프-제외 집계 구현 (b)자유변칙 v4 재측정 둘 다 완료해야 달성 여부를 확정할 수 있다. "백오프 노이즈" 주장은 아직 미검증 가설로, 초과 갭을 해소된 것으로 간주하지 않는다.**
- **토큰 SLO**: 절대 임계 미확정은 의도적("베이스라인 먼저"). 계측(usageMetadata) 가동 전까지 수치 못 박지 않음 — **정합**(실측 없이 임계 박으면 허수).
- **자유변칙 ≥85%**: 현재 72%로 미달이나 **목표는 DoD(미래 게이트)이지 현재 상태 주장 아님** — 정합.

### 7.2 빠진 축 점검
- §8 원문 6요지(평가·회귀/머지후검증/비용지연/프라이버시/시크릿/신선도)는 전부 반영.

### 7.3 P2b DoD 연결 (Phase 3 착수 게이트)
P2b DoD = **자유변칙 PASS ≥85% · 직군 최저 ≥70% · 카테고리별 ≥70% · 환각 ≤2/440 · p95 ≤5000ms** (§6 #25).
