# Phase 0 — 진단 배터리 결과 (토대 안정화)

> 나리야 두뇌가 앱 공개 데이터를 막힘없이·정확히 가져오는지 검증한 결과. 최종 갱신: 2026-05-29.
> 상위 계획: `../00_MASTER_PLAN.md`

## 방법
- 로컬 서버에 실제 Gemini 키 + DMDW 자격증명을 주입하고, 도메인 태깅된 **78문항** 진단 배터리를 자동 호출.
- 도메인별 **수치응답 / "없음"응답 / 오류**를 집계하고, 실패를 **진짜 버그 vs 환경 한계(키 미설정)** 로 분리.
- 2회 실행(보강 전/후) 비교.

| 도메인 | 판정 | 비고 |
|---|---|---|
| 예보-해역 | ✅ | 전 구역 풍향·풍속·파고·하늘 수치 |
| 예보-해구 | ✅ | 시계열(48h 후 등) 포함 |
| 예보-중기 | ✅ | 3~10일 |

| 부이-목록/관측 | ✅(부분) | 마라도는 파고부이라 풍속 없음=정상 |
| 유속 | ✅ | cm/s + 노트 변환(이전 단위버그 수정) |
| 집계/비교 | ✅ | 랭킹·구역간 비교 |

| 수심·해무CCTV·바다낚시지수 | ⛔ 환경한계 | 로컬 live 피드/데이터 없음 → 웹폴백(운영에선 내부응답 가능) |

→ **78문항 오류 0건.**

## 보강 조치(코드)
1. 1차: 유속 단위(cm/s+노트), 좌표 해석(coordsFor), 환각방지 합성규칙, 후속맥락(memory), STT 교정(correctedQuery).
2. 2차: 동해중부앞바다 예보 폴백(하위구역 대체), 지수 라우팅 힌트(스쿠버 오연결 제거), 부이 관측 필드 다중풀 병합. — 커밋 `b1a34aa`
3. 조석: 시각 미제공 시 GPS/표준항/tideSearch 폴백으로 **앱 바텀시트 이동 버튼 보장**. — 커밋 `33e0b4c`

## 중요한 발견
- **제6호 태풍 장미는 실제 발효 중**이었고, 로컬에서 "없음"으로 나온 건 DMDW 자격증명 부재 탓이었음. 운영 서버에 `KMA_DMDW_USER_ID/PWD` 설정 필요.
- 수심/CCTV/낚시지수/일부 조석은 도구는 존재, **운영 환경의 키·피드·데이터**가 있으면 응답.

## 후속(운영 반영 필요)
- 운영 시크릿: `KMA_DMDW_USER_ID/PWD`(태풍), TideBED 키(조석 전지점).
- 테스트용 Gemini 키 폐기.
- 위 코드 커밋의 운영 배포 + APK 재빌드.
