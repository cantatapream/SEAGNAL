### 1.4 핵심 설계 결정

| 항목 | 결정 | 사유 |
|---|---|---|
| 어떤 라벨 우선? | `해역=` (focus.zone) > `부이/지점=` (focus.buoy) > `원어휘=` (focus.originalLocToken) 의 순으로 LLM 이 1개 선택 | 표준명 우선·없으면 원어 — phase0_runner expect_zone_match 가 substring 매칭이므로 표준명이 명시될 때 가장 안전 |
| 위치 | 답의 첫 부분 | "X는 ~없어요" 자연 어순. 끝 부분 명시는 LLM 이 자주 누락 |
| 형식 | "원형 그대로 1회" | P36 기존 어휘와 동일 — 룰 정합성 |
| 예시 2개 | "동해중부앞바다는 그 정보는 없어요", "거문도는 지금은 가져오지 못했어요" | NAV-2-01b 와 ANG-2-01b 등 양 직군 대표 케이스 |
| 위치 (prompt 내) | L2161 환각금지 bullet 안 (별도 bullet 신설 X) | 같은 룰의 *예외*이므로 같은 bullet 내. 별도 bullet 시 LLM 우선순위 혼동 |
| 토큰 비용 | 약 90 자(공백 포함) ≈ 30–35 토큰 | p95 무영향 (현 synth 추정 1.5k+ 토큰) |

### 1.5 L2174 P36 룰과의 정합

- 현재 L2174 P36 는 "후속(거기/그곳/그 해역/그 부이) 으로 그 대상을 가리키면 ··· 원형 그대로 1회 이상 명시" 라고 명시.
- **빈결과 케이스에서도 적용되어야 함을 명시적 예외로 못 박는 보강**이 본 설계.
- 결과적으로 L2161 의 "짧게 ~라고만" 강한 형식 강제와 L2174 의 "원형 명시" 룰 사이의 모호한 우선순위가 해소됨.

## 3. False Positive 회귀 가드

### 3.1 비도메인 후속 — focus.zone 강제 포함 시 어색?

#### 시나리오
사용자가 1턴에서 "거문도 파고" → focus.zone="남해서부먼바다" 확정. 2턴에서 비도메인 잡담("거기 인구는?" / "거기 맛집은?")으로 옮긴 경우.

- 현행 처리: L2078 `isDomainQuery` 가 false → L2134 `webSearchAnswer` 경로 (synth 미호출).
- **본 설계의 L2161 예외는 synth 가 호출되어야 발동** → 비도메인 잡담은 synth 미경유 → **영향 0**.

#### 가드 결론
- `isDomainQuery=false` 일 때 본 설계의 영향 0. 별도 도메인 게이트 명시 불필요.
- 단, 안전 마진으로 prompt 문구에 "**해당 후속이 우리 도메인(기상·해상)** 일 때만" 명시할지 검토.

### 3.2 추가 가드 권고 — 도메인 게이트 명시

L2161 예외에 다음 조건절 추가 권고 (절충안):

> "단, [직전 확정 대상] 의 ··· 가 있고 **사용자의 질의가 기상·해상 도메인일 때**, 그 이름을 답의 첫 부분에 원형 그대로 1회 포함하세요. 도메인 외(관광/역사/일반상식) 후속이면 일반 거절문만."

- 효과: 비도메인 후속에서 LLM 이 잘못 발동시킬 위험 0.
- 비용: 토큰 +15. 가독성은 손해(룰이 길어짐).
- 실용 결정: **3.1 의 isDomainQuery 게이트가 이미 webSearchAnswer 경로로 분기**하므로 prompt 도메인 게이트 *생략 권고* (=비용 절약). 단, 회귀 모니터링 1라운드 후 잡음 발견 시 추가.

### 3.3 메타 자기요약 (cat=6) 회귀

- L2161 빈결과 룰은 "수집결과가 비어있으면" 발동.
- 메타 자기요약 (MEM-LEAK-05 등) 은 results=[] 일 때 L2165 의 별도 메타 룰이 우선 — synth 가 메타 질문을 인지하면 memory 요약 (focus.zone 무관).
- focus.zone 명시 발동 위험: 메타 질문 "내가 처음 뭘 물었어?" 에서 focus.zone="인천·경기남부앞바다" 가 있으면 답 첫 부분에 명시? → LLM 이 메타 자기요약 룰을 따라가면 거기에 zone 포함은 *자연스러움* (어색 X).
- **MEM-LEAK-05 expect_no_leak**: 라벨 `[직전 확정 대상]`/`memory:` 출력 금지. focus.zone 의 *값* "인천·경기남부앞바다" 는 expect 의 answer_excludes 에 없음 → 회귀 무.

### 3.4 ADM-OK-2-warning-read 회귀

- ADM-OK-2 는 "남해동부 지금 발효된 특보" — `get_warning` 이 실데이터 반환 (빈결과 아님).
- L2161 의 "수집결과가 비어 있으면" 트리거 X → 본 설계 미발동 → **회귀 0**.

### 3.5 cat=1 ANG-1-08/09 — web_search 환각 회귀?

- 이미 L2078 isDomainQuery=true (홍도/연평도 모두 ISLAND_BUOY_RE 매칭) → L2134 web_search 미경유.
- 그러나 v5_run3 로그에는 web_search 답이 나옴 → 다른 경로(plan 단계 web_search 명시 호출). 본 설계 비관여.
