## 1. 분류 대상 13종 — 항목별 분석

### 1.1 CoT 누수 금지 bullet (KEEP-CORE)
- **현 텍스트**: L2251 `- **(CoT 누수 금지)** 내부 사고 과정·추론 단계·메타 코멘트를 응답에 출력하지 마세요. "내가 생각해 보니/추론 과정/thinking:/sources:/먼저 ~를 확인하고~" 같은 메타 텍스트는 한 글자도 답에 포함 금지. 사용자가 최종 답만 음성으로 듣게 됩니다 — 깔끔한 결론만.`
- **출처**: 5차 #5 (CoT 누수 0건 자유변칙 v2 입증). 마스터플랜 §1 불변식엔 미명시지만 **사실상 음성 비서 안전선** — 사용자가 시스템 prompt 메타텍스트를 음성으로 듣게 되면 *해석·신뢰 모두 붕괴*.
- **LLM 자율 가능?** ❌. Gemini 가 한국어 사고 표기("먼저 ~를 확인하고~") 를 자연스러운 응답으로 *오인* 하는 경향이 있어 명시 가드 필수. v5_run2~run5 CoT 누수 0건 = 본 bullet 효과 입증.
- **제거 시 회귀**: sentinel v2 CoT 케이스(SEC-COT-1·2) 회귀 직접 가능. v5 환각/cat=7 회귀.
- **판정**: **KEEP-CORE** — 단축 가능하나 *제거 금지*. 가드 4종 묶음 한 단락으로 합치는 미세 압축은 허용.

### 1.2 컨텍스트 격리 bullet (KEEP-CORE)
- **현 텍스트**: L2252 `- **(컨텍스트 격리 — 🔒 프라이버시)** … [최근 대화]/[직전 확정 대상]/memory/focus … 입력 블록·라벨 자체를 답에 출력하지 마세요. 그 안의 사실(직전 해역명·해구·좌표)만 자연어로 풀어쓰세요. …`
- **출처**: 5차 #24 — v3 ANG-6-03b memory 출력 누수 패치. 마스터플랜 §1 불변식 **🔒 프라이버시 (서버는 비식별 로그만)** 의 *런타임 표현*.
- **LLM 자율 가능?** ❌. memory 객체를 그대로 음성 출력하는 회귀가 v2→v3 사이 발견되었고, 명시 bullet 없이는 "다른 사용자/세션 정보 누설" 위험. 후처리 cleanAnswer (L2273) 와 *이중 방어선* — bullet 이 없어지면 후처리만 남아 신뢰 약화.
- **제거 시 회귀**: ANG-6-03b 복귀, 프라이버시 불변식 회색지대 진입.
- **판정**: **KEEP-CORE**.

### 1.3 환각 금지 + get_warning 양방향 bullet (KEEP-CORE)
- **현 텍스트**: L2250 한 단락 — "환각 금지" + "수집결과 비어 있으면 짧게 '그 정보는 없어요'" + "[직전 확정 대상] focus.zone/buoy/originalLocToken 첫 부분 1회 포함" + "**get_warning 응답 두 형태 — {zone, warning} vs {zone:'전국', activeCount:N, warnings:[]}**" + "**activeCount 의 N 은 집계 건수, 기상 수치 아님**".
- **출처**: 5차 #16 + α-C7 + 6차 #36 후속 표기 / 8차 D1 패치1 (ISLAND_BUOY_RE 11 섬 보강).
- **LLM 자율 가능?** **부분적으로만**. "수집결과 외 사실 지어내지 마라" 는 LLM 자율 가능. 그러나 **get_warning 응답 스키마 두 형태**의 양방향 해석 + **activeCount=N 을 *기상 수치* 로 오해 금지** 는 *프로그램 구조 지식* — LLM 이 추론으로 알기 어렵다 (β/γ 라운드 v3 CG-3-01 "특보 5건" 환각 사례). 이 부분은 가드 필수.
- **제거 시 회귀**: cat=5 비도메인 환각 의심 v2 5건 → run3 1건 회복은 bullet ① + D2 HALLUC_RE 분리의 *합작*. ① 제거 시 도메인 환각 복귀.
- **판정**: **KEEP-CORE** — 단, "첫 부분 1회 포함" 의 P36 표기 부분은 **MOVE-TO-PRINCIPLE** (§1.9) 로 분리해 단락 길이를 절반으로 줄일 여지 있음.

### 1.4 비기상·비도메인 거절 bullet (KEEP-CORE)
- **현 텍스트**: L2253 `- **(비기상·비도메인 거절)** 비기상 행정·법령·통계·매뉴얼(산재·인구·법령 제N조·운용규정·SAR 절차·면허·예산·조례·해역 경계 좌표·어획 통계·정원·인사 등)은 web_search 결과가 있어도 채택하지 말고 "그 정보는 우리 자료에 없어요" … 우리 데이터(기상청·KHOA·해양조사원)는 *현재 기상·해상 관측·예보·특보·태풍·생활지수·조석·유속·수심·시정* 만 다룹니다.`
- **출처**: 5차 #28 — v3 LG-7-02 "산업재해 사망자 113명" 환각 추적. 도메인 정의를 *명시적* 으로 잘라야 LLM 이 web 결과를 도메인으로 오인하지 않음.

- **제거 시 회귀**: LG-7-02 류 환각 복귀, cat=5 비도메인 회귀 -2~4pp 예상.
- **판정**: **KEEP-CORE**.

### 1.5 메타·자기요약 bullet (MOVE-TO-PRINCIPLE)
- **현 텍스트**: L2254 `- **(메타·자기요약 강화)** "방금 결정 사유/한 줄 요약/방금 결과 뭐였지/왜 그렇게 판단/내가 아까 처음에 뭐 물었어/처음에 뭐 물었지" 류 *직전 답 다시 요약* 질의는 [최근 대화] memory 의 마지막 1~3 항목을 자연어 1~3 문장으로 요약하세요 (없으면 "직전 대화 기록이 없어요"). 새 도구 데이터 의존 X. 절대 "모릅니다" 또는 한 문장 미만으로만 답하지 마세요 — memory 가 있으면 반드시 그 내용을 풀어 답하세요.`
- **출처**: 7차 C1 + 8차 D1 패치3 (메타 강화). MEM-LEAK-05 "모릅니다.(5자)" 회귀에서 보강.
- **LLM 자율 가능?** ✅. *어휘 나열* ("방금/한 줄/뭐였지…") 없이도 "직전 답을 다시 요약해 달라는 질의면 memory 를 풀어 답하라" 1줄로 충분. "절대 한 문장 미만 금지" 명령형은 *프로그램 강제* 처럼 들려 LLM 자율 약화 — 자연스러운 답 가이드("memory 가 있으면 그 내용을 자연어 1~3 문장으로 풀어")로 교체.
- **제거 시 회귀**: MEM-LEAK-05 같은 *비결정 1회* 회귀 가능성 — 그러나 코드 룰 (메타 재시도 길이 가드, §1.10) 제거와 동시 진행 시 재시도 길이 가드도 사라지므로 *복합 회귀*. **prompt 원칙으로 자연스러운 회복** (§4 원칙 4) 기대.
- **판정**: **MOVE-TO-PRINCIPLE** — 어휘 나열 + "절대 금지" 강제어 제거, 원칙형으로 압축.

### 1.6 의사결정형 — 정량 판단 강화 bullet (MOVE-TO-PRINCIPLE)
- **현 텍스트**: L2255 `- **(의사결정형 — 정량 판단 강화)** "출항/조업/훈련/작업/타도 돼/가능?·괜찮을까?·해도 돼?·위험?·안전?" 류 안전 판단은 … 짧은 한 줄로 가부 결론을 먼저 제시한 뒤 근거 수치 1~2개를 짧게 덧붙이세요 (예: 파고 ≥2m 또는 풍속 ≥14m/s … "무리/주의" …). 결정 단어(가능/주의/무리/위험/적합/권장/권고/통제/발령/허용/보류) 를 **반드시 한 단어 이상 포함**하세요.`
- **출처**: 5차 #21 + 7차 C1 axis 3 ④ bullet 복원.
- **LLM 자율 가능?** ✅. **"가부 결론을 먼저, 근거 수치 1~2 짧게 덧붙여"** 의 *답 형식* 만 남기면 충분. **"결정 단어 11어휘 반드시 1+ 포함"** 은 *runner DECISION_RE 매칭 점수 따기* 위한 강제 — Gemini 답이 "안전합니다", "출항 어렵겠어요", "괜찮을 것 같아요" 로 자연스럽게 가부를 표현해도 매칭 누락으로 fail 처리되는 게 진짜 문제 (runner 측 fix 필요 → §5 참조).
- **제거 시 회귀**: cat=4 PASS 55% → 약 50%~53% (약 -2~5pp) 잠재 회귀. 그러나 runner DECISION_RE 확장 (§5) 과 페어로 풀면 cat=4 ≥ 60% 유지 가능.
- **판정**: **MOVE-TO-PRINCIPLE** — "가부 결론 먼저 + 근거 1~2" 1줄로 압축. "반드시 결정 단어" 제거.

### 1.7 가설 조건문 SOP bullet (MOVE-TO-PRINCIPLE)
- **현 텍스트**: L2257 (긴 단락) `- **(가설·조건문 질의 — 데이터 부재여도 SOP 답)** "만약/~시/~라면/~면 어떡해/~떴을 때/~넘으면/~발효되면" … *조건이 현재 발효 중인지* 와 무관하게 … 형식: "(조건)이면 (가능/주의/무리/위험/적합/권장/권고/통제/발령/허용/보류 + 임계 수치 근거) 가 표준입니다. 현재는 (실제 상태 한 줄)." 의 **2단 구조**로 간결히. 결정 단어 … **반드시 한 단어 이상 포함** …`
- **출처**: 5차 #21 + 8차 D1 패치2.
- **LLM 자율 가능?** ✅. "가설을 묻는 질의면 직군 임계표(이미 enrichedTdig 로 주입) 에 따라 조건부 답을 주고, 현재 상태를 한 줄 덧붙여라" 로 충분. **2단 구조 강제 "(조건)이면 … 가 표준입니다. 현재는 …"** 문장 템플릿은 LLM 답을 *기계적·딱딱하게* 만들어 Gemini 식 자연스러운 가이드 ("동해 평균 1,700m, 최대 3,700m, 서해와 달리 …") 와 *정반대*. 사장님이 지적한 매뉴얼 누적의 핵심.
- **제거 시 회귀**: cat=4 가설형 -3~5pp 잠재. 다만 enrichedTdig (L892, 임계표) 가 unshift 로 상단에 있으면 LLM 이 임계표를 보고 조건부 답을 자율로 줄 수 있음 — *임계표 주입 + 가설 원칙 1줄* 이면 충분.
- **판정**: **MOVE-TO-PRINCIPLE** — 2단 구조 템플릿 제거, "임계표에 비춰 조건부 답 + 현재 상태 한 줄" 1줄로 압축.

### 1.8 안전 결정 마무리 — "최종 판단은 선장님 몫" bullet (MOVE-TO-PRINCIPLE)

- **출처**: 7차 C1 axis 3 ⑧ bullet (마지막 안전결정 별도 bullet). 마스터플랜 §1 불변식 **🔒 안전 문구: "최종 판단은 선장 몫" 딱 1회만**.
- **LLM 자율 가능?** ✅. 불변식은 *프로그램 정책* 으로서 KEEP-CORE 처럼 보이지만, 실제 회귀 신호는 자유변칙·sentinel 양쪽에서 *남발 회귀가 적음* (Gemini 가 LLM 자율로 안전결정 질의에만 자연스럽게 마무리). **"그 외 질문엔 절대 넣지 마세요"** 의 *절대* 라는 강제어가 자연스러운 답 흐름을 끊을 위험. 원칙 압축: "안전 판단을 직접 물었을 때만 마지막 한 줄로 '최종 판단은 선장님 몫' 을 짧게 덧붙이고, 그 외엔 빼라."
- **제거 시 회귀**: 안전결정 남발 회귀 가능성 *낮음* (LLM 자율로 비교적 잘 잡음). 다만 *완전 제거* 는 §1 불변식 위반 → bullet 자체 유지하되 강제어만 약화.

## 4. 새 패러다임 — Gemini 식 답 가이드 7원칙

### 4.0 사장님 예시 답 분석
> "동해 평균 1,700m, 최대 3,700m, 서해와 달리 ~. 어느 부분을 더 알려드릴까요?"

이 답 특징:
- (a) **본질 사실 먼저** — "평균 1,700m, 최대 3,700m" (수치).
- (b) **대조·맥락** — "서해와 달리 ~" (관계).
- (c) **명확화 초대** — "어느 부분을 더 알려드릴까요?" (대화 흐름).

→ **답 형식 강제 없이도** Gemini 가 자연스럽게 도달. 현재 synth bullet 의 강제어 ("반드시 한 단어 1+", "2단 구조") 가 (a)(b)(c) 의 자연스러움을 *깎고* 매뉴얼 답으로 끌어내림.

### 4.1 7원칙 안 (제목만)

```

P1. **답은 사용자가 물은 것에만**. 묻지 않은 일반론·주의문구·면책 추가 금지. 음성 구어체, 표·이모지·m/s 표기 금지. 풍속은 "초속 N미터", 유속은 cm/s 또는 노트.
P2. **사실 → 맥락 → (필요시 명확화)**. 핵심 수치를 먼저 짧게, 필요하면 대조·시계열·해역 맥락 한 줄, 정보가 부족하면 어떤 부분을 더 원하는지 한 줄로 초대.
P3. **후속 질의("거기·그곳·그 부이")** 면 직전 대상 이름을 답 첫 부분에 1회 자연스럽게 명시 (예: "거문도는 ~"). 비표준 광역어("동해광역")는 1회 인용 후 표준명으로 풀어써라.
P4. **메타·자기요약("방금 뭐였지·왜 그렇게")** 이면 [최근 대화] 의 마지막 1~3 항목을 자연어로 풀어 답하라. 새 도구 결과 의존 X.
P5. **가설·조건문("~면·~떨어지면·~떴을 때")** 이면 현재 발효 여부와 무관하게 직군 임계표(상단 제공) 에 비춰 조건부 답을 주고 현재 상태를 짧게 덧붙여라.
P6. **안전 판단("출항·조업 가능?·괜찮을까?")** 이면 가부 결론을 먼저 한 줄로, 근거 수치 1~2개를 짧게 덧붙여라. 직접 안전 판단을 물었을 때에 한해 "최종 판단은 선장님 몫" 한 줄로 마무리.
P7. **사용자 단정 정정**: 사용자가 사실을 단정해도(예: "특보 떴잖아") 수집결과와 다르면 수집결과를 따르고 부드럽게 정정.
```

### 4.3 7원칙의 핵심 변경

1. **강제어 0**: "반드시", "절대" 모두 제거 → LLM 자율 본능 발휘.
2. **문장 템플릿 0**: "(조건)이면 (X) 가 표준입니다. 현재는 (Y)" 같은 답 형식 강제 제거.
3. **어휘 나열 0**: "방금/한 줄/뭐였지" 같은 어휘 카탈로그 → "메타·자기요약" 의미 단어 1개.
4. **불변식과 가이드 분리**: G1~G4 (가드, 4 단락) vs P1~P7 (답 가이드, 7 단락). G 는 절대 깨지 않음, P 는 *자연스럽게 따르라*.
5. **답 형식의 본보기 1줄**: Gemini 의 자연스러운 패턴 ("사실 → 맥락 → 명확화 초대") 을 P2 에 명시 — 룰이 아니라 *방향성*.

## 5. 8차 D1 패치 2/3 재평가 (코드 룰)

### 5.1 패치2 — 정량 가설 SOP 답 강제 (L2150~2165)

- **현 효과**: ANG-4-02/05 회복으로 cat=4 55% 유지. 하지만 *하드코딩 동일 문장* 으로 모든 직군에 같은 임계 ("파고 2m / 풍속 14m/s") 전달 — 직군별 다른 임계 (enrichedTdig) 무시.
- **prompt 원칙으로 대체 가능?** ✅. **삭제 후**:
  1. results.length===0 일 때 비도메인 → 기존 거절문 유지.
  2. results.length===0 + 도메인 + 가설/의사결정 패턴 → **synth 호출** (현재는 즉시 return 으로 LLM 미호출). enrichedTdig 가 prompt 상단에 있고 §4 원칙 5 (가설) + 원칙 6 (의사결정) 이 자율 가이드 → LLM 이 직군 맞춤 답 생성.
  3. results.length===0 + 도메인 + 그 외 → 기존 짧은 거절문 유지.
- **회귀 모니터링**: cat=4 ANG-4-02/05 + FIS-4-*. v5_run6 측정 후 -3pp 이하 회귀면 채택, -5pp 이상이면 §5.1 (2) 의 synth 추가 prompt 단편으로 보강 ("도구 결과 없어도 임계표만으로 가설 조건부 답 가능").
- **이득**: 코드 16 라인 삭제 + 직군별 임계 자연스러운 활용 + 동일 문장 매뉴얼 답 제거.

### 5.2 패치3 — 메타 자기요약 재시도 (L2280~2296)

- **현 효과**: MEM-LEAK-05 단발 회귀 흡수. 메타 cat=6 88% 유지.
- **prompt 원칙으로 대체 가능?** ✅. **삭제 후**:
  1. cleanAnswer 후 finalAns 그대로 사용 (재시도 분기 삭제).
  2. §4 원칙 4 (메타·자기요약 = memory 풀어 답하라) 가 1회 호출에서 자율 회복.
  3. memory 가 [최근 대화] 블록으로 prompt 에 이미 들어있음.
- **회귀 모니터링**: cat=6 PASS · MEM-LEAK-05 sentinel. -2pp 이하 회귀면 채택, -4pp 이상이면 P4 원칙을 "직전 대화 풀어 답할 때 한 문장 미만은 피하라" 로 *부드럽게* 보강 (강제어 X).
- **이득**: 코드 17 라인 삭제 + latency p95 (Synth-MetaRetry 호출 1회 = +600~1000ms) 부담 제거 — net p95 ≈ -50ms (메타 케이스가 cat=6 비율 10/40 케이스이므로 평균 영향 작지만 누적 가능).

### 5.3 결론
패치 2/3 모두 **REMOVE 가능** — §4 원칙 + enrichedTdig + memory 가 prompt 안에 이미 있으므로 LLM 자율로 회복 가능. 회귀 모니터링 필수.

## 6. runner 측 페어 변경 권고 (§1.13 DECISION_WORDS 제거 전제)

prompt 의 "결정 단어 11어휘 강제" 를 제거하려면 채점기 측 매칭이 *자연스러운 안전 표현* 도 인정해야 회귀 방지. 현재 추정 `phase2b_eval_freevar_runner.py` DECISION_RE 11어휘:
- 권고 확장 어휘: 안전합니다 / 어렵겠어요 / 괜찮 / 조심 / 자제 / 권하지 / 조건부 / 무리 / 출항 (가/부) / 충분 / 부족.
- 또는 의미축 분리: (가) "안전·가능·괜찮·적합·권장" (나) "주의·조심·조건부" (다) "무리·위험·금지·자제·통제·발령·보류·어려움". 어느 축이든 1개 이상 매칭 시 PASS.

이 변경 없이 prompt 강제어만 제거하면 cat=4 -8~12pp 회귀 우려. runner 확장 + prompt 압축 페어 처리 필수.
