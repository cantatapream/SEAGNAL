# 해군

## 정의 / 관점 (공개 항해기상 한정)

대한민국 해군은 해양 방위, 해상교통로 보호, 해양주권 수호를 임무로 하는 군종이다. 함정(구축함·호위함·초계함·고속정 등), 잠수함, 해상작전헬기(MH-60R 등), 해상초계기(P-3CK, P-8A 등)를 운용한다. 함정·항공기 운용과 상륙·특수작전에서 기상·해황이 작전 가능 여부를 직접 결정짓는다. 본 지식베이스는 **군사기밀·작전상세를 제외**하고, 공개된 일반 항해기상(파고·풍속·시정·조석·해류 등) 관점에서만 다룬다.

## 핵심 관심사 (우선순위순, 함정 유형별 운용 차이 포함)

### 전 함정 공통

1. **파고(유의파고) 및 너울** — 함정·고속단정·항공기 이착함 안전의 최우선 지표; 선체 동요(롤링·피칭)와 직결 — **[앱매핑]** 해상 단기예보(해역별 파고), 해구번호별 72h 시계열, 기상부이 관측 파고, 전국 파고 랭킹

2. **풍향·풍속** — 함정 조종성·연료효율·갑판 작업 안전(고속단정 투하·헬기 이착함 포함)에 직접 영향 — **[앱매핑]** 해상 단기예보(해역별 풍향·풍속), 부이 관측 풍속, 전국 풍속 랭킹·비교

3. **해상특보(풍랑·강풍 주의보·경보)** — 출항·작전·훈련 중단 기준 판단의 공식 지표 — **[앱매핑]** 해상특보 화면, 특보 현황

4. **태풍 경로·강도** — 태풍 접근 시 단계별 함정 피항 작전(소형정 기지 내 이동, 대형함 해상 피항 등) 수행 — **[앱매핑]** 태풍 현황·경로 화면, 해상특보, 해상일기도

5. **조석·물때(고조·저조)** — 상륙작전·항만 입출항·상륙정 해안 접근 시 필수; 인천상륙작전처럼 조차가 작전 성패를 좌우한 역사적 사례 있음 — **[앱매핑]** 조석 바텀시트(고조·저조 시각·조위)

6. **해무(해상 안개)·시정** — 항해 경계, 충돌 회피, 헬기 운용에 결정적; 동해·서해·남해 모두 해무 빈발 — **[앱매핑]** 해무 CCTV, 기상부이 시정 관측

7. **유향·유속(해류·조류)** — 함정 항법 보정, UDT/SEAL 수중침투 루트 계획, 고속단정 기동 계획에 필요 — **[앱매핑]** 유향·유속(해류) 데이터

8. **해역별 기상 비교·랭킹** — 다중 작전해역 동시 파악, 최악 해역 우선 확인 — **[앱매핑]** 전국 해역 파고/풍속 랭킹·비교

9. **중기예보(3~10일)** — 훈련·작전 일정 수립, 보급·기동 계획에 필요한 선행 정보 — **[앱매핑]** 중기예보 화면

10. **수온·수심** — 잠수·구조 다이버 활동 온도 관리, 부이 수온 관측 참고 — **[앱매핑]** 기상부이 수온 관측; 수심 데이터 (음향전파/SVP 상세는 [GAP])

11. **해양종합정보 지도** — 함정 출항 전 전반적인 해역 상황 일괄 파악 — **[앱매핑]** 해양종합정보 지도 화면

12. **해상일기도** — 광역 기압계 파악, 악기상 선행 판단 — **[앱매핑]** 해상일기도 화면

13. **GPS 기준 최근접 부이 실시간 관측** — 현재 위치 해역의 실측 파고·풍속 즉시 확인 — **[앱매핑]** GPS 기준 최근접 부이 기능

14. **동해·서해·남해 해역별 특성 차이** — 동해(수심 깊고 파고 강함, 조차 소), 서해(조차 대, 수심 얕음), 남해(섬 많고 조류 복잡) — 해역별 운용 판단에 필요 — **[앱매핑]** 해구번호별 예보, 해양종합정보 지도

15. **군 전용 기상정보·작전해역 전용 예보** — 해군 내부 기상지원(군 전용 기상 채널) — **[GAP]** 앱에 없음

### 함정 유형별 추가 관심사

16. **대형함(구축함·호위함·상륙함) 전용 — 사격·비행갑판 운용 기상 조건** — 함포 사격 시 파고·풍속 한계, 비행갑판 헬기 이착함 한계풍속; 상륙함(LPH·LST)은 해안 상륙 조류·조위 복합 판단 필요 — **[앱매핑]** 해구별 시계열, 부이 실시간, 조석 바텀시트

17. **고속단정·고무보트(RIB/RHIB/조디악) — 단파 및 돌발 너울 감지** — 선체 무게 대비 파고 영향이 대형함보다 훨씬 크며, 파고 1m 이상 시 승선자 안전 위협; 단기 돌발파 감지가 핵심 — **[앱매핑]** GPS 최근접 부이 실시간, 해구 72h 시계열

18. **해상초계기·항공기(P-3CK, P-8A) — 저시정·착빙·난류 여부** — 해상 저공 비행 중 시정·난류·착빙 조건이 비행안전 직결; 해무 CCTV 및 기상부이 시정이 출격 판단 보조 자료 — **[앱매핑]** 해무 CCTV, 기상부이 시정

19. **해상작전헬기(MH-60R) — 갑판 기상창(weather window) 확보** — 이착함 갑판풍 방향·풍속·롤링 각도가 핵심; 갑판풍 정풍(head wind) 조건 선호, 횡풍 시 제한치 도달 여부 — **[앱매핑]** 해상 단기예보 풍향·풍속, 부이 실시간 풍속

20. **잠수함·수중 작전 — 수온 약층(thermocline) 및 수심별 조류** — 수온 약층 위치는 음향 탐지 환경에 결정적 영향; 수온·수심 복합 판단 필요 — **[앱매핑]** 기상부이 수온; 수심 데이터 ([GAP] SVP 정밀도 부족)

21. **구조·구난(SAR) — 표류 예측 및 탐색 범위 산정** — 익수자·조난 선박 표류 방향 예측에 유향·유속·풍속·파향 복합 사용; 골든타임 내 탐색구역 설정이 생존 결정 — **[앱매핑]** 유향·유속, 해상 단기예보 풍향, GPS 최근접 부이

22. **입출항·기동 계획 — 야간 시정 확보 및 야간 해무 예측** — 야간 입출항 시 해무 CCTV 실시간 + 전일 시정 패턴 파악 필요 — **[앱매핑]** 해무 CCTV, 기상부이 시정

23. **기온·체감온도(갑판 작업·승조원 피로도)** — 한겨울 동해 작전 시 갑판 결빙·저체온 위험, 여름 서해 폭염 승조원 피로; 부이 기온 관측 활용 — **[앱매핑]** 기상부이 관측(수온·기온 참고)

### 함정·소형정 일반 운용 임계 (공개 참고 기준)
- **고속정·고속단정(RIB/RHIB)**: 파고 1~2m 이상 시 운용 제한 검토 (소형 선체, 안정성 취약); Sea State 4(파고 1.25~2.5m) 진입 시 탑승자 안전 위협
- **해상작전헬기(MH-60R)**: 최대 풍속 약 45노트(23m/s) 환경에서도 비행 가능, 파고 2.5m 이상 해상에서도 수중탐지 장비 작동 가능 (공개 사양 기준); 이착함은 갑판 롤링 각도·갑판풍 조건 추가 고려
- **해상초계기(P-3CK·P-8A)**: 저공 해상 비행 시 난류·착빙·저시정 조건 주시; P-3CK 2025년 5월 포항 추락 이후 기상 외 기체 정비 이슈도 병행 점검
- **태풍 대비**: 해군은 72시간 전부터 단계별 경보 발령, 48시간 전 전 함정·항공기 안전구역 대피 원칙 (2003년 태풍 매미 대비 사례 공개)
- **잠수·구조 다이버**: 수온 15°C 이하 시 드라이수트 권장(저체온 위험), 유속 2노트(약 1m/s) 이상 시 수중 이동 제한 검토

### 해역별 특성 고려 항목
- **동해**: 수심 깊음(깊은 파랑), 조차 소(1m 미만), 북한 해류·쓰시마 해류 교차; 수온 약층이 뚜렷해 잠수함 음향 환경 복잡
- **서해**: 조차 대(2~4m, 인천 최대 약 9m), 수심 얕음, 해무 빈발; 조류가 빠르고 복잡해 고속단정·상륙함 입출항 시 조류 주시
- **남해**: 다도해로 파고 상대적 완화, 조류 복잡, 여름 태풍 진입 경로; 해협 통과 시 조류 가속 현상 주의

### 조석 관련 의사결정
- 상륙작전·항만 입출항 시 고조 전후 2~3시간 창조류 이용이 유리
- 서해 조차 특성상 만조 시각과 저조 시각의 가항수심 차이가 항법에 결정적
- 물때 7물·8물(사리 전후) 최대 조류 시각에 고속단정 침투 루트 재계산 필요

3. **MH-60R 해상작전헬기 도입 확정 및 운용** (2025~2026)

   - 출처: https://aboda.kr/entry/%ED%95%9C%EA%B5%AD-%ED%95%B4%EC%83%81%EC%9E%91%EC%A0%84%ED%97%AC%EA%B8%B0

   - 해군 차기 호위함(FFX-III 배치-III) 건조 사업 진행 중. 복합기상 환경에서 자동화 항법·기상대응 기능 강화 요구가 제기되면서 공개 해양기상 데이터 활용 필요성 증대.
   - 출처: https://www.dapa.go.kr/dapa/ma/selectBoardArticle.do?id=40619&boardId=I_00000025 (방위사업청 공고)

5. **해양경찰·해군 합동 수색구조(SAR) 개선** (2025~2026)
