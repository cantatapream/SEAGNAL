# 레저스포츠 활동자

> SEAGNAL 음성비서 "나리야" RAG 지식베이스 — 레저스포츠 직군
> 작성일: 2026-05-28 | 버전: 2.0 (2차 보강)

---

## 정의 / 하위 유형

해양레저 활동자는 바다·연안 환경을 무대로 스포츠·레크리에이션을 즐기는 인구를 포괄한다.

| 하위 종목 | 정의 |
|-----------|------|
| **서핑** | 파도를 이용한 보드 스포츠. 국내 인구 약 120만 명(2024년 기준). 양양·제주·부산·태안 주요 스팟 |
| **요트·세일링** | 바람을 동력으로 삼는 범선 스포츠. 전국 마리나·항포구 기반 |
| **카약·카누·SUP** | 패들 추진 소형 수상 레저. SUP(스탠드업패들보드)는 서핑+카약 복합형으로 진입장벽 낮음 |
| **프리다이빙·스킨스쿠버** | 수중 잠수 레저. 제주·울릉도·속초 등 투명도 높은 해역 선호 |
| **제트스키·동력수상레저** | 엔진 동력 수상 레저. 조종면허 필수. 연안 및 마리나 중심 |
| **연안 보트낚시(레저)** | 소형 레저보트 기반 낚시. 갯바위 접근+외해 출조 포함 |
| **윈드서핑·카이트서핑** | 돛/연을 이용해 바람으로 추진하는 보드 스포츠. 풍속 의존성 최고. 국내: 무의도·영종도·태안 |
| **웨이크보드·웨이크서핑** | 동력보트 인파를 이용한 보드 스포츠. 내수면+연안 마리나 중심. 조종면허 불필요(탑승자) |

## 핵심 관심사

1. **파고 (유의파고) 실시간·예보** — 서핑 가능 여부·요트 안전·낚시 출조 결정의 1순위 기준. 파고 0.5~1.5m = 서핑 입문/SUP, 1.5~3m = 서핑 중급, 3m↑ = 위험/제한 — **[앱매핑]** 해역별 단기예보(파고), 부이 실시간 관측, 72h 시계열 예보, 파고/풍속 랭킹 화면

2. **풍속·풍향** — 오프쇼어(육지→바다) = 서핑 최적; 온쇼어(바다→육지) = 파도 불량. 요트는 적정 풍속 3~7 보퍼트(~14m/s) 선호; 제트스키·SUP는 7m/s↑ 위험. **윈드서핑·카이트서핑**은 반대로 풍속 6~12m/s가 최적이며 온쇼어도 활용 가능 — **[앱매핑]** 부이 관측(풍속·풍향), 해상 단기예보, 해양종합정보 지도(풍 레이어)

3. **기상특보(풍랑주의보·경보) 발효 여부** — 풍랑주의보(파고 3m↑, 풍속 14m/s↑ 3시간): 수상레저기구 운항 법적 제한. 경보(파고 5m↑, 풍속 21m/s↑): 전면 운항 금지. **강풍주의보·경보도 별도 확인 필요** (육상 강풍이 연안 급변수로 작용) — **[앱매핑]** 해상특보 발효현황 화면, 특보·태풍 화면

4. **물때(조석) — 고조·저조 시각·조위** — 서핑은 간조→만조 전환 물때가 파도 최적, 갯바위낚시는 간조 전후, 해루질/잠수는 저조 시간 중요. 서·남해는 조차 크므로 특히 민감. **다이빙은 조류 전환 직전·직후(slack time) 가 입수 최적** — **[앱매핑]** 조석/물때 바텀시트(고조·저조 시각·조위), 조석 화면

5. **수온** — 슈트 선택·안전에 직결. 28~30°C: 수영복, 23~27°C: 3mm 슈트, 20~22°C: 5mm+후드, 20°C↓: 드라이슈트. 서핑 쾌적 수온 18°C↑. **프리다이빙은 수중 온도 약층(thermocline)에서 갑작스러운 냉수 노출이 경련·기절 위험** — **[앱매핑]** 기상부이 관측(수온), GPS 최근접 부이

6. **해무(안개) 및 시정** — 시정 0.5km↓: 수상레저 운항 제한. 요트·보트의 충돌 사고 위험. 특히 서해·남해안 봄~여름 해무 빈발. **제트스키·카약은 레이더 미장착으로 해무 시 충돌 위험 최고** — **[앱매핑]** 해무 CCTV 화면, 부이 관측(시정), 해양종합정보 지도(해무 CCTV 레이어)

7. **스웰(너울) 주기·방향** — 피리어드 7초↑ = 서핑 가능 파도 형성, 12초↑ = 우수한 파도. 동해는 북동/동 스웰, 제주 남부는 남 스웰, 태안(서해)은 북서 스웰 선호. **방향에 따라 같은 파고도 스팟별 파도 질이 크게 달라짐** — **[앱매핑]** [GAP] 앱에 너울 주기·방향 상세 데이터 없음

8. **태풍 현황·경로** — 태풍 접근 시 강한 파도 유입(숙련 서퍼 관심)과 동시에 안전 위험 급증. 연안 접근 시 요트·보트 피항 필수 — **[앱매핑]** 태풍 현황·경로 화면, 특보·태풍 화면

9. **해류(유향·유속)** — 프리다이빙·스킨스쿠버: 강한 조류 = 드리프트 다이빙 위험. 서핑: 연안류가 서퍼를 이동시킴. 카약·SUP: 해류 역행 시 체력 소모 급증 — **[앱매핑]** 유향·유속(해류) 데이터, 해양종합정보 지도(유속 레이어)

10. **중기예보(3~10일)** — 주말 서핑 여행 계획, 요트 원거리 항해 일정, 다이빙 투어 예약 취소 결정에 활용 — **[앱매핑]** 중기예보(3~10일) 화면

11. **서핑 생활지수** — 국립해양조사원 제공 서핑지수(파고·풍속 복합 산출). 당일 가능/불가능 한눈 파악 — **[앱매핑]** 생활지수: 서핑 지수

12. **수심** — 카약·SUP: 모래사장·암반 지형 파악. 스킨스쿠버: 다이빙 포인트 적합도. 보트낚시: 저수심 좌초 회피 — **[앱매핑]** 수심 데이터, 해양종합정보 지도(수심 레이어)

13. **이안류(離岸流) 경보** — 해수욕장에서 해안 수직 방향으로 빠르게 이탈하는 물살. 여름 서퍼·수영객 인명사고 원인 1위 — **[앱매핑]** [GAP] 앱 내 이안류 경보 데이터 없음

14. **해파리 출현 정보** — 7~9월 노무라입깃해파리·작은상자해파리 집중 출현. 서퍼·다이버·수상레저 활동자 쏘임 사고 급증 — **[앱매핑]** [GAP] 앱 내 해파리 출현 경보 데이터 없음

15. **입수금지구역·수상레저 금지구역** — 해수욕장 지정 유영금지 구역(일반적으로 수심 2m 이상 또는 부이 밖), 군사작전구역, 항로·항구 진입 금지구역, 수산자원보호구역. 서퍼·SUP·카약 등 비동력 레저는 구역 혼동으로 과태료·사고 위험 — **[앱매핑]** [GAP] 앱 내 금지구역 레이어 없음

16. **수상레저안전법 자격 요건 및 신고 의무** — 동력수상레저기구(제트스키·모터보트) 조종 시 1·2종 조종면허 필수. 수상레저사업 신고(해경). SUP·카약·서핑보드는 동력 없으면 면허 불필요하나 연안 안전법 적용. 야간·악천후 출항 시 신고의무 강화(수상레저안전법 제17조) — **[앱매핑]** [GAP] 자격·신고 정보 없음; 해양경찰청 수상레저종합정보시스템(boat.kcg.go.kr) 안내 가능

17. **렌탈·강습 운영 시즌 및 해수욕장 개장일** — 서핑 강습 시즌: 양양 6~9월 집중(성수기), 제주 연중. SUP·카약 렌탈: 6~9월. 해수욕장 공식 개장(7월 초~8월 말)은 안전요원 배치 및 구역 통제와 연동. 비성수기 입수 시 구조 대응력 저하 — **[앱매핑]** [GAP] 앱 내 개장 정보 없음

18. **자외선(UV)지수·일출·일몰 시간** — 수면 반사로 UV지수 육상 대비 2배 이상. 장시간 서핑·SUP 활동자 일광화상 위험. 일출·일몰 시간은 야간 출항·입항 계획의 기준 — **[앱매핑]** [GAP] 앱 내 UV지수·일출일몰 없음

19. **스쿠버다이빙 전용 지수(수중 시정·조류·수온 복합)** — 국립해양조사원 스킨스쿠버 생활지수 존재하나 앱 미연동. 수중 시정(탁도), 조류 강도, 수온 세 요소 복합 판단 필요. 특히 태풍·강우 후 강하 탁수 발생 주의 — **[앱매핑]** [GAP] 앱 내 스쿠버 전용 지수 미연동; 외부: 국립해양조사원 스킨스쿠버 지수(khoa.go.kr/khoa/lifeforecast/sub2.do)

20. **전국 파고·풍속 비교 랭킹** — 어느 해역이 지금 가장 파도가 좋은지(서퍼 입장) 또는 가장 잔잔한지(요트·보트 입장) 빠르게 비교. 주말 원정 서핑 스팟 선택에 활용 — **[앱매핑]** 전국 파고·풍속 랭킹·비교 화면 (충족)

21. **윈드서핑·카이트서핑 풍속 지수** — 6m/s↑ = 윈드서핑 기본, 8m/s↑ = 카이트서핑 최적. 돌풍(Gust) 편차 여부 중요 — **[앱매핑]** 단기예보·부이 관측(풍속)으로 부분 충족; [GAP] 돌풍·Gust 예보 데이터 없음

## 의사결정 요인 / 임계치·규정

### 서핑
| 항목 | 좋음(입문) | 좋음(중급↑) | 위험·비추천 |
|------|-----------|------------|------------|
| 유의파고 | 0.5~1.5m | 1.5~3m | 3m↑ (풍랑주의보 수준) |
| 풍속 | 3m/s↓ (오프쇼어) | 5m/s↓ | 10m/s↑ (온쇼어 강풍) |
| 스웰 주기 | 7~10초 | 10초↑ | 5초↓ (짧은 피리어드) |
| 수온 | 23°C↑ (수영복) | 18~23°C (3mm 슈트) | 15°C↓ (두꺼운 슈트 필수) |
| 최적 물때 | 간조→만조 전환기 | — | 최대 조류 시 (이안류 위험) |
| 바람방향 | 오프쇼어(육지→바다) | 사이드쇼어 | 온쇼어(바다→육지) |
| 스웰 방향 | 스팟 전면 정면~45° | 45~90° 사이드 | 배향(등지는) 스웰 |

| 오버헤드(overhead) | 파도 키 이상, 머리 위 파도 | 서 있는 사람의 키를 초과하는 파고 |
| 클로즈아웃(close-out) | 클로즈아웃, 한꺼번에 무너지는 파도 | 파도가 한 선에서 동시에 전부 부서져 라이딩이 불가능한 상태 |
| 돌풍(Gust) | 순간최대풍속, 돌풍, 급변풍 | 평균 풍속보다 순간적으로 강하게 부는 바람 |
| 레드플래그(red flag) | 입수금지 깃발, 빨간 깃발, 해수욕장 입수금지 | 해수욕장에서 입수 금지를 나타내는 적색 안전 깃발 |
| 브레이크(break) | 파도 브레이크, 파도 부서지는 지점, 브레이크포인트 | 파도가 얕은 수심에서 부서지기 시작하는 지점 |
