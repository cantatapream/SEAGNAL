## 필수 섹션(순서·제목 고정)
1. `## 정의 / 하위 유형`
2. `## 핵심 관심사` — 각 항목 형식: `- 관심사 — 한줄 이유 — [앱매핑] 도구/화면` 또는 `— [GAP]`
3. `## 자주 묻는 질문(예상) → 앱 도구 매핑` — **표 칼럼 고정**: `| # | 질문 | 앱 매핑 | 충족도 |` (충족도 ∈ {충족, 부분충족, GAP})
4. `## 의사결정 요인 / 임계치·규정`
5. `## 전문용어·동의어` — **표 칼럼 고정**: `| 표준어 | 구어·은어·동의어 | 설명 |`
6. `## 최근 관심·언급 주제` — 각 항목에 **출처 URL + (수집일)** 필수, 비공식 출처는 `(비공식)` 표기
7. `## 나리야 선제 제안·개인화 규칙` — 아래 규칙 포맷 준수
8. `## GAP 보완 후보 (외부 연동)` — **표 칼럼 고정**: `| GAP 항목 | 외부 소스 기관 | 딥링크/URL | 비고 |` (불가 시 `대체 불가`)
9. `## 앱 데이터 매핑 요약표` — `| 관심사 | 앱 도구/화면 | 충족/GAP |`
10. `## 출처`

## 선제 규칙 ID·포맷 (P3 기계추출 보장)
- **규칙 ID 규약**: `TR-<직군약어>-NN` (두 자리). 직군약어: CG/FISH/LEIS/MOF/NAVY/GOV/ORG/ANGL.
- 각 규칙은 다음 4요소 + **반구조화 트리거**:
```
### TR-FISH-01: <제목>
- 트리거(조건식): {metric: "wave_height", op: ">=", threshold: 3, unit: "m"} AND {metric:"time_window", ...}
- 트리거(서술): 사람이 읽는 한 줄 설명
- 제안 멘트: "<사용자에게 할 말>"
- 근거 앱데이터: <도구/화면명>
```
- `metric` 표준 키: `wave_height`(m) · `wind_speed`(m/s) · `warning`(특보종류) · `water_temp`(°C) · `visibility`(km) · `typhoon_eta`(h) · `tide_phase`(사리/조금/만조/간조) · `current_speed`(cm/s).
