# 통보문 (해상) 경고 ↔ 풍랑특보 발효 매칭 분석

분석 스크립트: `run_bulletin_match.js`
산출물: `out/bulletin_warnings.json`(파싱 구조화본), `out/bulletin_match_summary.json`(요약)
분석 기간: **2024-12-05 이후** (발효 이벤트 / 통보문 모두)
작성일: 2026-06-14

---

## 1. 방법론

### 1.1 입력
- `data/bulletins.json` — dmdw "[날씨해설] 단기전망" 통보문 **10,743건**(객체, ID 키). 각 항목의 `marine` 배열에서 **`(해상)`이 포함된 줄만** 경고 대상으로 사용.
- `data/warnings_2023-2026.csv` — 특보 발효/해제 기록(5컬럼: `발표시간,지역,발효시각,해당지역,내용`).
- `out/prelim_events.json` — 예비특보 이벤트(풍랑 10,190 / 태풍 463).

### 1.2 통보문 (해상) 파싱 (목표 1)
각 `(해상)` 줄에서 구역별로 다음을 추출하여 `out/bulletin_warnings.json`에 zone-level 행으로 저장(한 줄에 여러 구역이면 구역마다 1행):
- **구역명**: 정규식 `[가-힣][가-힣()]*(?:먼바다|앞바다|연안바다|전해상|해상)`. 괄호 안 하위구역은 분리.
- **풍속 m/s 상한**: `30~50km/h(9~14m/s)` 류에서 m/s 값의 상한(=14). 범위·단일값 모두 처리.
- **물결 m 상한**: `1.5~3.0m`, `최대 5.0m 이상` 류에서 상한. `m/s`는 부정형 lookahead로 제외.
- **풍랑특보 명시 플래그**(`warnFlag`):
  - `active` = 이미 발효(`풍랑특보가 발효된 / 발효 중`)
  - `prelim` = 예비특보 명시 또는 `발표될 가능성/발표 예정`
  - `mention` = 풍랑 단어는 있으나 위 분류 외
  - `release` = 해제만 언급
  - `none` = 풍랑 단어 없음(순수 바람/물결 경고 또는 안개·돌풍 등)
- **예상 시점 표현**: `오늘/내일/모레/…부터/까지` 류 텍스트 그대로.

### 1.3 발효 이벤트 파싱 (목표 2)
CSV에서 `풍랑 … 발표` 행만 사용. `발효시각`(col2)과 `해당지역`(col3)을 **`(N)` 인덱스로 조인**하여 이벤트 단위로 분해.
- 발효시각 텍스트 `2026년 06월 02일 01시 00분` 파싱.
- 해당지역의 `제주도앞바다(제주도동부앞바다…)` 형태는 부모+자식 모두 구역으로 펼침.
- **해제 제외**(`발표`만), 레벨은 `경보/주의보` 구분.
- CSV는 발효 1건이 `전국`+개별청 여러 행으로 중복 기재되므로 **(발효시각, 구역, 레벨)** 키로 중복 제거.

### 1.4 구역명 매칭 규칙 (목표: 구역 정규화)
`zonePolygon.js`의 `normName`(공백·중점·마침표·괄호 제거)을 기반으로 자체 포함관계 규칙(`zoneMatch`) 구현. 통보문과 CSV의 표기 차이를 흡수:
- `decompZone`: `안쪽/바깥` 수식어와 `해상/전해상` 우산을 분리 → `{base, sub(안/바깥/전), sea}`.
- 매칭 성립 조건:
  1. **base 동일**(또는 `해상` 우산일 땐 prefix 포함: `동해중부해상`(base=`동해중부`) ⊂ `동해중부먼바다`).
  2. 한쪽이 우산(`전`/`해상`/`전해상`)이면 안쪽·바깥·전 모두 매칭. 예: 통보문 `동해중부먼바다` ↔ 발효 `동해중부안쪽먼바다`, `동해중부바깥먼바다` 모두 매칭.
  3. 양쪽 모두 구체(`안`/`바깥`)면 동일 sub일 때만 매칭.

이 규칙은 통보문이 흔히 광역(`동해중부먼바다`, `~해상`)으로 경고하고 발효는 세분(`안쪽/바깥`)되는 실제 패턴을 반영한다.

## 3. 사전경고율 / 리드타임 (목표 3)

각 풍랑 발효 이벤트에 대해 **발효시각 0~5일 전** 같은 구역의 (해상) 통보문이 있었는지 탐색.

| 지표 | 값 |
|---|---|
| 발효 이벤트 | 2,980 |
| **사전경고 있음** | **2,289 (76.8%)** |

리드타임(최초 경고 → 발효, 시간 h):

| 분류 | n | p10 | p25 | **중앙값** | p75 | p90 | 평균 |
|---|---|---|---|---|---|---|---|
| 전체 경고 | 2,289 | 32.7 | 58.7 | **103.5 (≈4.3일)** | 113.8 | 117.5 | 87.2 |
| 풍랑 명시 | 2,154 | 32.5 | 60.7 | **105.7 (≈4.4일)** | 114.0 | 117.5 | 87.8 |
| 물결/바람만(풍랑 미명시) | 135 | 39.5 | 48.5 | **83.7 (≈3.5일)** | 106.3 | 114.5 | 77.6 |

- 사전경고가 있을 때 **중앙값 약 4.3일** 전부터 통보문이 해당 구역을 경고. p90이 117시간(≈4.9일)에 몰려 있어 탐색창 상한(5일)에 다수가 붙음 → 실제로는 더 일찍부터 경고했을 가능성(창 확대 여지).
- **풍랑을 명시한 경고가 단순 물결/바람 경고보다 리드타임 중앙값이 약 22h 더 길다**(105.7h vs 83.7h). 즉 통보문이 "풍랑특보 가능성"을 적시할수록 더 일찍 신호를 준다.
- 단, 풍랑 명시(2,154)가 물결/바람만(135)보다 압도적으로 많아 "전체"는 사실상 풍랑명시군과 동일.

## 4. 역방향: 거짓경고율 / 적중률 (목표 4)

통보문 (해상) **경고행** 정의: `warnFlag ∈ {active, prelim, mention}` 또는 `물결 상한 ≥ 2.0m` 또는 `풍속 상한 ≥ 14 m/s`. 각 경고행에 대해 **이후 3일 내** 같은 구역 풍랑 발효 여부 확인.

| 지표 | 값 |
|---|---|
| 통보문 (해상) 경고행 | 11,141 |
| 3일내 실제 발효 | 5,882 |
| **적중률** | **52.8%** |
| **거짓경고율** | **47.2%** |

> 해석 주의: "거짓경고"의 상당수는 (a) 통보문이 `active`(이미 발효 중)을 단순 안내한 경우 — 이때 "3일내 새 발효"는 정의상 잘 안 잡힘, (b) 광역 우산 경고(`~해상`)가 실제로는 일부 세부구역만 발효된 경우다. 따라서 47.2%를 순수 오경보로 보면 과대평가다. 아래 5절의 플래그·강도 세분이 더 정확한 신호다.

|---|---|---|---|

**보정표 핵심 신호**:
- **`prelim`(예비/가능성 명시) → 발효율 84.0%** — 가장 강한 단일 예측자.
- 풍속 **≥14 m/s → 발효율 약 57~60%**, 12~14 m/s 구간(20.5%)과 뚜렷한 단차.
- 물결 **≥3.0m → 발효율 약 53~60%**, 2.5~3.0m(26.4%)와 단차.
- `active`(31%)·`none`(35%)은 낮음 — `active`는 이미 발효 안내라 "3일내 신규 발효" 정의상 낮고, `none`은 풍랑 위험을 명시하지 않은 약한 신호.
- **비단조 주의**: 풍속 18+(46.5%)·물결 4.0+(52.5%)가 한 칸 아래보다 약간 낮다. 최강 경고는 종종 광역 우산(`~해상`)으로 발효 시점이 3일 창 밖이거나, 이미 발효된 사후 안내가 섞인 영향으로 추정.

## 7. 한계 및 파싱이 놓친 패턴

1. **5일 창 절단(우편향)**: 리드타임 p75~p90이 113~120h에 쏠림 → 실제 최초 경고는 5일보다 더 앞설 수 있어 리드타임이 **하한 추정**일 가능성. 창을 7~10일로 늘려 재측정 권장.
2. **거짓경고율(47.2%)의 과대평가**: `active`(이미 발효 안내)와 광역 우산 경고가 분모에 포함됨. "신규 onset 예측력"만 보려면 `prelim` 위주로 보는 것이 정확(84%).
3. **광역 우산 매칭의 관대함**: `~해상`/`~먼바다` 우산을 안쪽·바깥 모두에 매칭 → 사전경고율을 다소 높게(관대하게) 잡을 수 있음. 반대로 엄격 매칭(sub 일치 강제) 시 수치가 떨어질 수 있어, 본 결과는 **관대한 상한**으로 해석.
4. **경보(警報) onset 미포함**: CSV상 경보는 `변경`으로만 등장. 주의보→경보 격상은 본 onset 정의 밖. 경보 단독 발효를 별도로 보려면 `변경` 행 추가 파싱 필요.
5. **구역추출 실패 67줄(0.9%)**: 구역명 없는 일반 해상 안내(돌풍·천둥·안개)로, 풍랑 경고가 아니어서 제외 타당.
6. **풍속/물결 null 행**: `바람이 매우 강하게` 처럼 수치 없는 정성 표현(풍속 null 1,419 / 물결 null 1,645)은 강도별 보정표 분모에서 자동 제외됨. 정성 표현도 `prelim`/`active` 플래그로는 포착되므로 5절 플래그 테이블이 보완.
7. **레벨**: 발효 이벤트가 전부 `주의보`로 집계(경보 격상 미반영) — 강도 상한 분석은 못 함.
