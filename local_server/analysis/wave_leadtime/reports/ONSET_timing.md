# onset 타이밍 검증 ("언제 발효되나", 풍속, 기준 run = 발효 36h 전)

표본 72건 중 onset 예측됨 59건 (나머지는 기준 run 에서 임계 미도달 = 타이밍 예측불가)

## 예측 onset vs 실제 발효시각 오차

- 오차(예측onset − 실제발효) 중앙값 **-15.0시간** (음수=일찍 예측), 절대 중앙값 **15.0시간**
- |오차| ≤ 6시간: **27%**, ≤ 12시간: 42%

## 기상청 발표 대비 선행성

- 예측 onset 이 실제 발표(announce)보다 앞선 비율: **90%**, 선행 중앙값 14.0시간

> |오차| 작을수록 "언제" 예측 정확. 선행성 높을수록 기상청보다 먼저 알릴 수 있음.
