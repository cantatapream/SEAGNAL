# Fable 모델 전반 재검토 — 특보 예측 분석 로직 (2026-06-12)

> 범위: 운영 코드(advisory/*) ↔ 검증 결과(analysis/wave_leadtime/*) 정합성.
> 이미 검증 완료된 항목은 재검토하지 않고 결과를 전제로 사용한다(아래 §4).

## 1. 결론 요약

검증 방법론과 그 결과(폴리곤+면적의 상대 판별력, 예비특보 평가, 6년 기후값)는 **타당**하다.
그러나 **운영 엔진은 검증으로 폐기한 구 로직을 아직 그대로 쓰고 있고**, 사용자에게 표출하는
**절대 확률(%)은 현재 근거가 없다.** 기능 재활성화(ON) 전 반드시 §2의 P1 세 건을 해소해야 한다.
(현재 기능은 OFF 상태이므로 운영 사고 위험은 없음.)

## 2. 발견 사항 (우선순위순)

### P1-1. 엔진이 여전히 "원형 반경 + 최대밴드" — 과탐 원인 미수정
- `advisory/predictionEngine.js:226` `radOf = (H?55:30) × RAD_MULT(1.8)` → 먼바다 99px(≈80km 원).
- `:238-252` `analyzeZone(... radiusPx, minBandPixels:12)` — 원 안 어디든 12픽셀만 넘으면
  그 밴드를 구역값으로 취함 = **"구역값"이 아니라 "주변 지역 최대값"**.
- 이것이 19건 일제 예측(80%/63% 균일) 사태의 확정 원인이며, 검증(152,480표본)에서
  폴리곤내부+면적비율이 동일 재현율에서 오탐 18~25%p 낮음을 확인했다.
- **조치(Phase E)**: `zonePolygon.zonePixelIndices + analyzeByIndices` 로 교체,
  운영점 `maxBand≥25kt & areaFraction≥0.30`. 구역별 인덱스는 청별 1회 사전계산.

### P1-2. 표출 확률(%)의 근거 부재 + 무효화된 출처 표기
- `predictionConfig.js:68-77` WIND/WAVE_PROB_TABLE 은 구(probCalib) 산출인데, 그 보정은
  원형 방식 + 음성표본 부족 환경에서 나온 것 — 재보정 시 절대값이 붕괴함을 확인했다.
- 파일 머리(`:9-11`)의 "재현율 89% · 정밀도 78% · 확률 잘 보정됨" 주석은 **현재 증거와
  불일치(낡은 주장)** — Phase E 때 갱신 필수.
- 서술문구(`predictionEngine.js:277`) "과거 유사 패턴 기준 발효 가능성 NN%" 역시
  보정 안 된 %를 단정 표현한다.
- **조치**: `fetch_calm.js`(잔잔표본 수집) → `calib_abs.js`(P(발효|밴드,면적), 2026 홀드아웃)
  완료 전까지 %를 카드에 노출하지 않거나 등급(높음/관심)만 노출.

### P1-3. 등급 컷과 확률표의 결합이 과탐을 증폭
- `gradeOf`(`predictionConfig.js:61`)는 prob≥0.5 면 표출 → 표에서 25kt=0.63 이므로
  **25kt 밴드에 12픽셀만 스치면 무조건 "관심 63%"** 가 뜬다. P1-1 의 지역최대 샘플링과
  결합해 인접 구역 연쇄 표출을 만든 구조적 원인. 폴리곤+면적 교체 시 함께 해소되지만,
  등급 기준을 (밴드,면적) 2차원으로 다시 정의해야 한다.

### P2-1. combinedProb = max(풍속표, 파고표)
- 두 미보정 표의 OR-max(`predictionConfig.js:81`). 파고표는 풍속표보다 검증이 더 약하다.
- **조치**: 재보정 시 파고는 독립 확률원이 아니라 보조 신호(동시충족 가산)로 격하 권장.

### P2-2. 사이클 간 히스테리시스 없음
- 매 사이클 독립 생성이라 경계 신호가 표출↔비표출로 깜빡일 수 있다. 억제(suppression)는
  발효/예비특보만 거른다. **조치**: Phase E 에서 (zone,onset±6h) 단위 dedup + 2사이클 유지.

### 사소(참고)
- `LEAD_MAX_H=96` 이나 실제 아카이브는 ~72h — 무해한 필터(빈 프레임은 자연 제외).
- 엔진의 KST 벽시계 규약은 일관 — 오프라인 평가에서 발견한 −9h 파일명 버그는
  캐시 파일명 한정 문제로 운영 엔진(listFrames 경유)과 무관함을 확인.

## 3. 데이터로 확정된 사실 (이번 사이클 신규)

| 항목 | 수치 | 함의 |
|---|---|---|
| KMA 공식 발표→발효 리드(풍랑, 6년 7,404건) | 중앙 **2.0h**, 99%가 3h내 | 공식특보는 사실상 동시통보 — 24~72h 선행은 빈 시간대 |
| KMA 예비특보 자체 정밀도 | 62% (5,716 에피소드) | 우리 오탐 평가의 공정 기준선 |
| 예비 발표 순간 일치(발효O/발효X) | 64% / 39% | 판별폭 25%p — 신호가 실제 구분력 보유 |
| 예비보다 24h 선행 탐지 | 61% | 고유 가치 |
| 무예비 발효의 사전 포착 | 62% (표본 286, 커버리지 14%) | 잠정 — 표본 편향 주의 |
| 풍랑 계절성(6년 9,946건) | 12~3월 정점, 6월 최저 | 겨울철 가중 검증·임계 점검 근거 |

## 4. 재검토 불필요(완료 확정) 항목

- 폴리곤 샘플러 정확성(13/13 단위테스트) · 44/44 구역-청 매핑.
- onsetScan 프레임-외부 스캔 ≡ zone-외부 (5,000 시나리오 동치 증명) · OOM 해소.
- 두 앵커(발표/발효 기준 3일 전) 검증 — 152,480표본, 오탐 18~25%p 감소 확인.
- 예비특보 census(1,103통보문→5,716에피소드) + 전수 평가(13,500작업).
- suppression(발효·예비 구역 억제) 동작.
- 차트 보정(CALIB)·팔레트 분류 — 기존 검증 유지.
