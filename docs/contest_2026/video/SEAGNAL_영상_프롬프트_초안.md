## 1. inputs [수정]

- 사용자에게서 받을 것: **법률 챗봇 화면**(관리자 전용이라 Claude가 못 찍음) — 질문·답이 보이는 화면 녹화 10초 또는 캡처 2~3장. 없으면 기존 캡처 `S14-1_챗봇답변_크롭.png` 사용.
- Claude가 직접 준비: 앱 화면(seagnal-server.fly.dev 를 휴대폰 크기 412×900, 배율 3으로 열어 캡처·녹화), 음악·효과음(직접 합성), 숫자(10-19 확인값만).
- 글자 로고: 「SEA:GNAL」 / 꼬리말: 「바다 : 그 날의 신호」.

## 2. direction [그대로 + 수정 몇 줄]

- [그대로] Apple 키노트 스타일, 2D, **한 번에 이어지는 한 장면(one continuous take)**. 모든 장면은 앞 장면에서 만들어진다: 페이드·흐림·컷 없음. 물체가 모양을 바꾼다 — 글은 마스크 선에서 솟아오르고, 아이콘은 0에서 스프링으로 튀어나오고, 막대는 그려지고, 화면은 밀리고, 검은(→남색) 도형이 화면을 덮었다가 다음 장면으로 오그라든다.
- [수정] 바탕: 따뜻한 흰색 · UI: **남색 #0B1E3F** · 강조: **청록 #2AD8E2** · 경고만 주황. 앱 화면 위에는 iOS 26 리퀴드 글라스.
- [수정] 글꼴: 로고 Archivo(wdth 125, 800) · 한글 머리말 Pretendard(700~800) · 코드 Geist Mono.
- [그대로] 커서가 실제 클릭·드래그·타이핑으로 모든 변화를 일으킨다. 카메라는 Screen Studio 식으로 확대해 각 순간이 화면을 채우고, 커서도 같이 커진다.
- [추가] 휴대폰 안의 조작은 커서 대신 **손가락 터치 원(누르면 작아졌다 퍼지는 원)** 으로 — 안드로이드 앱이므로. (의논 거리 ②)
- [추가] 사실만: 숫자는 2026-10-19 확인값, 알림 문구는 앱 코드의 실제 형식, 화면은 실제 앱. 「확률」 표현 금지.
- [그대로] 금지: 크로스페이드, 흐림으로 나타나기, 밝기로 「현상」되기, 3D 뒤집기, 입자, 글로우, 1초 넘는 정지, 템플릿 같은 것.

## 3. structure [수정 — 3편]

공통: 120BPM, **64박(32초)**, 박자마다 무언가 바뀐다. 각 편의 **마지막 장면 = 첫 장면**(로고). 드롭(17박), 조용한 구간(49~56박), 박자 복귀(57박).

### 1편 「묻기 전에 먼저」 — 무엇·왜·어떻게(AI로 만든 앱)
- 열기(1~8): 「SEA:GNAL」 글자가 가운데 **「:」의 점**으로 아코디언처럼 빨려 들고, 점이 남색 알약으로 커지며 「바다 : 그 날의 신호」가 솟는다. 클릭 → 조리개 6날이 닫혔다 열리며 **특보정보 탭 화면**.
- 문제(9~16): 말풍선 셋이 0에서 튀어나온다 — 「특보 언제 풀려요?」「처벌 대상이에요?」「내일 파도 어때요?」 → 모여 「☎ 파출소」 알약 → 머리말 「묻기 전에 먼저」.
- 만들기(17~32, 드롭에 착지): 알약이 리퀴드 글라스 터미널이 된다. 한 줄이 쳐진다: 「특보가 발효되면 관심 해역 사용자에게 바로 알려 줘」 → 코드가 쏟아지고 접히며 **앱 화면**으로 바뀐다. 머리말 「현직 해양경찰관이 AI로 만든 앱」.
- 무대(33~48): 앱이 Mac 창으로 물러났다가 **안드로이드 휴대폰**으로 줄어든다(테두리가 화면 가장자리에서 자람). 터치 → 해역별 특보현황이 펼쳐지고, 위에서 **특보 알림**이 떨어진다.
- 숫자(49~56, 조용한 구간): 도형 하나가 모양을 바꾸며 숫자를 넘긴다 — 1,862명 설치 → 82만 건 알림 → 공공데이터 75종 → AI 작업 7,217회.
- 닫기(57~64): 도형이 화면을 덮었다가 알약 → 점 → 글자가 튀어나와 첫 장면.

### 2편 「특보 알림 하나를 정확하게」 — 특보·바다 정보
- 열기(1~8): 로고 → 알약 「특보정보」.
- 지도(9~16): 특보구역 지도가 펼쳐지고 **93개 구역**(44 + 연안바다·평수구역 49)이 칠해진다.
- 특보의 일생(17~32, 드롭): 도형 하나가 바뀐다 — 발표 → 발효 → 알림 ✓ → 해제. 휴대폰 알림 → 터치 → **안전권고 팝업**.
- 바다 정보(33~48): 바다 한 지점 터치 → 정보 11가지 카드가 차례로 튀어나옴 → 부이 실측 → 태풍 4개 기관 경로가 그려짐.
- 조용한 구간(49~56): 「1분마다 확인 · 823,412건 도달」.
- 닫기(57~64).

### 3편 「사고 나던 곳을 미리」 — 연안 안전·법률
- 열기(1~8): 로고 → 알약 「연안 안전」.
- 위험예측(9~24, 드롭 17): 관광지 1,354곳이 지도에 점으로 튀어나오고 단계 색으로 칠해짐 → 한 곳 터치 → 바텀시트(위험지수·「평소보다 몇 배」) → 막대 4개가 그려짐(3.34배·약 2.1배·1.96배·1.67배).
- 브리핑(25~40): 시간 알약이 바뀐다 07:30 → 17:30 → 23:00, 머리말 「해양경찰관 교대 직전」 → 총평 화면 → 흐름 [서버 규칙 → AI → 검사기].
- 법률(41~48): 질문이 쳐지고 → 답(결론·근거 조문·벌칙·서식)이 위에서 아래로 쌓임.
- 조용한 구간(49~56): 「판단은 사람이, 정리는 AI가」.
- 닫기(57~64).

## 4. build [그대로 + 수정]

1. [수정] HTML 하나, **1920×1080**. 모든 스타일은 async seek(t) 안에서 시간으로 계산 — CSS 전환·타이머·프레임 사이 상태 없음.
2. [그대로] 스프링은 닫힌 형식 계단 응답. 여러 목표를 가진 값은 변화마다 스프링 하나씩 더한 합.
3. [그대로] 리퀴드 글라스: 유리마다 뒤 장면의 복제본을 SVG feImage 변위 맵(둥근 사각 거리장)으로 걸러, 배율이 조금씩 다른 feDisplacementMap 셋(색 번짐 가장자리) + 테두리 빛.
4. [그대로] 조리개: 육각 구멍 둘레 6날. 각 날은 꼭짓점 둘, 두 변의 연장, 둘 사이의 **짧은** 호.
5. [수정] 글자 짜부라뜨리기: 모든 글자가 **「:」의 점**을 향해 같은 비율로 움직이고 그린 폭도 따라감(wdth 축을 좁히고 나머지는 배율) — 글자끼리 붙은 채로.
6. [수정] 영상 소스: 앱 화면 녹화(Playwright 녹화) — 전부 인트라 프레임으로 다시 인코딩(ffmpeg -g 1), blob URL 로 불러 프레임마다 'seeked' 를 기다린 뒤 그림.
7. [수정] 소리: **음악을 직접 합성** — 120BPM, 킥·스네어·하이햇·베이스·코드 패드, 17박 드롭, 49~56박 조용한 구간, 57박 복귀. 클릭·타자 효과음도 합성해 측정한 정점에 맞춰 놓음. 전체 -14 LUFS.
8. [수정] Playwright 로 렌더: 프레임마다 4개 하위 프레임을 ffmpeg tmix 로 섞어 60fps. 박자마다 한 프레임 확인, 한 프레임짜리 튐(이웃의 3배 넘는 프레임 차) 검사.
9. [추가] 용량: 2-pass x264 로 목표 비트레이트 = (19,900,000바이트 × 8 − 음성) ÷ 길이. 결과 파일이 **19,900,000바이트 이하**인지 확인, 넘으면 비트레이트를 낮춰 다시.

## 5. gotchas [그대로 + 추가]

- [그대로] backdrop-filter: url() 은 Chromium 에서 변위 맵을 잘못 읽는다 → 장면 복제. 덮기는 모서리 너머까지 키우고 약 0.3초. visibility: visible 자식은 숨긴 부모를 뚫고 보인다 → inherit. 모양이 바뀌는 도형 안에서 바뀌는 글은 자체 마스크. python http.server 는 영상 범위 탐색 불가 → blob URL.
- [추가] 앱을 여는 Chromium 은 프록시 CA 를 SPKI 로 신뢰시켜야 열림(--ignore-certificate-errors-spki-list=<프록시 CA 공개키 해시>).
- [추가] 앱을 열면 설치 경로 설문 창이 뜬다 → 「나중에」만 누르고 응답하지 않는다. 방문 수가 조금 오를 수 있다.

## 의논할 것

1. 3편 구성과 제목(위 3절) — 넣고 싶은 기능·뺄 기능
2. 휴대폰 안 조작: **손가락 터치 원**(추천) / 원본처럼 커서
3. 길이: 편마다 **32초(64박)**(추천) / 40초(80박) — 19.9MB 안에서 둘 다 가능(어림: 1080p 60fps 그래픽 영상은 32초에 약 5Mbps)
4. 머리말 문구(장면마다 한 줄) — 위 초안 문구로 갈지
5. 「20MB」가 **파일 하나당**인지(지금 초안은 편마다 19.9MB)

## 결정 (사용자 2026-10-19)
- 3편 구성 그대로. 가로 1920×1080.
- 휴대폰 안 조작도 **커서**로(원본 방식).
- 길이: 정해진 박자 수 없이 **편마다 19.9MB(19,900,000바이트) 안에서** 담을 내용을 다 담는다. 한 편에 다 들어가면 한 편도 가능 — 영상이 길어도 된다.
  → 방법: 1편 일부를 먼저 렌더해 **초당 용량을 실측**한 뒤, 화질을 지키는 선에서 편 수·길이를 정한다(추측으로 정하지 않음).
- 음악: Claude가 직접 합성.
- 챗봇 장면: 질문·답변 원문 `챗봇_대화_원문.md`·`챗봇_답변_전문.txt`. 질문은 다다닥 타이핑 → 진행 문구 4단계 → 답이 쭈르륵 → 스크롤로 끝까지, **내용은 빠르게 지나간다.**
