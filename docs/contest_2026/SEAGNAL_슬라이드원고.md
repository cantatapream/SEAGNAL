    5. AI 활용: 어려운 해양 법령을 AI 법률 챗봇이 쉬운 말로

    - 개정 감지: 법률·시행령·시행규칙은 매일 새벽 1시 국가법령정보센터에서 확인. 행정규칙을 포함한 원문 전체는 매주 일요일 현행본과 대조. 매주 수요일에는 빠진 조문·별표 점검
    - 내용 갱신: 개정이 감지되면 관리자에게 알리고, 개정 전·후 조문을 나란히 비교해 승인하면 반영
    - 시행일 맞춤 표출: 개정본을 미리 받아 두었다가 시행일이 되는 날부터 새 내용으로 답함. 시행 전에는 현재 유효한 내용으로
  - 쓸수록 정확해지는 구조
    - 답변마다 👍/👎 평가
    - 👎 답변은 AI가 먼저 다시 검토해 문제 원인(근거 부족, 엉뚱한 조문 등)을 분류
    - 지식베이스에 없어 원문을 직접 찾아 답한 질문, 사용자가 확인해 준 일상 용어의 뜻은 새 지식 후보로 자동 적재

    - 실제로 인용한 근거만 표시
    - 같은 질문에 매번 같은 방식으로 답하도록 설정
  - 사용 AI와 향후 계획

## 슬라이드 29. 향후 계획과 확산 전략

- **한 줄 메시지**: 해양경찰만 가진 유통망으로, 국민 해양안전 앱으로
- **화면 구성**
  - 왼쪽: 기능 계획 3가지
  - 오른쪽: 확산 경로 흐름도 (관 채널 + 온라인 채널 → 초기 집중 홍보 → 저변 확대 → 입소문·자생 성장)
- **슬라이드에 표시할 내용**
  - 기능 계획
    - AI 법률 챗봇 일반 공개
    - AI 실험실 VM에 로컬 LLM 탑재: 외부 API(ChatGPT·Gemini) 대신 직접 운영하는 AI로 비용 절감, 더 크고 안정적인 환경에서 무료 고품질 서비스
    - 사용자 의견 기반 지속 개선, 공공데이터 추가 연계
  - 확산 전략: 해양경찰만 가진 유통망
    - 어업인·해양레저 인구는 면허·신고·순찰 때문에 해양경찰과 관공서를 반드시 거침 → 민간 앱은 가질 수 없는, 대상자에게 직접 닿는 통로
    - 관(官) 채널 (비용 없이 직접 도달): 파출소·함정·연안순찰 현장 QR코드·리플릿 / 해경 주관 수상레저 조종면허 과정 / 어선·어업 등록·허가 창구(지자체), 수협·어촌계 홍보물 / 어업인 안전교육·간담회·해양안전 캠페인
    - 온라인 채널: 낚시·해양레저 커뮤니티·인스타그램 / 낚시·어선·해양레저 유튜버 협업 / 해양경찰 공식 채널
    - 확산 단계: 초기 집중 홍보 → 빠른 저변 확대 → 입소문·재방문으로 스스로 성장
- **이 기능이 담고 있는 정보**: 로컬 LLM = 외부 회사 API를 부르지 않고 우리 서버에서 직접 돌리는 AI 모델
- **발표 설명**: "지금까지는 내부 홍보만 했습니다. 해양경찰은 면허, 신고, 순찰로 어업인과 레저객을 직접 만납니다. 이 통로로 알리면 빠르게 퍼질 수 있습니다. 또 AI 실험실 서버를 지원받아 자체 AI를 올리면 비용 없이 더 좋은 서비스를 할 수 있습니다."
