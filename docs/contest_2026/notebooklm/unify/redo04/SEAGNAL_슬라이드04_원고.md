> 특히 2번 카드 셋째 줄 「이거 처벌 대상이에요?」와 맨 아래 둘째 줄 「문의 폭주 → 긴급한 사고 신고 전화를 놓칠 위험」을 **한 글자도 틀리지 않게** 씁니다. 따옴표·괄호를 더하지 않습니다.

## 다시 만들 슬라이드 (한 장)
- 제목: 같은 질문에 답하느라, **긴급한 전화를 놓칠** 수 있다
- 부제: 없음
- 구성:
  - 왼쪽: 세로 큰 반투명 카드 안 인용문, 가운데 정렬:
    ‘파출소에서 근무할 때, / 기상특보가 발표될 때마다 / 많은 어업인에게서 특보가 / 언제 발효·해제 되느냐는 / 같은 전화를 계속 받았습니다. / 특보 한 건에 문의가 폭주해, / 정작 긴급한 전화를 / 못 받을 수도 있는 / 상황이었습니다.’
  - 왼쪽 카드와 오른쪽 사이: 세로 청록 빛 선
  - 오른쪽 위~가운데: 큰 일러스트 — 「COAST GUARD」라고 적힌 책상 위 청록 유선전화 3대, 수화기가 들려 울리는 모습, 주황 경고 삼각형(!)과 주황 울림 표시·번개선, 바닥에 흩어진 서류, 뒤쪽 모니터에 코드·막대그래프
  - 오른쪽 아래 카드 3개 가로 한 줄:
    - (먹구름·번개·비 아이콘) **해양기상특보:** / 특보 언제 발표· / 발효·해제돼요?
    - (저울 아이콘) **법률 정보:** / 이 배로 이 시간에 / 조업해도 돼요? / 이거 처벌 대상이에요?
    - (바람 아이콘) **기상 정보:** / 내일 파도·바람· / 물때 어때요?
  - 맨 아래 글 두 줄:
    - - 같은 **질문**에 **반복 응대** → 현장 경찰력이 불필요하게 소모
    - - 문의 폭주 → **긴급한 사고 신고** 전화를 놓칠 위험
- 빈 틀: 없음
- 출처 줄: 없음
- ★이 장에서 바꿀 것 (공통 규칙에 더해):
  - 오른쪽 「COAST GUARD 책상과 울리는 전화」 그림은 이 장의 내용 그림이라 남긴다(그 안 주황 경고 표시도 그대로)
