# SEA:GNAL — 세 장 다시 만들기 (슬라이드 4·28·31)

> 이 세 장만 A → B → C 순서로 만듭니다. 장마다 참고 그림이 지금 그 장입니다 — **배치·그림·색은 참고 그림과 같게** 하고, 글은 아래 원고를 씁니다.
> 제목 모양은 style_ref_slide03.jpg(가운데·흰색 굵게·**굵게** 표시만 청록)와 같게, ★ 등 기호는 붙이지 않습니다.
> 「 / 」는 줄바꿈입니다. 숫자·글은 한 글자도 바꾸지 않습니다.

## 다시 만들 슬라이드 A (참고 그림 ref_A_slide04.jpg)
- 제목: 같은 질문에 답하느라, **긴급한 전화를 놓칠** 수 있다
- 부제: 없음
- 구성:
  - 왼쪽: 세로 큰 반투명 카드 안 인용문, 가운데 정렬:
    ‘파출소에서 근무할 때, / 기상특보가 발표될 때마다 / 많은 어업인에게서 특보가 / 언제 발효·해제 되느냐는 / 같은 전화를 계속 받았습니다. / 특보 한 건에 문의가 폭주해, / 정작 긴급한 전화를 / 못 받을 수도 있는 / 상황이었습니다.’
  - 왼쪽 카드와 오른쪽 사이: 세로 청록 빛 선
  - 오른쪽 위~가운데: 큰 일러스트 — 「COAST GUARD」라고 적힌 책상 위 청록 유선전화 3대, 수화기가 들려 울리는 모습, 주황 경고 삼각형(!)과 주황 울림 표시·번개선, 바닥에 흩어진 서류, 뒤쪽 모니터에 코드·막대그래프
  - 오른쪽 아래 카드 3개 가로 한 줄:
    - (먹구름·번개·비 아이콘) **해양기상특보:** / 특보 언제 발표· / 발효·해제돼요?
    - (저울 아이콘) **법률 정보:** / 이 배로 이 시간에 / 조업해도 돼요? / 이거 처벌 대상이에요?
    - (바람 아이콘) **기상 정보:** / 내일 파도·바람· / 물때 어때요?
  - 맨 아래 글 두 줄:
    - - 같은 **질문**에 **반복 응대** → 현장 경찰력이 불필요하게 소모
    - - 문의 폭주 → **긴급한 사고 신고** 전화를 놓칠 위험
- 빈 틀: 없음
- 출처 줄: 없음
- ★이 장에서 바꿀 것 (공통 규칙에 더해):
  - 오른쪽 「COAST GUARD 책상과 울리는 전화」 그림은 이 장의 내용 그림이라 남긴다(그 안 주황 경고 표시도 그대로)

  - ★특히 「법률 정보:」 카드의 「이 배로 이 시간에 / 조업해도 돼요? / 이거 처벌 대상이에요?」와 맨 아래 「문의 폭주 → 긴급한 사고 신고 전화를 놓칠 위험」을 한 글자도 틀리지 않게(「처벌」「시간」 정확히, 따옴표·괄호 없이)

## 다시 만들 슬라이드 B (참고 그림 ref_B_slide28.jpg)
- 제목: 썰물 때 드러난 바위와 갯벌, 언제 **물에 잠기는지 미리** 알려 준다
- 부제: 왼쪽 「암초 **6,829개** / 갯바위 면 **9,959개**」, 오른쪽 「서해·남해 **315개 지점** 조석」. 가운데 세로 구분선으로 좌우 나뉨.
- 구성:
  - 가운데: 빈 휴대폰 틀 2개 나란히(왼쪽 반·오른쪽 반 각 1개)
  - 왼쪽 위 상자: 바위 종류: / 노출암 4,287 / 간출암 1,778 / 세암 658 / 암암 106
  - 왼쪽 아래 상자: 물에 잠기는 바위 경고: / 3시간 안에 잠길 간출암 / 빨간 테두리 깜빡임 + / 카운트다운 1분 주기 갱신 — 「1분」 빨간색
  - 오른쪽 위 상자(오른쪽 휴대폰에 연결선): 시간대별 갯벌 노출 면적 표시 / 및 시간 슬라이더 (3일치 예측) — 아래에 물결 곡선 + 슬라이더(D1 · D2 · D3, 손잡이 D1)
  - 오른쪽 아래 상자: 물빠짐 예측 팝업: / 서천·군산 금강 하구 갯벌 / (물 잠김 남은시간 01시간 12분) — 「01시간 12분」 청록, 오른쪽에 지도·핀 작은 아이콘
  - 아래 가로 전체: 어두운 띠 상자 「서해·남해는 조석간만의 차가 커 갯벌 고립 사고가 잦습니다. / 앱은 3시간 내 잠길 간출암을 깜빡이며 남은 시간을 알리고, 갯벌이 언제 다시 잠길지 시간대별로 보여줍니다.」
- 빈 틀: 휴대폰 틀 2개(가운데 좌·우)
- 출처 줄: 국립해양조사원 「개방海」 전자해도 암초 자료·연안 위험정보(갯바위), 국립해양조사원 TideBED 조석
- ★이 장에서 바꿀 것 (공통 규칙에 더해):
  - 왼쪽 아래 「물에 잠기는 바위 경고」 상자의 빨간색을 주황(#F59E0B)으로 — 경고 상자 색 통일
  - 빈 휴대폰 틀 2개는 같은 자리·크기로 비워 둔다
  - 출처 오타: 「전자에도」 → 「전자해도」, 「국랍해양조사원」 → 「국립해양조사원」
  - ★출처 줄은 「국립해양조사원 「개방海」 전자해도 암초 자료·연안 위험정보(갯바위), 국립해양조사원 TideBED 조석」을 한 글자도 틀리지 않게

## 다시 만들 슬라이드 C (참고 그림 ref_C_slide31.jpg)
- 제목: (두 줄) 1줄: 낚시부터 바다갈라짐까지, 오늘 **바다 나가기 좋은지** 한눈에 — 2줄: 생활 지수 **7종** (5단계 등급) · 바다낚시 지수 앱 이용 **5위** (4,273회)
- 부제: 없음(제목이 두 줄)
- 구성:
  - 빈 휴대폰 틀 4개 가로 한 줄(각 틀 양옆에 회로선 장식), 아래 라벨: "[낚시]" "[서핑]" "[바다갈라짐]" "[너울]"
  - 표(가운데, 원근감 있게 기울어진 판 위) — 왼쪽 칸 청록 글자, "바다낚시"·"너울" 칸은 밝은 테두리 상자로 강조:
    | 지수 | 내용 |
    |---|---|
    | 바다낚시 | 오전·오후 파고, 수온, 풍속, 물때 및 어종별 낚시지수 |
    | 서핑 | 초·중·상급 지수, 유의파고, 파주기, 해당 해역 특보 동시 확인 |
    | 해수욕 | 오전·오후 지수, 파고, 수온 (폐장 기간 표시) |
    | 스킨스쿠버 | 오전·오후 지수, 유속, 물때 |
    | 갯벌체험 | 체험 가능 시간, 5단계 지수, 발표 시각 |
    | 바다갈라짐 | 지역별 7일간 체험시간(분 단위), 기온, 날씨 |
    | 너울 | 전국 해안선 233곳 소해구별 4단계 색 띠(관심·주의·경계·위험) |
    (표에 머리글 줄은 없음 — 위 "지수|내용"은 표 형식용)
  - 하단 가로 상자: "해양 활동 지수와 그 자리의 바다 상태(파고, 수온, 바람)를 함께 보여줍니다. / **서핑** 화면에서는 **지수가 좋아도 해상특보가** 있는지 즉시 확인할 수 있습니다."
- 빈 틀: 빈 휴대폰 틀 4개(위쪽 한 줄, 왼→오른쪽 [낚시]·[서핑]·[바다갈라짐]·[너울])
- 출처 줄: "국립해양조사원 생활지수 공공API 6종, 기상청 MMIS 소해구"
- ★이 장에서 바꿀 것 (공통 규칙에 더해):
  - 표 뒤의 입체 지구본을 지운다
  - 빈 휴대폰 틀 4개는 **세로로 선 휴대폰**(가로:세로 약 1:2)으로 — 눕히거나 비스듬히 그리지 않는다
  - 빈 휴대폰 틀 4개는 같은 자리·크기로 비워 둔다
  - ★제목 두 줄과 표 7줄(바다낚시·서핑·해수욕·스킨스쿠버·갯벌체험·바다갈라짐·너울)이 모두 들어가야 한다. 제목이 표를 밀어내지 않게 휴대폰 틀을 조금 줄여도 된다
  - ★참고 그림의 누운 휴대폰 틀은 세로로 선 휴대폰 4개로 바꾼다
