# SEA:GNAL 슬라이드 — NotebookLM 지시문

## 사용 방법

1. NotebookLM 새 노트북을 만들고 소스로 **`SEAGNAL_슬라이드원고.md` 하나만** 올립니다.
   - `SEAGNAL_소개.md`·`SEAGNAL_근거자료.md`는 올리지 않습니다. 같은 내용이 다른 표현으로 섞여 들어가 숫자나 문장이 어긋날 수 있습니다.
2. 스튜디오에서 **슬라이드 자료(Slide Deck)** 를 고르고, 맞춤 설정 칸에 아래 「지시문」을 그대로 붙여 넣습니다.
   - 맞춤 설정 칸에 글자 수 제한이 있는지는 확인하지 못했습니다. 잘리면 「무드 & 디자인 특성」 단락부터 줄여 주세요.
   - 처음 사용자가 준 디자인 요청(역할·3D 렌더링·시네마틱)의 틀을 살리고, 정보량은 「최소화」 대신 「충분히, 읽기 쉽게」로, 색은 바다 청색으로 바꾼 합친 버전입니다 (사용자 확정 2026. 10. 6.).
3. 만들어진 슬라이드에서 휴대폰 틀·빈 자리에 `images/` 폴더의 실제 캡처와 로고를 덧붙입니다. 어느 자리에 어느 파일이 들어가는지는 원고의 「📷 이미지」 칸과 맨 끝 「부록 — 이미지 파일 목록」에 있습니다.
4. 숫자가 원고와 다르게 나온 슬라이드가 있으면 그 장만 다시 만들도록 고쳐 달라고 요청합니다.

## 지시문 (붙여 넣을 글)

```
[NotebookLM 슬라이드 디자인 요청]

■ 역할: 전문 프레젠테이션 디자이너
■ 스타일: 3D 렌더링 포인트 + 정보 전달 중심
■ 목적: 발표자 없이 심사위원이 슬라이드만 읽고 앱을 평가한다. 슬라이드 글만으로 내용이 이해되어야 한다.

[컬러 시스템]
• 배경: 짙은 남색 #0B1E3F
• 텍스트: #FFFFFF (보조 글은 밝은 회색)
• 강조: 청록 #14B8C4 / 보조 하늘색 #7DD3FC
• 특보·경고 강조만: 주황 #F59E0B
• 폰트: 제목·숫자의 영문은 Sora, 한글은 굵고 깔끔한 고딕체

[무드 & 디자인 특성]
• 바다·파도·빛을 담은 3D 오브젝트, 은은한 조명, 시네마틱한 깊이감
• 3D 연출은 표지와 탭 시작 장, 각 장의 포인트 장식에만 쓰고, 글·숫자·표가 많은 장은 가독성을 우선한다

[레이아웃 가이드]
• 원고의 슬라이드 1~30을 순서와 장 수 그대로 만든다. 합치거나 빼거나 새로 만들지 않는다.
• 제목은 원고 「## 슬라이드 N.」 뒤 문장을 그대로 쓴다. 「★」 장은 더 눈에 띄게.
• 각 장에 한 줄 메시지·핵심 숫자·해설·출처를 반드시 올린다. 표·목록은 카드·표·아이콘으로 정리하되 정보를 빼지 않는다. 출처는 아래쪽 작은 글씨.
• 숫자·날짜·단위는 원고 그대로. 반올림·추정·새 숫자 금지. 핵심 숫자는 가장 크게.
• 「📊 차트로 그릴 데이터」는 그 숫자로 차트를 그린다.
• 「📷 이미지」 자리는 화면이 비어 있는 휴대폰 틀, 로고·사진 자리는 빈 사각형으로 둔다. 앱 화면·로고를 상상해서 그리지 않는다.
• 원고에 없는 기능·수치·기관·수상 내역을 만들지 않는다. 모든 글은 한국어.

위 가이드를 바탕으로 고품질 슬라이드를 생성해주세요.
```

## 색을 이렇게 고른 이유

- 3D 연출을 표지·탭 시작 장과 포인트 장식으로 한정한 것은, 정보가 많은 장에서 글과 숫자가 3D 장식에 묻히지 않게 하려는 것입니다.
- Sora는 영문 글꼴이라 한글이 없을 수 있어(확인하지 못함) 한글 글꼴을 따로 적었습니다.
- 앱 아이콘(`images/logo_SEAGNAL_앱아이콘.png`)이 **짙은 남색 바탕에 청록 네온 선**이라, 슬라이드 색을 아이콘과 맞췄습니다.
- 앱 화면도 어두운 남색 바탕이라, 캡처를 덧붙였을 때 슬라이드와 따로 놀지 않습니다.
- 주황은 경고를 떠올리는 색이라 **특보·경고 강조에만** 씁니다.
