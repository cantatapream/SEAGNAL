# SEA:GNAL 슬라이드 — NotebookLM 지시문

## 사용 방법

1. NotebookLM 새 노트북을 만들고 소스로 **`SEAGNAL_슬라이드원고.md` 하나만** 올립니다.
   - `SEAGNAL_소개.md`·`SEAGNAL_근거자료.md`는 올리지 않습니다. 같은 내용이 다른 표현으로 섞여 들어가 숫자나 문장이 어긋날 수 있습니다.
2. 스튜디오에서 **슬라이드 자료(Slide Deck)** 를 고르고, 맞춤 설정 칸에 아래 「지시문」을 그대로 붙여 넣습니다.
   - 맞춤 설정 칸에 글자 수 제한이 있는지는 확인하지 못했습니다. 잘리면 「디자인」 단락부터 줄여 주세요.
3. 만들어진 슬라이드에서 휴대폰 틀·빈 자리에 `images/` 폴더의 실제 캡처와 로고를 덧붙입니다. 어느 자리에 어느 파일이 들어가는지는 원고의 「📷 이미지」 칸과 맨 끝 「부록 — 이미지 파일 목록」에 있습니다.
4. 숫자가 원고와 다르게 나온 슬라이드가 있으면 그 장만 다시 만들도록 고쳐 달라고 요청합니다.

## 지시문 (붙여 넣을 글)

```
이 자료는 해양 종합정보 앱 SEA:GNAL의 경진대회 심사용 슬라이드 원고다. 발표자 없이 심사위원이 슬라이드만 읽고 평가한다. 슬라이드 글만으로 내용이 이해되어야 한다.

[구성] 원고의 슬라이드 1~30을 순서와 장 수 그대로 만든다. 슬라이드를 합치거나 빼거나 새로 만들지 않는다.
[제목] 각 장 제목은 원고 「## 슬라이드 N.」 뒤의 문장을 그대로 쓴다. 「★」 표시 장은 핵심 강점이므로 더 눈에 띄게 꾸민다.
[내용] 각 장에 한 줄 메시지·핵심 숫자·해설·출처를 반드시 올린다. 「슬라이드에 표시할 내용」의 표와 목록은 카드·표·아이콘 목록으로 읽기 쉽게 정리하되, 정보를 빼지 말고 숫자와 고유명사는 바꾸지 않는다. 출처는 슬라이드 아래쪽에 작은 글씨로 둔다.
[숫자] 원고의 숫자·날짜·단위를 그대로 쓴다. 반올림·추정·새 숫자를 만들지 않는다. 핵심 숫자는 그 장에서 가장 크게 보이게 한다.
[차트] 「📊 차트로 그릴 데이터」 칸이 있는 장은 그 숫자로 차트를 직접 그린다.
[이미지] 「📷 이미지」에 적힌 앱 화면 자리는 화면 부분이 비어 있는 휴대폰 틀로, 로고·사진 자리는 빈 사각형으로 둔다. 앱 화면·로고·사진을 상상해서 그리지 않는다. 나중에 실제 캡처를 덧붙인다.
[금지] 원고에 없는 기능·수치·기관·수상 내역을 만들지 않는다. 발표 말투(“말씀드리겠습니다” 등)를 쓰지 않는다.
[디자인] 바다를 떠올리는 청색 계열. 배경 짙은 남색(#0B1E3F), 주 강조 청록(#14B8C4), 보조 하늘색(#7DD3FC), 특보·경고 강조만 주황(#F59E0B). 글자는 흰색·밝은 회색으로 대비를 높게. 깔끔한 평면 디자인, 큰 글씨, 넉넉한 여백. 표지만 바다 배경 그림을 쓰고 나머지 장은 장식을 줄인다.
[언어] 모든 글은 한국어로 쓴다.
```

## 색을 이렇게 고른 이유

- 앱 아이콘(`images/logo_SEAGNAL_앱아이콘.png`)이 **짙은 남색 바탕에 청록 네온 선**이라, 슬라이드 색을 아이콘과 맞췄습니다.
- 앱 화면도 어두운 남색 바탕이라, 캡처를 덧붙였을 때 슬라이드와 따로 놀지 않습니다.
- 주황은 경고를 떠올리는 색이라 **특보·경고 강조에만** 씁니다.
