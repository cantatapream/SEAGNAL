## 2. 수상작 24편의 공통점 — 왜 뽑혔나

### 2-1. 모든 분야 공통 (거의 전편에서 확인)

1. **작성 가이드 ①~⑤ 제목을 그대로 쓰고 순서대로 답함** — 24편 모두. 심사표와 같은 순서라 읽기 쉽다.
2. **한 사람의 구체적 장면에서 출발** — "70대 어머니가 수술 후 혼자 계신 시간"(온담이), "인성부장을 처음 맡은 아내가 밤 11시부터 형광펜으로"(학폭 비서), "새벽 3시 아기 울음"(뿌앵), "동네 주민이 '이 민원 어디에 넣어요?'"(고양이 민원네비).
3. **AI를 '역할 분담한 팀'으로 설명** — 도구마다 맡은 일을 나눠 적음. 예: "Claude Code는 개발 파트너, GPT-4o-mini는 사용자 응답"(전남 관광 최우수), "YAMNet은 무슨 소리인지, HyperCLOVA X는 무엇을 해야 하는지"(청각장애 부모 앱). **왜 그 도구를 골랐는지**도 적음(국산 AI 선택 이유, 회사 자료는 로컬 LLM만).
4. **AI를 '통제한 방법'을 강조** — 상위작일수록 이 비중이 큼.
   - 기획서 먼저 쓰기: plan.md(LinkScape), 설계서 먼저(사내 관리툴)
   - 규칙 파일: CLAUDE.md(전남 관광), DECISIONS.md(통제된 AI 비서)
   - 인수인계 문서: HANDOVER.md(LinkScape)
   - 자동 검사: 1,211건(사내 관리툴), 35개(청각장애 부모 앱), 210개 중 196개 통과(고양이 민원네비)
   - 다른 AI로 교차 검증(고양이 민원네비, 사내 관리툴)
   - 지어내지 않게 막기: "정보 없음" 처리(OLA)
5. **결과를 숫자로, 전후 비교로** — "1시간→0분"(트럭 배차), "초진 문서 10분→2분"(병원), "하루 8시간→10분"(통제된 AI 비서), "클릭률 0.59%→6.65%·매출 270%"(마케팅). 재지 않은 것은 **"재지 않았다"고 밝힘**(사내 관리툴).
6. **"지금도 쓰고 있다"는 증거** — "어머니가 매일 쓰심", "전 직원 16명 매일", "하루 30~40명 환자", "v4.4.1까지 버전이 올라감".
7. **기존 서비스와 비교해 빈틈을 짚음** — 스텔라리움(전지적 지구 시점), 안전디딤돌·국민신문고(OLA), FigJam·노션(LinkScape).
8. **실패와 한계를 솔직하게 적음** — "AI가 18번 틀렸다"(사내 관리툴), "오탐 9건 제거"(고양이 민원네비), "백색소음 환경에서 울음을 못 잡던 결함 수정"(청각장애 부모 앱). 신뢰를 높이는 장치로 쓰임.
9. **윤리 단락을 따로 둠** — 기기 안 저장, 개인정보 마스킹, 출처·라이선스 표기, "진단이 아님" 고지, "결정은 사람이".
10. **⑤ 재현은 번호 단계 + 비용** — "세 단계"(강의안), "ⓐ~ⓔ 순서"(고양이 민원네비), "지자체명만 바꾸면 이식", "월 1만 원 이하", "무료 크레딧".
11. **바로 써 볼 수 있는 주소** — jntour.site(전남 관광), 웹 링크(전지적 지구 시점), 토스 '뿌앵'.
12. **첨부 5개를 꽉 채움** — 시연 영상(mp4)·화면 캡처·요약 PDF 조합이 가장 많음. 교육 최우수는 짧은 영상 4편.

### 2-3. 지역사회 분야 수준 판단
- 상위작은 **실제 운영 서비스**(전남 관광), **테스트 수치**(고양이 민원 93%), **공공데이터 연계**(OLA)를 갖췄다.
- 반면 「전통시장」은 "기대할 수 있습니다" 수준의 구상 위주인데도 수상했다. **분야 내 경쟁 수준이 아주 높지는 않다**(추정).
- **같은 분야의 직접 경쟁작이 있다** — 「대한수호신」(2026-09-29 등록, 시즌3 심사 대상으로 보임).
  - 공통점: 항해사 출신 1인이 Claude Code로 만든 **바다·산 안전 앱**, 특보를 위치에 맞게 안내.
  - 그쪽이 강조한 것: "AI가 안전 문구를 지어내지 못하게 구조로 막음"(출처 없는 문장이 있으면 서버가 안 켜짐), 서버 테스트 292개, 실제 휴대폰으로 끊어 보고 결함을 찾은 과정.
  - 그쪽의 약점: 서버가 개인 컴퓨터에서 돌아 **아직 상시 운영 전**이고, 실제 사용자 수치가 없다.
  - **SEA:GNAL은 실사용 규모로 확실히 앞서지만, "AI를 어떻게 통제했나"를 쓰지 않으면 그 항목에서 밀릴 수 있다.**

## 3. SEA:GNAL 진단 — 강점과 약점

### 3-1. 강점 (수상작 대비)

| 항목 | SEA:GNAL | 수상작 중 최대 |
|---|---|---|
| 실사용 규모 | 설치 1,800여 명, 특보 알림 726,282건 도달, 7개월 넘게 운영 | 전 직원 16명, 환자 하루 30~40명 |
| 공공데이터 연계 | 기상청(MMIS·API허브·날씨누리·방재기상플랫폼)·국립해양조사원·법제처·해외 3개 기관 | TourAPI 1종(최우수) |
| 문제 출발점 | 파출소 민원전화 폭주 경험(현장 근무자 본인) | 같은 유형 |
| 사용자 피드백 반영 | 건의 18건 중 13건 반영, 알림 유지율 월 98.8% | 버전 이력(사내 관리툴) |
| 기존 서비스 대비 차별점 | 이미 정리됨(원고 28장) | 같은 유형 |
| 행정 효과 | 민원 3대 유형을 앱이 먼저 해결 | 「QR 30초」·「고양이 민원네비」와 같은 방향 |

**저장소에 이미 있는 "AI를 통제한 증거"** — 상위작이 가장 공들여 쓴 부분인데, 우리는 실제로 더 많이 해 왔다. 2026-10-06에 저장소에서 직접 센 값:
- 저장소 기록 시작일(2026-02-01)부터 **커밋 8,572회**. 그중 AI(Claude) 작성 7,213회, 작업한 날 187일.
  - 개발 착수(2025년 8월)~2026년 1월 기록은 이 저장소에 없다.
- 규칙 파일(CLAUDE.md), 인수인계 문서(HANDOFF.md), 세션 기억(MEMORY.md)을 운영하고 있다.
- **시행착오 기록(_LESSONS.md) 397건** — 수상작 「AI가 18번 틀렸다」의 대규모 판.
- 자동 검사 게이트(verify_all.sh)에 등록된 **검사 번호 59종**.
  - ⚠**정정 (2026-10-06 다시 셈 — 위 숫자들은 세는 기준이 섞여 있었다)**: 슬라이드에는 아래 값을 쓴다.
    커밋은 `origin/main`(0cdc14bfb, 2026-10-06 13:34 KST)에서 2026-02-01 이후 **병합 제외 7,069회**, 그중 작성자 Claude **6,921회**, 작업한 날 **188일**
    (병합 포함이면 8,523회. 위 8,572·7,213·187은 세는 방법을 남기지 않았다 — 같은 날 작업 브랜치에서 병합 포함·작성자 이름/메일에 claude 포함으로 세면 8,577·7,229로 비슷하게 나온다).
    자동 검사는 `verify_all.sh` 의 주석 아닌 줄에 나오는 검사 번호 `V5-*` **57종**(V5-12는 주석에만 있음) + 테스트 묶음(SUITES) **56개**. 위 59는 세는 기준을 남기지 않아 재현하지 못했다.
- "추측 금지 — 코드·데이터로 확인한 것만" 규칙. 결함 위험이 큰 변경은 **다른 AI에게 독립 검토**를 시킴.
