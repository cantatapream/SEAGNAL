# Play 스토어 휴대전화 스크린샷 8장 (2026-11-19)

Google Play 스토어 「바다:그 날」 등록정보에 올릴 휴대전화 스크린샷(9:16, 1080×1920) 8장과,
나중에 고쳐 다시 만들 수 있도록 그 원본·편집 소스를 함께 보관한다.

## 폴더

| 폴더·파일 | 무엇 |
|---|---|
| `final/` | **업로드용 완성본 8장.** 파일 이름 앞 번호 = 스토어에 올리는 순서 |
| `sources/` | 완성본을 만드는 편집 소스 — 장마다 HTML 한 개 + 공통 `base.css` + 잘라 둔 화면 조각(`s1_*.png` ~ `s9_*.png`) |
| `originals/` | 잘라내기 전 원본 캡처(사용자 휴대폰·PC 캡처, 08번 배경 지도만 운영 앱 캡처). 다른 범위로 다시 자를 때 쓴다 |
| `render.js` | `sources/` 의 HTML 을 찍어 `final/` 에 PNG 로 저장하는 스크립트 |

## 8장 구성 (순서대로)

| 번호 | 제목 | 탭 | 쓰인 원본 |
|---|---|---|---|
| 01 | 바다 특보, 실시간으로 알려드려요 | 특보정보 | 푸시 알림 + 해역별 특보현황 2장(울진 버튼 줄에서 이어 붙임) |
| 02 | 파도 예보와 부이 실측값을 한 번에 | 해양종합정보 | 파고·파향 지도 + 마라도 부이 창 |
| 03 | 누른 곳의 바다, 한 화면에 다 보여요 | 해양종합정보 | 제주 지도(핀) + 위치 정보 창 2장(좌우 배치) |
| 04 | 태풍 진로, 4개 기관 예보를 비교 | 해양종합정보 | 조작 막대(기관 선택 목록) + 진로 지도 + 행동요령 2장(해상·육상) |
| 05 | 해양 법령, 물어보면 근거까지 | 특보정보 | 챗봇 질문·답변 + 조문 창 |
| 06 | AI가 오늘 우리 연안바다를 브리핑 | 특보정보 | AI 연안 안전 브리핑 2장(관할 이름 줄은 잘라냄) |
| 07 | 사고 많은 곳, 고립 위험까지 미리 | 해양안전생활 | 사고 격자 지도 + 제주권 통계 / 간출암 잠김 지도 + 그래프 창 |
| 08 | 낚시·서핑·갯벌, 오늘 어때요? | 해양안전생활 | 해양생활 지도 위에 바다낚시·서핑·갯벌체험(2장 이어 붙임)·바다갈라짐 창 |

공통 규칙: 화면 테두리 남색(#2a3557) · 아래 여백 같음 · 강조 표시(동그라미·네모·화살표)는
빨간색(#ef4444) 굵은 점선 + 검은 테두리 · 맨 위 번호표에 해당 탭 이름.

## 고치는 법

1. 글자(제목·설명·번호표)는 `sources/<번호>_<이름>.html` 안의 `<div class="tag">`, `<h1>`, `<div class="sub">` 를 고친다.
   제목에서 노란 강조는 `<em>…</em>` 로 감싼 부분이다.
2. 화면 위치·크기는 같은 HTML 의 `style="left:…;top:…;width:…;height:…"` 값을 고친다(단위 px, 슬라이드는 1080×1920).
3. 다른 화면으로 바꾸려면 `originals/` 에서 새로 잘라 `sources/` 의 같은 이름 조각 파일을 덮어쓴다.
4. 다시 만든다:

   ```bash
   node docs/store_listing/2026-11-19_playstore_screenshots/render.js
   ```

   한 장만: 뒤에 번호를 붙인다(예: `render.js 04`).
   Playwright(Chromium)와 인터넷이 필요하다 — 제목 글꼴(Noto Sans KR)을 Google Fonts 에서 받는다.

이 폴더 그대로 `render.js` 를 돌리면 `final/` 8장이 보관본과 픽셀 단위로 똑같이 나오는 것을 확인했다(2026-11-19).
