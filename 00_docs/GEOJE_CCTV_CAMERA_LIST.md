- 돈덕-0010 → 둔덕-0010
- 돈덕-0011 → 둔덕-0011
- 돈덕-0012 → 둔덕-0012

## 주요 발견사항

1. cctv.xml 파일에서 모든 데이터가 제공됨 (JavaScript 코드: `./assets/xml/cctv.xml`)
2. 각 카메라마다 4가지 URL 제공:
   - `url`: HTTPS 스냅샷
   - `url1`: HTTP 스냅샷 (직접 IP: 118.47.118.178)
   - `url2`: HTTPS HLS 스트림
   - `url3`: HTTP HLS 스트림 (직접 IP)
3. 위경도 좌표(x=위도, y=경도), 방향각(deg), 거리(m=100 고정) 포함
4. cameraId 범위: 100152, 101693~101717, 102327~102366 (연속적이지 않음)
5. 질문에서 언급된 "해상감시1(주포)"는 XML에서 "해상감시1(후포)"가 실제 명칭
6. "사등-0031 주소"는 오량리 619-14번지 (질문의 "오량리"와 일치)
