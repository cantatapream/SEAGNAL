# SEA:GNAL(바다날씨) - 사내 홍보자료 및 상세 사용법

---

## Part 1. 홍보자료

---

### 앱 소개

> **"바다 : 그 날의 신호"**
> **SEA:GNAL — MARINE WEATHER & SAFETY**

전국 해상 실시간 기상특보 및 해구별 맞춤 기상전망, 조석/일출몰 정보를 제공하는 **전문 해역 기상 서비스 앱**입니다.

---

### 이런 분들께 추천합니다

- 해상 기상특보를 **실시간으로** 확인해야 하는 분
- 해구별 **파고·풍속·풍향** 등 상세 해양기상 정보가 필요한 분
- **조석(물때)·일출몰·월령** 정보를 한눈에 확인하고 싶은 분
- 관심 해역의 기상특보 **푸시 알림**을 받고 싶은 분
- 태풍 발생 시 **실시간 경로 추적**이 필요한 분
- 현장에서 **관측부이** 데이터를 바로 확인하고 싶은 분

---

### 핵심 기능 한눈에 보기

| 기능 | 설명 |
|------|------|
| **기상정보** | 전국 해역별 실시간 기상특보 현황 (경보/주의보/예비) |
| **해구기상** | 44개 해구별 상세 기상전망 + 관측부이 데이터 + Windy 연동 |
| **조석정보** | 지도 기반 조석(물때) 예측 + 일출몰/월출몰 + 음력 정보 |
| **태풍정보** | 태풍 발생 시 실시간 경로 추적 및 예보 |
| **공지사항** | 앱 관련 공지 및 안내 게시판 |
| **푸시 알림** | 관심 해역 기상특보 발표/발효/해제 시 즉시 알림 |

---

### 다운로드

- **Google Play 스토어**에서 **"SEA:GNAL"** 또는 **"바다날씨"** 검색
- 앱 아이콘: 파도와 심전도 파형이 결합된 네이비 블루 아이콘

---

### 앱의 차별점

1. **실시간 특보 모니터링**: 기상청 특보 발표 즉시 반영, 해역별 특보 현황을 한눈에 확인
2. **44개 해구 상세 전망**: 3시간 간격 풍향/풍속/파고 예측 차트 + Windy 시각화 연동
3. **관측부이 실시간 데이터**: 기상부이, 파고부이, 등표 등 실측 데이터 제공 (파고, 풍속, 수온, 기온, 기압 등)
4. **스마트 조석 정보**: 지도에서 위치 클릭만으로 고조/저조 시각, 일출몰, 월출몰, 음력 한번에 확인
5. **맞춤형 푸시 알림**: 관심 해역만 골라서 특보 알림 수신, 야간 알림 일시정지 지원
6. **안전 권고 알림**: 기상특보 발효 시 출항 제한 등 안전 관련 권고사항 자동 안내

## Part 2. 상세 사용법

---

### 1. 앱 설치 및 첫 실행

1. Google Play 스토어에서 **"SEA:GNAL"** 검색 후 설치
2. 앱 실행 시 스플래시 화면(파도+심전도 로고) 표시 후 메인 화면 진입
3. 첫 실행 시 **알림 권한 허용**을 권장합니다 (기상특보 푸시 알림 수신을 위해 필요)

---

### 2. 메인 화면 구성

앱 상단에 5개 탭이 있으며, 탭을 눌러 각 기능으로 이동합니다.

```
[ 기상정보 | 해구기상 | 조석정보 | 태풍정보 | 공지사항 ]
```

**헤더 영역 안내:**
- **좌측 상단**: "바다 : 그 날의 신호 / SEA:GNAL" 앱 타이틀
- **우측 상단**: 현재 시각 (실시간 업데이트), 날짜, 요일
- **Today / Total**: 오늘 방문자 수 / 누적 방문자 수
- **⚙ 아이콘**: 설정 (글꼴 크기, 알림 설정, 관심 해역)
- **최근 업데이트**: 마지막 데이터 갱신 시각 표시
- **헤더 영역을 터치**하면 데이터가 새로고침됩니다

---

### 3. 기상정보 탭 (첫 번째 탭)

전국 해상 기상특보의 **실시간 현황**을 확인하는 핵심 기능입니다.

#### 3-1. 해역별 특보현황

- 화면 상단에 **발효 건수**와 **발표 건수**가 배지로 표시됩니다
  - **발효 ○건**: 현재 효력이 살아있는 특보 수
  - **발표 ○건**: 발표되었으나 아직 발효 전인 특보 수
- **통보문 / 특보종합** 버튼을 눌러 원본 통보문 및 특보 종합 정보를 확인할 수 있습니다

#### 3-2. 해역 구분

4개 해역으로 구분되어 있습니다:
- 🌊 **동해 (East Sea)**
- 🌊 **서해 (West Sea)**
- 🌊 **남해 (South Sea)**
- 🗿 **제주해역 (Jeju Sea)**

각 해역을 펼치면 하위 해상(예: 동해남부해상, 동해중부해상 등)이 나타나고, 해상을 다시 펼치면 개별 해역(예: 울산앞바다, 경북남부앞바다 등)이 표시됩니다.

#### 3-3. 특보 상세 정보

각 해역 카드에는 다음 정보가 표시됩니다:
- **특보 유형 배지**: 풍랑 주의보, 풍랑 경보, 풍랑 예비 등
  - 🔴 **경보**: 가장 위험한 단계
  - 🟡 **주의보**: 주의가 필요한 단계
  - 🟢 **예비**: 특보 발표 예정 단계
- **발표시각**: 특보가 발표된 시각
- **발효시각**: 특보의 효력이 시작되는 시각
- **해제예정**: 특보 해제 예정 시각 (정보가 있는 경우)

#### 3-4. 기상예보 / 해구기상 / 윈디 바로가기

특보가 없는 평상시에도 각 해역 카드에 3개 바로가기 버튼이 제공됩니다:
- **기상예보**: 해당 해역의 오늘~내일 날씨, 파고, 풍속 예보 팝업
- **해구기상**: 해당 해역의 해구별 상세 기상전망 (3시간 간격 차트)
- **윈디**: Windy.com 연동 시각화 화면으로 이동

#### 3-5. 관측부이 데이터

각 해역에 설치된 관측부이를 클릭하면 **실측 데이터**를 확인할 수 있습니다:
- **파고**: 현재 파도 높이 (m)
- **풍속**: 현재 바람 속도 (m/s) 및 풍향
- **수온**: 해수면 온도 (°C)
- **기온**: 대기 온도 (°C)
- **돌풍**: 순간 최대풍속 (m/s)
- **기압**: 해면기압 (hPa)
- **습도**: 상대습도 (%)
- **관측시간**: 데이터가 측정된 시각

#### 3-6. 안전 권고 알림

기상특보가 발효되면 **안전 권고 팝업**이 자동으로 표시됩니다:
- 30톤 미만 어선 출항 및 조업 제한 안내
- 안전지대 이동 및 대피 권고
- 해경 파출소 문의 안내
- 어선안전조업법 관련 행정처분 안내

---

### 4. 해구기상 탭 (두 번째 탭)

전국 44개 해구의 **상세 기상전망**을 지도와 차트로 확인하는 기능입니다.

#### 4-1. 해구도 지도

- 한반도 주변 해역을 **44개 해구**로 구분한 지도가 표시됩니다
- 지도에서 해구 영역을 **클릭**하면 해당 해구의 상세 기상전망을 볼 수 있습니다
- 한번 더 클릭하면 상세 정보 팝업이 열립니다

#### 4-2. 관측부이 오버레이

- 지도 위에 관측부이 아이콘이 표시됩니다
- 부이 아이콘을 클릭하면 **실시간 관측 데이터** 팝업이 열립니다:
  - 파고, 풍속, 풍향, 기온, 수온, 기압
  - 관측 시간 표시
- 부이 종류: 기상부이, 파고부이, 등표, 해양과학기지 등

#### 4-3. 해구별 기상전망 차트

해구를 선택하면 상세 전망 모달이 열립니다:
- **3시간 간격** 예보 (00시, 03시, 06시, 09시, 12시, 15시, 18시, 21시)
- **풍향**: 화살표 아이콘으로 방향 표시
- **풍속**: 숫자 (m/s) + 위험 수준에 따라 색상 변경 (빨간색 = 강풍)
- **유의파고**: 막대 차트 + 수치 표시 (m)
- **파향**: 파도 진행 방향
- **파주기**: 파도 주기 (sec)
- **풍속-파고 복합 차트**: 풍속은 꺾은선, 파고는 막대로 시각적 비교
- 최대 3일치 예보 확인 가능

#### 4-4. Windy 연동

- 각 해구 전망 모달에서 **"Windy"** 버튼을 누르면 Windy.com의 해당 해역 시각화 화면으로 이동
- 바람, 파도, 기온 등을 직관적 애니메이션으로 확인 가능

#### 4-5. 내 위치 기능

- **"내 위치"** 버튼을 누르면 GPS 기반으로 현재 위치에 해당하는 해구를 자동 탐지
- 가장 가까운 해구의 기상전망을 바로 확인할 수 있습니다

#### 4-6. 대해구 모드

- 좌측 하단 **"대해구 모드"** 버튼으로 대해구/소해구 지도를 전환할 수 있습니다

---

### 5. 조석정보 탭 (세 번째 탭)

**조석(물때) 예측**, **일출몰/월출몰**, **음력** 정보를 지도 기반으로 제공합니다.

#### 5-1. 날짜 선택

- 상단에 현재 날짜가 표시되며, **◀ ▶ 버튼**으로 날짜를 앞뒤로 이동
- 📅 **달력 아이콘**을 눌러 특정 날짜를 직접 선택 가능
- 날짜 아래에 **음력 날짜**가 함께 표시됩니다

#### 5-2. 조석 지도

- **OpenStreetMap 기반** 지도에서 원하는 해안 위치를 클릭하면 해당 지점의 조석 정보가 표시됩니다
- "물 때를 확인할 위치를 클릭하세요" 안내 문구가 표시됩니다
- **내 위치** 버튼으로 현재 위치의 조석 정보를 바로 확인 가능

#### 5-3. 조석 상세 정보

위치를 선택하면 다음 정보가 팝업으로 표시됩니다:

**고조/저조 시각 및 조위:**
- **고조** 🔺: 만조 시각과 조위(cm), 평균 대비 증감량
- **저조** 🔻: 간조 시각과 조위(cm), 평균 대비 증감량
- 현재 예상 조위가 실시간으로 표시됩니다

**태양/달 정보:**
- ☀ **일출/일몰** 시각
- 🌙 **월출/월몰** 시각
- 🌕 **월령**: 현재 달의 나이 (일수)
- ✨ **밝기**: 달의 밝기 (%)

#### 5-4. 즐겨찾기

- 조석 팝업 상단의 **"☆ 즐겨찾기 추가"**를 누르면 해당 위치가 즐겨찾기에 저장됩니다
- 즐겨찾기는 **최대 4개**까지 저장 가능
- 저장된 즐겨찾기는 화면 하단에 버튼으로 표시되어 **한 번의 터치**로 바로 이동
- 즐겨찾기 버튼의 **× 표시**를 눌러 삭제 가능

---

### 6. 태풍정보 탭 (네 번째 탭)

태풍 발생 시 **실시간 태풍 경로 추적 및 예보** 정보를 제공합니다.

- 태풍 미발생 시에는 "현재 발생한 태풍이 없습니다" 안내가 표시됩니다
- 태풍 발생 시:
  - 태풍 이름, 현재 위치, 중심기압, 최대풍속
  - 예상 경로 및 진행 방향
  - 영향권 해역 정보

---

### 7. 공지사항 탭 (다섯 번째 탭)

앱 관련 **공지사항 및 안내**를 확인하는 게시판입니다.

- 게시글 목록에서 제목을 클릭하면 상세 내용이 팝업으로 열립니다
- 첨부파일이 있는 경우 다운로드 가능
- 검색 기능으로 원하는 공지사항을 찾을 수 있습니다

---

### 8. 설정

메인 화면 우측 상단의 **⚙ 아이콘**을 누르면 설정 화면이 열립니다.

#### 8-1. 글꼴 크기

앱 전체의 글꼴 크기를 조절할 수 있습니다:
- **작게** (기본): 표준 크기
- **보통** (기본값): 약간 크게 (+2px)
- **크게**: 더 크게 (+4px)
- 선택 즉시 앱 전체에 반영됩니다

#### 8-2. 알림 설정

푸시 알림의 수신 여부와 세부 조건을 설정합니다:

- **알림 마스터 토글**: 전체 알림 ON/OFF
- **발표/발효 알림**: 기상특보 발표 및 발효 시 알림
- **해제 공지 알림**: 기상특보 해제 시 알림
- **밤시간 알림 일시정지**: 야간(22시~07시) 알림 수신 차단
- **안전 권고 알림**: 특보 발효 시 안전 권고 팝업 표시 여부

#### 8-3. 관심 해역 설정

- **전체 해역** 또는 **관심 해역만** 선택 가능
- 관심 해역을 선택하면 해당 해역의 특보만 푸시 알림으로 수신
- 44개 해구 중 원하는 해구를 복수 선택 가능

---

### 9. 제보 기능

메인 화면에서 **제보 버튼** (📢 아이콘)을 통해 운영팀에 피드백을 보낼 수 있습니다:
- 오류 제보, 기능 건의, 데이터 이상 신고 등
- 제보 내용은 운영팀에서 검토 후 답변을 보내드립니다
- 답변이 등록되면 앱 내에서 확인할 수 있습니다

---

### 10. 데이터 새로고침

- **헤더 영역(앱 타이틀 부분)을 터치**하면 전체 데이터가 새로고침됩니다
- 새로고침 시 기상정보 탭으로 자동 이동하며 최신 데이터를 불러옵니다
- "최근 업데이트" 시각이 갱신됩니다

---

### 11. 푸시 알림 상세

앱에서 제공하는 푸시 알림의 종류와 내용입니다:

| 알림 유형 | 내용 | 예시 |
|---------|------|------|
| **특보 발표** | 새로운 기상특보 발표 시 | "풍랑 주의보 발표 ○서해남부남쪽안쪽먼바다, ..." |

## Part 3. 사용자에게 노출될 수 있는 운영 기능 안내

---

일반 사용자가 앱을 사용하면서 마주칠 수 있는 운영 관련 표시입니다.

### 1. 서버 점검 안내

- 서버 점검 시 앱 실행 화면에 **"서버 점검 중입니다"** 안내가 표시됩니다
- 점검 완료 후 자동으로 정상 화면으로 전환됩니다

### 2. 기능개선 작업 중 배지

- 운영팀이 기능 개선 작업을 진행 중일 때 헤더에 **"기능개선 작업 중"** 배지가 표시될 수 있습니다
- 앱은 정상 사용 가능하며, 일부 데이터 갱신이 일시적으로 지연될 수 있습니다

### 3. 데이터 수집 상태 표시

- 기상 데이터 수집에 일시적 장애가 발생하면 헤더 영역에 수집 상태 알림이 표시될 수 있습니다
- 이 경우 일부 데이터가 최신이 아닐 수 있으나, 자동 복구되며 새로고침으로 갱신 가능합니다

### 4. 설문조사 팝업

- 운영팀에서 서비스 개선을 위한 **설문조사 팝업**을 표시할 수 있습니다
- 참여는 자유이며, 한 번 완료하면 동일 설문은 다시 표시되지 않습니다

### 5. 안전 권고 팝업

- 기상특보(풍랑 주의보/경보 등) 발효 시 **안전 권고** 팝업이 자동 표시됩니다
- 이는 운영팀이 설정한 안전 관련 공지이며, 출항 제한 등 중요 안내 사항을 포함합니다
- 설정에서 안전 권고 알림을 OFF할 수 있습니다

### 6. 특보 이력 조회

- 기상정보 탭에서 **"특보종합"** 버튼을 누르면 과거에 발표/발효/해제된 특보의 이력을 시간순으로 확인할 수 있습니다
- 운영팀에서 등록한 특보 알림의 발송 이력도 포함될 수 있습니다

## 부록. 자주 묻는 질문 (FAQ)

**Q. 알림이 오지 않아요.**
→ 설정 > 알림 설정에서 알림이 ON인지 확인해 주세요. 또한 기기의 알림 권한이 허용되어 있는지 확인해 주세요. "밤시간 알림 일시정지"가 켜져 있으면 22시~07시에는 알림이 오지 않습니다.

**Q. 관심 해역만 알림을 받을 수 있나요?**
→ 네. 설정 > 관심 해역에서 원하는 해역만 선택하면 해당 해역의 특보만 알림으로 수신됩니다.

**Q. 조석정보에서 내 위치가 안 나와요.**
→ 위치 권한을 허용해 주세요. 앱 설정 또는 기기 설정에서 SEA:GNAL 앱의 위치 권한을 "허용"으로 변경해 주세요.

**Q. 데이터가 최신이 아닌 것 같아요.**
→ 헤더 영역(앱 타이틀)을 터치하면 전체 데이터가 새로고침됩니다. "최근 업데이트" 시각을 확인해 주세요.

**Q. 글꼴이 너무 작아서 보기 어려워요.**
→ 설정 > 글꼴 크기에서 "보통" 또는 "크게"로 변경해 주세요.

**Q. 즐겨찾기는 몇 개까지 저장할 수 있나요?**
→ 조석정보의 즐겨찾기는 최대 4개까지 저장 가능합니다.
