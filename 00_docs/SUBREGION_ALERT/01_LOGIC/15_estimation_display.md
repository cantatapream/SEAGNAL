# 자식해역 특보 표출 로직 — 1.15 추정 표시 정책

## 0. 본 파일의 위치

본 파일은 `01_LOGIC/` 시리즈의 마지막(15번) 파일이며, 자식해역 표출 시 **확정 정보와 추정 정보를 시각적으로 구분**하는 정책을 정리합니다.

이전 파일들에서 다룬 보수적 판정 결과는 일부 자식해역 정보가 추정 상태가 됩니다. 이 추정 정보를 사용자에게 어떻게 표시할지 결정하는 것이 본 파일의 목적입니다.

---

## 1. 추정 상태의 정의

### 1.1 확정 상태 (Confirmed)

방재기상 응답에 정상으로 들어온 자식해역의 정보입니다.

- 자식 행이 발효 행으로 응답에 존재
- 캡 규칙이 자연스럽게 적용되거나 미적용
- 직전 사이클과 일치하는 정보

### 1.2 추정 상태 (Estimated)

다음 케이스 중 하나에 해당하는 자식해역 정보입니다.

- 부모-자식 동시 사라짐 후 부모 해제 시각까지 유지 중 (강한 추정)
- 1회 빠짐 후 다음 사이클 대기 중 (약한 추정)
- 캡 규칙으로 자식 데이터가 절단된 경우 (약한 추정)
- 범위형 시각으로 잠금 중 (강한 추정)

### 1.3 정의의 근거

이 분류는 본 작업의 보수적 판정 정책(원칙 4)에서 자연스럽게 도출됩니다.

- 보수적 판정으로 유지되는 자식해역은 사용자에게 진실이라는 보장이 약함
- 따라서 사용자가 그 정보의 신뢰 수준을 인지할 수 있도록 시각적 구분 필요

---

## 2. 추정 단계의 분류 (3단계)

본 작업은 추정 상태를 다음 3단계로 분류합니다.

### 2.1 확정 (Confirmed) — 단계 0

방재기상 응답에 정상으로 들어온 자식해역. 추정 마커 없음.

| 항목 | 값 |
|---|---|
| 케이스 | 정상 응답에 발효 행으로 등장 |
| 신뢰도 | 가장 높음 |
| 표시 마커 | 없음 (○ 일반 표시) |
| 툴팁 | 없음 |

### 2.2 약한 추정 (Weakly Estimated) — 단계 1

다음 케이스가 약한 추정에 해당합니다.

| 항목 | 값 |
|---|---|
| 케이스 | 1회 빠짐 후 화면 유지 중 / 캡 적용 |
| 신뢰도 | 중간 |
| 표시 마커 | 작은 ⓘ 아이콘 또는 옅은 색 |
| 툴팁 | "본 정보는 실제 발표내용과 다를 수 있습니다." |

### 2.3 강한 추정 (Strongly Estimated) — 단계 2

다음 케이스가 강한 추정에 해당합니다.

| 항목 | 값 |
|---|---|
| 케이스 | 부모-자식 동시 사라짐 후 잠금 / 범위형 시각 잠금 |
| 신뢰도 | 낮음 (그러나 사용자 안전을 위해 발효로 표시 유지) |
| 표시 마커 | 더 명확한 ⓘ 아이콘 또는 회색조 |
| 툴팁 | "본 정보는 실제 발표내용과 다를 수 있습니다." |

## 3. 추정 단계 결정 로직

### 3.1 결정 함수

```
function determineConfidenceLevel(child):
  if child.status == "pending_release":
    return "STRONGLY_ESTIMATED"  # 동시 사라짐 잠금 / 범위형 시각

  if child.missedCount > 0:
    return "WEAKLY_ESTIMATED"  # 1회 빠짐

  if child.cappedLevel != child.rawLevel or
     child.cappedTmEd != child.rawTmEd:
    return "WEAKLY_ESTIMATED"  # 캡 적용

  return "CONFIRMED"  # 일반 정상 상태
```

### 3.2 단계 갱신 시점

자식해역의 추정 단계는 매 사이클 갱신됩니다.

- Step 3.7 (사라짐 카운트 갱신) 후 갱신
- Step 3.8 (잠금) 후 갱신
- Step 3.9 (표시 데이터 생성) 시 단계 결정

### 3.3 단계 전이

자식해역의 추정 단계는 시간에 따라 다음과 같이 전이합니다.

```
정상 등장 → 확정 (CONFIRMED)
1회 빠짐 → 약한 추정 (WEAKLY_ESTIMATED)
2회 연속 빠짐 → 화면 제거
부모-자식 동시 사라짐 → 강한 추정 (STRONGLY_ESTIMATED)
부모 해제 시각 도달 → 화면 제거
다시 정상 등장 → 확정으로 복귀
```

## 4. UI 표시 형식

### 4.1 권장 시각적 디자인

추정 단계에 따른 시각적 디자인 권장사항입니다.

| 단계 | 텍스트 | 마커 | 색상 | 툴팁 |
|---|---|---|---|---|
| 확정 | 풍랑 경보 | 없음 | 빨강 (또는 일반 색) | 없음 |
| 약한 추정 | 풍랑 경보 ⓘ | ⓘ | 빨강 (옅게) | "본 정보는 실제 발표내용과 다를 수 있습니다." |
| 강한 추정 | 풍랑 경보 ⓘ | ⓘ (강조) | 회색조 | "본 정보는 실제 발표내용과 다를 수 있습니다." |

### 4.2 툴팁 통일

약한 추정과 강한 추정 모두 동일한 툴팁 텍스트를 사용합니다.

```
"본 정보는 실제 발표내용과 다를 수 있습니다."
```

이는 사용자에게 추정 정보임을 명확히 알리되, 단계 차이를 텍스트로 구분하지 않고 시각적 강조 정도로만 차별화합니다.

### 4.3 표시 위치

추정 마커는 자식해역 항목의 텍스트 옆에 작게 표시합니다.

- 예: `가파도연안 풍랑 경보 ⓘ`

## 5. 데이터 모델 — confidence 필드

### 5.1 자식해역 객체에 추가되는 필드

```
{
  regId: "S2122000",
  regKo: "가파도연안",
  parentRegId: "S1232000",
  wrnTp: "풍랑",
  wrnLvl: 3,
  tmEf: "2026-04-30 14:00",
  tmEd: "2026-05-01 06:00",
  status: "pending_release",
  missedCount: 0,
  lastSeenAt: "2026-04-30 22:05",
  confidence: "STRONGLY_ESTIMATED",  ← 신규 필드
  estimationReason: "CONCURRENT_DISAPPEAR_LOCK"  ← 신규 필드
}
```

### 5.2 estimationReason 가능 값

| 값 | 의미 |
|---|---|
| `null` | 확정 상태 (이유 없음) |
| `"MISSED_ONCE"` | 1회 빠짐 (약한 추정) |
| `"LEVEL_CAPPED"` | 캡 규칙 적용 (약한 추정) |
| `"TIME_CAPPED"` | 시각 캡 규칙 적용 (약한 추정) |
| `"CONCURRENT_DISAPPEAR_LOCK"` | 동시 사라짐 잠금 (강한 추정) |
| `"RANGE_TIME_LOCK"` | 범위형 시각 잠금 (강한 추정) |

### 5.3 영속화

`confidence`와 `estimationReason` 필드는 `subregion_lifecycle.json`에 영속화됩니다. 자세한 스키마는 `02_DATA_MODEL/03_subregion_lifecycle_schema.md` 참조.

## 6. 사용자 영향

### 6.1 안전 측 정책

본 추정 표시 정책은 사용자에게 안전 측으로 작용합니다.

- 추정 정보는 발효 중으로 표시됨 (거짓 해제 방지)
- 단, 그것이 추정임을 사용자가 인지할 수 있도록 마커 부가
- 사용자는 정확한 정보가 필요한 경우 통보문 또는 기상청 페이지 직접 확인 가능

### 6.2 푸시 알림 미발송

자식해역에는 푸시 알림이 발송되지 않습니다. 따라서 추정 상태가 푸시로 사용자에게 잘못 전달되는 일은 없습니다.

### 6.3 화면 보는 사용자에게의 영향

화면에서만 정보가 보이므로 사용자가 화면을 직접 봐야 추정 상태를 인지합니다.

- 화면을 보는 사용자: 추정 마커와 툴팁으로 신뢰 수준 인지
- 화면을 안 보는 사용자: 추정 정보로 인한 영향 없음

## 7. 추정 상태의 운영 모니터링

### 7.1 운영 통계

추정 상태가 발생하는 빈도를 운영 차원에서 모니터링하면 데이터 품질 개선에 도움이 됩니다.

- 약한 추정 빈도 → 일시 오류 / 캡 적용 빈도
- 강한 추정 빈도 → 동시 사라짐 / 범위형 시각 빈도

### 7.2 통계 수집

각 추정 발생 시 운영 로그에 기록합니다. 로그 형식은 `03_OPERATIONS/05_log_format.md` 참조.
