기상청 통보문 본문에 가끔 `&middot;` (= `·`) 같은 미디코딩 엔티티 잔존:
- `태안&middot;서산 북쪽 평수구역` → `태안·서산 북쪽 평수구역`

**조치**: 본문 파싱 시 엔티티 디코딩 함수 강화
```javascript
function decodeEntities(text) {
  return text
    .replace(/&middot;/g, '·')
    .replace(/&nbsp;/g, ' ')
    .replace(/&amp;/g, '&')
    .replace(/&lt;/g, '<')
    .replace(/&gt;/g, '>')
    .replace(/&quot;/g, '"');
}
```

## 4. 명칭 매칭 — 정규화 변환

### 4-1. 앱 ↔ 통보문 명칭 차이

| 출처 | 표기 형식 | 예시 |
|---|---|---|
| 앱 (`empty_tree.json`, `mappings.js`) | `[부모]중[자식]` 합쳐서 | `제주도서부앞바다중북서연안바다` |
| 통보문 (CSV·실시간) | `[부모]([자식])` 괄호 | `제주도서부앞바다(북서연안바다)` |

### 4-2. 정규화 함수

```javascript
// 앱 명칭 → 정규화 키
function normalizeAppName(appName) {
  // "제주도서부앞바다중북서연안바다" → ["제주도서부앞바다", "북서연안바다"]
  const match = appName.match(/^(.+앞바다|.+먼바다)(.+)$/);
  if (!match) return [appName, null];
  let [, parent, rest] = match;
  // 중간의 "중" 제거
  if (rest.startsWith('중')) rest = rest.substring(1);
  return [parent, rest];
}

// 통보문 명칭 → 정규화 키
function normalizeNoticeName(parent, child) {
  // ("제주도서부앞바다", " 북서연안바다 ") → ("제주도서부앞바다", "북서연안바다")
  return [parent.trim(), child.trim()];
}

// 두 키 비교
function isSameSubregion(appName, noticeParent, noticeChild) {
  const [appParent, appChild] = normalizeAppName(appName);
  const [noticeP, noticeC] = normalizeNoticeName(noticeParent, noticeChild);
  return appParent === noticeP && appChild === noticeC;
}
```

### 4-3. 공백·점 정규화

- 괄호 안 분리자 = `.` (마침표, 5년 CSV 검증)
- `( 자식1 . 자식2 . 자식3 )` → split('.') 후 trim
- 콤마(`,`) 분리는 사용 안 함 (5년치 0건)

### 4-4. "제외" 처리

```javascript
// "(북서연안바다 제외)" 또는 "(북서연안바다. 남서연안바다 제외)"
const EXCLUSION_RE = /\(([^)]+?)\s*제외\s*\)/;
```

매칭 시 괄호 안 자식해역들에 `status: "EXCLUDED"` 적용.
