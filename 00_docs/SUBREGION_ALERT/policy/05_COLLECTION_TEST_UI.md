# 정책 ⑤ — 특보 수집 테스트 UI 확장

**작성일**: 2026-05-16
**버전**: 1.0
**관련 정책**: `01_COLLECTION_SCOPE.md`

---

## 1. 배경

기존 통합관리자센터 → 특보 알림 → 특보 수집 테스트 탭은 **전국(stn=108) 단위** 로만 통보문을 표시. 9개 광역 수집 정책 도입에 따라 **광역별 구분 표시** 가 필요.

또한 코드 분석 결과 두 가지 UI 가 공존:
- `admin.js` 의 `renderCollectTestSubTab()` (인라인, 2개 탭만)
- `admin_collect.js` 의 `openAlertTestModal()` (모달, 3개 탭)

→ **인라인 버전에 "전망 수집" 탭 추가하여 3개 탭으로 통일**.

### 2-1. 사이드바 항목

- **⦿ 전체** — 9개 광역 통합 보기 (사용자 결정으로 충북 제외)
- 9개 광역 — 풀이름 또는 약칭
- 각 광역 옆 카운트: `통보문 총수 미수집수`
- **사용자 결정**: 충북은 사이드바에 표시 안 함

### 2-2. 범례

- ✅ 수집됨 (정상 처리)
- ⏳ 대기 중 (AI 분석 진행 중)
- ❌ 수집 실패 (재시도 필요)
- ⚪ 미수집 (수동 수집 가능)

## 5. "전망 수집" 탭 통일

### 5-1. 변경 사항

`admin.js` 의 `renderCollectTestSubTab()` 에 세 번째 탭 추가:

```javascript
// 변경 전 (2개 탭)
<button id="atm-tab-status">수집 현황</button>
<button id="atm-tab-collect">통보문 수집</button>

// 변경 후 (3개 탭)
<button id="atm-tab-status">수집 현황</button>
<button id="atm-tab-collect">통보문 수집</button>
<button id="atm-tab-forecast">전망 수집</button>   ← 신규
```

### 5-2. 전망 수집 탭 동작

기존 `admin_collect.js` 의 `renderATMForecast()` 함수 그대로 활용. 초단기/단기 전망 통보문(cmt:) 수집 결과 표시.
