- `울산앞바다중연안바다` ↔ `S2120400 울산앞바다중 연안바다`
- `제주도서부앞바다중가파도연안바다` ↔ `S2122000 가파도연안바다`
- ... 외 45개

**조치 권장**:

- 며칠~일주일 모니터링하여 등장하는지 확인
- 등장 시 매핑 추가 / 미등장 시 우리 앱 정의 검토
