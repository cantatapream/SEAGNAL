## 5. 정규식 — 5년치로 검증된 최종 버전

### 5-A. 해당지역 컬럼 파싱 — Pattern P1·P2

```javascript
// P1: 부모(자식 제외) — 자식이 부모에 포함되지 않음 명시
const P1_PARENT_EXCLUDE = /(?<parent>[가-힣]+앞바다)\s*\(\s*(?<children>[^)]*?(?:연안바다|평수구역)[^)]*?)\s*제외\s*\)/g;

// P2: 부모(자식 단독, 제외 없음) — 자식만 영향
const P2_PARENT_CHILDREN = /(?<parent>[가-힣]+앞바다)\s*\(\s*(?<children>[^)]+?)\s*\)(?!.*제외)/g;
```

### 5-B. 괄호 안 자식해역 토큰화

**핵심: 콤마(`,`) 아니라 마침표(`.`) 가 분리자!**

```javascript
// 괄호 안 자식해역 분리
function splitChildren(insideParens) {
  return insideParens
    .split('.')                  // 마침표로 분리
    .map(s => s.trim())          // 공백 제거
    .filter(s => s.length > 0 && /(연안바다|평수구역)/.test(s));
}
```

**검증된 분리 사례**:
- `(천수만 평수구역 . 가로림만·당진 평수구역 . 안면도 서쪽 평수구역)` → 3개
- `(북서연안바다 . 남서연안바다)` → 2개

### 5-C. 발효시각 컬럼 파싱

```javascript
// 발효시각 줄: '(N) 종류 동사 : YYYY년 MM월 DD일 HH시 MM분'
const EFFECTIVE_RE = /\((?<seq>\d+)\)\s*(?<type>[가-힣]+(?:주의보|경보|예비특보))\s*(?<action>발표|해제|변경|연장)\s*:\s*(?<datetime>\d{4}년\s*\d{2}월\s*\d{2}일\s*\d{2}시\s*\d{2}분)/g;
```

→ 앱이 이런 다중 사건을 시퀀스 번호(1)(2) 별로 정확히 분리 처리해야 함.

## 7. 표기 변형 (5년치 발견 사례)

| 변형 | 빈도 | 처리 |
|---|---|---|
| `( 연안바다 )` (공백 포함) vs `(연안바다)` | 둘 다 | 정규식에서 `\s*` 로 공백 허용 |
| `( 자식1 . 자식2 )` 마침표 분리 | 185건 | 분리자 = `.` |
| `(자식1. 자식2)` 공백 없는 마침표 | 6건 | 함께 처리 |
| 콤마(`,`) 분리 | **0건** | 처리 불필요 |
| `( 자식 제외 )` 마지막에 "제외" | 다수 | P1 |
| `(○○앞바다 중 ○○연안바다)` "중" 사용 | **1건** (2021-12-17) | 매우 드물어 무시 가능 |

### 9-C. 방식 A — PRELIM_CANCEL_NATURAL_RE (31일 윈도우 분석에서 확정)

```javascript
const PRELIM_CANCEL_NATURAL_RE =
  /(?<region>[가-힣.·\s()0-9~]+?)의?\s*(?<kind>[가-힣]+)\s*예비\s*특보(?:는)?\s*발표\s*가능성이\s*낮[아어]져\s*해제(?:합니다|하나)/g;
```

검증:
- "낮아져" / "낮어져" 두 어형 모두 매칭 (※ 표기 오차 발견)
- "예비특보" / "예비 특보" / "호우예비특보" 띄어쓰기 무관
- "해제합니다" / "해제하나" 어미 두 가지

### 9-D. 통합 처리 흐름

```javascript
function processNotice(notice) {
  const body = fetchSectionCmpView(notice.reportId);

  // 절 분리
  const { contentBlock, referenceBlock } = splitByMarker(body, '참고사항');

  // 1) □ 내용 절 — 모든 통보문 공통 처리
  const announcements = contentBlock.matchAll(EFFECTIVE_RE);
  for (const a of announcements) {
    const targetRegions = extractTargets(contentBlock, a.seq);
    applyChildPattern(targetRegions, a.type, a.action, a.datetime);
  }

  // 2) ★ 참고사항 절 — kind=pwn 전용
  if (notice.kind === 'pwn' && referenceBlock) {
    const cancellations = [...referenceBlock.matchAll(PRELIM_CANCEL_NATURAL_RE)];
    for (const c of cancellations) {
      removePendingPrelim(c.region, c.kind);
```
