- **제품**: SEAGNAL = 해양(어민·낚시인·레저인) 앱. 진행 중 = 개인화 해양법률 검색/챗봇 "나리야"(Karpathy LLM-Wiki 패턴).
- **작업 규칙**: 카파시 가이드라인(생각먼저·단순함·외과수술식·목표기반) 필수 — `.claude/skills/karpathy-guidelines/`. Superpowers 플러그인은 도입 보류(카파시로 충분).
- **법률 지식베이스**(`local_server/knowledge/legal/`): `_SCHEMA.md`(위키 만드는 규칙), `_CHATBOT.md`(답하는 규칙). 법 73개+별표+고시 수집 완료, 조례는 표본.
- **챗봇 설계**: 음성비서 폐기·텍스트 챗봇. 대화형 온디바이스 프로필(서버 저장 금지). 처벌 답변 점진적 공개(통상 1차→되물음→전체). 모르는 구어는 DB→웹뜻확인→사용자 되물음→_candidates 학습. 하이브리드 검색(glossary+임베딩+그래프)+프로필 필터. 인용 규율(위키 원문만, 환각0, 출처 concept ID).
- **처벌값 검수**: 원문 그대로 인용은 자동검증, 벌칙 포괄표현 매핑만 사람 REVIEW.
- **앱 기존 자산**: `services/user_memory.js`(A3압축/A4회수/A5관련성 — 미완성), `topic_embedding.js`, `gemini_client.js`, 통합관리자센터(로고10클릭). 앱 챗봇 기억은 이 user_memory.js 완성으로.

## 최근 진행 (rolling — 최신 15개, 오래된 건 압축/삭제)
- 위키 감사 루프 자동화(감사→수정→재감사): 오케스트레이터 트리거가 15분마다 전진. 1차 감사 완결(65/65, 구멍 36%: full61/thin12/missing19/hole3). 수정 단계 진행 중 → 다음 2차 감사.
- 감사가 찾은 핵심: 큰 규제법·기관법에 "페이지 자체가 안 만들어진 조문"이 많음(missing 19%). 일부 인용 타법 미수집(독도법→자연유산법 등).
