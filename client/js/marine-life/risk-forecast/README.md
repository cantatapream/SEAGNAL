# 위험예측

`index2.html`의 **해양생활 → 해양안전 → 위험예측** 버튼에 연결된 지도 오버레이다. 처음에는 연안만 켜며, 관광지나 해상 칸을 선택하면 시간축과 상세 시트가 열린다. 해상·연안 스위치는 기존 범례 칸에 쌓인다. 선택한 층을 끄거나 Escape를 누르면 시트와 선택 위험구역을 지운다.

지도 범례에는 예비특보·주의보·경보·특보급 날씨 가능성(3일째) 네 줄을 두지 않는다(과제13). 남기는 범례는 해상의 「종합 관심단계/공식 사고예보」 등 색상 범례 한 개뿐이다. 특보 경계선 자체는 지도에 그대로 그려지며, 특보 내용은 위험구역 상세 시트에 표시한다. 이 설명을 화면 안내 문구로 둘지 문서에만 둘지는 사용자 결정 대기다.

점수·시간축·특보 판정은 `/api/risk-forecast/*` 서버 응답을 사용한다. 연안 관광객 분석은 기존 계산을 유지한다. 해상은 GR4 크기의 공통 표출 격자 하나에서 현재 종합 관심단계·미래 공식 사고예보를 연속 면색으로 표시하고, 원본 사고·혼잡·현재 교통을 상세에서 비교한다. 클릭 위치에 포함되는 두 격자를 공간으로 연결하며 사고지수에 혼잡 가중치를 추가하지 않는다. 파고·풍속·파주기·파향은 같은 3시간대의 기상청 해구 예보를 별도 출처로 표시한다. 자료가 없거나 수집이 실패하면 정상값을 만들지 않는다.

- `risk_forecast.js`: 버튼·층·선택·60초 자료 갱신 조율
- `risk_api.js`: 요청당15초 제한·최대3회 일시 장애 재시도, 경로별 TTL과 동시 요청 중복 방지
- `risk_map_layer.js`: 육지로 잘린 연안 분할 원·모든 관광지의 선택 중심점, 부드러운 단일 해상 면색·확대 척수·공식 원본 위치 연결, 실제 발표된 특보 구역 배경 면(이름 없음), 21개 섬
- `risk_slider.js`, `risk_sheet.js`: 서버 시간축·자료 신선도와 상세 문장·연안 합계 배수 설명·동일 좌표 관광지 선택 목록
- `risk_format.js`: DMS 정수 초, 16방위, HTML·출처 URL 보호, 색과 숫자 명암
- `risk_basis.js`, `risk_basis_content.js`: 기준 상세 및 서버 PDF 다운로드
- `risk_forecast.css`: 기존 스위치·슬라이더를 재사용하는 표시 스타일

## 해상 화면 후속 수정 — 2026-10-13

위험예측 버튼은 페이지마다 비활성 모습으로 시작한다. 첫9회는 기능과 다른 오버레이에 영향을 주지 않고,10회째에 해제하면서 연다. 이후 같은 페이지에서는 보통 토글로 동작한다. HTML disabled는 클릭을 받지 못하므로 aria-disabled와 캡처 처리로 구현한다. 서버 인증이나 자동수집 중지 기능은 아니다.

연안·해상 스위치는 위험지형과 동일한 banzone/bzl 스타일을 사용한다. 해상ON은 기본 통합색, 하위 아코디언의 사고위험 예보·실시간 교통·혼잡도 예측은 한 항목만 선택된다. 선택 후 접고 뱃지로 알리며, 선택한 항목을 다시 끄면 기본 통합으로 돌아간다. 실시간 교통 선택은 현재로 복귀하고, 미래 버튼을 누르면 기본 미래 공식 사고예보로 전환한다.

메인 해상 슬라이더 대신46px 전폭 하단 바의 고정 날짜·시각 output과 현재/+3H/+6H/+12H 버튼을 제공한다.11시+3H는12시, 다음+3H는15시다. 바는 메인 탭 바로 위이며 출처·축척·색상범례는 그 위로 올린다. 상세 시트의 시간축은 유지하고 메인 시각과 독립적이다. 예보 범위 밖 버튼은 비활성화한다.

**과제2 — 연안·해상 공통 메인 시각**: 이 하단 바는 해상 전용이 아니라 연안·해상 공통 하나다(연안만 켠 기본 화면에서도 보인다). 연안 ON이면 서버 `meta.timeline.coast`의 3시간 칸(지금~내일 21시 — 아래 「가」)을 그대로, 해상만 ON이면 지금~내일 21시를 고른다. 두 층의 끝이 같으므로 내일 21시에서 앞으로 버튼이 모두 비활성이 된다(종전의 「해상 예보 범위 밖 (내일까지)」 안내는 연안만 남는 모레 구간이 없어져 삭제). 둘 다 끄면 바가 숨는다. 시트 시각은 계속 독립이다.

결측은 면색·클릭 대상에서 제외한다. 확대 시 화면 주변 격자만 만들고 전국 보기에서는 같은 색상의 폴리곤을 최대256개 도형으로 묶는다. 숫자는 확대된 실시간 교통에만 표시하며, 공간 클릭은 원래 격자와 수치로 연결한다. 완성된 면색에 흐림을 한 번 적용한다. 부가 경계/연안 실패가 정상 해상 프레임 표시를 막지 않는다.

## 특보 구역 배경 면 — 과제14

위험예측 지도의 배경에는 선택한 메인 시각에 **실제로 발표된 특보가 있는 해상 특보구역 면만** 칠한다. 구역 이름 글자는 없고, 특보가 없으면 아무것도 그리지 않는다. 예비특보 노랑 · 주의보 주황 · 경보 빨강이다. 연안 또는 해상 중 하나만 켜도 보이고 둘 다 끄면 숨긴다. 면은 위험 색상층 아래에 놓이며 육지 마스크로 잘린다.

- 자료: 서버 `GET /api/risk-forecast/warning-zones?t=` 한 번(연안·해상 위험 프레임과 독립, 점수 계산 없음). 응답의 `zones`는 `[{zone,color:pre|adv|wrn,state,from}]`이다.
- 도형: 기존 정적 `/api/warn-zones`(부모 44)와 `/api/warn-zones-sub`(자식 49). 부모는 자식 구역을 뺀 `properties._holedGeometry`를 쓰고 자식은 자기 도형을 쓴다. 관리자 메타 감시는 이 정적 도형을 읽지 않는다.
- 예비특보는 예정 시각이 지나도 주의보로 승격하지 않고 노랑으로 둔다. 구 연안 frame의 `borders`는 서버 응답에 남아 있지만 이 화면은 더 이상 그리지 않는다. `day3Dashed`(3일째 점선)는 「가」로 서버 응답에서도 뺐다.
- 공개 지도의 원천 오류 배너는 과제16 정책으로 숨긴다. 특보 조회 실패·구역 도형 누락은 빈 화면을 정상처럼 두지 않고 진단 로그(`console.warn`, 비밀 정보 없음)에 남기며, 특보 원천 자체의 실패·낡음은 관리자 오류현황이 기록한다. 정적 구역 도형 로드 실패는 관리자 감시 대상이 아니다(메타 감시에 정적 도형을 추가하지 않는다).

## 원천 오류 표시 정책 — 과제16

특보·해구 기상·행사 등의 실패/낡음/결측 공통 배너와 상세 시트의 공통 경고 목록은 공개 지도에서 숨긴다. 수집 상태를 정상으로 바꾸지는 않는다. 개별 값의 자료 없음, 선택한 상세를 읽지 못했을 때의 재시도는 유지한다. 오류 내역은 통합 관리자 센터 **AI → AI 사고예측 → 오류현황**에서만 확인한다. 운영 감시는 `risk_history_sources`의 작은 메타데이터와 기존 `risk_store.sources`의 신선도 규칙을 사용하며 화면용 예보 캐시를 강제 로드하지 않는다. 상세는 [오류 이력 운영 문서](../../../../00_docs/operations/risk-forecast-error-history.md)를 참고한다.

## 자료 없음 문구 판정 — 과제4

행사·특보·강풍이 **없는 날(원천은 정상 수신, 목록만 빔)** 은 서버 `missing`·프레임 `degraded` 에 들지 않아 화면에 자료 없음 문구가 나오지 않는다. **받지 못한 경우(파일 없음·손상·오류·낡음)** 만 `missing` 에 들고, 연안 시트에서는 행사 행의 「자료 없음」과 「확인된 요소 기준」 안내로 정상 없음과 구분된다. 전역 경고 목록은 과제16대로 숨기고 관리자 오류현황에 기록한다. 이안류 **비수기(`offseason`)** 는 정상 상태라 `rip` 결측으로 세지 않는다. 검사: `test_risk_missing_notice`.

## 상세 시트 고정 머리·하단 탭 위 배치 — 과제5·7

시트(`#risk-forecast-sheet`)는 지도 박스가 아니라 화면(viewport) 기준 `position:fixed`로 `bottom:var(--ls-bottom-chrome)`(메인탭+열린 서브탭 높이) 위에 놓는다. `--main-tab-height`가 탭 offsetHeight 실측값이라 아이폰 아래 여백(safe-area)이 이미 들어 있어 `env()`를 더하지 않는다. 서브탭이 열리면 변수가 서브탭만큼 커져 이중 여백이 생기지 않는다.

시트 안은 `.rf-sheet-head`(손잡이·닫기·제목·부제·시각 조작, 고정)와 `.rf-body`(내용, 이 안에서만 스크롤)로 나뉜다. 연안·해상·공식 사고 상세, 해상 종합·관할 브리핑 렌더, 같은 위치 관광지 선택 목록이 같은 머리를 쓴다. 닫기 버튼, PopupStack 등록, 휴대폰 뒤로가기는 그대로다. 미리보기(`risk_forecast_preview.html`)는 프레임 안 absolute 배치를 유지한다.

## 시트 고정 일시 표시 — 과제8

슬라이더 말풍선(`.ocean-sheet-tooltip`)을 없애고 슬라이더 위 빈칸에 `<output class="rf-time-label">`로 「'26.10.14(수) 15:00」(KST)를 고정 표시한다. 값은 시트의 `selected.at`(손잡이를 움직이면 그 값)이며 `RiskFormat.stamp`로 만든다. 메인 지도 시각(`t`)은 읽지 않는다 — 메인 15시, 시트 18시로 옮기고 닫으면 메인은 15시, 다른 지점의 새 시트도 15시로 시작한다. 해상 메인 하단 바의 현재/+3H/+6H/+12H와 고정 일시는 그대로다.

## 즉시 열기와 로딩 스켈레톤 — 과제6

지점을 누르면 응답을 기다리지 않고 시트를 열어 회색 틀(`.rf-skeleton`)을 보인다. 제목은 이 지점의 이름을 아는 연안만 쓰고(해상은 「불러오는 중…」) 이전 지점의 제목·내용은 남기지 않는다. 시트 시각 조작을 바꿔도 같은 지점의 제목은 두고 본문만 회색 틀로 바꾼다. 60초 자동 갱신은 열린 상세를 회색 틀로 바꾸지 않는다. 열린 시트는 응답 전부터 휴대폰 뒤로가기(PopupStack) 대상이다.

늦게 온 응답은 기존 검사(요청 세대·선택 객체·요청 시각 일치)로 버린다: 먼저 누른 다른 지점, 이전 시트 시각, 이미 닫은 시트의 응답은 화면에 나오지 않는다. 요청이 실패하면 회색 틀 대신 오류와 「다시 시도」를 보이며 결측을 정상처럼 꾸미지 않는다.

## 위험구역 현황 아코디언과 지도 중앙 이동 — 과제10

연안 「위험구역(3km 안)」 줄의 「위험구역 N곳 현황」은 버튼 모양(높이 40px 이상, ▾ 표시)의 접힘 아코디언이다. 구역을 누르면 지도가 그 구역을 **시트에 가려지지 않은 남은 지도 영역의 가운데**로 이동·확대하고, 목록에서 그 구역이 눌린 상태(`aria-pressed`)로 표시된다. 다른 구역을 누르면 이전 표시는 해제되고, 다른 지점을 고르면 구역 표시가 지도에서 사라진다. 해상 관할 해역 이동(`marinePoint`)도 같은 여백 계산(`visiblePadding`)을 쓴다. 설계 결정 U72·U74⑦·U78⑥은 `coastal_safety_forecast.design.md`.

## 가 연안 2일 제한 — 2026-10-15

사용자 원문: 「연안 해상 기간 차이 관련해서는 연안도 2일까지 표출하도록 하고, 관련하여 2일 이후 데이터는 받아오지 않도록 하여 메모리 소모 등 문제를 최소화할 수 있도록 해.」 · 「나」 「시간 버튼이 앞으로만 감 관련하여 현재 상태로 놔두어. 가.를 처리하면 해결될 것 같은데」

연안도 해상과 같이 **오늘·내일**만 표출한다. 연안 시간축은 3시간 칸 그대로이며 마지막 칸은 **내일 21시**다(해상은 1시간 칸 내일 23시, 메인 하단 바는 3시간 칸 내일 21시). +3H/+6H/+12H 버튼은 「나」대로 바꾸지 않았고, 끝 칸에서는 기존 규칙대로 비활성이 된다.

- 서버 `risk_store`: 연안 기간을 `coastTimeline()` 한 곳(`T.timeline(now,3,2,21)`)에서 정한다. `meta.timeline.coast`·연안 상세/프레임·특보 구역 조회(`validateTime`)·연안 특보 슬라이더 끝·강풍 끝·읽을 행사 월이 모두 이것을 쓴다. 모레 시각 요청은 400이다.
- 없앤 3일째 기능: 상세 안내 `day3`(「특보가 발효될 수 있을 정도의 날씨…」), 연안 프레임 `day3Dashed`, `meta.timeline.coast.day3From`, 이것에만 쓰이던 해구 예보 하루 최대값 `dayMax`, 화면의 해상 범위 밖 안내(`seaOutOfRange`).
- 보관하지 않는 자료: 관광지 집중률(연안 전용)은 원천이 약30일을 주지만 **수집일~+2일**만 저장한다(다음날 새벽 00~06시에도 「오늘·내일」이 필요해서 +2일까지). 행사 월 파일은 모레가 다음 달이어도 읽지 않고, **내일이 다음 달일 때만** 다음 달 파일을 메모리에 올린다.
- 공용 자료는 자르지 않았다: 해구 예보(`zone_forecasts.json`, 예보 탭 공용)·너울(`swell_smallzone`, 너울 화면 공용)·특보·강풍·이안류(오늘만 사용). 공식 선박 사고예보 수집(3일·24칸)은 해상 쪽이라 이번 범위 밖이다 — [validation.md](validation.md)의 「가」 절.
