# 해상 교통·공식 예보·사고 이력 통합

현재 전국 GR4 교통량(척수)·밀집도와 공식 혼잡 GAN 예보, 공식 사고 MLP 예보, 기존 선박사고 이력을 위치로 연결한다. 연안 관광객 사고 데이터·기존 연안 배수 모델과 혼합하지 않는다. 현재 척수와 미래 예보의 시각은 별도 표기한다. 공식 사고 원시 지수는 확률이나 상대배수로 변환하지 않는다.

## 수집과 메모리

`sea_realtime_collector`는 Fly 운영에서 5분 구간마다 최신 한 벌을 원자 교체한다. `MTIS_REALTIME_SERVICE_KEY`를 설정하면 해당 키를 우선 사용하고, 미설정이면 기존 MTIS 사고 키를 사용해 공식 v2를 시도한다. 키가 없거나 API가 실패하면 마지막 정상 파일을 그대로 두고 오류 상태만 남긴다(웹으로 대신하지 않는다 — 아래 「MTIS 웹 수집 제거」). 밀집도 누락을 0으로 채우지 않는다. API 모든 페이지의 totalCount·등록시각·ID 중복을 검증한다. 기본 호출 상한 1,200건/일은 앱의 보호 상한이며 공식 허용량이 아니다. 최신 조회만 수행하며 2023년 이후 장기 과거자료를 수집하지 않는다.

최신 파일 `sea_realtime.json.gz`는 `cells` 경계를 한 번, `rows=[i,척수,밀집도]`로 저장한다(2026-10-15 전 저장본은 뒤에 선종7·톤수10 칸이 더 있으나 읽지 않는다). 시각은 API 등록시각(regDt)으로 표기하고 관측시각이라고 부르지 않는다. 15분 이상 낡은 현재값은 지도 숫자·관심 판단에서 제외하고 상세에서 마지막값의 최신성 확인 필요를 표시한다. 누락은 정상·안전·0척으로 치환하지 않는다. 원천 실패는 마지막 정상 파일을 유지한다.

혼잡 예보는 `marine_congestion_codec`가 격자ID·좌표·생성시각을 공통 표로 분리하고 시각별 `[i,지수,단계,생성시각index]`를 저장한다. 기존 저장본과 상세 API 계약을 계속 지원하며 최대8시각만 기존 행 객체로 해석한다. 관할 분석은 작은 수치 위치표로 개별 격자를 조회한다. 과거 선박사고는 요청마다 전부 다시 읽지 않고 최근5개연도 공간 버킷·요약을 공유한다. 상세/브리핑은 외부 수집이나 Gemini 호출을 실행하지 않는다.

## 공간과 시각

해역명은 기존 `risk_sea_cells.describe`의 주요 지명 좌표·16방위·해리 거리와 `해양종합정보 → 해구기상`의 `marine_zone_area.json` 대해구 및 같은 3×3 소해구 번호를 사용한다. 예: 제주항 북서방 8.2해리 해역(163-6해구). 원본 교통 GR4와 약5㎞ 사고 격자를 실제 선택 위치의 공간 포함으로 연결한다. 공유 경계는 ID순 한 칸을 대표로 고른다. 과거 사고 통계는 연결한 사고 예보 격자 전체의 값임을 명시한다.

현재 교통은 최신값으로 계속 별도 표기한다. 혼잡은 선택시각이 속한 정시, 사고는 선택시각이 속한3시간대, 기상은 기존 해구별 예보의 유효범위와 가장 가까운 제공시각을 사용하고 각 실제 예보시각을 표시한다. 통합 시간대별 표는 오늘·내일로 제한한다. 기존 공식 사고 수집기의3일 원본은 유지한다. (2026-10-15 정정: 사용자 「해상 공식 사고예보는 2일까지만」에 따라 수집기도 오늘·내일 16칸만 받고, 통합 조회 시각 `time()`도 지금+72시간 대신 오늘00시+48시간 미만만 받는다 — 설계 결정 U80, [guide.md](guide.md) 「해상 공식 사고예보 2일 제한」.)

시트 시각은 열린 시트 안에서만 유효하다. 메인15시 → 시트18시 → 닫으면 메인15시 유지, 다른 시트도15시 시작. 시트에서 바꾸는 시각은 메인 지도 프레임을 변경하지 않는다. 기존 미완료 메인 슬라이더 작업은 이번 PR에 포함하지 않는다.

## 사고 이력 범위

현재 앱 자료의 가장 최근 연도를 끝으로 최근5개연도를 집계한다(현재 자료는2021~2025). 위치·날짜·사고유형·원인·사망·실종을 사용하고 구조인원은 피해 합계에 더하지 않는다. 충돌·접촉·좌초/좌주·전복·침몰/침수·화재·폭발·표류·행방불명 유형과 기상악화 원인을 포함한다. 해양오염·부유물감김은 원인이 기상악화여도 우선 제외한다. 기타 기관손상·운항저해 등은 기상악화 원인이 명시된 경우에만 포함한다. 기상악화 침몰은 전체 사고1건, 기상 원인 별도1건으로 집계한다. 인명 수치 미기록은0명 확인으로 표현하지 않는다. 공단 MLP는 부유물감김 등을 포함하므로 앱 필터로 공식 지수를 다시 산출하지 않는다.

## 관할 브리핑

기존 파출소 폴리곤에 교통 격자 중심을 배정해 전체 현재 척수를 집계한다(선종별 척수는 2026-10-15 제거). 겹친 관할은 이름순1개로 고정 배정하여 이중 합산하지 않는다. 실제 선박 위치가 없으므로 결과는 '관할 대응 격자 기준'이며 경계 선박의 정확한 관할 척수로 표현하지 않는다. 수신 격자가 없는 관할은 자료 없음이다. 과거 사고는 사고점 위치로 관할에 배정한다.

모든 현재·예보 격자를 검토하고 같은 공식 사고격자를 중복 관심구역으로 집계하지 않는다. 같은 사고격자에 연결된 모든 교통격자를 분석한 뒤 관심단계가 높은 격자를 대표로 선택하고, 단계가 같으면 현재 척수가 많은 격자를 선택한다. 공식 사고 주의/경계, 혼잡 높음/매우높음, 현재 GR4 21척 이상을 근거로 관심 해역을 추출하고 우선순위20개를 표시하되 전체 건수도 보존한다. 기상과 사고 이력은 설명 근거이지 사고확률 가중치가 아니다. '순찰하라' 대신 '관심 필요·운항 시 주의 필요·공식 경계 단계 확인 필요'를 사용한다. 선택한 시각에서 오늘·내일의 주의 시간대를 근거와 함께 표시한다. 문장은 규칙 기반으로 생성하며 같은 결과를 격자 시트와 브리핑이 공유한다.

## 모바일 지도 단순화(2026-10-13 사용자 추가 요구)
GR4 하나로 표출 격자를 통일한다. 사고예보/혼잡예보/현재교통 중 한 항목만 면색으로 표시하며 점·점선·중복5㎞ 격자선을 제거한다. 사고는 원본5㎞ 값을 GR4 중심 위치로 연결한 표출이며 새로운 고해상도 사고예측이 아니다. 격자선은 확대 시에만 가늘게, 현재 척수 숫자는 더 확대할 때만 충돌 방지(declutter)와 함께 표시한다. 범례는 선택 항목의4단계만 한 줄로, 관할 선택은 접힌 항목으로 둔다. 상세에서 세 원천을 함께 비교한다.

현재 기본 지도는 앱의 종합 관심단계(낮음/관심/주의/경계)이다. 공식 낮음·보통이면서 현재 GR4척수14이상이면 관심을1단계 높이고, 공식 주의·경계는 낮추거나 상향 가중하지 않는다. 미래는 공식 사고단계(낮음/보통/주의/경계)로 자동 전환한다. 현재 미수신·낡음은 공식값만 사용한 셀 수를 응답에 표시하고 상세에서 알린다. 밀집도와 척수를 중복 가중하지 않으며, 조합표는 검증된 사고확률이 아닌 사용자가 합의한 관심 규칙이다. 주요 기준은 상세의 접힌 기준보기로 이동한다.
사고정보 화면의 Heatmap은 점밀도 합산 방식이므로 그대로 복제하지 않는다. 원본 GR4 면색의 경계만6px blur로 부드럽게 하고 육지를 다시 마스킹한다. 숫자는 별도 선명한 텍스트층으로 확대할 때만 표시한다. 색을 부드럽게 해도 원본값·단계·클릭 공간 포함은 변경하지 않는다.

색상은4개 고정색을 칠하지 않고0~1색상위치를 RGB 연속 보간한다. 공식 단계별 원지수 범위의 로그 위치로 같은 등급 안의 색을 구분하고, 현재는 합의한 관심단계를 유지하며 등급 안의 공식 지수 위치와 현재 척수(28척 상한) 위치를 절반씩 반영한다. 이것은 색상 표시규칙이며 사고발생확률이나 별도 공식지수가 아니다. 범례는 좌측하단 한 개이며 제목·연속 그라데이션 막대·4단계 이름을 쓴다. 현재/예보 뱃지가 바뀌고 의미가 바뀔 때에만650ms제목 강조를 주며 reduced-motion에서는 애니메이션을 생략한다.

교통 격자가 없는 사고예보 해역도 빠뜨리지 않도록 원본GR4와 같은0.025도 표출망으로 확장한다. 확장 칸은 내부 display_ ID를 쓰고 공식GR4번호로 표현하지 않는다. 원본5㎞ 사고 값은 칸 중심 공간포함으로 연결하고, 정확한 클릭 위치의 원본 격자는 상세에서 다시 확인한다. 현재 교통 미수신 칸은0척으로 만들지 않는다.

사용자 최종 범례 디자인: 사고정보 .accident-grid-legend와 동일한150px폭·7px/9px여백·rgba(10,15,28,.9)배경·8px라운드·테두리·폰트·하단탭 회피 위치를 사용한다. 제목은 왼쪽 정렬이며 별도 뱃지나 밝은 배경이 없다. 의미 변경 시 제목 텍스트의650ms투명도 강조만 적용한다.

## 최우선 후속 화면 계약 — 2026-10-13

기존 본문 중 메인 슬라이더·지도 관할 브리핑 진입·가로형 숨긴 스위치는 이 항목으로 대체한다. 하단 메인 탭과 지도 출처 사이의46px 전폭 바에 `[MM.DD.(요일) HH:mm] [현재] [+3H] [+6H] [+12H]`를 놓는다. 앞칸은 버튼이 아닌output이다.11시+3H→12시→다시+3H→15시,11시+6H→15시,+12H→21시. 자정의 날짜도 갱신하고 공개 조회범위 마지막을 넘는 버튼은 사용불가. 상세시트 시간축의 독립성은 유지한다.

진입 버튼은10회째부터 해당 페이지에서 사용할 수 있다. 해상ON은 기본 현재종합/미래공식 사고색상으로 시작한다. 위험지형과 동일한 세로형 박스/토글을 사용하고, 해상 아래 아코디언 안의 사고위험 예보·실시간 교통·혼잡도 예측은 최대1개만ON한다. 선택 후 접고 표출중 뱃지를 표시한다. 현재교통은 미래관측이 아니므로 선택하면 현재로 돌아간다. 미래 이동 시 기본 공식 사고표시로 복귀한다.

경위도 공통표와 공간매칭은 입력이 바뀔 때만 다시 계산하고, 경계를 클라이언트에 반복 전달하지 않는다. 전국 화면은 같은 색 폴리곤을 최대256개의MultiPolygon으로 묶는다. 확대 화면만개별격자/현재숫자를 생성한다. 결측은 스타일도 클릭도 없으며 정상0은 유지한다. 흐림은 면색canvas완성후한번만 처리한다. 복수 지도층과 숨긴 옛 혼잡점은 생성하지 않는다. 원본 값을 합산/평균해 새로운 위험수치를 만들지 않는다.

관할별 브리핑은 이 지도에서 제거하며 후속 메인 브리핑 위치를 위한 서버 계약은 남긴다. 로컬 모의수집/렌더링 검증과 Fly운영 정상수집을 구분한다. 2026-10-13 사용자로그의JSON파싱중 V8힙한계 종료는 별도 병렬 조사이며 이 화면 수정만으로 해결되었다고 주장하지 않는다.
