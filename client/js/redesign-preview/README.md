# redesign-preview `client/js/redesign-preview/`

**디자인 미리보기.** 하단 「해양안전생활」 탭을 **3초 안에 10번** 누르면 앱 전체에 새 디자인이 덧씌워지고,
다시 10번 누르면 원래대로 돌아온다. 기능·데이터·동작은 그대로이고 **겉모습만** 바뀐다.
켜 둔 상태는 그 기기에 저장되어 앱을 다시 열어도 유지된다.

사용자가 "새 디자인이 어떻게 바뀌는지 직접 보고 판단하려고"(2026-10-19 사용자 요청 — *"내가 어떻게 구현되었는지 확인하기 위한 절차로서 말이야. 폐기할 수도 있지"*) 만든 **시험용**이다.
일반 사용자에게 알리지 않은 숨은 진입로이며, 폐기할 수 있도록 원래 코드는 하나도 고치지 않았다.

## 파일 구성
| 파일 | 역할 |
|------|------|
| `redesign_preview.js` | 스위치 — 탭 10연타 감지(사용자 클릭만 셈), `body.rd-preview` 켜고 끔, 기기 저장(`localStorage` `rd_preview_on`), 켜짐/꺼짐 안내 문구. 특보 배지 글자를 읽어 경보(`.rd-lv-alarm`)·주의보(`.rd-lv-advisory`) 꼬리표를 단다. 「해역별 특보현황」 머리줄은 발효 특보 중 가장 높은 단계(`appState.alerts[].level`)로 색을 정한다(`.rd-hdr-advisory`). |
| `redesign_preview.css` | 새 디자인 — 모든 규칙이 `body.rd-preview` 아래에만 걸린다(꺼져 있으면 영향 0). 반드시 `<head>` 의 **마지막 stylesheet** 여야 원래 규칙을 이긴다. |

## 디자인 원칙과 근거
2026-10-15·10-19 두 차례 검사(impeccable 자동 검사기 + 휴대폰 크기 실제 화면 + 기능별 설계 문서 대조)에서 나온 문제를 고친다.

| 원칙 | 원래 화면 | 미리보기 |
|------|-----------|----------|
| 빨강은 경보·위험에만 | 경보·주의보 모두 같은 빨강(`.status-badge.warning`), 공지 배지도 빨강, 머리줄 4개가 회색·청록·빨강/초록·파랑 | 경보 = 빨강 / 주의보 = 주황 / 예비 = 노랑 점선 / 특보 없음 = 차분한 청록 회색. 머리줄은 모두 같은 카드, 발효 특보가 있을 때만 그 단계 색 테두리 |
| 글자 최소 11~12px | 지도 버튼 라벨 8px, 하단 탭 약 10.9px, 정보창 아이콘 라벨 8.3px | 지도 버튼 11px 두 줄, 하단 탭 12px, 정보창 11~12px |

| 꾸밈 효과 걷어내기 | 사선 무늬 배경, 그라데이션 로고 글자, 계속 깜빡이는 배지·로고, 네온 빛번짐, 해역 이모지 | 단색 바탕, 단색 글자, 깜빡임·빛번짐 제거, 이모지 숨김 |
| 흐린 글자 대비 4.5:1 이상 | 톱니 `#64748b` 1.3~2.2:1, 흰 글자 대 하늘색 2.4:1 | 보조 글자 `#93a1b7` 이상만 사용(약 6:1) |

## 화면에서 찾아가는 법
하단 「해양안전생활」 탭을 3초 안에 10번 누른다 → 아래쪽에 「디자인 미리보기 켜짐」 안내.
끄려면 다시 10번. 기기 저장을 직접 지우려면 개발자 도구에서 `localStorage.removeItem('rd_preview_on')`.

## 바뀌지 않는 것(한계)
- **지도 위에 프로그램이 직접 그리는 것**(너울 해안선의 빛번짐, 지수 마커 색, 위험예측 칸 색)은 CSS 가 닿지 않아 그대로다.
- JS 가 글자 크기·색을 **인라인 style 로 박는 곳**(해구 기상 표, 태풍 패널 등)은 대부분 그대로다.
- 챗봇(`css/ai_chat.css`, 글자 크기가 전부 px)은 손대지 않았다.
- 동작·문구는 바꾸지 않았다. 예: 위험예측에서 특보 자료가 낡았을 때 「특보 없음」과 같아 보이는 것(`risk_marine.js` `activeWarns`, 사용자 결정 2026-10-16)은 그대로다 — 디자인이 아니라 동작 문제라서.

## 폐기하는 법
1. 이 폴더(`client/js/redesign-preview/`)를 지운다.
2. `client/index2.html` 에서 `redesign_preview` 가 들어간 두 줄(stylesheet `<link>`·주석 1줄, `<script>` 1줄)을 지운다.
3. `node scripts/refactor/gen_architecture.js > ARCHITECTURE.md` 로 도면을 다시 만든다.
