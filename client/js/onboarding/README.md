# 온보딩 — 관심해역 설정 (`zone_setup.js`)

앱을 처음 켠 사람이 **자기가 관심 있는 바다 구역만 골라 두는 화면**입니다.
고르고 나면 곧바로 튜토리얼(`js/tutorial/tutorial.js`)이 이어집니다.

> ⚠ 아직 일반 사용자에게는 보이지 않습니다. 튜토리얼과 같은 **숨은 진입로**로만 열립니다 —
> 화면 맨 아래 **「공지사항」 탭을 3초 안에 5번 연달아** 누르면 열립니다.
> (콘솔에서 `window.openZoneSetup()` 으로도 열 수 있습니다.)

---

## 1. 화면 순서

| 단계 | 무엇을 보여주나 | 다음으로 가는 길 |
|---|---|---|
| ① 안내 | "관심 해역을 설정해보세요 / 관심 해역만 선택하면 꼭 필요한 특보 알림만 받을 수 있어요" | [관심 해역 설정하기] → ② · [건너뛰기] → 바로 튜토리얼 |
| ② 바다 고르기 | 🌅 동해 · 🌊 서해 · 🏖️ 남해 · 🍊 제주 — 여러 개 고를 수 있음 | [확인] → ③ |
| ③ 지도에서 구역 고르기 | 고른 바다마다 한 번씩. 그 바다의 특보구역만 지도에 그려 주고, 눌러서 고른다(다시 누르면 해제) | [확인] → 다음 바다 / 마지막이면 저장 후 튜토리얼 |

②에서 바다를 두 개 골랐으면 ③이 두 번 나오고, 오른쪽 위에 `1 / 2` 처럼 진행 정도가 보입니다.

## 2. 어디에서 자료를 가져오나

| 무엇 | 어디에서 |
|---|---|
| 바다·구역 목록(44개) | `js/core/config.js` 의 `SEA_REGIONS` · `SUB_REGION_ZONES` |
| 지도에 그릴 실제 경계 | `GET /api/warn-zones` (해양종합정보 지도가 쓰는 것과 같은 자료) |
| 배경 바다지도 | `window.oceanCreateKhoaLayer('BASEMAP_RLTM3857')` — 앱의 해아름(KHOA) 지도. 없으면 OSM |
| 저장 자리 | `js/settings/settings.js` 의 `UserSettings`(브라우저 저장소 `weatherAppSettings_v1`) |

구역 이름은 자료마다 적는 법이 달라서(`동해남부 남쪽 안쪽먼바다` ↔ `동해남부남쪽안쪽먼바다`,
`인천.경기` ↔ `인천·경기`) `OceanWarnZone.normalizeZoneName` 으로 맞춥니다.
**2026-09-24 기준 API 44개와 앱 44개가 이름까지 정확히 일치함을 확인했습니다**(양쪽 차집합 0건).

## 3. 저장 규칙

고른 구역만 켜고 나머지는 끕니다. 고른 구역이 들어 있는 **중분류·대분류도 함께 켭니다** —
부모가 꺼져 있으면 자식도 화면에 안 나오기 때문입니다(`UserSettings.isVisible` 규칙).
저장한 뒤에는 설정(⚙️) 화면에서 [저장]을 눌렀을 때와 **같은 뒷정리**를 합니다:
푸시 알림 대상 갱신(`subscribeUser`) → 특보(`renderApp`) → 기상현황 → 예보 → 해역별 예측 다시 그리기.

**하나도 안 골랐으면 아무것도 바꾸지 않습니다.** [건너뛰기]도 마찬가지입니다 —
전에 설정해 둔 것이 있으면 그대로 둡니다(실제로 확인함, 아래 4번).

닫을 때는 `zone_guide_dismissed` 를 `true` 로 둡니다. `js/settings/zone_guide.js` 의
"관심 해역을 설정해보세요" 팝업과 **같은 말을 두 번 하지 않기 위해서**입니다.

## 4. 실제로 확인한 것 (2026-09-24, 배포본 + 이 파일로 교체해 시험)

기기 390×844, 터치 켬, 서비스워커 끔, 실제 서버(`seagnal-server.fly.dev`) 기준.

- 5연타 → 안내 화면 열림 · 바다 칩 4개(`🌅 동해 해역` 등) 정상
- 동해 지도에 폴리곤 12개, 제주 7개 — 그 바다 것만 들어옴
- 지도를 눌러 고르기 / 다시 눌러 해제 — 둘 다 됨(1개 → 2개 → 1개)
- 마친 뒤 저장값: 켜진 항목 8개(고른 구역 2개 + 그 중분류·대분류), 전체 55항목 기록
- [건너뛰기] · 하나도 안 고르고 마치기 — **기존 설정 그대로**(`{"서해":false}` 유지)
- 세 경로 모두 튜토리얼로 이어지고, 화면 오류 0건

## 5. 만들면서 겪은 것 (같은 함정 반복 방지)

- **지도 칸 높이를 `flex` 로 늘리면 터치가 안 먹는다.** 그림은 제대로 그려지는데
  OpenLayers 속 `.ol-viewport` 의 `height:100%` 가 0으로 풀려, 손가락이 닿는 면이 사라진다.
  → 높이를 화면 비율(`46vh`)로 못박아 부모 높이를 확정해 준다. (증상: `pointerdown` 조차 안 옴)
- **배경이 밝은 바다지도라 흰 선·흰 글자는 묻힌다.** 안 고른 구역은 어두운 선·어두운 글자로.
- **구역 이름표는 겹친다.** `declutter: true` 로 겹친 것을 숨기고, 대신 지도 아래에
  고른 구역 이름을 글로 적어 무엇을 골랐는지 확실히 보이게 했다.
