연안 위험 예측·분석 — 이번 판

  • 위험지수 상자 오른쪽 위 [기준 상세] 버튼(해상·연안 모두) — 누르면 아래에서 설명 창이 올라옴: 무엇을 나타내나 · 「평소/기준」의 뜻 · 어떻게 셌나 · 배수→위험지수 표 · 「N% 높음/낮음」 읽는 법 · 단계 말 · 넣지 않은 것 · 한계.
  • 연안: 관광지마다 3km 원을 총점 색으로 칠함(왼쪽 위 스위치로 연안·해상 따로 끄고 켬).
  • 바텀시트 제목 = 관광지 이름, 아래 줄 = 주소 · 파출소 관할 · 해수욕장 여부.
  • 슬라이더 = 3시간 간격, 3일(해상과 같은 말풍선).
  • 위험지수 상자 = 「한산하고 위험구역 없는 곳의 평범한 날보다 / 사고 가능성 약 N배」 + 사망·실종 사고 가능성 한 줄.
  • 안내 문구(특보·예비특보·특보급 가능성·떠밀림)는 위험지수 바로 아래.
  • 요소 줄 순서: 사람 혼잡 → 위험구역 → 사망사고 발생구역 → 주말 행사 → 달 → 너울 → 이안류. 해당 없는 요소는 줄을 뺌(예: 위험구역 0곳, 행사 없는 날).
  • 요소마다 두 줄 + 사망·실종 한 줄: 「○○(으)로 평소 대비 약 N배 높은 사고 발생 가능성 / 사고 종류 : … / 사망·실종 사고 : N% 높음」.
  • 이안류·너울은 「정책 점수」라고 밝힘(약 23% 높게 반영).

확인해 주실 것

위험지수(100점): 3점(평소의 8배) = 100, 그 위는 100. 연안은 요소를 더하므로 여름 주말 붐비는 해수욕장은 100에 자주 닿을 수 있습니다(예시의 갈매기해수욕장 100). 연안만 상한을 높일지(예: 4점 = 100) 정해 주세요.

사람 혼잡 단계: 관광지 집중률 12.5 / 25 / 50 경계로 1·2·3단계(설계서 U18 근거 — 집중률이 쌓이면 다시 잼).
