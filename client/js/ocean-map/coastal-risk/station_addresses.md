# 파출소 97곳 주소 — 최신 확인 목록 (2026-10-16)

> 「활동지점 안전 브리핑」의 관할 대표 위치는 **파출소 주소를 좌표로 바꿔** 쓴다(§11.6-12, 사용자: *"파출소위치는 웹에서 검색하면 각 주소가 나올거야. 그 주소로 하면될것같은데"*).
> 주소 원천 = 정리판 `local_server/config/coastal_safety/coastguard_stations.geojson` 의 `address`(각 지방해양경찰청 사무분장 규칙 [별표 1] PDF 에서 읽은 것).
> 좌표 = 운영 서버가 처음 한 번 카카오 검색(행사 위치 찾기와 같은 `coastal_events_collector.geocode`, 키 `KAKAO_REST_API_KEY`) → `data/station_briefing/locations.json` 에 저장.
> 카카오가 「일치 없음」이거나 주소를 해석할 수 없으면 **대체 위치**(그 관할에 붙은 관광지·위험구역 중심 평균, 없으면 관할 해역 상자 중심)를 쓰고 브리핑에 `location.estimated:true`(「대표 위치 추정」)를 단다.

## 확인 상태

- **이 작업트리에서는 카카오를 부르지 않았다**(외부 호출 금지). 97곳 중 실제 좌표를 얻은 곳은 **0곳** — 운영 첫 생성 때 정해진다.
- 「카카오 검색에 쓰는 주소」 = PDF 글자 깨짐을 고친 꼴(`station_briefing_inputs.normalizeAddress`).
- **2026-10-16 독립 검토(C4) 뒤 정리판 8곳을 고쳤다** — 구룡포 「호 미로」·대산 「삼길포 1로」·고창 「구시포 해변길」·광양 「항만 9로」·부산 남항 「해양새벽 시장길」·통영 「통영 해안로」(별표 PDF 줄바꿈·띄어쓰기가 도로명 가운데 들어감 — `address_lines` 의 줄 경계로 확인), 성산(「서귀포시」 빠짐), 울릉(도 이름 「강원특별자치도」 → 「경상북도」 + 「울릉순환 로」). 원문은 정리판 `address_raw`, 고친 이유는 `address_fix` 에 남겼다. **고친 주소가 실제 주소와 같은지 웹·카카오로 대조하지는 않았다** — 줄바꿈·도 소속(울릉군=경상북도, 성산읍=서귀포시)만 근거다.
- 카카오 대조 키(`coastal_events_collector.addressKey` — 시도·시군구·도로/지번): 고친 뒤 **97곳 모두 키가 만들어진다**(고치기 전 96곳 — 성산 1곳은 키 없음, 직접 셈). ⚠**「키가 만들어진다」는 「카카오 답과 일치한다」가 아니다** — 고치기 전 구룡포도 키(`구룡포읍/호/미로`)는 만들어졌지만 카카오 도로명 「호미로」의 키(`구룡포읍/호미로`)와 달라 「일치 없음」이 될 수밖에 없었다(2026-10-16 이전 이 문서의 「96곳 통과」는 이 뜻으로 읽어야 한다). 실제 일치 여부는 운영 첫 생성 때 `locations.json` 으로 정해진다.
- **웹 표본 확인(WebSearch, 3곳)**: 성산 — 「제주특별자치도 서귀포시 성산읍 성산등용로 107-10」(wiki.onul.works 한 곳, 정리판에 「서귀포시」 빠짐) · 울릉·한림 — 검색으로 주소를 찾지 못했다. **나머지 94곳은 웹에서 확인하지 않았다.**
- 울릉파출소 주소의 도 이름이 「강원특별자치도」로 적혀 있었다(울릉군은 경상북도) — 2026-10-16 정리판에서 「경상북도」로 고침(원문은 `address_raw`).
- 공식 원천 후보: 공공데이터포털 「해양경찰청 파출소·출장소 주소」 자료(data.go.kr catalog 15105156 — 검색 결과에서 이름만 봤고 내려받아 대조하지 않았다).
- 사람 확인 뒤 주소를 고치려면 정리판 `address` 를 고친다(원문은 `address_raw` 로 옮겨 둔다) — 주소나 정리된 질의(`normalizeAddress` 결과)가 바뀌면 서버가 다음 생성 때 카카오에 다시 묻는다(「일치 없음」이었던 곳도 — `ensureLocations`, 시험 `[C4]`).
- 카카오 영구 오류(키 없음·401·403)면 그 실행에서 바로 멈추고 6시간 묻지 않는다(호출 고장 3번 연속이면 30분) — 매 실행 97곳 재시도·로그 97줄을 막는다. 한 실행의 위치 찾기는 60초 상한.
